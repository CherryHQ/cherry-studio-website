# AI Office Assistant: Let AI Handle Documents, Spreadsheets and Reports

Meeting notes, weekly reports, reviewing a 40-page proposal, turning data into a spreadsheet: none of it is hard, but it all takes time. Cherry Studio's agents work directly in a folder on your computer. They read your materials, edit documents and produce Word, Excel and PowerPoint files, saved in the folder you choose.

## What it can take off your plate

| Task | What you give the agent | What you get back |
| --- | --- | --- |
| Meeting notes | Transcripts or notes in the working folder | Decisions, owners and deadlines |
| Weekly or daily reports | This week's notes | A report draft ready to send |
| Long document review | A proposal or contract to check section by section | Comments and a revised draft |
| Data cleanup | A batch of spreadsheets or data files | A tidy Excel file with charts |
| Presentations | An outline and source material | Slides or an HTML page |
| Multilingual material | A document set and a glossary | Translations with consistent terms |

## Unlike a chat window, it works on your files

In a chat window you paste content in and copy results out. A Cherry Studio agent has its own working folder: pick a local folder and it reads the files there and writes new ones, while the side panel shows what it's doing.

For example:

```
Read the meeting notes in this folder, list the decisions, owners and deadlines, and save them as action-items.md. Don't change the original files.
```

## Preview files before you send them

Word, PDF, PowerPoint, image and Excel files from an agent open in a preview panel. For Excel you can check every sheet, formula result and chart before you download it or pass it on. (See [Artifacts, citations and export](/docs/en/advanced-basic/chat/artifacts-export/).)

## Put weekly chores on a schedule

Once a weekly report works, make it a scheduled task: every Friday afternoon the agent compiles the report from your notes, or every morning it summarizes yesterday's messages. Connect a channel and the results arrive in the chat app you already use. (See [Weekly report from notes](/docs/en/advanced-basic/cases/notes-weekly-report/) and [Scheduled tasks](/docs/en/advanced-basic/automation/scheduled-heartbeat/).)

## Small tools for everyday work

- **Selection Assistant**: select text in any app to translate, summarize or polish it.
- **Quick Assistant**: a global shortcut opens a small window for a quick question.
- **Screenshot OCR**: capture part of the screen and ask about it, including tables and error messages.

## Before you start

- Give the agent its own working folder instead of pointing it at your entire Documents folder.
- Keep confirmation on for actions that delete or overwrite files.
- Have a person check contracts and financial figures.

## FAQ

### Could the agent damage my files?

The agent can only work in the folder you choose, and you can require confirmation for sensitive actions. It also helps to say "don't change the original files" in your request so it saves results as new files.

### Can it create Word and Excel files?

Yes. Agents can produce Word, Excel, PowerPoint, PDF and HTML files, and you can preview them in the app before downloading.

### Do I need a powerful computer?

No. With cloud models, your computer only runs the app and reads and writes files. You only need stronger hardware if you want local models for sensitive material.

### How is this different from the AI built into Office?

Office's AI mostly helps you write and edit inside one document. A Cherry Studio agent can work across all the files in a folder and pull information together, and you choose the model.
