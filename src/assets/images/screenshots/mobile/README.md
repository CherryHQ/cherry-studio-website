# Localized mobile screenshots

The marketing page selects `zh/` or `en/` from the active interface language. Keep matching filenames and scenes in both directories, including iPhone and iPad imagery.

These files are verbatim copies of the existing real App captures in `docs-site/content/assets/mobile/zh/` and `docs-site/content/assets/mobile/en/`. Keep language-specific text, examples, and full-size links paired when refreshing documentation and marketing assets. No screenshot content was translated or retouched.

The scenes show conversations, drawing templates, navigation, the file library, an example HTML preview, and tablet conversation/image previews. Template thumbnails and the HTML example illustrate those interfaces; they are not evidence of a completed generation task. These are representative product images, not release-specific artwork. The original capture/version provenance remains with the documentation assets and their source records.

`app-store/` retains the previous store-delivery assets separately. Do not use a shared fixed-language screenshot set on both language sites.
