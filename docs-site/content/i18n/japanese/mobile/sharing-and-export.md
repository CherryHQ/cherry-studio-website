# 共有とエクスポート

1 つの回答を共有したり、複数のやり取りを画像、Web ドキュメント、または編集可能なテキストに変換したりできます。コンテンツを選択し、プレビューを確認して、宛先を選択します。

## 選択したメッセージを共有する

1. 回答の共有アクションまたはメッセージの共有メニューを使用します。
2. 選択ページでメッセージを選択します。最初は元のメッセージが選択されます。
3. 全画面プレビューを開くことを確認します。
4. フォーマット、画像レイアウト、思考コンテンツを含めるかどうかを選択します。
5. 「共有」をタップし、システムシートで宛先を選択します。

**選択したメッセージ**のみがエクスポートされます。質問は自動的に含まれないため、状況に合わせて必要に応じて選択してください。出力は、選択順序に関係なく、会話の時系列に従います。

一度に最大 128 個のメッセージを選択します。未完了のメッセージは選択できません。選択行には短い抜粋が表示されます。エクスポートは、選択された完全なコンテンツを読み取り、選択された形式に従ってコード/イメージを表示します。

## 形式を選択してください

| フォーマット | に良い | 制限事項 |
| --- | --- | --- |
| PNG画像 | メッセージングアプリでの直接読み取り | デフォルトではページングされます。ブロックコードのプレビューには開始部分のみが表示されます |
| HTML | より豊富なレイアウト、完全なコード、拡張可能なコンテンツ | ブラウザまたは互換性のあるリーダーが必要です |
| Markdown | さらなる編集のためにソース テキスト、コード、テーブルを保持する | レンダリングは受信アプリに依存します |

長い画像のエクスポートは複数のページに分けられます。1 枚の長い画像を選ぶこともできますが、非常に長い画像は多くのメモリを使用し、受け取るアプリで開けない場合があります。その場合は、ページに分けた画像、HTML、または Markdown を選んでください。

画像/HTML エクスポートにより、ソースのプレゼンテーションが簡素化されます。詳細な引用チェックのために会話の元のソースに戻ります。画像プレビューは完全なソース アーカイブではありません。

## 選択画面にさまざまな形式が記載されているのはなぜですか?

一部のバージョンでは、複数選択は HTML および Markdown のみをサポートするという古いメッセージが残っています。現在のプレビューでは、複数のメッセージの画像もサポートされています。プレビューで実際に提供されている形式を使用してください。イメージの準備が失敗した場合は、HTML または Markdown を使用します。

## 思考とツールのアクティビティを含める

これらはデフォルトでは省略されます。 **思考コンテンツを含める** では、生のツール リクエストや診断データをエクスポートせずに、目に見える推論、中間の散文、および読みやすいツール名を追加します。

HTML ではこの内容を展開して確認できます。画像には、含める処理過程を展開した状態で出力します。不要な途中経過を共有しないよう、プレビューを確認してください。

## Markdown イメージはオフラインでも動作しますか?

ローカル/生成された PNG および JPEG イメージは Markdown ファイルに埋め込まれるため、サイズが増加する可能性があります。一部のリーダーは埋め込み画像をブロックします。受信者が表示できない場合は、HTML または画像エクスポートを使用してください。

埋め込めないローカルの GIF、WebP などは、エクスポート先で「画像を表示できない」ことを示す説明に置き換わります。ほかの添付ファイルは名前や説明だけが残る場合があり、元のファイルすべてが文書に含まれるわけではありません。必要な元ファイルは別途共有してください。

外部画像の URL はリモート リンクのままであり、自動的にオフラインで使用可能になることはありません。

## 画像のエクスポートに失敗しました

画像変換が失敗した場合、アプリは HTML を試行します。 HTML プレビューも失敗した場合は、Markdown が保持され、使用可能な形式が示されます。共有する前に形式を確認してください。

アプリをバックグラウンドにするか変換をキャンセルすると、変換は中断されます。その際、別の形式へ自動的に切り替わることはありません。長いエクスポートはアプリを前面に表示したまま行い、必要に応じて選択するメッセージを減らすか、ページに分けた画像を使用してください。

プレビューを閉じるとメッセージの選択に戻ります。システム共有シートを閉じるとチャットに戻ります。 **共有シートを開いただけでは、宛先がコンテンツを保存または送信したことは証明されません。**

## 透かしを削除する

エクスポートする前に **設定 → 一般設定 → 共有時の透かし** をオフにしてください。これはデフォルトでオンになっており、今後の会話、画像、および関連ファイルのエクスポートに影響します。既存の保存/共有ファイルは変更されません。

## ファイルライブラリとオリジナルファイル

サイドバーで **ファイル** を開いて、インポートされた添付ファイルと保存された生成/エクスポート ファイルを見つけます。サポートされている画像、テキスト、Markdown、および HTML がアプリで開きます。他の形式は、システムまたは別のアプリを通じて開くことができます。

* 画像のプレビューは、ズーム、共有、写真への保存をサポートしています。
* 大きなテキストのプレビューは部分的な場合があり、コピーでは表示されたコンテンツが使用されます。 **元のファイルの共有には、完全なオリジナルが含まれます。**
* 失敗した HTML プレビューは、ソース ビューにフォールバックするか、別の場所で開くことができます。
* 必要なファイルは削除する前に保存してください。システム共有をキャンセルしても、ライブラリに既に保存されているエクスポート ファイルは自動的に削除されません。

## HTML を画像またはスライドに変換する

完全にプレビュー可能な HTML ファイルの場合は、**画像として共有** または **PPT として共有** を選択し、変換を待ってから、システム共有を通じて保存します。

PPTX スライドには、ページの写真が含まれています。外観は維持されますが、**テキスト、表、図形を個別に編集することはできません**。さらに編集する必要がある場合は、オリジナルを保存してください。

アプリデータをアンインストールまたは消去する前に、ファイルを Cherry Studio の外または別のデバイスに保存し、開くことを確認してください。アプリ ライブラリ内のファイルのみがアプリ データとともに失われる可能性があります。

エクスポートでは、アプリ全体の復元可能なバックアップではなく、選択した作業が保存されます。設定転送の制限については、[デスクトップ インポート](desktop-sync.md) を参照してください。

## 生成されたファイルまたはプレゼンテーションを共有する

選択したチャット メッセージの代わりに保存されたファイルを共有するには、そのファイル カードを開いて [その他] メニューを使用します。 [ファイルの作成と編集](file-generation.md)を参照してください。 HTML ファイルでは、[画像として共有および PPT として共有](html-export.md) も提供されます。結果の PPT には、編集可能なテキスト オブジェクトではなく、ページ画像が含まれます。
