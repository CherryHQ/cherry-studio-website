# モデル情報と一覧の更新

「更新」にはいくつかの意味があります。モデル情報の更新では、選択したモデルが切り替わったり、アカウントに権限が付与されたり、すべての新しいモデルがリストに自動的に追加されたりすることはありません。

| 欲しいもの | どこでやるか | 何が変わるのか |
| --- | --- | --- |
| 新しいモデル名、機能、制限、または価格 | プロバイダーの **モデル** タブを開きます | アプリが使用する共有モデル情報 |
| プラットフォームが現在返すモデル | 対象プロバイダーの「モデル」タブで **同期** をタップ | 追加できるモデルと、今回の応答に含まれなかったモデルを確認し、適用する変更を選択します |
| コンピューターの既存のセットアップ | **デスクトップから同期**を選択してください | 選択されたプロバイダー構成と欠落している有効なモデル |
| アプリの新機能と修正 | 公式インストール チャネルを通じてアップデートする | アプリ自体 |

## モデル情報はいつ更新されますか？

初めて使用するとき、アプリはバックグラウンドでモデル情報をダウンロードします。モデルの選択、作成、編集では、完了するまでロードまたは再試行の状態が表示される場合があります。最初のダウンロードが失敗した後、ネットワークを確認して再試行してください。

ダウンロードした情報はデバイスに保存されます。その後の起動では、起動のたびに再度ダウンロードすることなく、その保存された情報が使用されます。 **プロバイダーの [モデル] タブを開くと**、バックグラウンドでの更新試行がトリガーされます。

**モデル情報を更新しました** は、新しいバージョンが適用され、[モデル] 画面に留まっている場合にのみ表示されます。カタログが変更されていない場合、バックグラウンド更新が失敗した場合、またはページから移動した場合は、通知が生成されない可能性があります。沈黙は必ずしも失敗を意味するわけではありません。

## オフラインでは何が起こるのでしょうか?

更新が失敗した場合でも、保存されている既存のカタログは引き続き使用できます。ダウンロードが失敗しても、モデル設定はクリアされません。情報を保存せずに初めて使用する場合も、インターネット接続が必要です。

保存された情報をオフラインで参照しても、クラウド モデルはオフラインでは使用できません。リクエストを送信するには、プロバイダーへの接続が必要です。

## 私の編集内容は上書きされますか?

リモート情報更新では、保存されたモデルのオーバーライドやカスタム モデルは書き換えられません。デフォルトに従っているフィールドは新しい情報を継承するため、デフォルトの名前、機能、または価格が変更される可能性があります。

これらの更新では、**API キー、プロバイダー アドレス、または認証設定**は変更されず、プロバイダーも有効になりません。手動で入力したトークン制限をクリアし、カタログ/アプリのデフォルトに再度従うようにする場合は、保存します。

## プロバイダーのモデルリストを取得する

1. **設定 → モデルサービス → 対象のプロバイダー → モデル**を開きます。
2. プロバイダー構成の変更を保存し、「**同期**」をタップします。
3. **追加できるモデル** と **リモートサービスから返されなかったモデル** を確認します。
4. 必要な変更を選択し、「**アップデート**」をタップします。自動的には何も選択されません。
5. 削除を適用する前に確認事項をお読みください。

リストを取得してもプロバイダーは有効になりません。失敗した結果または空の結果は既存のモデルを保持します。構成を修復するか、再試行するか、[モデルを手動で追加](model-management.md)してください。

## 「返されなかった」と表示されたモデルは、提供終了したのでしょうか？

必ずしもそうとは限りません。キー、アカウント権限、不完全なリスト API、および一時的な障害が結果に影響を与える可能性があります。

一度の応答だけでモデルが自動削除されることはありません。削除には選択と確認が必要で、会話履歴は残ります。保護されたモデルは削除されない場合があります。[モデルの削除ルール](model-management.md)を確認してください。今回の応答に含まれていなかったという理由だけで、正常に使えているモデルを一括削除しないでください。

## 同期が失敗してもチャットが機能するのはなぜですか?

モデルの検出とチャットでは、異なるリクエスト アドレスが使用されます。一部のプラットフォームはチャットをサポートしていますが、モデルリスト API を公開していません。

カスタムプロバイダー設定では、個別の **モデル一覧のリクエスト URL** が表示されます。プラットフォームがサポートしていない場合は、プラットフォームから正確なモデル ID をコピーし、手動で追加して、接続を確認します。

## 新しいモデルが存在しますが、表示されません

次のことを確認してください。

1. [モデル] タブを開いて情報を更新できるようにしました。
2. 関連するプロバイダーと同期するか、モデルを手動で追加しました。
3. あなたのアカウント/キーはそれにアクセスできます。
4. プロバイダーとモデルが有効になり、ピッカー フィルターが [すべて] に設定されます。

モデル情報、アカウント アクセス、ローカルに追加されたモデルは別のものです。アプリはモデルの接続形式もサポートしている必要があります。
