# よくある質問

## インストール直後にチャットできないのはなぜですか

Cherry Studio はクライアントであり、モデルのクレジットは含まれません。先にプロバイダーを追加し、API キーを入力し、チャット用のモデルを少なくとも 1 つ有効にしてください。

## プロバイダーを追加したのに、モデル一覧が空です

API キー・Base URL・アカウントの権限・現在のネットワークを確認してください。一部のプロバイダーは完全なモデル一覧を返さないため、モデル ID を手動で入力する必要があります。

## 画像・ツール・ファイルの機能が使えないのはなぜですか

これらの機能は、アプリのバージョン・モデル・プロバイダーの API・システム権限の組み合わせで決まります。まずモデルが対応しているかを確認し、次にエージェントのツール設定とシステムの許可を確認してください。

## Android でインストールがブロックされます

公式ページから APK を取得し直し、Android の案内に従って、使用中のブラウザまたはファイルマネージャーに不明なアプリのインストールを許可してください。インストール後にその権限は取り消せます。

## TestFlight のリンクが開けない、または参加できません

TestFlight がインストールされていることを確認し、Safari またはシステムのブラウザで招待を開いてください。テスト枠が上限に達している、ビルドの期限が切れている、Apple 側で一時的な問題が起きている場合は、時間をおいて再試行してください。

## モバイル版はデスクトップ版のデータを自動で同期しますか

自動同期を前提にしないでください。プロバイダーとモデルの設定はモバイル側で追加し直し、重要なチャットやファイルは、使用中のバージョンで利用できる書き出しや共有の機能で個別に保存してください。

## 問題はどのように報告すればよいですか

アプリのバージョン・端末の機種・OS のバージョン・再現手順・エラーメッセージを記録してください。スクリーンショットから API キー・個人のファイル・非公開のチャット内容を取り除いたうえで、公式サイトのフィードバック窓口をご利用ください。
