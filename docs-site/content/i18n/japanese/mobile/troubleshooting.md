# よくある質問とトラブル対処

接続の問題の場合は、添付ファイルのない短いメッセージから始めて原因を絞り込みます。

## インストール直後にチャットできないのはなぜですか?

API キーを構成し、モデルを追加し、そのプロバイダーを有効にして、エージェント用に選択します。 [デスクトップ構成をインポート](desktop-sync.md)するか、[クイック スタート](quick-start.md)に従ってください。

プラットフォームの消費者チャット サブスクリプションには、他のアプリの API クレジットが含まれていない場合があります。プラットフォームで確認してください。

## プロバイダーは存在しますが、モデル ピッカーが空です

プロバイダー/モデルの有効化、モデルの目的、およびフィルターを確認します。エントリの埋め込み/再ランキングは、通常のチャット モデルではありません。テキスト/画像ピッカーには異なるモデルが表示される場合があります。 「すべて」に戻り、最初のモデル情報のダウンロードを待ちます。

モデルが追加されていない場合は、[同期または手動で追加](model-management.md)してください。

## モデルのアップデートはキーやカスタム設定を上書きしますか?

モデル情報の更新では、プロバイダーのアドレス/キーが変更されたり、保存されたモデルのオーバーライドが書き換えられたりすることはありません。デフォルトのフィールドは新しい情報を継承できます。

**デスクトップ プロバイダーの同期では、選択したプロバイダーのアドレスとキーが置き換えられます。** [モデルの更新](model-updates.md) および [デスクトップのインポート](desktop-sync.md) を参照してください。

## 同期は失敗しますが、チャットは機能します

モデルリスト API はチャットとは別のものであり、プラットフォームは後者のみをサポートする場合があります。正確なモデル ID を手動で追加し、接続を確認します。検出に失敗しても、既存のモデルはクリアされません。

一覧に返されなかったモデルが、提供終了したとは限りません。[モデルの同期](model-updates.md)を参照してください。

## 接続エラーとは何を意味しますか?

| エラー | まず確認してください |
| --- | --- |
| 401 / 不正 | 完全、有効、保存済み、有効化されたキー |
| 403 / 禁断 | アカウント、リージョン、モデル、または組織へのアクセス |
| 404 / 見つかりません | ベースアドレス、API、正確なモデルID、重複したリクエストパス |
| 429 / リクエストが多すぎます | レート制限とクレジット。繰り返し送信するのではなく待ってください |
| ネットワーク障害/タイムアウト | プロバイダーの到達可能性、プロキシ、およびサービスのステータス |
| コンテキスト/リクエストが大きすぎます | 添付ファイル/履歴を減らすか、適切なモデルを選択してください。構成された制限を上げるだけでは役に立ちません |

プロバイダーはさまざまなコードを使用できます。エラーの詳細とプラットフォームの説明を読んでください。 [プロバイダーのセットアップ](providers-and-models.md) を参照してください。

## 変更した設定が有効にならないのはなぜですか?

* プロバイダーのアドレス/キーおよびモデルの作成/編集には、ページの保存/追加アクションが必要です。
* 既存のエージェントの編集、グローバル モデルの選択、およびモデル リスト内の API の選択は自動的に保存されます。障害通知を探します。
* 接続チェックまたはモデルの同期の前に、プロバイダーの変更を保存します。
* グローバルなデフォルト モデルの変更では、既存のすべてのエージェントが更新されるわけではありません。

[モデル管理](model-management.md) および [エージェント編集](agents-and-tools.md) を参照してください。

## モデルを削除できないのはなぜですか?

グローバルデフォルトは、最初に **設定 → デフォルトモデル** で変更またはクリアする必要があります。エージェントが使用する別のモデルを削除するということは、そのエージェントの代替モデルを選択することを意味します。

## 画像のプレビューはできますが、送信できません

プレビューとモデル入力のサポートは異なります。ビジョン対応モデルを選択し、形式、画像数、サイズを確認してください。画像機能フラグを切り替えても、テキストのみのモデルにビジョンを追加することはできません。

スキャンされた PDF、空の文書テキスト、および大きな添付ファイルについては、[チャットとファイル](chat-and-files.md) を参照してください。

## Web 検索スイッチとプラグイン ボタンはどこにありますか?

Web 検索スイッチはエージェント エディターにあります。それを有効にし、サービスを設定し、チャットで検索をリクエストします。プラグインは、使用可能な接続が存在する場合にのみコンポーザーに表示されます。

接続されたプラグインは直接使用することも、**＋ → プラグイン** を通じて使用するプラグインを指定することもできます。 [ウェブ検索](web-search.md) および [プラグイン接続](plugins.md) を参照してください。

## プラグインの認証が待機し続ける

Cherry Studio に戻り、ステータスを確認し、アカウント/ワークスペースを確認します。認証を再度開くか、もう一度確認してください。期限切れのリクエストを再開します。組織の権限が不足している場合は、サービスで処理する必要があります。

DingTalk アクションは、追加の承認後に再度リクエストする必要があります。 WeCom リンクは、有効期限が切れる前に WeCom で開く必要があります。 [プラグイン](plugins.md)を参照してください。

## 最新の回答のみを再試行できるのはなぜですか?

再試行すると、最新の回答が置き換えられます。分岐を利用して早めに方向を変えてください。再試行/削除によって外部アクションは元に戻されません。再試行するとコストが高くなる可能性があります。 [回答アクション](chat-and-files.md) を参照してください。

## コンテキストの圧縮により私の会話は削除されますか?

目に見える歴史が残る。以前の資料はモデル用に要約されており、元の詳細が一部欠落している可能性があります。正確さが重要な場合は、重要な情報を再度指定します。 [長い会話](chat-and-files.md) を参照してください。

## エクスポートされた画像が分割され、コードが不完全になるのはなぜですか?

長い画像はデフォルトでページにエクスポートされます。単一の長いイメージのオプションが利用可能です。コード パネルには、限定されたプレビューが画像で表示されます。完全なコードの場合は、HTML または Markdown を選択します。変換に失敗すると、使用可能な形式が変更される可能性があるため、プレビューと形式ラベルを調べてください。

選択、透かし、思考コンテンツ、およびファイルについては、[共有とエクスポート](sharing-and-export.md) を参照してください。

## バックグラウンドでの生成が停止するか、通知が表示されない

**設定 → 通知** とシステム権限を確認してください。 OS は依然としてバックグラウンド作業を制限する可能性があります。再試行する前に会話/描画を検査してください。 [バックグラウンド返信](settings-and-usage.md) を参照してください。

## ペアリングするとチャット履歴は自動的に同期されますか?

いいえ。選択したプロバイダー構成と有効なモデルがインポートされ、チャットが除外され、継続的な同期ではありません。重要なコンテンツは別に保存してください。 [デスクトップインポート](desktop-sync.md) および [データ](data-privacy.md) を参照してください。

## Android がインストールをブロックするか、TestFlight が参加できません

[公式ダウンロードページ](https://cherryai.com/download?platform=mobile)をご利用ください。 Android では、ダウンロードするアプリが APK をインストールするための許可が必要な場合があります。 iPhone/iPad で招待を開く前に、TestFlight をインストールしてください。容量、ビルドの有効期限、サービスの可用性がインストールに影響する可能性があります。

[ダウンロードとインストール](installation.md)を参照してください。

## ツールが実行されない、またはファイルが保存されなかった

* モデルはテキストでのみ応答するか、承認を待つか、権限がないことを報告します。[AI にツールを使用させる](using-tools.md) でモデル、機能、接続、アクセスを確認してください。
* Android がカレンダー アプリを開くか、イベントの書き込みの結果が不確実です。[カレンダーとリマインダー](calendar-and-reminders.md) に従って、再試行する前に既存のレコードを調べてください。
* 位置情報が失敗するか、ヘルス データが空か部分的です。[位置情報とヘルス レコード](location-and-health.md) を参照してください。結果が空であっても、レコードが存在しないことは証明されません。
* ファイルが保存されていないコード ブロックを取得するか、編集しても元のファイルが変更されないままになります。[ファイルの作成と編集](file-generation.md) を参照してください。
* HTML を持っているが、PPT が必要であるか、PPT のテキストを個別に編集できません。[HTML から画像および PPT](html-export.md) を参照してください。

## 未解決の問題を報告するにはどうすればよいですか?

アプリ・端末・OS のバージョン、再現手順、エラー内容を添えて、[App リポジトリの問題報告](https://github.com/CherryHQ/cherry-studio-app/issues)から連絡してください。公開前に、API キー、認証情報を含む URL、私的な会話、ファイルの内容などを削除するか、見えないように伏せてください。
