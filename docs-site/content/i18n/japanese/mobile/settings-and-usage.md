# 設定・使用量・バックグラウンドの応答

サイドバーから [設定] を開いて、読書設定、デフォルト、およびバックグラウンド動作を変更します。

## テーマ、言語、テキストサイズ

**設定 → 一般設定**:

* ライト、ダーク、またはシステム テーマを選択します。
* アプリの言語を選択します。アプリとドキュメントの言語は個別に選択されます。
* フォント サイズを開き、そのプレビューを使用して快適なサイズを選択します。
* 今後のエクスポート用に共有ウォーターマークを有効/無効にします。

変更は直接保存されます。終了する前に、失敗した保存を再試行してください。

## デフォルトモデルと描画モデル

**設定 → デフォルトモデル**:

* **デフォルトモデル** は、新しいエージェントに最初のテキスト モデルの選択肢を提供します。
* **図面モデル** は、テキスト エージェントが使用するデフォルトの描画と画像生成ツールを提供します。

選択または選択を解除すると、すぐに保存されます。既存のエージェントは独自のモデルを保持します。エディターまたは会話ピッカーで変更してください。

リストが空の場合は、利用可能なモデルを追加し、最初にそのプロバイダーを有効にします。機能、制限、価格については、[モデル管理](model-management.md) を参照してください。

## 使用法を理解する

サイドバーからホームを開き、**AI の使用状況**を確認します。その詳細ビューでは、記録されたアクティビティが日付、モデル、またはプロバイダーごとにグループ化されます。

応答には、そのモデル、入力/出力、経過時間、コストに関する使用状況の詳細も含まれます。 **トークン** は、単語数ではなく、モデルのコンテンツの単位です。履歴、思考、繰り返しのツール呼び出しによってもトークンが消費される場合があります。

* プロバイダーが報告する料金と、設定された価格に基づく見積もりにはさまざまな情報源があります。ラベルを調べます。
* 価格が未設定の場合、一部の費用が集計されていない可能性があります。無料で使えたという意味ではありません。
* 再度応答したりツールを使用したりすると、追加のリクエストが作成される可能性があります。チャットを削除しても、クレジットは返金されず、記録された使用状況も削除されません。
* これらの数字は、プロバイダー アカウントの完全な残高や正式な請求書ではなく、このアプリによって記録された使用量を示しています。

実際の請求額と残りのクレジットについては、プロバイダー アカウントを確認してください。

## アプリをバックグラウンドにしても応答を続ける

**設定 → 通知**を開きます。

| オプション | 目的 |
| --- | --- |
| iPhone/iPad: ライブアクティビティ | アプリをバックグラウンドにした後、サポートされているロック画面またはダイナミックアイランドでタスクのステータスを表示します |
| Android: バックグラウンド応答 | 生成を継続して通知にステータスを表示しようとします |
| 返信完了通知 | アプリがバックグラウンドにあるときに返信が完了したときに通知を試みます |

進行状況の表示と完了アラートは別のオプションです。システム通知許可も必要です。有効なアプリの切り替えは、拒否されたアクセス許可をオーバーライドできません。タスク通知をタップすると、その内容に戻ります。

すでにタスクを表示している間の完了は、通常、静かに完了します。ライブ アクティビティは主にアプリをバックグラウンドにした後に表示されるため、フォアグラウンドにライブ アクティビティが表示されないことが必ずしも問題を示しているわけではありません。

## 画面をロックすると生成が中断されるのはなぜですか?

バックグラウンド サポートは、継続的な実行を保証するものではありません。バッテリー ポリシー、オペレーティング システムの制限、ネットワークの損失、プロセスの終了により、作業が停止する可能性があります。長いタスクは可能な限りフォアグラウンドに置いてください。

アプリが処理できる中断は、部分的な応答を保持し、自動的に再送信せずに中断状態を表示します。 OS がプロセスを強制終了した場合、保存されたコンテンツのみが信頼できます。最新の保存されていない部分は失われる可能性があります。会話または描画レコードを開いて結果を調べ、再試行するかどうかを決定します。

タスクは、ツールの承認のために一時停止することもできます。アプリに戻って応答します。通知が配信されない場合でも、タスクの状態はアプリで引き続き利用できます。

## プライバシーと権限

**[設定] → [プライバシー]** には、個別の匿名使用とエラーレポートのコントロールがあります。 **設定 → システム権限** は、カメラ、写真、カレンダー、その他のデバイスのアクセスを管理します。一方が他方に置き換わることはありません。

[データ、プライバシー、および権限](data-privacy.md) を参照してください。
