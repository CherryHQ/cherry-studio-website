# データ・プライバシー・権限

会話と設定は現在のデバイスに保存されます。クラウド モデルと接続されたツールは、リクエストに必要な情報を引き続き受け取ります。

## データはどこに行くのでしょうか?

| 特徴 | 関連するデータ |
| --- | --- |
| クラウドチャット/画像生成 | 選択したプロバイダーは、メッセージ、今回の応答に使用する会話履歴、画像、解析された文書コンテンツ、または描画プロンプトを受信します。 |
| 検索・Web ページの読み取り | 選択したサービスにキーワードや URL が送信され、取得した内容はモデルが回答するために使用されます |
| プラグイン/カスタムツール | 接続されたサービスは、承認されたリクエストを処理します。取得したコンテンツはモデルに提供される場合があります |
| カレンダー、リマインダー、場所 | 許可されたデバイス情報が読み取られるか、変更されます。関連する結果を回答に含めることができます |
| デスクトップインポート | 選択されたプロバイダーのアドレス、キー、およびサポートされているモデル構成をローカル ネットワーク経由で転送 |

保存期間は、各サービスのポリシーとアカウント設定によって異なります。ローカル ストレージは、クラウドでの会話を完全にオフラインにするわけではありません。

## 匿名の使用状況とエラーのレポート

初めて使用する場合、またはプライバシー ポリシーの更新では、匿名データの使用について説明した後、**同意して続行**するか、**同意しない**かを選択するよう求められます。後で **[設定] → [プライバシー**] で選択を変更します。

* **匿名の使用状況データを共有します:** には、インストール ID、アプリ/システムのバージョン、使用されているモデル、トークンの数量が含まれます。会話テキスト、ファイル、または API キーではありません。
* **匿名のエラー レポートを送信する:** は、別の設定を使用してクラッシュや障害を調査するのに役立ちます。

使用状況レポートを無効にしても、モデル プロバイダーに送信するメッセージがブロックされたり、プラグイン アクセスが取り消されたりすることはありません。これらの接続は個別に管理します。

## キーとプラグインの認証

API キーはモデルサービスへのアクセスを許可します。エージェントの指示、公開スクリーンショット、問題レポートにそれらを含めないでください。公開された場合は、プロバイダーでキーを取り消し、アプリでキーを置き換えます。

組み込みのプラグイン認証情報はデバイスの安全なストレージを使用し、デスクトップのインポートでは転送されません。カスタム MCP サーバーの静的認証ヘッダーはサーバー構成とともにローカルに保存されるため、慎重な取り扱いも必要です。

## システム権限を管理する

**設定 → システム権限**を開きます。ツールの承認とオペレーティング システムの承認は別々に表示される場合もあれば、両方が必要になる場合もあります。

| 症状 | 何を確認するか |
| --- | --- |
| 一部の写真のみが表示されます | 選択した写真へのアクセスが有効になっている可能性があります。システムの選択/許可を調整する |
| アクセスを拒否した後にプロンプトが表示されない | システム設定で Cherry Studio 権限を変更します |
| カレンダーの読み取りは機能しますが、編集は機能しません | 読み取り権限と書き込み権限を個別に確認する |
| 健康記録がない | レコードが存在し、そのデータ型が許可されていることを確認してください |
| ペアリングは機能しますが、構成を読み込めません | ローカルネットワークアクセスと[デスクトップインポート](desktop-sync.md)を確認してください |

エージェント機能スイッチは、エージェントが関連する組み込みツールを使用できるかどうかを制御します。システム権限は、アプリのデバイス データへのアクセスを制御します。プラグインとカスタム MCP ツールを個別に管理します。エージェントの機能を無効にしても、システム権限は取り消されません。システム設定を使用してアクセスを取り消します。自動ツール承認はシステム権限をバイパスしません。 Android は現在、iOS リマインダーおよび健康記録ツールを提供していません。

## 機種変更やアプリデータ削除の前に

デバイスのペアリングは、完全なバックアップや自動チャット同期ではありません。主に、会話履歴ではなく、プロバイダーの構成とモデルをインポートします。

アンインストール、アプリデータの消去、またはデバイスの変更を行う前に、[重要なメッセージとファイルをエクスポート](sharing-and-export.md)してください。これらを Cherry Studio の外または別のデバイスに保存し、開くことを確認します。コピーがアプリ内のファイルライブラリにしかない場合、アプリデータの削除とともに失われる可能性があります。イメージ、HTML、および Markdown は作業を保存しますが、すべてのアプリ設定の復元可能なバックアップではありません。

## 履歴を削除すると操作が取り消されますか?

いいえ。削除または再応答しても、カレンダーの変更、編集された外部ドキュメント、または送信されたメッセージは元に戻されず、モデル費用は返金されません。取り消しが必要な場合は、関連するサービスで実際の結果を検査してください。

## バグレポートには何を含めるべきですか?

アプリ・端末・OS のバージョン、手順、期待した結果、実際の結果、エラー内容を記載してください。公開前に、API キー、認証情報を含む URL、私的な会話、ファイルの内容などを削除するか、見えないように伏せてください。
