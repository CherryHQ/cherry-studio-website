## 端末上のデータ

アプリの設定、プロバイダーの構成、チャット履歴は主に使用中の端末に保存されます。アプリの削除、システムデータの消去、機種変更の前に、重要な内容を別途保存してください。モバイル版がデスクトップ版と自動的に同期すると考えないでください。

## プロバイダーへ送られるデータ

メッセージやファイルを送信したとき、あるいは画像を生成したとき、リクエストは設定で選んだモデルプロバイダーへ送られます。データの保持と処理の方法は、そのプロバイダーのプライバシーポリシー・アカウント設定・API 利用条件によって決まります。

## API キー

* API キーは公式アプリ内でのみ入力してください。
* スクリーンショット・ログ・チャット・問い合わせの中で、完全なキーを公開しないでください。
* 漏えいの可能性がある場合は、プロバイダーの管理画面で直ちに無効化し、新しいキーを作成してください。
* モバイル用には、個別に無効化でき、利用上限を設定したキーの利用を検討してください。

## システム権限

写真・ファイル・カメラ・カレンダー・リマインダーなどの機能には、システム権限が必要になる場合があります。アプリは関連する機能を実際に使うときに許可を求めます。権限は Android または iOS の設定でいつでも変更できます。

最小権限の原則に従ってください。使わない機能には許可を与えず、データを書き込むツールやアプリの外で動作するツールには手動確認を残してください。
