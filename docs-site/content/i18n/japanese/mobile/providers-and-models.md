# プロバイダーとモデル

プロバイダーは AI サービスを提供するプラットフォームです。モデルとは、そのプラットフォームを通じて使用する特定の AI です。同じモデルが複数のプロバイダーから入手可能であり、それぞれが独自の資格情報を持っています。

まず、**API キー** を入力し、モデルを追加して、プロバイダーを有効にします。 API キーは、アプリへのアクセスのためにプロバイダーが発行する認証情報です。 Cherry Studio にはモデル クレジットは含まれません。可用性と料金はプロバイダー アカウントによって異なります。

## 組み込みプロバイダーを追加する

1. **設定 → モデルサービス** を開き、追加ボタンをタップします。
2. プロバイダーを検索し、「**追加**」をタップします。組み込みエントリは、共通の接続設定を提供します。
3. そのプロバイダーの API キーを入力します。プロバイダーから別の指示がない限り、推奨されたアドレスと API オプションをそのままにしておきます。
4. 保存してモデルリストを取得し、必要なモデルを選択して確認します。リストが利用できない場合は、モデルを手動で追加します。
5. セットアップを完了し、モデル サービス リストでプロバイダーのスイッチを確認します。無効のままの場合はオンにして、会話でモデルを選択します。

既存のプロバイダーを再度追加するのではなく、編集します。プロバイダーを一時的に無効にして、後で再度有効にすることができます。

## カスタムプロバイダーを追加する

プラットフォームがカタログにない場合、または専用のアドレスを提供する場合は、カスタム プロバイダーを使用します。

1. **カスタムプロバイダー** を選択し、認識可能な名前を入力します。
2. プラットフォームによって文書化されている API 形式を選択します。 OpenAI、Anthropic、および Gemini は接続形式を説明します。プラットフォームがサポートしているものを選択してください。
3. サービスへの接続に使用するベース アドレスである **ベース URL** と、その API キーを入力します。
4. 表示された**リクエスト URL**を確認し、保存します。
5. モデルを取得するか、プラットフォームから正確なモデル ID を手動で追加します。プロバイダー リストに戻り、必要に応じてスイッチを有効にします。

### ベース URL にはどのアドレスが入りますか?

プロバイダーのベース アドレス (`https://api.example.com/v1` など) を使用します。ログイン/ダッシュボード ページを使用したり、`/chat/completions` で終わる完全なリクエスト URL を貼り付けたりしないでください。アプリはリクエスト パスを追加します。これを 2 回含めると、アドレスが正しくなくなります。認識された完全な URL には修正のヒントが表示されます。

一部のゲートウェイでは、API バージョンが自動的に挿入されないアドレスが必要です。プロバイダーがこれを要求する場合は、`#` (例: `https://api.example.com#`) を追加し、リクエスト URL プレビューを確認します。それ以外の場合はマーカーを外したままにしてください。

複数の API をサポートするプロバイダーは、個別のアドレスとデフォルトの API を持つことができます。デフォルトを変更すると、それに続くモデルに影響を与える可能性があります。続行する前に確認をお読みください。

## プロバイダーを編集してキーを管理する

プロバイダーの **設定** タブを開いて、その名前、アドレス、キーを編集します。 「個人」や「バックアップ」などのオプションの重要なメモは識別ラベルであり、権限は変更されません。

* エントリごとに 1 つのキーを追加します。キーは個別に編集、有効化、無効化、または削除できます。 1 つのフィールドに複数を貼り付けないでください。
* キーエディターを閉じると、ページの下書きに変更が残ります。ページの **保存** アクションをタップして、アドレスとキーを一緒に保存します。
* 少なくとも 1 つの有効なキーを有効にしておきます。すべてのキーが無効になっているプロバイダーは、通常のリクエストを行うことができません。
* 変更の破棄を求めるプロンプトは、保存されていない編集内容がまだあることを意味します。

サポートされているチャット リクエストは、応答が開始されていない限り、承認エラーまたはレート制限エラーの後に別の有効なキーを試行できます。これは、すべてのエラー、イメージ生成、モデルリスト要求をカバーするものではなく、アカウント クレジットも増加しません。

## 接続を確認してください

まず保存し、**モデルチェック** を開いてモデルを選択し、チェックを実行します。このページにはリクエストのアドレスと結果が表示されます。

成功は、プラットフォーム上のすべてのモデルではなく、その構成と選択したモデルに適用されます。接続を確認してもプロバイダーは有効になりません。プロバイダー リストでスイッチを確認してください。

## モデルとデフォルトの選択

会話モデル ピッカーは、現在のエージェントのモデルを変更します。プロバイダーが有効になっていて、モデルが使用可能である必要があります。 **すべて**、**無料**、および **画像** フィルターを検索または使用して、リストを絞り込みます。モデルが消えた場合は、**すべて** に戻ります。

ビジョンは記録された画像入力のサポートを反映します。無料は記録された価格を反映しています。実際の機能、無料許容量、割り当て量はプロバイダーによって異なります。

**設定 → デフォルトモデル** で、デフォルトと図面モデルを選択します。選択または選択を解除すると、すぐに保存されます。既存のエージェントは独自のモデルの選択を保持します。グローバルデフォルトを変更しても、すべてのエージェントが更新されるわけではありません。
