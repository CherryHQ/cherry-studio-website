# AI にツールを使ってもらう

ツールを使用すると、エージェントは情報を取得したり、Web ページを読んだり、カレンダーを確認したり、回答をファイルとして保存したりするアクションを実行できます。その後、モデルはその結果を使用して応答を継続します。ツール名を覚える必要はありません。必要な材料、タスク、結果を説明してください。

## どのツールが必要ですか?

| あなたのタスク | 準備するもの | ガイド |
| --- | --- | --- |
| Web ページを調べたり読んだりする | エージェントの Web 機能を有効にし、検索サービスと読み取りサービスを構成します。 | [Web検索とページ閲覧](web-search.md) |
| スケジュールの確認、イベントの作成、To-Do の管理 | カレンダーまたはリマインダーを有効にし、システム権限を付与します | [カレンダーとリマインダー](calendar-and-reminders.md) |
| 現在位置を取得したり、記録されたアクティビティを要約したりする | デバイスの機能を有効にして承認します。ヘルスはiOSのみです | [位置情報と健康記録](location-and-health.md) |
| チェックリスト、表、または Web ページを保存する | ツール呼び出しをサポートするテキスト モデルを選択してください | [ファイルの作成と編集](file-generation.md) |
| HTML ファイルを画像またはプレゼンテーションに変換する | 保存したHTMLファイルを開き、その共有メニューを使用します | [HTML から画像と PPT](html-export.md) |
| Feishu、Notion、およびその他のサービスのマテリアルの読み取りまたは更新 | マテリアルにアクセスできるアカウントにプラグインを接続します | [プラグインと外部ツール](plugins.md) |
| テキストエージェントに画像の生成を依頼する | 画像生成を有効にし、描画モデルを構成する | [画像生成](image-generation.md) |
| 誰かが提供するリモート ツール サービスを使用する | MCP サーバーを追加し、保存されたエージェントで有効にします | [カスタムツールセットアップ](plugins.md) |

モデルにツールを使わせるには、そのモデルがツール呼び出しに対応している必要があります。保存済みの HTML ファイルを手動で変換する場合、この条件は必要ありません。モデル編集画面で対応機能にチェックを入れるだけでは、モデル自体にない機能を追加することはできません。

## まずは小さなタスクを 1 つ試してみる

1. ツール呼び出しをサポートするテキスト モデルを選択します。
2. 現在のエージェントを編集し、その **システム** セクションで必要な機能を有効にします。ファイルの読み取りと書き込みには、個別のシステム機能スイッチはありません。
3. プラグインのアカウントを接続するか、デバイスの機能を使用するときに権限を付与します。エージェントのスイッチとシステム権限は別個の要件です。
4. 1 つの特定のタスクを依頼し、結果を検査してから続行します。

以下から始めます:

> まずスマートフォンで書き込み可能なカレンダーを一覧にし、明日の予定を読み取ってください。開始時刻順に並べ、各予定が属するカレンダー名を示してください。何も作成・変更しないでください。

結果が返ってきたら、次の例の「個人」を、結果に含まれる実際の書き込み可能なカレンダー名に置き換えてください。書き込み可能なカレンダーがない場合は、まずシステムのカレンダーアプリで設定してください。

> 先ほどリストした個人カレンダーに、明日の北京時間午後 3 時から午後 3 時 30 分までの「資料の整理」を作成します。正常に保存されたかどうかを教えてください。

個別のリクエストはターゲットを確認するのに役立ちます。対象となるアクションの前にアプリに承認を要求させるには、エージェントの承認モードも **必要なときに尋ねる** に変更します。最初に質問するという書面による指示は、その設定に代わるものではありません。

## リクエストを具体的にする

**素材の場所 → 日付またはコンテンツの範囲 → アクション → 出力形式 → 今すぐ変更するかどうか** を含めます。

* 「この Feishu ドキュメントを読んでください: [リンク]。セクション 2 のみを所有者、タスク、期限として要約します。不足している詳細には未確認としてマークを付けます。タスクはまだ作成しないでください。」
* 「添付したチェックリストを品目、数量、メモの列を含む CSV ファイルに変換します。packing-list.csv として保存します。」
* 「Amap を使用して、上海の人民広場から虹橋駅までの公共交通機関のルートを比較します。乗り換えと推定所要時間が含まれます。携帯電話の位置情報は読み取らないでください。」

1 つのタスクでファイル、Web ページ、カレンダー、プラグインを組み合わせることができますが、それぞれの機能が利用可能である必要があります。ドキュメントを読んでも、タスクを作成する権限は付与されません。現在地を取得しても、ルート計画サービスには接続されません。

## 一部のアクションのみが承認を求めるのはなぜですか?

| アクション | 必要なときに尋ねる |
| --- | --- |
| 組み込みの検索、ファイル読み取り、および許可されたデバイス データの読み取り | 通常は直接実行されます |
| 組み込みのテキストファイルの作成と編集 | 直接実行します。このモードでは、ファイルを変更するたびにプロンプトが表示されません。 |
| システムイベントとリマインダーの作成、更新、または削除 | ツールの承認が必要です |
| プラグインとカスタムツール | ツールのルールに従っており、承認が必要な場合があります |
| テキストモデルによる画像生成 | 自動承認モードを含め、常に承認が必要です |

**自動的に承認します** は対象となるアクションを承認しますが、アカウントとシステムの権限は引き続き適用されます。現在、新しいエージェントはデフォルトでこのモードになっています。 [エージェントとツール](agents-and-tools.md)を参照してください。

## タスクが完了したことをどうやって確認できますか?

ツールの操作は、応答のプロセスの詳細に表示されます。コンテンツを準備したり、承認を待ったり、システム アプリでの続行を求めたりしても、アクションが完了したことを意味するわけではありません。

* **読み取りは成功しました:** 概要に依存する前に、ソースとクエリ範囲を確認してください。結果が空であっても、必ずしもレコードが存在しないことを意味するわけではありません。
* **ファイルが作成されました:** ファイル カードを開くか、サイドバーの [ファイル] でファイルを見つけます。コード ブロックや「作成された」という文は、ファイルが保存されたことを証明するものではありません。
* **外部変更が成功しました:** ツールの結果を確認し、必要に応じてターゲットのカレンダー、ドキュメント、またはタスクを確認します。
* **一部のみ成功:** 完了したアクションを特定し、残っているアクションのみを終了します。

## 停止または失敗した場合はどうなりますか?

| あなたが見るもの | 次のステップ |
| --- | --- |
| ツール呼び出しを必要としないテキスト応答 | 読み取りまたは保存を明示的に要求します。モデル、機能スイッチ、接続を確認してください |
| 承認待ち | ターゲットとアクションを確認し、許可または拒否します。システム許可は別の手順になる場合があります |
| 権限が不十分です | システム設定またはサービスで解決してください。リクエストを言い換えるとアクセスを許可できません |
| 検索または読み取りに失敗しました | 報告されたネットワーク、リンク、またはアカウントの問題を確認し、より狭い範囲で試してください。 |
| 書き込みがタイムアウトになり、結果が不確かになりました | 重複を避けるために再試行する前にターゲット サービスを確認してください |
| Android がカレンダー アプリを開きました | そこでアクションを確認して終了します。フォームを開いても保存は確認されません |

返信を停止したり、チャットを削除したり、回答を再生成したりしても、完了した外部アクションは取り消されません。取得したマテリアルは、選択したモデルに送信することもできます。 [データ、プライバシー、および権限](data-privacy.md)を参照してください。
