# カレンダーとリマインダー

カレンダーは、開始時間と終了時間が設定されたアクティビティに適しています。リマインダーは、完了する必要がある事柄に適しています。まず既存のアイテムを確認してから、適切なアイテムを作成または更新するようにエージェントに依頼してください。

内蔵カレンダー ツールは、iOS および Android の携帯電話のシステムからアクセスできるカレンダーを使用します。組み込みリマインダーは現在、iOS のみをサポートしています。 Feishu、DingTalk、およびその他のサービスは独自の [プラグイン](plugins.md) を使用します。電話カレンダーへのアクセスを許可しても、それらのアカウントは接続されません。

## 始める前に

1. ツール呼び出しをサポートするテキスト モデルを選択します。
2. 現在のエージェントを編集し、**システム** セクションで **カレンダー** または **リマインダー** を有効にします。
3. プロンプトが表示されたら許可を与えるか、**設定 → システム権限** でのアクセスを確認します。
4. 実行前に作成、変更、削除を確認するには、エージェントの承認モードを **必要なときに尋ねる** に設定します。

読み取り権限と書き込み権限は異なる場合があります。イベントを作成できるということは、すべてのイベントを読み取るアクセス権を意味するわけではありません。読み取り専用カレンダーは、新しいイベントや更新されたイベントを受け入れることができません。

## 明日のスケジュールを確認する

特に複数のアカウントや重複した名前がある場合は、最初にカレンダーを特定します。

> 私の携帯電話で利用可能なカレンダーを一覧表示し、どれが書き込み可能であるかを教えてください。変更しないでください。

次に、範囲を指定します。

> 仕事カレンダーで明日のイベントを確認します。時間順に並べ替え、開始、終了、タイトル、場所をリストします。

各クエリは最大 90 日間をカバーし、最大 200 のイベントまたはリマインダーを返します。大規模なコレクションの場合は、週または月ごとにクエリを実行します。返される 1 つのリストにすべてのレコードが含まれるわけではありません。

## イベントを作成する

> 「個人」カレンダーに、明日の北京時間 15:00〜15:30 の予定「旅行の詳細の整理」を作成してください。場所は「自宅」、メモは「チケットと宿泊先を確認する」にしてください。

**日付、タイムゾーン、開始時刻と終了時刻、カレンダー**を指定します。北京時間や東京現地時間などの明示的なゾーンは、旅行やリモート会議に役立ちます。

保存後、エージェントにその時間範囲を再度読み取って、イベントが存在することを確認するように依頼します。結果が不確実な場合は、再試行する前にシステム カレンダーを確認してください。

### 人を招待したり、イベントを繰り返したり、事前アラートを設定したりできますか?

現在の組み込みツールは、出席者の招待、繰り返しルール、または個別の事前アラート設定を公開しません。会議タイトルが付いたイベントでは、招待状は自動的に送信されません。これらの詳細をシステム カレンダーで構成するか、関連する機能を持つ Office プラグインを使用します。

## 既存のイベントを更新または削除する

変更する前にイベントを見つけて特定します。

> 「個人」カレンダーから、明日 15:00 の「旅行の詳細の整理」を探してください。まず、その予定の現在の開始・終了時刻と場所を教えてください。

確認後:

> そのイベントを 16:00 ～ 16:30 に移動します。場所とメモは変更しないでください。

削除する前に、タイトル、日付、カレンダーも確認してください。チャットを削除しても、削除されたイベントは復元されません。

## iOS のリマインダーで ToDo を管理

| 目標 | リクエスト例 |
| --- | --- |
| リストを選択してください | 「リマインダーリストをリストアップして、どれが書き込み可能かを教えてください。」 |
| アイテムを追加する | 「『個人』リストに『小包を送る』を追加してください。期限は明日の北京時間午前9時、メモは『返送伝票を持参する』にしてください。」 |
| 未完了のアイテムを探す | 「『個人』リストで今週が期限の未完了のリマインダーを、期限順に一覧にしてください。」 |
| 日付を変更する | 「先ほど確認した『小包を送る』の期限を明日の午後2時に変更し、他の内容は変えないでください。」 |
| アイテムを完了する | 「その『小包を送る』リマインダーを完了済みにしてください。」 |
| アイテムを削除する | 「先ほど確認した『小包を送る』だけを削除してください。同じ名前のほかの項目は削除しないでください。」 |

項目を完了すると、その項目は変更されたステータスで保持されます。削除すると削除されます。ツールでは、開始日、期限、メモを設定できます。時間指定の通知が必要な場合は、システムのリマインダー アプリでアラート設定と通知権限を確認してください。

**リマインダーに書かれた位置はメモであり、到着によってトリガーされるアラートではありません。** システム アプリで複雑な繰り返しや位置トリガーを設定します。日付でフィルターされた結果がリスト全体であるとは限りません。そこにも日付のないアイテムをチェックしてください。

## Android がシステム カレンダーを開くのはなぜですか?

一部の Android デバイスが操作を直接完了できない場合、アプリはシステム カレンダー ページを開くことがあります。

* **作成フォーム:** 日付と内容を確認し、目的のカレンダーを選択し、手動で保存します。
* **既存のイベント ページ:** 現在の値を検査し、残りの変更を手動で適用します。ご希望の変更内容が反映されない場合がございます。

そのページを開いても、それを保存したかどうかは Cherry Studio にわかりません。書き込みがタイムアウトした場合、または書き込みの結果が不確実な場合は、書き込みがすでに完了している可能性があります。別のイベントを作成する前にカレンダーを確認してください。

## カレンダーまたはアイテムがありません

まず、システムのカレンダー アプリまたはリマインダー アプリにアカウントとレコードが存在することを確認します。次に、Cherry Studio 権限、日付範囲、選択したカレンダーを確認します。企業の制限、読み取り専用のサブスクリプション、または携帯電話に同期されていない素材により、アクセスが制限される場合があります。

承認動作については [AI にツールを使用させる](using-tools.md) を、システム アクセスとデータの使用については [データ、プライバシー、および権限](data-privacy.md) を参照してください。
