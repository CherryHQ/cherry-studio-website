# ファイルの作成と編集

エージェントはテキストをファイルとして保存し、プレビュー、修正、共有することができます。これは、チェックリスト、会議メモ、表データ、単純な Web ページに適しています。

## 回答をファイルとして保存する

ツール呼び出しをサポートするテキスト モデルを選択し、次のファイル名を持つ **保存されたファイル** を明示的に要求します。

> 上記の旅行に関するアドバイスを Markdown チェックリストに変えてください。それをweekend-packing-list.mdとして保存し、開くことができるファイルを提供します。

Markdown は、見出し、リスト、表のテキスト形式です。プレーン テキストの場合は、`.txt` ファイルを要求します。

生成中に表示されるテキストは、既に保存されているファイルではなく、準備中の内容です。完了するまで待ってから、結果のファイル カードを開きます。サイドバーの **ファイル** の下にもあります。

回答にコード ブロックのみが含まれている場合は、「この内容を回答に表示するだけでなく、実際のファイルとして保存してください。」とフォローアップします。

## どの形式を選択すればよいですか?

| 望ましい結果 | フォーマット | 例 |
| --- | --- | --- |
| プレーンテキスト | TXT | 「call-notes.txt という名前で保存します。」 |
| 見出し、リスト、表のある記事 | Markdown | 「meeting-notes.md という名前で保存します。」 |
| スプレッドシート アプリのデータ | CSV | 「品目、数量、メモの列を使用し、shopping-list.csv として保存します。」 |
| デザインされたページまたはプレゼンテーション | HTML | 「project-overview.html という名前のスタンドアロン HTML ファイルを作成します。」 |

内蔵のファイル書き込みツールは、テキストをファイルあたり最大 1 MB まで保存します。 **ファイルに `.docx`、`.xlsx`、または `.pptx` という名前を付けても、そのファイルは正規の Office ドキュメントにはなりません。** CSV はスプレッドシート アプリで開きますが、ワークブック シート、スタイル、グラフは含まれません。

PPT が必要な場合は HTML のプレゼンテーションを作成し、[HTML を画像や PPT に変換する](html-export.md)手順を利用してください。接続したプラグインに別の文書作成機能がある場合は、そのプラグインが実際に対応する範囲で利用できます。

## 既存のファイルの読み取りと編集

1. 会話で、**＋ → ファイル** を選択し、ファイルを選択またはアップロードします。
2. 変更するもの、置き換えるもの、変更しないものを正確に指定します。
3. 修正したファイルを開いて結果を確認します。

たとえば:

> 添付された shopping-list.csv で、Umbrella の数量を 1 から 2 に変更します。他のすべての行は変更しないでください。

> 作成したmeeting-notes.mdで、「Deliver next Monday」を「Deliver next Wednesday」に置き換えます。それ以外はすべて保管してください。

テキストファイルは直接編集できます。サポートされている PDF および Office ドキュメントは、モデルが読み取るための抽出されたコンテンツを提供できますが、組み込みエディターは元のレイアウトやファイル構造を直接変更できません。代わりに、コンテンツを抽出して新しい Markdown ファイルに整理するように依頼します。添付ファイルの形式と読み取り制限については、[チャットとファイル](chat-and-files.md) を参照してください。

### 編集するとオリジナルが上書きされますか?

* アップロードされたファイルまたは以前の応答によって作成されたファイルを編集すると、`meeting-notes v2.md` などの新しいバージョンが保存され、ソースが保持されます。
* エージェントは、変更ごとに新しいバージョンを作成するのではなく、1 回の応答内で現在のドラフトを繰り返し修正し、1 つのファイルで仕上げることができます。

これは継続的な同期ではありません。 Cherry Studio でインポートされたコピーを編集しても、携帯電話またはクラウド ストレージの他の場所にあるオリジナルは更新されません。

### 置換するテキストが見つからないのはなぜですか?

編集時は、ファイル内の元の文章と一致する箇所を探します。文章がすでに変わっている、同じ文が複数ある、空白や句読点が異なると、置換する箇所を特定できない場合があります。エージェントに該当部分を読み直してもらい、より長い文や前後の文脈を指定してください。同じ内容をすべて変更したい場合に限り、「一致する箇所をすべて置換」と依頼してください。

## ファイルの一部を読み取るということは、すべてを読み取ることを意味しますか?

いいえ。大きなファイルの場合は複数回の読み取りが必要になる場合があり、ドキュメントの抽出には独自の制限があります。完全なレビューを行うには、エージェントに未読のセクションを読み進めて、ギャップがあれば指摘するよう依頼してください。抽出でソースの一部がすでに省略されている場合、それ以上の読み取りではそれを回復できません。文書を分割して再度提供してください。

読み取りツールは、この会話でアクセス可能な添付ファイルまたは生成されたファイルを使用します。携帯電話上のすべてのファイルをスキャンするわけではありません。新しい会話を続けるには、添付ファイル メニューからファイルを再度選択します。

## ファイルの検索、プレビュー、共有

サイドバーから **ファイル** を開いてタイプ別に参照し、リスト ビューとグリッド ビューを切り替えます。ファイルをタップしてプレビューします。内部プレビューのない形式は、別のシステム アプリで開くことができます。

プレビューの右上の **もっと** メニューでは、他のアプリと共有したり開いたりすることができます。テキスト ファイルもコピーできます。長いファイルが部分的にのみ表示されている場合、コピーには表示されている部分のみが含まれます。共有では完全なオリジナル ファイルが使用されます。

ファイルはこのデバイスに保存されます。共有を通じて重要なマテリアルをシステム ファイル アプリまたはその他のストレージに保存し、ローカル ファイルをクリーニングしたり Cherry Studio をアンインストールしたりする前に、それを開くことができることを確認してください。チャット メッセージのエクスポートには、別のワークフロー [共有とエクスポート](sharing-and-export.md) が使用されます。

組み込みのテキスト ファイルの読み取り、作成、編集は、**必要なときに尋ねる** モードを含め、通常は直接実行されます。 [ツールの承認](using-tools.md)を参照してください。
