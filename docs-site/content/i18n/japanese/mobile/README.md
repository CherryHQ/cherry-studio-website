# Cherry Studio モバイル版

Cherry Studio Mobile は、Android、iPhone、および iPad 用に設計された AI クライアントです。独自のモデル サービスをチャットに接続し、エージェントを構成し、モバイル デバイスから画像を生成します。

## 現在の状況

モバイル アプリは現在 **ベータ版**です:

* Androidは公式APKとして配布されています。
* iPhone および iPad ビルドは、Apple TestFlight を通じて配布されます。
* 画面と機能はすぐに変更される場合があります。デバイスにインストールされているバージョンの動作に従ってください。

[ダウンロードページのモバイルオプション](https://cherryai.com/download?platform=mobile)を開くか、最初に[ダウンロードとインストール](installation.md)をお読みください。
