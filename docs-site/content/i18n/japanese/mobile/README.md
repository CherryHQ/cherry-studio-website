# Cherry Studio モバイル版

Cherry Studio モバイル版は、Android・iPhone・iPad 向けに設計された AI クライアントです。自分のモデルサービスを接続して、モバイル端末でチャット、エージェントの設定、画像生成を行えます。

## 現在の状況

モバイル版は現在 **ベータ** 段階です。

* Android は公式 APK で配布しています。
* iPhone と iPad は Apple の TestFlight で配布しています。
* 画面と機能はバージョンごとに大きく変わる場合があります。実際の動作は、インストールしたバージョンに従ってください。

[ダウンロードページのモバイル版](https://cherryai.com/download?platform=mobile)を開くか、先に[インストールガイド](installation.md)をお読みください。

## できること

* 組み込みまたはカスタムのモデルプロバイダーを追加し、よく使うモデルを整理する。
* 会話中にモデルを切り替え、テキスト・画像・ファイルを送信する。
* 指示・モデル・利用可能なシステムツールを設定したエージェントを作成する。
* 設定済みの画像モデルで画像を生成し、プレビューする。
* Android スマートフォン・iPhone・iPad でタッチ操作に適した画面を使う。
