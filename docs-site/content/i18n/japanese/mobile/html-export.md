# HTML を画像や PPT に変換する

HTML ファイルには、デザインされたレイアウト、色、画像を含めることができます。保存した HTML ファイルを Cherry Studio で開き、画像または PPT として共有します。提案書、学習カード、短いプレゼンテーションに役立ちます。

## HTML ファイルを準備します

既存のファイルをアップロードするか、ツール呼び出しをサポートするモデルにファイルの作成を依頼します。

> 上記のプロジェクト概要を、目標、計画、次のステップの 3 ページからなるスタンドアロン HTML プレゼンテーションに変換します。 16:9 の比率、読みやすい文字を使用し、オンライン画像やフォントは使用しないでください。 project-overview.html として保存します。各ページに class="slide" を使用した独自のコンテナーを与えます。

最後の文は、ページにマークを付ける方法をモデルに指示します。自分でコードを書かなくてもコピーできます。単一の情報カードにはページ マーカーは必要ありません。

ファイルの保存が完了するまで待ってから、カードを開くか、サイドバーの **ファイル** でファイルを見つけます。チャットに HTML コード ブロックしかない場合は、まずモデルに [ファイルとして保存](file-generation.md)するように依頼します。

## 画像または PPT として共有

1. 完全な HTML ファイルを開いて、そのテキスト、画像、レイアウトを確認します。
2. 右上隅の「**もっと**」をタップします。
3. **画像として共有** または **PPT として共有** を選択します。
4. 準備、ページのキャプチャ、ファイルの書き込みを待ちます。必要に応じて、進行状況領域で **キャンセル** を使用して停止します。
5. システム共有シートで宛先を選択します。

生成された PNG または PPTX も、後で開いたり共有したりできるように **ファイル** に残ります。共有シートを閉じても、別の保存先に保存されたわけではありません。

## 形式はどのように異なりますか?

| フォーマット | こんな方に最適 | 結果 |
| --- | --- | --- |
| 画像 (PNG) | クイックビューイングおよび情報カード | 文書全体の 1 つの画像。複数のページが縦に積み重ねられる |
| PPT (PPTX) | 一度に 1 ページずつ表示する | 16:9 スライド上に配置された各ページの画像 |

**PPT のテキストとグラフはページ画像の一部であり、個別に編集可能なオブジェクトではありません。** 内容を変更するには、HTML を修正して再変換してください。受信者がオリジナルの編集可能なソースを必要とする場合は、HTML も共有します。

明示的なページ マーカーを含む HTML はページごとに変換されます。通常の長いページは 16:9 のセクションに垂直にスライスされ、段落や表を切り取ることができます。プレゼンテーションとして自動的に再設計されることはありません。これが発生した場合は、モデルに、混雑度の低い別のページを依頼してください。

アスペクト比が異なるページでも比率は維持され、白い余白が生じる場合があります。変換では幅の広いページ レイアウトが使用されるため、幅の狭い携帯電話のプレビューとは異なる場合があります。

## ウォーターマークとインタラクティブ コンテンツはどうなりますか?

変換は**設定 → 一般設定 → 共有時の透かし**に従います。有効にすると、画像または最後の PPT スライドにフッターが追加されます。この設定は、新しく生成されたファイルに影響します。後で変更しても、保存された結果は再構築されません。

変換すると、保存された HTML の新しいコピーが開きます。クリックしたボタン、展開したパネル、プレビュー中に入力したフォームはコピーされません。アニメーションとビデオは再生可能な PPT コンテンツになりません。モデルに、目的の状態を静的ページ コンテンツとして保存するように依頼します。

## 変換ができない、または失敗するのはなぜですか?

* **ファイルは HTML ではありません:** Markdown、プレーン テキスト、およびチャット コード ブロックには、これらの変換アクションがありません。
* **長いファイルの一部のみがロードされました:** 不完全な HTML は変換できません。短くするか分割します。空のコンテンツも変換できません。
* **画像またはフォントの読み込みに失敗しました:** オンライン リソースにアクセスできる必要があります。外部依存関係のないバージョンを要求します。
* **ドキュメントが長すぎます:** PPT は最大 64 ページをサポートしており、画像にはサイズ制限があります。コンテンツを減らしたり、ファイルを分割したり、1 つの長い画像の代わりに別のプレゼンテーション ページを使用したりします。
* **レイアウトが変化し続けるか、アプリがバックグラウンドに移行する:** 複雑な動的ページが失敗する可能性があります。アプリをフォアグラウンドに保ち、必要に応じて静的レイアウトを使用します。

元の HTML は、失敗またはキャンセル後も引き続き使用できます。再試行する前に、報告された原因に対処してください。重要なファイルを共有した後は、受信側アプリでページ数と内容を確認してください。
