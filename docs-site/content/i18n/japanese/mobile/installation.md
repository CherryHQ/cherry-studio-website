# ダウンロードとインストール

インストールは必ず[公式ダウンロードページのモバイル版](https://cherryai.com/download?platform=mobile)から行ってください。提供元が不明なパッケージはインストールしないでください。

## Android

現在の APK は ARM64 端末向けに提供しています。

1. ダウンロードページで **APK をダウンロード** を選びます。
2. ブラウザのダウンロード履歴またはファイルマネージャーから APK を開きます。
3. システムがインストールをブロックした場合は、表示される案内に従って、使用中のブラウザまたはファイルマネージャーに「不明なアプリのインストール」を一時的に許可します。
4. インストール画面に戻り、インストールを完了します。

インストール後は、付与した「不明なアプリのインストール」権限を解除できます。新しいバージョンが公開されたら、公式ページから APK を取得して上書きインストールしてください。更新前にリリースノートを確認することをおすすめします。

## iPhone と iPad

iOS / iPadOS 版は現在 TestFlight で配布しています。

1. App Store から Apple の **TestFlight** をインストールします。
2. モバイル版ダウンロードページで **TestFlight に参加** を選びます。
3. TestFlight で招待を承認し、**インストール** を選びます。

テスト枠とビルドの有効期限は Apple のベータ配信の仕組みで管理されています。招待を一時的に利用できない場合は、時間をおいて再試行するか、公式の配信チャンネルを確認してください。

## インストール後

アプリを初めて開いたら、[クイックスタート](quick-start.md)に進み、モデルサービスを追加して最初のメッセージを送信してください。
