# クイックスタート

次の 4 ステップで、最初のメッセージを送信できます。

## 1. プロバイダーを追加する

アプリ設定のモデルサービスを開き、組み込みプロバイダーを 1 つ選びます。互換 API を使う場合は、カスタムプロバイダーを作成して Base URL を入力します。

## 2. 認証情報を入力する

プロバイダーが発行した API キーを入力し、画面の案内に従って保存または接続テストを行います。API キーは他人に渡さず、公開されたチャット・スクリーンショット・不具合報告に貼り付けないでください。

## 3. モデルを追加する

プロバイダーからモデルを取得するか手動で追加し、少なくとも 1 つのモデルを有効にします。チャット・視覚・ツール・画像生成への対応はモデルによって異なります。

## 4. メッセージを送信する

チャット画面に戻り、既定のアシスタントを開くか新規作成し、モデルを選んで短いメッセージを送ります。返信が届けば、基本設定は完了しています。

次は[プロバイダーとモデル](providers-and-models.md)、または[チャットとファイル](chat-and-files.md)をお読みください。
