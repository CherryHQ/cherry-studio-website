# Web 検索とページの読み取り

検索により関連するページが見つかります。ページ読み取りでは、リンクからコンテンツを抽出します。彼らはさまざまなサービスを利用できます。

## 検索してみてください

1. ツール呼び出しをサポートするテキスト モデルを選択し、現在のエージェントのエディタで **ウェブ検索** を有効にします。
2. 「このプロジェクトの最近のリリースを検索してソースを含めてください」または「このリンクを読んで要点を要約してください: [URL]」と尋ねます。
3. ツールのプロセスとソースを検査します。ソースを開いて元のページを読んでください。

通常、新規インストールでは、個人キーを必要とせずに、検索用に ExaMCP を選択し、ページ読み取り用に Jina を選択します。既存のユーザーは選択内容を保持します。デフォルトのサービスは依然として接続とサービスの制限に依存します。

現在の Composer には、別個の Web 検索スイッチがありません。エージェント エディタで **ウェブ検索** を有効にし、サービスを設定して、メッセージの検索を要求します。検索したというモデルに依存するのではなく、実際のツールのアクティビティとソースを探してください。

## 検索または閲覧サービスを変更する

**設定 → ウェブ検索** を開きます:

* **検索プロバイダー:** キーワードを使用してページを検索します。
* **URL フェッチ プロバイダー:** は、指定された Web リンクのコンテンツを読み取ります。

サービスを選び、必要なキーやアドレスを入力して、メッセージを送信する前に接続確認用のボタンで接続を確認します。サービスの選択はすぐに保存され、API キーは編集を終えると保存されます。保存エラーが表示された場合は対処してください。詳細設定の選択肢や数値も、別途ページを保存する操作なしで保存されます。

通常、モデル プロバイダー キーと検索サービス キーは別個です。 Zhipu 検索は、キー構成のモデル プロバイダー設定にリンクします。他のサービスは独自のフォームを使用します。

## 詳細設定

最初はデフォルトのままにして、特定のニーズに合わせて調整します。

| 設定 | 目的 | トレードオフ |
| --- | --- | --- |
| 結果数 | 検索結果の数 | 視点が増えると、処理する材料も増えます |
| 結果の圧縮 | 検索内容が短縮されているかどうか | カットオフにより使用量が削減されます。圧縮がないからといってモデル容量が無制限になるわけではありません |
| Web ページの文字数 | 読み取ったページから使用する文字数の上限 | 上限を小さくすると、後半の詳しい内容が省略される場合があります |

ページの読み取りにも別の制限があります。長いページは部分的にしか読まれない場合があります。詳細を確認する場合は、原本を開いてください。同じフェッチを繰り返しても、次のセグメントは自動的に取得されません。

## チャットは機能しますが、検索は機能しません

チャットモデル、検索サービス、閲覧サービスは個別に接続します。確認してください:

1. モデルがツール呼び出しをサポートしており、エージェントの **ウェブ検索** スイッチが有効になっているかどうか。
2. 選択したサービスが設定チェックに合格したかどうか。
3. リクエストが明確に検索を要求し、キーワードまたはリンクを提供するかどうか。
4. ネットワーク、キー、権限、クォータ、またはページ アクセスの問題に関するツール エラー。

検索またはページ読み取りに失敗すると、その回答は新しい Web 試行の開始を停止し、可能な場合には既に取得した情報を使用します。プロバイダーをサイレントに切り替えることはありません。問題を修正し、新しいメッセージを送信して再試行してください。

## ログインしたページを読み取れないのはなぜですか?

読書サービスは独自のネットワークからリンクにアクセスし、携帯電話のブラウザのログインを継承しません。制限付きページやログイン専用ページにはアクセスできない場合があります。

Feishu または Notion リソースに [対応するプラグイン](plugins.md) を使用するか、[チャットとファイル](chat-and-files.md) を使用して承認されたエクスポートを添付します。

## データはどこに行くのでしょうか?

検索キーワードと対象 URL は、選択した検索/閲覧サービスに移動します。返されたマテリアルはモデルで使用されます。 Web 検索に属さないキーや個人情報を含めないでください。 [データとプライバシー](data-privacy.md) を参照してください。
