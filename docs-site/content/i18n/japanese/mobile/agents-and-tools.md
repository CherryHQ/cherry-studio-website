# エージェントとツール

エージェント（Agent）は、役割の指示・モデル・利用できるツールをまとめて保存した、再利用できる作業設定です。文章作成の補助、情報整理、予定に関する操作など、繰り返す作業に適しています。

## エージェントを作成する

1. エージェントを新規作成し、名前・アイコン・作業の指示を設定します。
2. その作業に適したモデルを選びます。
3. Web 検索・画像生成・システムツールは、必要な場合にだけ有効にします。
4. ツールの承認方法を確認してから保存します。

指示には、目的・出力形式・制約を明確に書いてください。API キー・パスワードなど、長期間有効な認証情報をエージェントの指示に書かないでください。

## ツールとシステム権限

カレンダーやリマインダーなどのシステムツールは、初回利用時に OS の権限を要求します。本当に必要な機能にだけ許可を与えてください。権限は後から Android または iOS の設定で確認・取り消しできます。

ツールはデータを読み取ったり、アプリの外で操作を実行したりする場合があります。重要な予定・ファイル・外部への送信内容については手動確認を残し、実行後に結果を確認してください。
