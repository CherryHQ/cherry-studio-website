# エージェントとツール

エージェントは、名前、アバター、指示、モデル、およびツール承認設定を保存します。執筆、学習、仕事用に個別のエージェントを作成し、個別のトピックについて独立した会話を開始します。

## 再利用可能なエージェントを作成する

1. エージェント リストを開いて [追加] をタップするか、会話ヘッダーのエージェント ピッカーからエージェントを作成します。
2. 名前を入力し、アバターを選択し、それがどのように機能するかを説明します。
3. そのモデルを選択します。検索、プラグイン、カレンダーのアクションには、ツール呼び出しをサポートするテキスト モデルが必要です。
4. ツールの承認を選択し、システムで必要な機能を有効にします。必要に応じて、保存後にカスタム ツールを追加します。
5. 「**保存**」をタップします。チャットピッカーから作成すると、新しい会話が開きます。管理リストから作成するとそこに戻ります。

指示の例:

> 仕事資料の整理を手伝ってください。 3 文の要約から始めて、次に実行項目をリストします。不足している所有者と期限を、でっち上げるのではなく「確認中」としてマークします。英語で答えてください。

繰り返しルールを手順に保存します。現在のタスクとドキュメントをチャットに添付します。エージェントの指示にキーやパスワードを保存しないでください。

## 編集内容を保存する必要がありますか?

**エージェントを作成するには保存が必要です。既存のエージェントを編集すると、自動的に保存されます。**

名前と指示は、入力を少し停止した後に保存されます。アバター、モデル、承認の変更はすぐに保存されます。保存に失敗すると、開いているエディターに下書きが保持され、再試行が可能になります。終了する前にエラーを解決してください。

エージェントはモデルなしで保存できますが、使用可能なモデルを選択するまで会話を開始できません。

## 承認モード

| モード | 行動 |
| --- | --- |
| 必要に応じて確認する | ツールのルールで要求されている場合にのみ質問します。一部の読み取りは直接続行できます |
| 自動承認 | システム権限、無効化されたツールの制限、およびアクセス可能なデータの制限を維持しながら、対象となる操作を承認します。 |

最初の Cherry エージェントを含む新しいエージェントは、現在、デフォルトで **自動承認** になっています。既存のエージェントは設定を維持します。承認が必要なカレンダーの変更、リマインダーの削除、または外部ツールのアクションの確認が必要な場合は、「必要に応じて確認」を選択します。

承認によって、使用できないツールが使用可能になることはありません。 **テキスト モデルによって呼び出される画像生成ツールは、プロバイダーのクレジットを消費するため、依然として毎回確認が必要です**。イメージ モデルを直接選択して [生成] を押すのは、別のワークフローです。

承認を求められたら、操作内容を確認して許可または拒否します。拒否したツールは実行されず、エージェントは手元の情報で回答する場合があります。App 内で承認しても、続けてシステムの権限確認が表示されることがあります。

## 端末で使えるシステムツール

エージェント エディターの **システム** セクションを使用して、その機能 (Web 検索、画像生成、カレンダー、リマインダー、ヘルス、位置情報) を選択します。プラットフォームとデバイスでサポートされている機能のみが表示されます。

* 編集画面から新しく作成したエージェントでは、カレンダー、リマインダー、ヘルスケア、位置情報は初期状態で無効です。必要なものを有効にしてください。既存のエージェントの設定は維持されます。
* これらのスイッチは現在のエージェントに適用されます。Web 検索を無効にすると内蔵の検索・ページ読み取りツールが使えなくなり、画像生成を無効にするとテキストチャットから内蔵の描画ツールを呼び出せなくなります。プラグインとカスタム MCP ツールは、それぞれの設定で個別に管理します。
* スイッチを有効にしても、システム権限は付与されません。要求されたらアクセスを承認し、**システム権限を管理する** を使用するか、**設定 → システム権限** を開きます。
* 既存のエージェントの変更は自動的に保存され、後続のリクエストに適用されます。すでに進行中の操作は元に戻されません。

| 能力 | 例 | 可用性 |
| --- | --- | --- |
| カレンダー | 「明日のイベントをリストアップしてください」; 「明日の午後 3 時に 30 分間の会議を設定してください」 | iOS および Android、読み取り/書き込みアクセスおよびシステム サポートの対象 |
| リマインダー | 「明日の午前9時に荷物を郵送するようリマインドして」 | iOS のリマインダー権限が必要です。Android では現在利用できません |
| 健康記録 | 「今週記録した歩数とワークアウトを要約する」 | iOS で許可したデータの種類のみ読み取れます。Android では現在利用できません |
| 現在地 | 「現在地を取得して、ルートの計画を手伝ってください」 | iOS および Android、位置情報許可付き |
| アプリファイル | 「その要約をファイルに保存して」 | 会話にアクセスできる添付ファイルと生成されたファイル |

Android の一部の日程登録・変更ではシステムのカレンダー画面が開き、そこで操作を完了する必要があります。画面が開いただけでは保存済みとは限りません。ヘルスケアの結果が空の場合、記録がないか、そのデータの読み取り権限がない可能性があります。

ツールは、すべての電話ファイルを自由に検査したり、他のアプリを乗っ取ったり、コンピューターをリモートで操作したりすることはできません。

## 他のツールはどこで設定すればよいですか?

* **ウェブ検索:** 設定で検索/ページ読み取りサービスを設定し、チャットで検索を依頼します。 [ウェブ検索](web-search.md)を参照してください。
* **プラグイン:** サイドバーで Feishu や Notion などのアカウントを接続します。接続されたプラグインは会話で使用できます。 **＋ → プラグイン** は明示的に名前を付けることができます。 [プラグイン](plugins.md)を参照してください。
* **カスタム MCP:** MCP は追加のツール サービスを接続します。 [設定] でサーバーを追加し、保存したエージェントのエディターでサーバーを有効にします。 [カスタム ツール](plugins.md) を参照してください。
* **描画:** **設定 → デフォルトモデル** で描画モデルを選択し、エージェントが描画ツールを提供できるように **画像生成** を有効にします。画像モデルを直接選択することもできます。

## 承認後にツールが使用できないままになるのはなぜですか?

モデルのツール呼び出しサポート、エージェントの機能スイッチ、接続、サーバー/ツールの有効化、およびシステム権限を確認します。プラグイン アカウントは、組織のポリシーやリソース アクセスによって制限されることもあります。

ドキュメントのリンク、日付範囲、カレンダー名など、明確なターゲットを指定します。まずはエージェントに関連項目を読んでリストアップするよう依頼し、目標が明確になったら変更をリクエストします。

実際の手順とリクエストの例については、[AI にツールを使用させる](using-tools.md)、[カレンダーとリマインダー](calendar-and-reminders.md)、[位置情報と健康記録](location-and-health.md)、および [ファイルの作成と編集](file-generation.md) を参照してください。
