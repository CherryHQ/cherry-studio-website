# パソコンから設定を取り込む

すべてのアドレスとキーを再度入力することなく、コンピューター上の Cherry Studio で既に構成されているサポートされているモデル プロバイダーを再利用します。

**これは、会話履歴やコンピュータのリモート コントロールではなく、プロバイダーの構成と有効なモデルをインポートします。** ペアリングでは継続的な自動同期は有効になりません。変更をインポートする場合は、再度実行してください。

## コンピュータを接続する

1. 両方のデバイスを自宅の Wi-Fi などの同じローカル ネットワークに接続し、Cherry Studio Desktop を実行し続けます。
2. デスクトップで**デバイスの接続**を開き、ペアリングQRコードを表示します。
3. モバイルでは、**設定 → デバイスの接続 → QRコードをスキャンします** を開きます。要求されたら、カメラとローカルネットワークのアクセス許可を許可します。
4. スキャンしてプロバイダーの選択に進みます。初回実行のオンボーディングでは、同じデスクトップ同期ルートが提供されます。

カメラが利用できない場合は、手動フィールドを使用してデスクトップからペアリング QR コンテンツを貼り付けます。通常の Web サイトのリンクではなく、ペアリング データが必要です。

## プロバイダーを選択してインポートする

ペアリングされたデバイスの詳細で **デスクトップからプロバイダーを同期** を使用します。または、モデル サービス リストのメニューで **デスクトップから同期** を選択し、コンピューターを選択します。

1. 有効なデスクトッププロバイダーが読み込まれるまで待ちます。
2. インポートするプロバイダーを選択します。
3. 選択したアドレスとキーは既存のモデルが残されたまま置き換えられるという通知をお読みください。
4. 追加、更新、スキップされたカウントを同期して確認します。
5. チャットでインポートされたモデルを選択します。オンボーディング中に、チャット モデルの選択ステップに進みます。

## 既存のモバイル設定はどうなりますか?

| アイテム | 結果 |
| --- | --- |
| 選択したプロバイダー | デスクトップ構成とキーを受け取り、モバイルで有効になります |
| 有効なデスクトップ モデルがモバイルに表示されない | 追加されました |
| 同じモデルがすでにモバイルに登場 | 既存のモバイル設定は保持されます。重複はありません |
| モバイル専用プロバイダー/モデル | 保持 |
| 無効化されたデスクトッププロバイダー/モデル | 輸入対象外 |
| チャット履歴とプラグインアカウントの付与 | 輸入されていない |

デスクトップとモバイルで異なるキーを使用する場合は、最初の行に特に注意してください。新しいモデルを追加する必要がない場合でも、プロバイダーは資格情報を置き換えることができます。

## 一部のプロバイダーが利用できないのはなぜですか?

プロバイダーの横に表示されている理由を読んでください。

* **サポートされていない認証:** デスクトップ ログインでは、モバイルで使用できるエクスポート可能なキーが提供されない可能性があります。サポートされているメソッドをモバイルで個別に設定します。
* **使用可能な API キーがない：** デスクトップ側で、使用可能な API キーが少なくとも 1 つ有効になっていることを確認してください。
* **構成を読み取れません:** モバイルを更新するか、そのエントリをスキップして他のエントリをインポートしてください。

Ollama、LM Studioなどのローカルモデルサービスは除きます。ペアリングによって、コンピューター上で実行されているモデルが携帯電話上で実行されるサービスに変わるわけではありません。

## ペアリングは成功しましたが、同期できません

ペアリングでは接続資格情報が保存されます。設定を取得するには、アクセス可能なコンピューターが必要です。デスクトップを実行したままにして、共有ローカル ネットワーク、ゲスト ネットワークの分離、ファイアウォール、およびプロキシの設定を確認します。

iPhone/iPad では、以前に拒否されていた場合は、システム設定で Cherry Studio のローカル ネットワーク許可を有効にします。アプリでペアリングの修復が必要であると表示された場合は、新しいデスクトップ QR コードをスキャンします。

## デバイスを削除すると、両方の側が取り消されるのでしょうか?

モバイル上の **デバイスを削除します** は、その電話に保存されている接続資格情報のみを削除します。デスクトップ認証も取り消すには、デスクトップのデバイス接続からモバイル デバイスを削除します。

構成のインポートは完全バックアップではありません。 [重要な会話とファイルをエクスポート](sharing-and-export.md) を個別にエクスポートします。
