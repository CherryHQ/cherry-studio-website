# チャットとファイル

## 会話を始める

チャット画面でアシスタントとモデルを選び、依頼を送信します。モデル選択を使えば、会話を離れずに設定済みのモデルを切り替えられます。

## 画像やファイルを添付する

入力欄の横にある追加ボタンから、システムの写真またはファイル選択画面で素材を選びます。添付を理解できるかどうかは、モデルが対応する入力形式とプロバイダーの API によって決まります。

送信前に次を確認してください。

* 使用中のモデルが、その画像またはファイル形式に対応している。
* モデルプロバイダーに送るべきでない情報がファイルに含まれていない。
* ファイルサイズと結果のコンテキスト長が、プロバイダーの上限を超えていない。

## 回答を扱う

回答エリアでは、コピーやシステム共有などの一般的な操作を利用できます。Markdown・コード・構造化された内容の表示は、アプリのバージョンと回答の形式によって変わります。

## 返信が届かない場合

まず短いプレーンテキストのメッセージを送ってみます。それでも失敗する場合は、モデルが有効かを確認したうえで、API キー・残高・ネットワーク・プロバイダーの稼働状況を確認してください。詳しい手順は[よくある質問](troubleshooting.md)を参照してください。
