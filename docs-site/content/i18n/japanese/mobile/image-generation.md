# 画像生成

説明、参照画像、またはテンプレートから画像を作成します。最初に画像生成モデルを構成します。画像を理解するテキスト モデルが必ずしも画像を生成するとは限りません。

## 3つの作成方法

| ワークフロー | ここから始めましょう | 結果が表示される場所 |
| --- | --- | --- |
| スタンドアロン図面 | サイドバーで**画像**を開き、右上の追加をタップしてモデルを選択します | 描画履歴 |
| チャット内の画像モデル | エージェントのイメージ生成モデルを選択します | その会話に画像が添付されている |
| テキストエージェントが使用する描画ツール | **設定 → デフォルトモデル** で描画モデルを設定し、エージェントの **画像生成** を有効にして、ツール対応のテキスト モデルに描画を依頼します。 | その会話内のツールのアクティビティと画像 |

3 番目のワークフローは、自動承認下であっても、イメージ ツールを実行する前に確認を要求します。スタンドアロン図面または直接選択したイメージ モデルの場合、[送信/生成]を押すとリクエストが送信されます。

## 説明から始める

1. イメージ生成モデルを選択します。
2. 主題、目的、スタイル、構成について説明します。
3. パラメータを開いて、サイズ、アスペクト比、カウント、またはその他の使用可能なコントロールを調整します。
4. 送信して待ち、結果をタップして拡大します。

例:

> 読書メモ用の横長の表紙画像: 木製テーブルの上に開いた本とお茶、柔らかな朝の光、温かみのある白と淡い木の色調、左側の空きスペース、テキストなし。

コントロールはモデルによって異なります。画像が大きい場合や出力数が多い場合は、時間とコストが増加する可能性があります。

## テンプレートから始める

図面テンプレートを選択し、そのプレビューを検査し、その主題やその他の利用可能な入力をカスタマイズします。テンプレートは出発点です。モデルと入力によって最終結果が決まります。

描画履歴と **生成の詳細** を再確認して、成功したプロンプトを再利用します。

## 参考画像を続けます

以下の自動参照ルールと入力保存ルールは、**スタンドアロン描画** および **直接のイメージ モデル会話**に適用されます。描画ツールを呼び出すテキスト エージェントは、代わりに会話/ツール リクエストを通じてマテリアルを選択します。

参照または編集をサポートするモデルの場合は、画像を添付して変更内容を説明します。「構図を維持し、背景を夕方に変更し、その他はすべて維持します。」

* 互換性のあるフォローアップでは、以前の単一の成功した出力を自動的に使用できます。複数の出力がある場合は、続行する出力を選択します。
* 生成の実行中に編集された入力は、結果によって置き換えられるのではなく、保持されます。
* 手動参照は自動参照を置き換えます。送信する前に添付画像をご確認ください。
* テキストから画像のみへのモデルに切り替えると、自動参照が一時停止されます。互換性のない明示的に添付されたイメージは削除するか、別のモデルを必要とします。
* 参照画像が必須のモデルでは、送信前に画像を添付してください。文字を入力しなくても使えるモードもあります。画面の案内に従ってください。

画像ビューアの編集やサイズ変更を選ぶと、選択した画像を使って作成画面を開きます。対応範囲は選択したモデルによって異なり、すべての画像モデルが任意の編集を行えるわけではありません。

## 失敗、キャンセル、繰り返しのリクエスト

失敗またはキャンセルされたフォローアップでは、可能な限り入力/参照の意図が保持されます。スタンドアロン描画では、以前の成功した結果が保持されます。キャンセルはプロバイダーが処理を停止したことを証明するものではなく、返金を保証するものでもありません。

エラーを調べます: サポートされていないモデル、互換性のない参照、クレジット、レート制限、およびタイムアウトには別の解決策が必要です。 「生成」を繰り返し押す前に、以前のタスクを確認してください。

## 保存して共有する

画像ビューアでは、写真への保存、システム共有、別のアプリで開くことができます。写真に保存するにはシステム アクセスが必要です。

今後のエクスポートを制御するには、**設定 → 一般設定 → 共有時の透かし** を使用します。チャットで作成した画像は、選択したメッセージとともにエクスポートできます。スタンドアロンの結果は図面履歴にあります。 [共有とエクスポート](sharing-and-export.md) を参照してください。
