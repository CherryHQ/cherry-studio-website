# V1 から V2 へのアップグレード

{% hint style="danger" %}
移行は片方向です：V1 のデータは V2 に移行できますが、V2 の新規データは V1 に同期されません。アップグレード前に、V1 の完全なバックアップと、アプリを完全に終了した後にコピーした V1 データディレクトリ全体を保持してください。
{% endhint %}

{% hint style="warning" %}
データを保持するための正しいパスは：**V1.9.13 → V2.0.2（データ移行を直接完了）** です。先に V2.0.0 をインストールする必要はありません。
{% endhint %}

## 現在の状況に応じた選択

| 現在の状況 | 操作 |
| --------------- | ------------------------------------ |
| まだ V1 を使用しており、データを保持したい | V1 を 1.9.13 に更新し、このページの手順に従って V2.0.2 を直接インストールします。 |
| すでに V2 を使用している | V2.0.2 に通常通りアップグレードし、現在の V2 データを継続使用してください。「再移行」をクリックしないでください。 |
| 以前に V1 の移行が失敗した、またはデータが欠落している | 現在の V2 を完全にバックアップしてから、「再移行」を使用して V1 からやり直すことができます。 |
| V1 のデータは不要 | 「無視してデフォルト値を使用」を選択し、デフォルト設定から開始できます。V1 のデータは移行されません。 |

## アップグレード前の確認事項

* V1 が 1.9.12 以上であることを確認し、最終版の 1.9.13 への更新と少なくとも一度の起動を推奨します。
* 初回移行には V2.0.2 を直接使用できます。
* カスタムデータディレクトリや外付けディスクが正常に読み書き可能であることを確認します。
* 会話、Agent、ナレッジベースのインポート、ファイル処理タスクがすべて終了していることを確認します。

{% hint style="warning" %}
移行ウィザードは現在の V1 データディレクトリを読み取り、V1 のバックアップ ZIP は読み取りません。バックアップは予期しない復旧のために使用され、元のデータディレクトリに代わって移行に参加することはできません。
{% endhint %}

## 操作手順

{% stepper %}
{% step %}
### V1 の更新とバックアップ

V1 を 1.9.13 に更新します。データバックアップページで「簡易バックアップ」をオフにし、完全なバックアップを作成します。バックアップはアプリのデータディレクトリ外に保存してください。
{% endstep %}

{% step %}
### V1 データディレクトリ全体のコピー

V1 のデータ設定でディレクトリの場所を確認し、Cherry Studio を完全に終了してからディレクトリ全体をコピーします。データベースファイルのみをコピーしないでください。
{% endstep %}

{% step %}
### カスタムディレクトリの確認

モバイルストレージ、ネットワークボリューム、またはその他のカスタム場所を使用している場合、パスがマウントされ、読み書き可能であることを確認します。パスにアクセスできない場合、デフォルトディレクトリに変更して移行を続行しないでください。
{% endstep %}

{% step %}
### V2.0.2 の初回起動

[V2 公式ダウンロード](https://cherryai.com.cn/download) から、システムとチップに適合する V2.0.2 のインストーラーを取得するか、[GitCode リリースページ](https://gitcode.com/CherryHQ/cherry-studio/releases/v2.0.2) または [GitHub リリースページ](https://github.com/CherryHQ/cherry-studio/releases/tag/v2.0.2) を使用します。V1 を完全に終了してからインストールし、起動します。
{% endstep %}

{% step %}
### 【データ移行ウィザード】の完了

ウィザードに表示されるデータ位置を確認し、「移行開始」を選択します。移行中はアプリを閉じず、データディレクトリを移動せず、外付けディスクを切断しないでください。
{% endstep %}

{% step %}
### 結果の確認と再起動

移行が完了したら、まず警告情報を展開し、「アプリ再起動」を選択します。
{% endstep %}
{% endstepper %}

## アップグレード後の確認

* 常用のモデルサービス、API Key、デフォルトモデルを確認します。
* アシスタントのグループ、プロンプト、Agent の権限、ナレッジベースのバインドを確認します。
* 常用の会話、ナレッジベース、ファイルを開き、失敗表示されているナレッジソースのみを再構築します。
* 【設定】→【ネットワーク検索】で、キーワード検索と URL 読み取りサービスを再確認します。
* サイドバーのブックマークとカスタム CSS を確認します。
* 【設定】→【データ】で、新しい V2 の完全なバックアップを作成します。

その他のエントリポイントの変更については、[【機能の違い】](v1-v2-feature-differences.md) を参照してください。

## 移行が失敗した場合のみ【再移行】を使用する

以前に V1 の移行が失敗した、またはデータが欠落している場合、V2.0.2 では【設定】→【データ】で「再移行」を選択できます。この操作はアプリを再起動し、保持されている V1 データから移行を再実行します。

{% hint style="danger" %}
「再移行」は現在の V2 データを永久に削除し、V1 と V2 のデータをマージしません。以前に V1 の移行が失敗した、またはデータが欠落していない限り、絶対にクリックしないでください。操作前に、現在の V2 の完全なバックアップを作成する必要があります。保持したい V2 の新規コンテンツは、別途エクスポートしてください。
{% endhint %}

## 移行が失敗した場合

| オプション | 使用タイミング | 注意事項 |
| ---------- | --------------- | ---------------------------------------------- |
| 【再試行】 | ディレクトリ、ディスク、または一時的なデータの問題を修正した後 | 優先的に選択してください。移行フローを終了しません。 |
| 【問題情報の保存】 | 再試行しても失敗し、サポートが必要な場合 | ファイルはローカルにのみ保存されます。パス、コンテンツ、認証情報を含む可能性があるため、Cherry Studio サポートチームにのみ提供してください。 |
| 【無視してデフォルト値を使用】 | V1 データのインポートを明確に放棄する場合 | 今回の書き込み済みの一部 V2 データをクリアし、デフォルト設定から開始します。以降、自動的に移行を促すことはありません。 |
| 【V1 を継続使用】 | 一時的に移行できず、作業を復元する必要がある場合 | V1 を再インストールし、元の V1 データディレクトリを継続使用します。 |

{% hint style="danger" %}
移行が失敗した、または「無視してデフォルト値を使用」を誤って選択した場合、データベースを自分で削除したり、繰り返し上書きインストールしたりしないでください。V1 の元のデータとバックアップを保持し、Cherry Studio サポートチームに連絡してください。
{% endhint %}

## よくある質問

<details>

<summary>V1 のバックアップ ZIP のみがある場合、直接移行できますか？</summary>

できません。まず互換性のある V1 で復元し、データが正常であることを確認してから、完全なデータディレクトリを保持し、V2 の移行を開始してください。

</details>

<details>

<summary>ナレッジベースはすべてインデックスを再構築する必要がありますか？</summary>

必要ありません。有効なインデックスは移行されます。失敗表示、埋め込みモデルの欠落、読み取り不能なソースのみを処理します。

</details>
