# V2 から V1 へのダウングレード

ダウングレードは、V2 が重要な業務を一時的に妨げている場合で、かつ利用可能な V1 データを保持している場合に適しています。V2 のデータを V1 形式に変換することはありません。

{% hint style="danger" %}
V2 で新規作成されたセッション、Agent、設定、ファイルは V1 に戻りません。V2 のバックアップも V1 にリストアできません。ダウングレード前に、最新の V2 バックアップと元の V1 バックアップまたはデータディレクトリのコピーをそれぞれ保持してください。
{% endhint %}

## 通常のダウングレード

{% stepper %}
{% step %}
### タスクの停止と V2 のバックアップ

実行中の対話、Agent、ファイル処理タスクを終了してください。【設定】→【データ】から新しい V2 の完全バックアップを作成し、アプリデータディレクトリ以外に保存してください。
{% endstep %}

{% step %}
### V1 データの存在を確認

アップグレード前に保持していた V1 データディレクトリのコピーまたは V1 バックアップを探してください。V1 バックアップのみがある場合は、互換性のある V1 でリストアする必要があり、V2 にインポートすることはできません。
{% endstep %}

{% step %}
### V1 のダウンロードとインストール

V2 を完全に終了し、[V1 公式ダウンロード](https://cherryai.com.cn/download/v1) から現在のシステムに合ったインストーラーを取得してインストールを完了してください。
{% endstep %}

{% step %}
### 元の V1 データで起動

V1 を起動し、アップグレード前の V1 データディレクトリを使用してください。V2 のデータベースや V2 バックアップで上書きしないでください。
{% endstep %}

{% step %}
### 確認後に作業を再開

よく使用するセッション、モデルサービス、ナレッジベース、ファイルを確認してください。V1 データが正常であることを確認するまで、V1 または V2 のバックアップを削除しないでください。
{% endstep %}
{% endstepper %}

{% hint style="info" %}
通常のダウングレードではデータベースの削除は不要です。V2 データを保持しておくと、後で V2 に戻りやすくなり、まだエクスポートしていない内容の誤削除も防げます。
{% endhint %}

{% hint style="danger" %}
V2 の【設定】→【データ】→【再移行】はダウングレードの入口ではありません。現在の V2 データを永久に削除し、元の V1 データから再インポートします。以前に V1 からの移行が失敗したか、データが欠落している場合を除き、クリックしないでください。
{% endhint %}

## V2 データベースを処理すべきタイミング

以下の場合のみ処理が必要です：

* 現在のすべての V2 データを明確に放棄し、V1 データのみを保持する場合；
* V1 → V2 の移行を再実行する必要がある場合。

これは通常のダウングレード手順ではありません。この操作は V2 のすべてのセッション、Agent、設定、その他のデータに影響し、特定のテスト記録のクリーンアップのみではありません。

### 安全な処理方法

1. V1 と V2 を完全に終了し、バックグラウンドタスクがないことを確認してください。
2. V1 1.9.13 の【設定】→【データ】→【アプリデータ】を開き、現在のアプリデータディレクトリに移動してください。
3. 以下の項目をデスクトップまたは他の安全な場所に移動し、直接削除しないでください：
   * `Data/cherrystudio.sqlite`
   * `Data/cherrystudio.sqlite-shm` および `Data/cherrystudio.sqlite-wal`（存在する場合）
   * `Data/Agents/.claude`
4. V1 を起動し、元の V1 データを確認してください。再移行が必要な場合は、V2 を起動して移行を完了してください。
5. V1 データが利用可能であり、V2 バックアップも見つかることを確認した後、以前に移動したファイルを削除するかどうかを決定してください。

{% hint style="danger" %}
アプリ実行中にデータベースを移動しないでください。`cherrystudio.sqlite` だけを移動して、同じディレクトリ内の `-shm` または `-wal` ファイルを見落とさないようにしてください。また、V2 データベースを V1 データベースに置き換えないでください。現在のデータディレクトリやファイルの用途を判断できない場合は、操作を停止し、Cherry Studio サポートチームに連絡してください。
{% endhint %}

## よくある質問

<details>

<summary>V2 の新しい対話は V1 に持ち帰れますか？</summary>

できません。V2 で保持したい内容をエクスポートし、V1 では元の V1 データのみを継続使用してください。

</details>

<details>

<summary>V1 をダウンロードすると V2 データが自動的に変換されますか？</summary>

されません。インストーラーはアプリのみをインストールし、データやバックアップ形式の変換は行いません。

</details>

<details>

<summary>データベースを直接削除して再試行できますか？</summary>

推奨しません。まず移動して保持し、検証を完了してから削除するかどうかを決定してください。誤って削除し、利用可能なバックアップがない場合、V2 データは復元できない可能性があります。

</details>

<details>

<summary>ダウングレード後に再び V2 に戻す場合、どのバージョンをインストールすべきですか？</summary>

以前の V2 データを継続使用する場合は、V2 を直接インストールでき、【再移行】をクリックしないでください。以前に V1 からの移行が失敗したか、データが欠落している場合は、現在の V2 を完全バックアップした後、【設定】→【データ】→【再移行】を使用できます。この操作は現在の V2 データを永久に削除し、V1 から再インポートします。

</details>
