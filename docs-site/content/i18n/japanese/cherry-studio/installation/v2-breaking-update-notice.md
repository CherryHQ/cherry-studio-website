# 破壊的変更に関するお知らせ

V2 は通常のオーバーライト更新ではありません。データ構造が変更され、アシスタント、Agent、ナレッジベース、Web 検索、ファイルなどの機能のエントリポイントと動作が調整されています。

{% hint style="danger" %}
V1 のデータは V2 への一方向移行のみ可能です。V2 で新規作成されたセッション、Agent、設定、ファイルは V1 に同期されず、V1 と V2 のバックアップは相互に復元できません。
{% endhint %}

## V2.0.2 では V1 を直接移行できます

V1 のデータを保持する必要がある場合は、**V1.9.13 → V2.0.2（データ移行を直接完了）** の手順に従ってください。V2.0.0 を経由する必要はありません。

| 現在の状況 | 対応方法 |
| --------------- | --------------------------------- |
| まだ V1 を使用しており、データを保持したい | V1 を 1.9.13 に更新し、完全なバックアップを作成した後、V2.0.2 を直接インストールします。 |
| すでに V2 を使用している | V2.0.2 に通常アップグレードし、現在の V2 データを継続して使用します。 |
| 以前の V1 移行が失敗した、またはデータが欠落している | まず現在の V2 の完全なバックアップを作成し、その後【再移行】の使用を検討してください。 |
| V1 のデータは不要 | 【無視してデフォルト値を使用】を選択できますが、V1 のデータは移行されません。 |

{% hint style="danger" %}
V2.0.2 への通常のアップグレードでは【再移行】をクリックする必要はありません。この操作は現在の V2 データを永久に削除し、元の V1 データから再インポートします。以前の V1 移行が失敗した、またはデータが欠落していない限り、絶対にクリックしないでください。
{% endhint %}

## アップグレード前に必ず完了すること

1. V1 を 1.9.13 に更新し、少なくとも一度正常に起動してください。
2. 【簡易バックアップ】をオフにし、V1 の完全なバックアップを作成します。
3. Cherry Studio を完全に終了し、V1 データディレクトリ全体をコピーします。
4. カスタムディレクトリや外部ディスクを使用している場合、パスがマウントされ、読み書き可能であることを確認してください。

移行ウィザードは現在の V1 データディレクトリを読み取り、バックアップ ZIP ファイルは読み取りません。バックアップは予期しない復旧のために使用され、元のデータディレクトリに代わって移行に参加することはできません。

## 【再移行】はデータマージではありません

V2.0.2 では【設定】→【データ】に【再移行】が追加されました。これは、以前の V1 移行の失敗やデータ欠落を修正するためにのみ使用されます。

操作前に、以下の事項の確認を求められます：

* 現在の V2 データは永久に削除され、元に戻せません。
* 元の V1 データは保持され、再起動後に再インポートされます。
* 事前に現在の V2 の完全なバックアップを作成する必要があります。

完全なバックアップを作成しても、V1 と V2 のデータが自動的にマージされるわけではありません。保持が必要な V2 の新規コンテンツは、事前に個別にエクスポートするか、完全なバックアップを保持してください。

{% hint style="danger" %}
【設定】→【データ】→【キャッシュをクリア】内の【v1 バージョンのレガシーデータ】は、【再移行】に必要な元の V1 データを削除します。移行結果が完全であることを確認し、独立したバックアップを保持する前に、この項目をクリーンアップしないでください。
{% endhint %}

## アップグレード後の重点確認事項

* モデルサービス、API Key、デフォルトモデル。Anthropic OAuth は移行されず、API Key の使用に切り替える必要があります。
* アシスタントのグループ分け、プロンプトの順序、Agent のツール権限、ナレッジベースのバインド。
* ナレッジベースの失敗ソース、Web 検索のキーワード検索と URL 読み取りサービス。
* カスタム CSS、サイドバーのお気に入り、欠落ファイル。

詳細な比較は [【機能の違い】](v1-v2-feature-differences.md) を参照してください。

## 移行失敗またはロールバックが必要な場合

* まず【再試行】を使用し、データディレクトリ、ディスク、またはデータの問題を修正してから続行してください。
* 【問題情報を保存】はローカルにのみ保存されます。ファイルにはパス、コンテンツ、認証情報が含まれる可能性があるため、Cherry Studio サポートチームにのみ提供してください。
* 【無視してデフォルト値を使用】はデフォルト設定から開始し、V1 のデータは移行されません。
* V1 への通常のロールバックにはデータベースの削除は不要です。また、V2 のバックアップを V1 に復元しないでください。

{% hint style="danger" %}
データベースを自分で削除または置換しないでください。誤操作、データディレクトリの確認不能、または再移行が必要な場合は、まずすべてのバックアップとデータディレクトリを保持し、Cherry Studio サポートチームに連絡してください。
{% endhint %}
