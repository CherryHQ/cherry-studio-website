# 生成型ミニアプリ

生成型ミニアプリは、Cherry Studio の【ミニアプリ】内で動作するローカル Web アプリです。UI と業務フローはユーザーが自由に定義でき、`window.cherry` を介して Cherry Studio に設定済みの AI モデルを呼び出すことで、汎用モデルをライティングアシスタント、情報抽出ツール、学習ツール、または専用業務アプリに変換できます。

通常の Web サイト型ミニアプリとの違いは外観ではなく、機能の源泉にあります。Web サイト型ミニアプリは単に URL を開くだけですが、生成型ミニアプリは `.miniapp` としてパッケージ化し、インストールと権限付与を経て初めて、Cherry の AI、サンドボックスデータ、ファイル、通知、ネットワーク、クリップボード機能を呼び出すことができます。

{% hint style="info" %}
Cherry Studio は実行環境、認可メカニズム、AI インターフェースを提供します。ミニアプリを自分で作成することも、AI プログラミングツールで HTML、CSS、JavaScript を生成してから、本ページの説明に従ってパッケージ化してインストールすることも可能です。
{% endhint %}

## 目標と前提条件

本ページを読み終えることで、以下が可能になります：

* 他者から提供された生成型ミニアプリのインストールと使用；
* 簡単な要件から独自の `.miniapp` パッケージを作成；
* ミニアプリから Cherry Studio の【デフォルトモデル】または【クイックモデル】を呼び出す；
* 権限、アクティビティログ、ストレージ、更新、アンインストール状態の確認。

既存のミニアプリを使用するには、信頼できる `.miniapp` ファイルまたはインストール URL の準備のみが必要です。自分で作成する場合は、Web ファイルの編集と ZIP アーカイブの作成ができる必要があります。AI 機能をテストする場合は、事前に Cherry Studio で利用可能な対話モデルを設定してください。

## 用語

| 用語 | UI 名称 | 本ページの定義 |
| ------ | ------------- | ----------------------------------------- |
| 生成型ミニアプリ | 【生成型ミニアプリ】 | UI とフローをカスタマイズし、Cherry Studio の AI 機能を呼び出せるミニアプリ |
| ローカルミニアプリ | 【ローカルミニアプリ】 | `.miniapp` パッケージでインストールされ、独立したサンドボックス内で動作するミニアプリの種類 |
| Web サイト型ミニアプリ | 【Web サイト】 | URL 経由で開かれる Web ページで、`window.cherry` 機能を備えていない |
| 権限 | 【権限】 | ミニアプリのインストール時に申請し、ユーザーが審査する機能範囲 |
| モデルスロット | 【デフォルトモデル】、【クイックモデル】 | ユーザーがそのミニアプリ用に選択する 2 つのモデル位置。ミニアプリはプロバイダー、モデル名、API キーを確認できない |

## 操作パス

既存のミニアプリを使用：`【ランチャー】→【生成ミニアプリ】→【ローカルミニアプリ】→ファイルを選択またはインストール URL を入力→権限を確認→【インストール】`

ミニアプリページからアクセスすることも可能：`【ランチャー】→【ミニアプリ】→右上の【ミニアプリを追加】→【ローカルミニアプリ】`

インストール済みミニアプリの管理：`【ミニアプリ】→対象を右クリック→【詳細を表示】`

## 操作手順

### インストールと初回使用

{% stepper %}
{% step %}
### インストール入口を開く

【ランチャー】で【生成型ミニアプリ】をクリックするか、【ミニアプリ】に入り右上の【ミニアプリを追加】をクリックします。表示されたパネルで【ローカルミニアプリ】に切り替えます。
{% endstep %}

{% step %}
### インストールソースを選択

`.miniapp` パッケージをインストール領域にドラッグ＆ドロップするか、【ファイルを選択…】をクリックします。開発者が HTTPS インストール URL を提供している場合は、URL を貼り付けて【読み込む】をクリックすることも可能です。
{% endstep %}

{% step %}
### 権限を確認

インストール確認ページには、ミニアプリ名、バージョン、説明、すべての権限が表示されます。必須権限は解除できません。オプション権限はデフォルトでチェックされていますが、インストール前に解除したり、インストール後に調整したりできます。

ミニアプリの用途と権限が一致し、ソースが信頼できる場合のみ続行してください。AI が必要なミニアプリでは、通常【AI 機能】→【対話】が表示されます。
{% endstep %}

{% step %}
### インストールして開く

【インストール】をクリックします。インストール完了後、ミニアプリは【ミニアプリ】グリッドに表示されます。アイコンをクリックして実行できます。
{% endstep %}
{% endstepper %}

### ミニアプリに AI モデルを選択

1. 【ミニアプリ】グリッドで対象のミニアプリを右クリックし、【詳細を表示】を選択します。
2. 【設定】に切り替え、【AI モデル】を探します。
3. ミニアプリの用途に応じて【デフォルトモデル】と【クイックモデル】を設定します。空欄の場合は、それぞれ Cherry Studio のグローバルデフォルトモデルとグローバルクイックモデルに従います。
4. ミニアプリを再起動し、AI 操作を一度トリガーします。利用可能なモデルがない場合、ミニアプリは AI が現在利用不可であることを通知する必要があります。

【デフォルトモデル】は長文生成、複雑な分析などの主要タスクに適しています。【クイックモデル】はタイトル提案、短文リライト、タグ抽出などの低レイテンシタスクに適しています。最終的にどのスロットを使用するかは、ミニアプリの設計によって決まります。

### 最小バージョンを作成

生成型ミニアプリは本質的に静的 Web プロジェクトです。最小構成のディレクトリには 2 つのファイルが必要です：

```
my-writer/
├── manifest.json
└── index.html
```

まず `manifest.json` を作成し、アプリ情報と `ai.chat` 権限を宣言します：

```json
{
  "id": "com.example.my-writer",
  "name": { "zh": "文章リライト", "en": "Rewrite Helper" },
  "description": "文章を入力し、Cherry Studio の AI モデルで書き換えます。",
  "version": "1.0.0",
  "entry": "index.html",
  "permissions": ["ai.chat"]
}
```

`id` には、自分が管理するリバースドメイン形式の使用を推奨します。小文字、数字、ドット、ハイフンのみを含むことができます。`com.cherrystudio.*` は公式予約範囲であり、使用しないでください。

次に `index.html` でグローバルオブジェクト `cherry` を介して AI を呼び出します。以下の例では、まず【デフォルトモデル】の利用可能性を確認し、ストリーミングテキストを逐次的に表示します：

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <link rel="stylesheet" href="/__cherry/theme.css" />
    <title>文章リライト</title>
  </head>
  <body>
    <textarea id="source" placeholder="書き換える文章を入力"></textarea>
    <button id="rewrite">書き換えを開始</button>
    <pre id="result"></pre>

    <script>
      const button = document.querySelector('#rewrite')
      const source = document.querySelector('#source')
      const result = document.querySelector('#result')

      button.addEventListener('click', async () => {
        const capability = await cherry.ai.getCapabilities({ model: 'default' })
        if (!capability.available) {
          result.textContent = '先にミニアプリの詳細で利用可能なモデルを設定してください。'
          return
        }

        result.textContent = ''
        await cherry.ai.chat(
          {
            model: 'default',
            reasoning: 'off',
            messages: [
              { role: 'system', content: 'あなたは中国語の編集者です。意味を保ちながら、より明確な表現にしてください。' },
              { role: 'user', content: source.value }
            ]
          },
          {
            callId: `rewrite-${Date.now()}`,
            onChunk: (text) => {
              result.textContent += text
            }
          }
        )
      })
    </script>
  </body>
</html>
```

`window.cherry` と `cherry` は同じホストインターフェースを指しており、SDK の導入は不要です。ミニアプリはテキストメッセージの送信のみが可能で、現在画像入力やツール呼び出しはサポートされていません。`default` または `quick` スロットの使用を指定するだけで、モデル名、プロバイダー情報、API キーは取得できません。

### パッケージ化とテスト

1. `manifest.json` がプロジェクトのルートディレクトリにあり、エントリファイルが `entry` と一致していることを確認します。
2. プロジェクトディレクトリ内で圧縮を実行します。macOS または Linux では以下を使用できます：

```bash
zip -r ../my-writer.miniapp . -x '.*' -x '__MACOSX/*'
```

Windows PowerShell では、まず ZIP を生成し、`.miniapp` 拡張子に変更します：

```powershell
Compress-Archive -Path .\* -DestinationPath ..\my-writer.zip
Rename-Item ..\my-writer.zip my-writer.miniapp
```

3. Cherry Studio の【ローカルミニアプリ】インストール領域で、生成された `my-writer.miniapp` を選択します。
4. インストールページで予想通りの権限のみが申請されていることを確認し、インストール後に開いて入力、AI 出力、エラー通知、再入場後の状態をテストします。
5. デバッグが必要な場合は、ミニアプリのツールバーにある【開発者ツール】を開き、ページエラーとサンドボックスによってブロックされたリクエストを確認します。

{% hint style="warning" %}
外側のディレクトリからプロジェクトフォルダ全体を圧縮しないでください。アーカイブのルートディレクトリから `manifest.json` が直接見えることを確認してください。Cherry Studio は 1 階層のディレクトリで囲まれたアーカイブも認識できますが、明確なルートディレクトリ構造の方がトラブルシューティングが容易です。
{% endhint %}

## 期待される結果

インストール完了後、【ミニアプリ】グリッドで新しいアイコンを確認できるはずです。開いてテキストを入力し、ボタンをクリックすると、結果領域にモデルから返されたテキストが継続的に表示されます。ミニアプリを右クリックして【詳細を表示】に入ると、申請された【AI 機能】権限、使用されたモデルスロット、最近の呼び出し記録を確認できます。

インストールは成功したが AI が利用できない場合は、まず【詳細を表示】→【設定】内のモデルを確認し、次に【権限】で【AI 機能】→【対話】が許可されているか確認してください。

## 設定説明

| 設定項目 | 製品デフォルト値 | 推奨開始点 | 役割 | 適用シナリオ | 注意事項 |
| ----- | --------------------- | ------------------------ | ----------------------- | -------------- | ----------------------- |
| インストールソース | — | 初回テストではローカル `.miniapp` ファイルを使用 | ローカルパッケージまたは HTTPS URL からのインストールを決定 | 個人テスト、チーム配布 | サードパーティ製ミニアプリは、発行者、ソースコード、権限を事前に確認 |
| AI 権限 | ミニアプリが宣言；オプション権限はインストール時にデフォルトでチェック | 機能完了に必須の権限のみ付与 | `cherry.ai.chat()` の呼び出しを許可 | すべての AI 機能 | 必須権限は個別に撤回不可；信頼できなくなった場合はアンインストール |
| デフォルトモデル | グローバルデフォルトモデルに従う | 検証済みの利用可能な対話モデルを使用 | 主要な生成と分析タスクを処理 | 長文、複雑な指示、構造化出力 | 呼び出しは対応するモデルサービスの使用量に計上される |
| クイックモデル | グローバルクイックモデルに従う | 短時間タスク用にレスポンスが速いモデルを選択 | 低レイテンシタスクを処理 | タイトル変更、補完、分類、タグ抽出 | ミニアプリが `quick` を明示的に選択した場合のみ使用 |
| 推論モード | ミニアプリが送信しない場合はオフ | 通常のリライトではまずオフ | 推論をサポートするモデルが先に推論を実行することを許可 | 複雑な分析、計画 | 切り替えをサポートしないモデルはこれを無視する |
| テーマスタイル | Cherry Studio のライト/ダークテーマに従う | `/__cherry/theme.css` を参照 | ホストが提供するカラー変数を使用 | すべてのカスタム UI | 外部 CDN リソースはサンドボックスによってブロックされるため、アプリ内にパッケージ化すべき |

### その他の呼び出し可能な機能

| 機能 | 用途 | 宣言方法 |
| --------------------- | ----------------------- | ---------------------------------- |
| `cherry.storage` | 文字列形式の設定と状態を保存する | `storage.*` または具体的なメソッド |
| `cherry.file` | ミニアプリ自身のサンドボックス内でファイルの保存、読み取り、エクスポートを行う | `file.*` または具体的なメソッド |
| `cherry.notification` | Cherry Studio を介してシステム通知を送信する | `notification.show` |
| `cherry.network` | マニフェストに宣言された HTTPS ドメインにアクセスする | `network.fetch` を使用し、`network` のドメインリストを記入する |
| `cherry.clipboard` | ミニアプリが表示され、キーボードフォーカスを得ているときにプレーンテキストの読み書きを行う | `clipboard.read`、`clipboard.write` |
| `cherry.app` | アプリのバージョン、言語、現在の権限を読み取る | 宣言不要 |

ローカルミニアプリは、`localStorage`、ブラウザの `fetch`、Cookie、ポップアップ、外部 CDN を直接使用できません。状態の保存には `cherry.storage` を使用し、ネットワーク接続には `cherry.network.fetch` を使用して、マニフェストで許可されたドメインを宣言してください。

## ユーザーケース

| シナリオ | 入力 | ミニアプリの処理 | 完了の目安 |
| ------- | ----------- | ------------------------- | -------------- |
| 執筆とリライト | 下書き、トーン、文字数要件 | 【デフォルトモデル】で本文を生成し、【クイックモデル】でタイトル候補を提示する | 元の意図を保持しつつ、異なる表現に素早く切り替えられる |
| 会議議事録の整理 | 貼り付けられた会議記録 | 結論、責任者、締切日を抽出し、固定フォーマットで出力する | 各アクションに責任者と時間フィールドがある |
| 多言語翻訳 | 原文、対象言語、用語集 | システムメッセージで用語と出力形式を固定し、翻訳結果をストリーミング表示する | 固有名詞が一致し、段落構造が保持される |
| 構造化情報の抽出 | 契約書、履歴書、フィードバックテキスト | モデルに固定フィールドで結果を返すよう要求し、ページ側で欠落項目を検証する | 必須フィールドが完全であり、異常な内容がマークされる |
| 学習練習 | ノート、問題形式、難易度 | 問題、ヒント、解説を生成し、サンドボックスデータで進捗を保存する | 再度開いた際に前回の練習から継続できる |
| 垂直ワークフロー | チームテンプレート、ビジネスルール | 入力、AI 処理、人間による確認、エクスポートを一つのインターフェースに統合する | 繰り返しタスクが同じフローで安定して完了する |

{% hint style="warning" %}
生成型ミニアプリの結果は、選択されたモデルによって生成されます。医療、法律、財務などの高リスク用途、および正式な業務に影響を与えるデータについては、適切な資格を有する者による再確認が必要です。
{% endhint %}

## よくある質問

<details>

<summary>Web ページの URL を入力しても、なぜ Cherry AI を呼び出せないのですか？</summary>

【Web サイト】は Web ページを開くことのみを担い、Web ページに `window.cherry` を注入しません。アプリを `.miniapp` パッケージとして作成し、【ローカルミニアプリ】からインストールしてください。

</details>

<details>

<summary>ミニアプリは私の API キーやモデルプロバイダーを確認できますか？</summary>

できません。ミニアプリは【デフォルトモデル】または【クイックモデル】のスロットへのリクエストのみを行います。Cherry Studio が呼び出しを代行し、モデル名、プロバイダー情報、API キーをミニアプリに公開することはありません。

</details>

<details>

<summary>インストール後、AI が利用できないと表示されるのはなぜですか？</summary>

まず【詳細を表示】→【設定】を開き、対応するモデルスロットに利用可能なモデルがあることを確認してください。次に【権限】で【AI 機能】→【対話】が許可されていることを確認してください。権限が必須権限に属しているが、そのアプリを信頼しなくなった場合は、直接アンインストールしてください。

</details>

<details>

<summary>ミニアプリがどの機能を呼び出したかを確認するにはどうすればよいですか？</summary>

【詳細を表示】→【アクティビティログ】を開きます。ここでは、AI、ネットワーク、クリップボード、ファイルエクスポートなどの外部呼び出しおよび拒否された呼び出しが記録されますが、プロンプト、モデルの応答、クリップボードの内容、ファイルの内容は記録されません。

</details>

<details>

<summary>更新、ロールバック、データ消去の違いは何ですか？</summary>

更新ではサンドボックスデータが保持され、新しい権限が追加された場合は再度確認を求められます。更新後、前のバージョンにロールバックできます。データ消去では、そのミニアプリが保存したデータとファイルが削除されますが、アプリ自体は保持されます。アンインストールでは、アプリ、認可、データがすべて削除されます。

</details>
