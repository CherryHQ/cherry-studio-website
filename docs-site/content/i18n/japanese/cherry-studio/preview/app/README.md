# ミニアプリ

【ミニアプリ】は、Webサービスやローカルにインストールされた小規模なツールを Cherry Studio 内で実行できるようにします。各AIベンダーのWeb版を開くだけでなく、カスタムの生成型ミニアプリをインストールし、認可されたインターフェースを通じて Cherry Studio に設定済みのAIモデルを呼び出すことも可能です。

### 2種類のミニアプリを区別する

| 種類 | 追加方法 | Cherry AI の呼び出し可否 | 適したシナリオ |
| ----- | ---------------------------- | -------------- | ----------------------------------- |
| Webサイト | 名前、URL、ロゴを入力 | 不可 | よく使うWebサイトを Cherry Studio に固定し、各サイト独自のログイン状態を保持 |
| ローカルミニアプリ | `.miniapp` パッケージをインストールするか、開発者から提供されたURLからインストール | 可能（インストール時に認可） | カスタムのAI執筆、要約、翻訳、情報抽出、垂直特化ワークフロー |

{% hint style="info" %}
「Cherry AI を呼び出せるカスタムミニアプリ」を作成する場合は、URL 入力だけの【Webサイト】ではなく、【ローカルミニアプリ】を使用してください。完全なチュートリアルは [生成型ミニアプリ](generative-mini-apps.md) を参照してください。
{% endhint %}

### 設定

【設定】→【ミニアプリ】で、ミニアプリについて以下の調整が可能です：

* **ミニアプリの表示 / 非表示**：ミニアプリを左右にドラッグして2つの領域に移動し、表示/非表示を制御できます
* **ミニアプリの並べ替え**：上下にドラッグしてミニアプリの順序を変更できます
* **ミニアプリ領域のフィルタリング**：選択に基づき、アクセスできないミニアプリを自動的に非表示にします
* **ミニアプリのキャッシュ数**：同時に開いているミニアプリの数がこの数を超えると、一部のミニアプリが非アクティブ状態になります

### 追加と管理

Cherry Studio のミニアプリは、以下の操作をサポートしています：

* **ラウンチパッドへの追加**：よく使うミニアプリをラウンチパッドに追加し、`+` エントリから素早く開けるようにします。【設定】→【ミニアプリ】で管理するか、ミニアプリのアイコンを右クリックして **ラウンチパッドに追加** を選択します
* **サイドバーへの追加**：よく使うミニアプリを左サイドバーに固定し、ワンクリックでアクセスできるようにします。ミニアプリのアイコンを右クリックして **サイドバーに追加** または **サイドバーから削除** を選択します
* **キープアライブ（Keep Alive）**：ミニアプリのウィンドウが切り替えられた際に即座に破棄されず、再度アクセスする際に再ログインや再読み込みが不要になります
* **Webサイトの追加**：ページの右上にある `+` をクリックし、【Webサイト】で名前、URL、ロゴを入力すると、グリッドに追加されます
* **ローカルミニアプリのインストール**：ページの右上にある `+` をクリックし、【ローカルミニアプリ】に切り替え、`.miniapp` パッケージを選択するか、開発者から提供されたインストールURLを入力します。権限を確認するとインストールが完了します
* **ローカルミニアプリの詳細表示**：ローカルミニアプリを右クリックして【詳細を表示】を選択すると、権限、AIモデル、ストレージ容量、アクティビティログ、更新を管理できます
* **削除 / 編集**：Webサイト型のミニアプリは右クリックで編集または削除できます。ローカルミニアプリは【詳細を表示】からアンインストールできます

ミニアプリを開くと、そのウィンドウにはツールバーが備わっています：**戻る**、**進む**、**更新**、**ブラウザで開く**。また、ページ内のリンクをデフォルトのウィンドウで開くか、システムブラウザで開くかを切り替えることもできます。

### ヒントとテクニック

* Webサイト型のミニアプリはサービスのWeb版を使用します。ログイン状態、Cookie、設定はすべてローカルに保存され、システムブラウザとは隔離されます
* ローカルミニアプリは独立したサンドボックス内で実行され、他のミニアプリやPC上の任意のファイルを読み取れません。認可された機能のみが呼び出せます
* ミニアプリの読み込みに失敗した場合は、右クリック → 更新、またはプロキシ設定を確認してください（[一般設定](../../../pre-basic/settings/general.md) を参照）
