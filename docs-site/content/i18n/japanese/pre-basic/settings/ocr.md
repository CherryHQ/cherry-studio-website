# OCR

OCR（Optical Character Recognition、光学文字認識）は、**画像内のテキストをコピー可能かつ AI が読み取れるテキストに変換する**機能です。以下のシナリオで利用されます。

* スクリーンショットやスキャン画像をチャットボックスにドラッグ＆ドロップして、AI にテキストの内容を理解させたい場合
* 画像形式の請求書や資料を [ナレッジベース](../../knowledge-base/knowledge-base.md) に追加し、後で検索できるようにしたい場合
* [エージェント](../../advanced-basic/agent.md) がローカルの画像を開いて分析する場合

OCR は独立した設定ページです。【設定】→【OCR】で一度認識エンジンを設定すれば、画像の文字認識を使用するすべての場所で同じ設定が適用されます。

### 認識エンジンの選択

パネル右上のドロップダウンボックスで OCR エンジンを切り替え、**選択したエンジンをデフォルトとして使用**します。組み込みエンジン：

| エンジン | 接続 / 実行方法 | 対象ユーザー |
| --- | --- | --- |
| **System OCR** | オフライン、設定不要 | システム標準の認識機能（macOS Live Text / Windows OCR）を利用。すぐに使用可能で最速 |
| **PaddleOCR** | API キーを入力（[PaddlePaddle 星河コミュニティ](https://aistudio.baidu.com/paddleocr/)）。セルフホスティングの場合は API アドレスを自分のサービスに設定。解析モデルを選択可能 | ローカルリソースを消費したくないが、Paddle の認識精度を求めている場合 |
| **ローカル PaddleOCR** | オフライン、【設定】→【ローカルモデル】でローカル OCR モデル（約 140MB）を事前にダウンロードが必要 | 中国語の認識精度が高く、完全にローカルで実行。プライバシー重視 |
| **Tesseract OCR** | オフライン、組み込み済み | クラシックなオープンソース OCR。多言語対応。フォールバックとして使用可能 |
| **Mistral** | Mistral API キー | マルチモーダル大規模モデルによる認識。複雑なレイアウトや手書き文字などに対応 |
| **Intel OV OCR** | ローカル実行（Intel OpenVINO、NPU アクセラレーション）| **Windows + Intel Core Ultra（NPU 搭載）かつ OV モデルがデプロイされている場合のみ表示**。その他のデバイスでは表示されません |

{% hint style="success" %}
どれを選べばいいか迷ったら、まず **System OCR** を試してください。ほとんどのスクリーンショットや鮮明なスキャン画像はそのまま処理でき、設定も不要です。認識精度が不十分な場合は、ローカル PaddleOCR や Mistral に切り替えてください。
{% endhint %}

System OCR を選択すると、パネルに <mark style="color:green;">macOS Live Text / Windows OCR エンジンが利用可能と検出されました</mark> と表示されます（システムがサポートしていない場合、この項目はドロップダウンに表示されません）。

{% hint style="warning" %}
* 「ローカル PaddleOCR」を選択する前に、【設定】→【ローカルモデル】で「ローカル OCR モデル」をダウンロードしてください。未ダウンロードの場合は呼び出せません。
* **Tesseract**（および Windows 上の System OCR）では、パネルの「言語」ドロップダウンで認識対象の言語を選択できます。
{% endhint %}

### ドキュメント処理との違い

OCR と [ドキュメント処理](doc-process.md) を混同されることがありますが、一言でまとめると以下の通りです。

* **OCR**：**画像 / スキャン書類** 内の文字認識（画像 → テキスト）。
* **ドキュメント処理**：**PDF / 複雑なレイアウトのドキュメント** の構造化解析（表や多カラムを含む PDF → 整ったテキスト）。

両者は独立しており、それぞれ個別に設定します。プレーンテキストの PDF、`.md`/`.txt`/`.docx` 内のテキスト段落は、どちらの処理も経らずに直接読み取られます。
