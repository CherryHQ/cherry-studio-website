# ローカルモデル

ローカルモデルは Cherry Studio に組み込まれており、**ダウンロード後すぐにオフラインで実行可能** な小型モデルです。プロバイダーの API を使用せず、API キーの入力も不要です。サイズが小さく、ご自身のコンピューター上で動作するため、「クラウドモデルを個別に設定するほどの価値がない」基本的な機能を補完するために使用されます。

`設定 → ローカルモデル` を開くと管理できます：

<figure><img src="../../../../assets/3ef4a2e692da5a39fccf7406.webp" alt=""><figcaption><p>ローカルモデル：① 2 つの組み込みローカルモデル——ローカル埋め込みモデル + ローカル OCR モデル（図はいずれも「準備完了」状態、右側の削除アイコンをクリックして削除可能）</p></figcaption></figure>

現在、2 種類のローカルモデルが組み込まれています：

| ローカルモデル | 基盤 | サイズ | 用途 |
| ------------- | -------------------- | -------- | --------------------------------------------------------------- |
| **ローカル埋め込みモデル** | Qwen3 Embedding 0.6B | 約 614 MB | テキストをベクトルに変換し、[ナレッジベース](../../knowledge-base/knowledge-base.md) の検索やリコールなどのシナリオで使用 |
| **ローカル OCR モデル** | PaddleOCR PP-OCRv6 | 約 140 MB | オフラインで画像 / スキャンデータの文字を認識し、[OCR](ocr.md) 機能で呼び出し可能 |

### ダウンロードとステータス

* モデル名の横にステータスバッジが表示されます。未ダウンロードのカードの**下部**に全幅の「**ダウンロード**」ボタンがあり、クリックするとダウンロードが開始されます。ダウンロード完了後、バッジは**準備完了**に変更されます。
* 準備完了のモデルは、右側の**削除**アイコンをクリックして削除し、ディスク容量を解放できます。必要に応じて再ダウンロード可能です。（埋め込みモデルがナレッジベースで使用されている場合、削除は拒否され、重みは保持されます。）
* 一部のプラットフォーム / アーキテクチャではローカル推論がサポートされていない場合、パネルに「**現在のプラットフォームではローカルモデルがサポートされていません**」と表示され、ダウンロードは提供されません。

ダウンロード中にミラーが利用できない場合、Cherry Studio は自動的に他のダウンロードソースを試みます。ダウンロード完了後、ローカル埋め込みモデルの推論プロセスはローカルで実行され、インターネット接続は不要です。

{% hint style="warning" %}
ページに【モデルファイルが不完全です。再ダウンロードして修復してください。】と表示された場合、ローカルキャッシュに必須ファイルが欠落していることを示します。該当するモデルを削除または再ダウンロードすることで修復できます。モデルファイルを手動で結合しないでください。
{% endhint %}

{% hint style="info" %}
ローカルモデルは**オプション**です。[モデルサービス](providers.md) でクラウド埋め込みモデルを設定済み、またはシステム標準の OCR で十分な場合は、ダウンロードしなくても構いません。
{% endhint %}

### ローカルモデルを使用するタイミング

* **クラウド埋め込みモデルがない / ナレッジベースのために個別に料金を支払いたくない場合**：ローカル埋め込みモデルをダウンロードすると、ナレッジベースは完全にオフラインでインデックス作成と検索が可能になります。
* **オフライン OCR が必要な場合**：ネットワークがない、または画像をサードパーティにアップロードしたくないシナリオでは、ローカル OCR モデルをダウンロードし、[OCR 設定](ocr.md) で「ローカル PaddleOCR」を選択してください。
* **プライバシーを優先する場合**：すべての計算がローカルで完了し、コンテンツはコンピューターから外部に送信されません。

{% hint style="warning" %}
ローカルモデルは「十分であれば良い」軽量なソリューションです。検索精度や認識精度に高い要求がある場合は、クラウドの[埋め込みモデル](../../knowledge-base/emb-models-info.md)や、より強力な OCR サービスの方が通常、より良い結果を得られます。
{% endhint %}
