# 通知

通知設定は、**バックグラウンド実行時にどのように通知するか**を制御します。他のウィンドウに切り替えて作業している場合、Cherry Studio は重要なイベントが完了した際にシステム通知を表示し、結果を待ったり見逃したりすることを防ぎます。

`設定 → 通知` を開くと、3 つの独立したスイッチがあります：

<figure><img src="../../../../assets/8f6458a65b2bb09759c9622f.webp" alt=""><figcaption><p>通知設定パネル</p></figcaption></figure>

| スイッチ | 通知タイミング | 推奨設定 |
| --- | --- | --- |
| **アシスタントメッセージ** | AI の返信が **成功** し、かつ生成に **30 秒以上** かかった場合のみ通知（スイッチの横に ⓘ 説明あり） | **オン**。推論モデルや長文生成を使用する場合、画面を監視する必要がありません |
| **バックアップ** | 自動 / 手動バックアップが完了したとき | **オン**。データの安全な保存を確認できます |
| **ナレッジベース** | ナレッジベース関連のタスク（インデックス構築など）が完了した後の通知 | **オン**。ナレッジベースの構築には通常時間がかかるため、完了通知があると安心です |

{% hint style="info" %}
これらの通知は、オペレーティングシステムの通知センターを通じて送信されます。通知が全く届かない場合は、Cherry Studio が通知を送信できるか、システムレベルで許可されているか確認してください（macOS の「通知」、Windows の「通知と操作」）。
{% endhint %}
