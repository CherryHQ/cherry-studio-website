# モデルサービス設定

このページでは、`設定 → モデルサービス` の個別プロバイダー設定画面の各機能について説明します。プロバイダーの完全な設定手順については、プロバイダー設定を参照してください。

{% hint style="info" %}
* 組み込みプロバイダーの場合、通常は対応する **API キー** の入力のみで問題ありません。
* プロバイダーによってキーの呼び名は異なりますが、キー、Key、API Key、トークンはすべて同じものを指します。
{% endhint %}

### API キー

プロバイダーの API キーを入力してください。Cherry Studio は **1 つのプロバイダーに複数のキーを設定し、ローテーションで使用する** ことをサポートしています（リストの先頭から末尾へ順に循環します）。管理方法は 2 種類あります：

* **クイック追加**：複数のキーを **カンマ** で区切って直接入力します。例：`sk-xxx1,sk-xxx2,sk-xxx3`。
* **API キー管理**：API キー入力欄右側の **鍵アイコンボタン**（ホバーで「API キー管理」と表示）をクリックすると、管理画面に移動します。各キーは独立したエントリとして管理でき、**ラベルの編集**、**有効 / 無効**、**コピー**、**削除** を個別に行えます。

{% hint style="warning" %}
複数のキーをカンマで区切る場合は、必ず **半角** カンマを使用してください。
{% endhint %}

### API アドレス

組み込みプロバイダーの場合、通常は API アドレスの入力は不要です（デフォルト値を使用します）。変更が必要な場合は、プロバイダーの公式ドキュメントに従って入力してください。

> プロバイダーから `https://xxx.com/v1/chat/completions` のような完全なアドレスが提供されている場合、通常は **ルートアドレス** `https://xxx.com` のみを入力すればよく、Cherry Studio が自動的に `/v1/chat/completions` を補完します。

{% hint style="info" %}
プロバイダーのリクエストパスが通常の `/v1/chat/completions` ではない場合、API アドレス欄に **完全なアドレスを入力し、`#` で終わるように** してください——`#` で終わる場合、バージョンパスの自動連結は行われず、入力したアドレスのみが使用されます。
{% endhint %}

### モデルの追加

プロバイダー設定画面の「**モデルリストの取得**」ボタンをクリックすると、そのプロバイダーがサポートするモデルを取得します。表示された「モデル管理」リストで、モデル右側の `+` をクリックしてモデルリストに追加します。**リストに追加されたモデルのみ** が、各所のモデルセレクターに表示されます。

モデル名の下部には、プロバイダーから返された **実際の API モデル ID** が表示されます。日付付きバージョンやベンダープレフィックス付きバージョンなど、名称が類似しているモデルは統合されなくなります。モデルの追加または選択前に、この ID を確認し、同名の別バージョンを選択しないようご注意ください。

### 接続性チェック

「**テスト**」ボタンをクリックし、モデルを選択して設定が正常に行われたかテストできます（複数のキーを設定している場合、どのキーでテストするかを選択することも可能です）。テストに失敗した場合は、モデルリストに誤って入力されたモデルやサポートされていないモデルがないか確認してください。

### API 設定（詳細）

一部のプロバイダーでは、「**API 設定**」で特定の機能を有効にできます。例：配列形式の message content のサポート、Developer Message、`enable_thinking`（Qwen3 などのモデルの思考を制御）、`service_tier`（OpenAI のみ）など。通常は変更する必要はありません。

{% hint style="danger" %}
設定が完了したら、必ずプロバイダー右上の **有効化スイッチ** をオンにしてください。オンにしないと、そのプロバイダーは未有効化のままとなり、そのモデルはモデル選択リストに表示されません。
{% endhint %}
