# 使用量統計

使用量統計は、Cherry Studio における **モデル呼び出し状況を可視化パネルに集約** します。費用、Token 使用量、リクエスト数、最も使用頻度の高いモデルが一目で把握できます。コストの推定、異常な消費の発見、異なるモデル間の使い分けに役立ちます。

`設定 → 使用量統計` を開きます。ページは **概要 / 探索 / リクエスト** の 3 つのセクションに分かれており、右上で **直近 30 日 / 直近 90 日 / 直近 1 年** を切り替えられます。すべてのデータは選択された期間に基づいて集計されます。

### 概要

上部に指標カードのグループがあります：

| 指標 | 意味 |
| --- | --- |
| **総コスト** | 期間内の推定費用（各モデルの公開価格に基づいて換算、参考情報です） |
| **リクエスト数** | 送信されたリクエストの総回数 |
| **総 Token 数** | 入力 + 出力の Token 総量 |
| **キャッシュヒット率** | プロンプトキャッシュにヒットした割合（ヒットしたキャッシュ読み取り ÷ 観測可能な入力）、高いほど節約になります |
| **アクティブ日数 / 最長連続日数** | 使用記録がある日数と連続使用した日数 |
| **ピーク日** | 1 日あたりの使用量が最も高い日付とその Token 量 |
| **使用量最多モデル** | 期間内で最も消費したモデル |
| **1 日平均** | 1 日あたりの平均 Token 量とリクエスト数 |

下部の **毎日のアクティビティ** ヒートマップは日別で使用量の強度を表示します。**Token / コスト** の 2 つの軸間で切り替え可能で、色が濃いほどその日の使用量が多いことを示します。

### 探索 / 分析

**探索** に切り替えると、使用量の分解分析ができます。**グループ**（プロバイダー / モデル / API キー / アシスタント・Agent）で分割し、**指標** を 1 つ選択して、**棒グラフ / ラインチャート / パイチャート / セグメント** などのグラフで分布とトレンドを確認します。

### リクエスト詳細

**リクエスト** では個別のリクエスト記録をリスト表示し、主な消費を生み出したリクエストを特定しやすくします。

> 特定の日付で確認したい場合は、概要の **毎日のアクティビティ** ヒートマップ上で該当日をクリックしてください。探索エリア（分析 + リクエスト）は **ドリルダウン** してその日付に絞り込まれ、タイトルが「○○日 詳細」に変更されます。「日付フィルタをクリア」をクリックすると元に戻ります。

{% hint style="info" %}
コストは **推定値** です：モデルの公開価格に基づいて換算されており、実際の請求は各モデルプロバイダーの請求書に基づきます。無料モデル、ローカルモデルは費用が発生しません。
{% endhint %}
