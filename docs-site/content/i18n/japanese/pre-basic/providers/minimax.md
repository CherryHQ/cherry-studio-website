# MiniMax

MiniMaxは中国の大手LLMベンダーの一つで、**マルチモーダル機能**（テキスト、音声、画像、動画の生成）が特に優れています。

## APIキーの取得

* [MiniMax オープンプラットフォーム](https://platform.minimaxi.com/) にアクセスしてアカウントを登録します
* 本人確認が完了した後、`账户管理 → 接口密钥` に移動してAPIキーを作成します

## Cherry Studioでの設定

* `設定 → モデルサービス` を開き、**MiniMax** プロバイダーの詳細ページに移動します
* APIキーを入力します
* APIアドレスはデフォルトのままにしてください
* **モデルリストの取得** をクリックします

## 推奨用途

| モデル | 適したシーン |
|---|---|
| `abab6.5s-chat` / `MiniMax-Text-01` | 日常の対話 |
| `abab6.5-chat` | 高品質な長文生成 |

{% hint style="info" %}
* MiniMaxは中国国内からのアクセスが容易で、新規ユーザーには一定の無料枠があります
* 海外ユーザーは **MiniMax Global** をご利用ください（Cherry Studioのプロバイダーリストでは別の独立した項目として表示されます）
{% endhint %}
