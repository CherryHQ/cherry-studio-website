# LM Studio

LM Studio は人気のある **ローカル大規模モデル GUI** で、オープンソースモデルのダウンロード、量子化、およびローカルでの推論をサポートしています。Cherry Studio は LM Studio のローカルサービスにフロントエンドとして接続でき、ローカルのプライバシーを維持しながら、より良い対話体験を得ることができます。

## 事前準備

1. [LM Studio 公式サイト](https://lmstudio.ai/) からクライアントをダウンロードしてインストールします
2. LM Studio で少なくとも 1 つのモデルをダウンロードします（Llama 3.x 8B または Qwen シリーズの試行を推奨）
3. LM Studio の上部にある **Server** タブを開き、**Start Server** をクリックします（デフォルトポート `1234`）

## Cherry Studio での設定

* `設定 → モデルサービス` を開き、**LM Studio** プロバイダーの詳細ページに移動します
* **API アドレス** はデフォルトで `http://localhost:1234` です。LM Studio のポートを変更した場合は、同期して修正してください
* **API キー** は空欄のままにできます（ローカル推論では認証は不要です）。LM Studio で認証を有効にした場合は入力してください
* **モデルリストを取得** をクリックすると、Cherry Studio は LM Studio に読み込まれたモデルを自動的に取得します

{% hint style="info" %}
**モデルリストが空ですか？** LM Studio は **メモリに `Load` された** モデルのみを公開します。Load されていないモデルはリストに表示されません。LM Studio に戻って先にモデルを Load してから「モデルリストを取得」を実行してください。
{% endhint %}

## 推奨される使い方

| シナリオ | 提案 |
| -------------------- | --------------------------------------------------------------------- |
| プライバシーに敏感な対話 | 小規模モデル（8B 以下）をローカルで実行し、完全にオフラインにする |
| Apple Silicon（M シリーズチップ） | LM Studio で MLX バックエンドを使用すると、llama.cpp よりも効率が大幅に向上します |
| 埋め込みモデル | LM Studio でも埋め込みモデルを読み込め、ナレッジベースに使用できます |

## Ollama との違い

| | LM Studio | [Ollama](ollama.md) |
| ---- | ------------- | ------------------- |
| 形態 | グラフィカルインターフェース + Server | コマンドライン / バックグラウンドサービス |
| モデル管理 | GUI での閲覧/ダウンロード | `ollama pull` |
| API | OpenAI 互換 | OpenAI 互換 |
| 適したユーザー | グラフィカル操作を好むユーザー | コマンドライン / Docker デプロイを好むユーザー |

どちらでも Cherry Studio に接続できます。個人の好みで選択してください。

## よくある質問

* **Cherry Studio が接続できない**：LM Studio で Server が Start されているか（緑の点の状態）を確認してください
* **レスポンスが遅い**：モデルが大きすぎる / VRAM が不足している場合、より小さいモデルに変更するか、より低い量子化（例：Q4 → Q3）を使用してください
* **文字化け / 出力が切断される**：コンテキスト長がモデルの制限を超えている場合、LM Studio で `n_ctx` を引き上げてください
