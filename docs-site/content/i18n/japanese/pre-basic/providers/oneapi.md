# OneAPI

* ログインしてトークンページに移動します

<figure><img src="../../../../assets/68288a2c3a095035189e8d25.webp" alt=""><figcaption></figcaption></figure>

* 新しいトークンを作成します（default トークンを直接使用することもできます↑）

<figure><img src="../../../../assets/b52ed2463a5c1ea3de393a3e.webp" alt="" width="563"><figcaption></figcaption></figure>

* トークンをコピーします

<figure><img src="../../../../assets/e485ab0dd933dd974e8648e3.webp" alt="" width="563"><figcaption></figcaption></figure>

* CherryStudio のプロバイダー設定を開き、プロバイダーリストの最下部にある `添加` をクリックします
* 備考名を入力し、プロバイダーで OpenAI を選択して、確定をクリックします

* 先ほどコピーしたキーを入力します
* API Key を取得したページに戻り、対応するブラウザのアドレスバーからルートアドレスをコピーします。例：

<figure><img src="../../../../assets/15e84703b85e9e47c3de65e4.webp" alt="" width="563"><figcaption><p><strong>https://xxx.xxx.com即可，“/”及其之后的内容不需要</strong></p></figcaption></figure>をコピーするだけです

{% hint style="info" %}
* アドレスが IP+ポートの場合、http://IP:端口即可，如：http://127.0.0.1:3000 を入力します
* `http` と `https` は厳密に区別してください。SSL が有効になっていない場合は https を入力しないでください
{% endhint %}

* モデルを追加します（管理をクリックして自動取得するか、手動で入力します）。右上のスイッチをオンにすると使用できます。

{% hint style="success" %}
OneAPI の他のテーマではインターフェースが異なる場合がありますが、追加の手順は上記の操作フローと同一です。
{% endhint %}
