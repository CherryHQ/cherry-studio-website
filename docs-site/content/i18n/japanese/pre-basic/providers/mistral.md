# Mistral

Mistral AI は欧州のオープンソース大規模モデルを代表する存在であり、Mistral / Codestral などのシリーズを提供し、性能と開放性を両立しています。

## API Key の取得

* Mistral コンソールの [API Keys ページ](https://console.mistral.ai/api-keys/)を開く（事前に登録/ログインが必要です）
* 新しい API Key を作成してコピーする

## Cherry Studio での設定

1. Cherry Studio の [モデルサービス設定](../settings/providers.md)を開き、組み込みリストから **Mistral** を見つける
2. 取得した API Key を入力する
3. **モデルリストの取得**をクリックし、必要なモデルを追加して、右上のプロバイダスイッチをオンにすると使用できます

{% hint style="info" %}
国内から Mistral にアクセスするには、通常、ネットワークプロキシの問題を自分で解決する必要があります。詳細は [Mistral 公式ドキュメント](https://docs.mistral.ai)を参照してください。
{% endhint %}
