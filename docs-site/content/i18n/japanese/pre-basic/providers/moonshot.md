# Moonshot AI (Kimi)

Moonshot AI は中国で有名な大規模言語モデルチームであり、主力製品は **Kimi** です。**超長文コンテキスト**（最大200万字）を特徴とし、大量のドキュメントやコードをAIに処理させるのに適しています。

## APIキーの取得

* [Moonshot オープンプラットフォーム](https://platform.moonshot.cn/) にアクセスしてアカウントを登録します
* `API Key 管理` に移動し、`sk-...` キーを作成します
* 任意の金額をチャージして有効化します（最低金額は非常に低いです）

## Cherry Studio での設定

* `設定 → モデルサービス` を開き、**Moonshot AI** プロバイダーの詳細ページに移動します
* `sk-...` キーを入力します
* APIアドレスはデフォルトで `https://api.moonshot.cn` です
* **モデルリストの取得** をクリックします

## 推奨される使い方

| モデル | 適したシナリオ |
|---|---|
| `moonshot-v1-8k` | 短いコンテキスト、低コストで高速 |
| `moonshot-v1-32k` | 中程度のコンテキスト、日常使用に十分 |
| `moonshot-v1-128k` | 長いコンテキスト、ドキュメント分析、コードレビュー |
| `kimi-k2-* / k2.5-*` | 最新フラッグシップ、推論能力がより高い |

## 適したシナリオ

* **超長文PDF / ドキュメント分析**：Moonshot の長文コンテキストの優位性が最も顕著です
* **大規模コードレビュー**：ファイルを分割せずに一度に読み込めます
* **電子書籍全体の要約**：長文コンテキストモデルにより、手動でのチャンク分割の手間を省けます

{% hint style="info" %}
* Moonshot の「コンテキストキャッシュ」機能により、繰り返し対話時のトークン消費を大幅に削減できます。公式ドキュメントを参照してください
* Kimi はWeb版に独自の対話インターフェースを持っていますが、Cherry Studio 経由でAPIに接続することで、Cherry Studio のアシスタント、ナレッジベース、MCPツールなどの拡張機能を利用できます
{% endhint %}
