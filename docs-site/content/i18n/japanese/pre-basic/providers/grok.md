# Grok

Grok は xAI が提供する大規模モデルで、「カジュアルなトーン + X (Twitter) のリアルタイムデータ連携」が特徴です。

## API キーの取得

* [xAI Console](https://console.x.ai/) にアクセスしてアカウントを登録します
* `API Keys` → `Create API Key` に移動し、`xai-...` キーをコピーします

## Cherry Studio での設定

* `設定 → モデルサービス` を開き、**Grok** プロバイダーの詳細ページに移動します
* **API キー** に `xai-...` を入力します
* **API アドレス** はデフォルトで `https://api.x.ai` となっており、変更は不要です
* **モデルリストの取得** をクリックし、`grok-4`、`grok-4-fast` などのモデルを追加します

## 推奨用途

| モデル | 適したシナリオ |
|---|---|
| `grok-4` | 総合性能が最も高く、複雑なタスクに最適 |
| `grok-4-fast` | 高スループット、低レイテンシのシナリオ |
| `grok-3-mini` | 低コストの日常会話 |

## ウェブ検索

一部の Grok モデルにはウェブ検索機能が標準搭載されており、モデル名の後に小さな地球アイコンが表示されます。チャットボックスで「ウェブ接続」を有効にして直接使用できます。詳細は [ウェブ接続モード](../websearch) を参照してください。

{% hint style="info" %}
* Grok は海外ネットワークへのアクセスが必要です。国内のユーザーはプロキシを設定してください
* xAI は無料枠（月次更新）を提供しており、日常の体験には十分です
{% endhint %}
