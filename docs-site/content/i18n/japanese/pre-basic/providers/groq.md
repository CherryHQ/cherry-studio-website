# Groq

Groq（注意：xAI の Grok ではありません）は、**LPU ハードウェアによる高速化と超低レイテンシ**を特徴とする推論サービスです。主に Llama / Mixtral / Whisper などのオープンソースモデルをホストしており、出力速度は通常のクラウド推論の数倍に達します。

## API キーの取得

* [GroqCloud](https://console.groq.com/) にアクセスしてアカウントを登録します
* `API Keys` → `Create API Key` を選択し、`gsk_...` キーをコピーします

## Cherry Studio での設定

* `設定 → モデルサービス` を開き、**Groq** プロバイダーの詳細ページに移動します
* **API キー** に `gsk_...` を入力します
* **API アドレス** はデフォルトで `https://api.groq.com/openai/v1` であり、変更は不要です
* **モデルリストの取得** をクリックします

## 推奨される使用法

| モデル | 適したシナリオ |
| ------------------------- | ---------- |
| `llama-3.3-70b-versatile` | 汎用対話、極めて高速 |
| `llama-3.1-8b-instant` | 単純なタスク、ミリ秒単位の応答 |
| `mixtral-8x7b-32768` | 長いコンテキスト |
| `whisper-large-v3` | 音声からテキストへの変換 |

## 適用シナリオ

* **リアルタイムチャットボット**：Groq の「ほぼ即時応答」は IM 連携に最適です（[チャンネル](../../advanced-basic/automation/channels.md) と組み合わせる）
* **大量の並行処理**：1 秒あたりのトークン数は通常のクラウド推論を大きく上回ります
* **最新モデルにこだわらない場合**：Groq は主に Llama シリーズなどのオープンソースモデルをホストしており、GPT-5 / Claude-4 などのクローズドソースモデルはありません

## Grok と Groq の区別

| | [Grok](grok.md) | Groq |
| -- | --------------- | --------------- |
| 会社 | xAI（マスク氏） | Groq Inc. |
| 特徴 | 自社開発大規模モデル + 接続機能 | LPU ハードウェア + オープンソースモデル推論 |
| モデル | `grok-4` などの自社開発 | `llama-3.x` などのオープンソース |

{% hint style="warning" %}
Grok（xAI）と Groq は混同されがちです。Cherry Studio のプロバイダーリストでは独立した 2 つの項目として表示されるため、ご注意ください。
{% endhint %}
