# DeepSeek

DeepSeekは中国国内の主要な大規模モデルプロバイダーの一つであり、V3 / R1 シリーズはプログラミングおよび推論タスクにおいて高い評価を得ています。また、価格も手頃です。

## API キーの取得

* [DeepSeek Platform](https://platform.deepseek.com/) にアクセスしてアカウントを登録します
* `API Keys` → `创建 API Key` に移動し、`sk-...` キーをコピーします
* 任意の金額をチャージします（最低 ¥1 で有効化できます）

## Cherry Studio での設定

* `設定 → モデルサービス` を開き、**deepseek** プロバイダーの詳細ページに移動します
* **API キー** に `sk-...` を入力します
* **API アドレス** はデフォルトで `https://api.deepseek.com` であり、変更は不要です
* **モデルリストの取得** をクリックします

## 推奨される使用法

| モデル | 適したシナリオ |
| ------------------- | ---------------------------------- |
| `deepseek-chat` | 汎用対話、コストパフォーマンスに優れる |
| `deepseek-reasoner` | 数学、コード、複雑な推論。出力に `<thinking>` 思考ブロックが含まれることに注意 |

## ネイティブなWeb検索

DeepSeek の Web 検索機能をサポートするモデルでは、プロバイダーのネイティブな Web 検索を直接使用できます。モデル選択時に、名称の横に 🌐 アイコンがあるか確認してください。具体的なサポート範囲はプロバイダーの更新によって変更される可能性があるため、モデル名だけで判断することは推奨されません。

対話中に 🌐 をオンにした場合、【設定】→【Web 検索】内の【設定済みの検索サービスを優先的に使用】がオンになっている場合、Cherry Studio は設定済みの検索サービスを優先的に使用します。このオプションをオフにすると、モデルのネイティブな Web 検索が優先的に使用されます。詳細は Web 検索モード を参照してください。

## グローバルメモリとの組み合わせ

DeepSeek には独自の埋め込みモデルがありません。ナレッジベースを使用する場合：

* 埋め込みモデルには他のプロバイダーのもの（例：[SiliconFlow](siliconcloud.md) の `bge-m3` または [OpenAI](openai.md) の `text-embedding-3-small`）を使用することをお勧めします
* 対話モデルには引き続き DeepSeek を使用できます

{% hint style="info" %}
- DeepSeek の料金はトークン単位で課金され、キャッシュヒットにより大幅に低価格になります（公式ドキュメントを参照）
- `deepseek-reasoner` の思考内容はデフォルトで対話に表示されますが、[対話設定](../../cherrystudio/preview/chat.md#dui-hua-she-zhi) で「思考内容の自動折りたたみ」を切り替えることができます
{% endhint %}
