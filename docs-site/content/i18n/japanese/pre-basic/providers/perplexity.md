# Perplexity

Perplexity の **Sonar** シリーズは **検索強化型対話** を特徴としています。回答はリアルタイムのオンライン検索と連携し、最新情報の引用が必要な場面に適しています。

## API キーの取得

* Perplexity の [API 設定ページ](https://www.perplexity.ai/settings/api) を開く（事前に登録/ログインが必要です）
* API キーを生成してコピーする

## Cherry Studio での設定

1. Cherry Studio の [モデルサービス設定](../settings/providers.md) を開き、組み込みリストから **Perplexity** を見つける
2. 取得した API キーを入力する
3. **モデルリストの取得** をクリックし、Sonar などのモデルを追加して、右上のプロバイダーのスイッチをオンにすると使用できます

{% hint style="info" %}
Perplexity モデルにはオンライン検索機能が標準で搭載されており、オンラインモードの追加設定は不要です。国内からのアクセスには、通常、ネットワークプロキシの問題を自分で解決する必要があります。詳細は [Perplexity 公式ドキュメント](https://docs.perplexity.ai/home) を参照してください。
{% endhint %}
