# DeepSeek V3.2

Cherry Studio ユーザーは、組み込みの **CherryIN** サービスを通じて **DeepSeek V3.2** を無料で体験できます。DeepSeek V3.2 は 2025 年 12 月 1 日にリリースされたフラッグシップのスパースアテンション MoE モデルであり、「思考」をツール呼び出しにネイティブ統合した初のモデルです。高度な Agent や長文脈シナリオに最適な選択です。

***

## DeepSeek V3.2 とは？

DeepSeek V3.2 は V3.2-Exp をベースに開発され、Mixture-of-Experts（MoE）アーキテクチャを採用しています。さらに **DeepSeek Sparse Attention（DSA）** というスパースアテンションメカニズムを導入し、超巨大な総パラメータ数を維持しながら、長文脈推論のコストを大幅に削減しています。

- アーキテクチャ：MoE + DeepSeek Sparse Attention（DSA）+ Multi-Head Latent Attention（MLA）
- 総パラメータ数：685B
- トークンあたりのアクティブパラメータ数：約 37B
- エキスパート数：レイヤーあたり 256 個
- オープンソースライセンス：MIT
- リリース日：2025 年 12 月 1 日（V3.2-Exp は 2025 年 9 月 29 日にリリース）

V3.2 では、API 向けの **DeepSeek-V3.2-Speciale** バージョンも同時にリリースされました。このバージョンは、IMO、CMO、ICPC World Finals、IOI 2025 において金メダルレベルの成績を収めています。

## 確立されたトレーニングとアライメントプロセスの継続

DeepSeek V3.2 は、V3 シリーズの成熟したトレーニングパイプラインを継承し、Agent シナリオ向けに重要な拡張を加えています。

1. **大規模事前学習**：大量の高品質な多言語コーパスを用いた基礎トレーニングを行い、コード、数学、科学知識をカバーしています。
2. **スパースアテンションの導入**：128K のシーケンス長でメインモデルと lightning indexer をトレーニングし、各クエリトークンが 2048 個のキーバリュートークンを選択してアテンションに参加します。
3. **大規模な Agent データ合成**：1,800 以上の環境と 85,000 以上の複雑な指示をカバーする、新しい Agent トレーニングデータ合成手法を採用しています。
4. **思考とツール呼び出しの融合**：V3.2 は DeepSeek 初の「思考」をツール呼び出しにネイティブ統合したモデルであり、「思考モード」と「非思考モード」の両方でツールを呼び出せます。

## フラッグシップ級のコア機能

DeepSeek V3.2 は「GPT-5 と同等のレベル」の総合的な能力を特徴とし、Agent と複雑な推論において大幅に強化されています。

- ✅ **ネイティブ思考 + ツール呼び出し**：thinking を tool-use に統合した初の DeepSeek モデル
- ✅ **トップクラスの推論能力**：V3.2-Speciale は IMO / CMO / ICPC World Finals / IOI 2025 で金メダルレベルの成績を達成
- ✅ **コードと開発タスク**：V3 シリーズの強力なコード能力を継承
- ✅ **長文脈の安定性**：DSA による長文書やコードベースレベルの分析能力
- ✅ **構造化ツール呼び出し**：マルチステップの計画と実行を行う Agent の構築に適しています

## DeepSeek Sparse Attention：より長く、より効率的に

DSA は V3.2 のコア技術アップグレードであり、**lightning indexer + 細粒度トークン選択** によって実現されています。

- 大規模モデルにおける細粒度スパースアテンションの初の実現
- コアアテンションの計算複雑さを O(L²) から低減
- 長文脈のトレーニングと推論を大幅に高速化し、かつ密集アテンションとほぼ同等の出力品質を維持

| シナリオ | 推奨される使い方 | 例 |
| --- | --- | --- |
| 短い対話 / 単純な Q&A | 直接呼び出し | 日常の質問応答、要約 |
| 中程度の複雑なタスク | ツール呼び出しを有効化 | データ分析、コードリファクタリング |
| 複雑な Agent タスク | 思考 + ツール呼び出し | マルチステップ計画、コードベース分析、長文書のレビュー |

## Cherry Studio でどのように使用するか？

1. Cherry Studio を開き、**設定 → モデルサービス** に移動します。
2. **CherryIN** プロバイダーを見つけ、有効にします。
3. モデルリストから **DeepSeek V3.2** を選択します。
4. チャット画面に戻り、上部のモデル選択で **DeepSeek V3.2** に切り替えると、対話を開始できます。

> 💡 ヒント：CherryIN が提供する無料モデルのクォータは Cherry Studio 公式が負担します。日常の体験や評価に適しています。本番環境では、DeepSeek 公式 API と併せて使用することを推奨します。
