# Zhipu GLM-4.6V

Cherry Studio ユーザーは、組み込みの **CherryIN** サービスを通じて **Zhipu GLM-4.6V** を無料で体験できます。Z.ai（Zhipu AI）が 2025 年 12 月に発表したビジョンフラッグシップモデルで、MoE アーキテクチャ、128K のネイティブマルチモーダルコンテキスト、ネイティブマルチモーダルツール呼び出しに対応しており、画像とテキストの理解およびマルチモーダル Agent シナリオの第一候補です。

***

## GLM-4.6V とは？

GLM-4.6V は Z.ai の GLM-V シリーズの最新世代ビジョン言語モデルであり、テキスト + 画像の統合モデリングをネイティブサポートしています。GLM-4.5V をベースに、コンテキストとツール呼び出し機能をさらに拡張しました。

- アーキテクチャ：Mixture-of-Experts（MoE）
- 総パラメータ数：106B
- アクティブパラメータ数：約 12B
- コンテキスト長：128K tokens
- オープンソースライセンス：MIT
- 公開日：2025 年 12 月 8–9 日
- ビジョンエンコーダー：マルチ解像度画像（最大 4K）に対応

シリーズには **GLM-4.6V-Flash（9B）** も含まれており、ローカルおよび低レイテンシシナリオ向けで、商用利用も無料です。

## GLM-V シリーズのマルチモーダル学習体系の継承

GLM-4.6V は GLM-4.1V-Thinking / GLM-4.5V の技術路線を継承し、ビジョンと Agent 方向でさらに強化しました：

1. **ネイティブマルチモーダルモデリング**：テキストと画像の共同学習により、テキストと画像の混合入力をサポート
2. **コンテキスト拡張**：学習コンテキストを 128K tokens に拡張し、1 回で約 150 ページの高密度ドキュメント、200 ページのスライド、または 1 時間の動画を処理可能
3. **ネイティブマルチモーダルツール呼び出し**：ツールが直接画像を受信・返却でき、拡張された MCP プロトコルに基づいて URL 形式でマルチモーダル成果物を処理
4. **強化学習による強化**：GLM-V シリーズのスケーラブルな RL プロセスを継承

## ネイティブマルチモーダル、実シナリオ向け

GLM-4.6V のマルチモーダル機能は、日常および専門的なシナリオをカバーしています：

- ✅ **リッチテキストコンテンツの理解**：長文ドキュメント、複数ページのテキスト、テキストと画像の混在レイアウト
- ✅ **ビジュアルウェブ検索**：視覚入力と組み合わせてオンライン検索と理解を行う
- ✅ **フロントエンド再現**：デザイン案や UI スクリーンショットからフロントエンドコードを生成
- ✅ **長コンテキストのマルチモーダルドキュメント分析**：PDF / スライド / 動画レベルの全体入力に対応
- ✅ **チャートとテーブルの解析**：構造化情報の抽出

***

## ネイティブマルチモーダルツール呼び出しと Agent 機能

GLM-4.6V のコアアップグレードの一つは、**「視覚認識 → 実行可能なアクション」** のクローズドループです。ツール呼び出しがネイティブで画像の入力と出力をサポートし、マルチモーダル Agent が実際のビジネスシーンで実装可能になります。

| シナリオ | 推奨用法 | 例 |
| --- | --- | --- |
| 簡単なテキストと画像の Q&A | 直接対話 | 「この画像には何がありますか？」 |
| 中程度の複雑なタスク | ツール呼び出しを有効化 | チャートを読み取った後にデータを検索 |
| 複雑なマルチモーダル Agent | マルチツール + MCP | スクリーンショット → 理解 → API 呼び出し → レポート生成 |

## 実用的な機能に焦点：マルチモーダルアシスタント

GLM-4.6V は実際の使用において、以下のシナリオに適しています：

- **ドキュメントアシスタント**：長文ドキュメント、スキャン済み文書、スライドの全体読み取りと要約
- **データ分析**：チャート、ダッシュボードのスクリーンショットの識別と解釈
- **フロントエンドとデザイン**：UI スクリーンショットに基づいてフロントエンドコードを生成または修正
- **ビジュアル検索**：画像と組み合わせてオンライン検索と情報統合を行う
- **マルチモーダル Agent**：ブラウザ、コード実行、検索などのツールと組み合わせて複雑なタスクを完了

## Cherry Studio でどのように使用するか？

1. Cherry Studio を開き、**設定 → モデルサービス** に移動します。
2. **CherryIN** プロバイダーを見つけ、有効にします。
3. モデルリストから **Zhipu GLM-4.6V** を選択します。
4. チャット画面に戻り、上部のモデル選択で **GLM-4.6V** に切り替えると、対話中に直接画像をアップロードしてテキストと画像のインタラクションを行えます。

> 💡 ヒント：CherryIN が提供する無料モデルのクォータは Cherry Studio 公式が負担します。日常の体験や評価に適しています。本番環境では、Z.ai（Zhipu）公式 API と組み合わせて使用することを推奨します。
