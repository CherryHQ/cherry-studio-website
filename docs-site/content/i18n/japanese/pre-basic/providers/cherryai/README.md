# CherryAI（無料）

**CherryAI** は Cherry Studio に公式に組み込まれた **無料モデル** の入口です。サードパーティのプラットフォームでの登録やキーの申請は不要で、開いた時点で無料枠付きのモデルを使用できます。まずは機能を試してみたい初心者ユーザーに適しています。

### 使用場所

`設定 → モデルサービス` を開き、組み込みリストから **CherryAI** を見つけてください。ソフトウェアにプリセットされているため、通常は追加の設定は不要です。**モデルリストの取得** をクリックすると、現在利用可能な無料モデルを確認できます。

### 利用可能な無料モデル

{% hint style="warning" %}
**無料モデルのラインナップは動的に変わります。** 具体的なモデル、それぞれのクォータとレート制限は、Cherry サーバー側からリアルタイムで配信され、不定期に調整されます。**すべてはソフトウェア内で【モデルリストの取得】をクリックして表示される実際の結果を基準としてください**。以下は一部の一般的な無料モデルの説明であり、現在の完全なリストを示すものではありません。
{% endhint %}

* [DeepSeek V3.2](free-deepseek.md)
* [智譜 GLM-4.6V](free-glm46v.md)
* [智譜 GLM-4.5-Air](free-glm45air.md)
* [Qwen3-8B](free-qwen.md)

より安定性が高く、高性能なモデルが必要な場合は、[CherryIN](../cherryin-1.md) または他の [プロバイダー](../README.md) を選択できます。
