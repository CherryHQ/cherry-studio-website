# CherryAI（無料）

**CherryAI** は Cherry Studio に組み込まれた公式の無料モデルサービスです。外部サービスへの登録や API Key の入力は不要で、チャットや基本的なテキスト処理を試す用途に適しています。

### 使用場所

`設定 → モデルサービス` を開き、組み込みリストから **CherryAI** を選択します。このサービスはアプリにあらかじめ設定されており、通常は追加設定を必要としません。

### 現在提供しているモデル

現在の CherryAI サーバー設定では、**Qwen3-8B** のみを提供しています。

{% hint style="warning" %}
モデルの提供状況、無料枠、レート制限はサーバー設定により変更される場合があります。Cherry Studio 上で実際に表示され、利用できるモデルを基準にしてください。このページは長期的な提供を保証するものではありません。
{% endhint %}

ほかのモデルや、より安定したサービスが必要な場合は、[CherryIN](../cherryin-1.md) または別の [プロバイダー](../README.md) を利用してください。

## Qwen3-8B

**有名な MaaS サービスプラットフォーム「SiliconFlow（硅基流动）」が、Qwen3-8B モデルの呼び出しサービスを無料で提供しています**。通義千問 Qwen3 シリーズにおけるコストパフォーマンスに優れたメンバーとして、Qwen3-8B はコンパクトなサイズながら強力な機能を備え、インテリジェントなアプリケーションと効率的な開発の理想的な選択肢です。

***

**🚀 Qwen3-8B とは？**

Qwen3-8B は、アリババが 2025 年 4 月に発表した通義千問第 3 世代大規模モデルシリーズにおける **80 億パラメータの Dense モデル**であり、**Apache 2.0 オープンソースライセンス**を採用しており、商業および研究目的で自由に利用できます。

* **総パラメータ数：80 億**
* **アーキテクチャタイプ：Dense（純粋な Dense 構造）**
* **コンテキスト長：128K トークン**
* **多言語対応：119 言語および方言をカバー**

コンパクトなサイズにもかかわらず、Qwen3-8B は推論、コード、数学、Agent 機能において安定したパフォーマンスを発揮し、前世代のより大きなモデルに匹敵する性能を誇り、実用的な場面において非常に高い実用性を示しています。

***

**📚 強力なトレーニング基盤、小規模モデルにも大きな知恵を**

Qwen3-8B は、**約 36 兆トークンに及ぶ高品質な多言語データ**を用いて事前学習が完了しており、ウェブテキスト、技術文書、コードリポジトリ、専門分野の合成データを包含し、知識の覆盖面が広いです。

その後の後学習段階では、**4 段階の強化プロセス**が導入され、以下の機能が特に最適化されました：

✅ 自然言語理解と生成\
✅ 数学推論と論理分析\
✅ 多言語翻訳と表現\
✅ ツール呼び出しとタスク計画

トレーニング体系の全面的なアップグレードにより、**Qwen3-8B の実際のパフォーマンスは Qwen2.5-14B に接近し、場合によってはそれを上回ります**、パラメータ効率の顕著な飛躍を実現しました。\\

**💡 ハイブリッド推論モード：思考 or 高速応答？**

Qwen3-8B は、**「思考モード」と「非思考モード」**の柔軟な切り替えをサポートしており、ユーザーはタスクの複雑さに応じて応答方式を自由に選択できます。

以下の方法でモードを制御します：

* **API パラメータ設定**：`enable_thinking=True/False`
* **プロンプト指示**：入力に `/think` または `/no_think` を追加

| モード | 適用シーン | 例 |
| --------- | -------------- | ----------------------------- |
| **思考モード** | 複雑な推論、数学問題、計画系タスク | <p>- 幾何学問題の解法<br>- 完全なプロジェクトアーキテクチャの作成</p> |
| **非思考モード** | 高速 Q&A、翻訳、要約 | <p>- 天気確認<br>- 中国語と英語の相互翻訳</p> |

この設計により、ユーザーは **応答速度と推論の深さの間で自由にバランスを取ることができ**、使用体験が向上します。

***

**⚙️ ネイティブで Agent 機能をサポートし、インテリジェントなアプリケーションを強化**

Qwen3-8B は優れた **Agent 化能力**を備えており、各種自動化システムに簡単に統合できます：

🔹 **関数呼び出し（Function Calling）**：構造化されたツール呼び出しをサポート\
🔹 **MCP プロトコル互換**：モデルコンテキストプロトコルをネイティブでサポートし、外部機能の拡張が容易\
🔹 **マルチツール連携**：検索、電卓、コード実行などのプラグインに接続可能

**Qwen-Agent フレームワーク**との組み合わせを推奨し、記憶、計画、実行能力を備えたインテリジェントアシスタントを迅速に構築できます。

***

**🌐 広範な言語サポート、グローバルなアプリケーション向け**

Qwen3-8B は、中国語、英語、アラビア語、スペイン語、日本語、韓国語、インドネシア語などを含む **119 言語および方言**をサポートしており、国際化製品開発、クロス言語カスタマーサービス、多言語コンテンツ生成などのシーンに適用できます。

中国語の理解は特に優れており、簡体字、繁体字、広東語の表現をサポートし、香港・澳門・台湾および海外華人市場に適しています。

***

**🧠 実用機能が強く、シーンカバー範囲が広い**

Qwen3-8B は、複数の高頻度アプリケーションシーンで優れたパフォーマンスを発揮します：

✅ **コード生成**：Python、JavaScript、Java などの主要言語をサポートし、ニーズに応じて実行可能なコードを生成可能\
✅ **数学推論**：GSM8K などのベンチマークで安定したパフォーマンスを示し、教育系アプリケーションに適している\
✅ **コンテンツ作成**：メール、レポート、コピーライティングの作成、構造が明確で自然な言語\
✅ **インテリジェントアシスタント**：個人ナレッジベース Q&A、スケジュール管理、情報抽出などの軽量 AI アシスタントを構築可能
