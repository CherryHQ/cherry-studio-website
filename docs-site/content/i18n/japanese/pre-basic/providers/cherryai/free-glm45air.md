# Zhipu GLM-4.5-Air

すべての開発者やユーザーが最先端の大規模モデルの能力を簡単に体験できるよう、**ZhipuはCherry StudioのユーザーにGLM-4.5-Airモデルを無料で提供しています**。エージェント（Agent）アプリケーション向けに設計された高効率な基盤モデルとして、GLM-4.5-Airは性能とコストの間に優れたバランスを実現しており、インテリジェントなアプリケーション構築の理想的な選択です。

***

**🚀 GLM-4.5-Airとは？**

GLM-4.5-AirはZhipuが最新にリリースした高性能な言語モデルで、先進的な**混合専門家アーキテクチャ（Mixture-of-Experts, MoE）**を採用しています。卓越した推論能力を維持しながら、計算リソースの消費を大幅に削減します。

* **総パラメータ数：1060億**
* **アクティブパラメータ数：120億**

スリムな設計により、GLM-4.5-Airはより高い推論効率を実現し、リソースが制限された環境でのデプロイに適しています。同時に、複雑なタスクの処理もこなせます。

**📚 統一されたトレーニングフローで、インテリジェンスの基盤を強化**

GLM-4.5-Airはフラッグシップシリーズと一貫したトレーニングフローを共有しており、堅牢な汎用能力の基盤を確保しています：

1. **大規模事前学習**：**15兆トークン**の汎用コーパス上でトレーニングを完了し、広範な知識理解能力を構築します；
2. **専門分野の最適化**：コード生成、論理推論、エージェントインタラクションなどの重要なタスクにおいて強化トレーニングを行います；
3. **長文脈のサポート**：コンテキスト長を**128Kトークン**まで拡張し、長いドキュメント、複雑な対話、または大規模なコードプロジェクトを処理できます；
4. **強化学習による強化**：RLを通じて、推論計画やツール呼び出しなどの面でのモデルの意思決定能力を最適化します。

このトレーニング体系により、GLM-4.5-Airは優れた汎化能力とタスク適応性が備わっています。

**⚙️ エージェント向けに最適化されたコア機能**

GLM-4.5-Airはエージェントアプリケーションのシナリオに合わせて深く適応されており、以下の実用的な機能を備えています：

✅ **ツール呼び出しのサポート**：標準化されたインターフェースを通じて外部ツールを呼び出し、タスクの自動化を実現します\
✅ **ウェブブラウジングと情報抽出**：ブラウザプラグインと連携し、動的なコンテンツの理解とインタラクションを完了します\
✅ **ソフトウェアエンジニアリング支援**：要件解析、コード生成、欠陥の識別と修正をサポートします\
✅ **フロントエンド開発のサポート**：HTML、CSS、JavaScriptなどのフロントエンド技術に対する優れた理解と生成能力を備えています

このモデルは、**Claude Code、Roo Code**などのコードエージェントフレームワークに柔軟に統合でき、また任意のカスタムAgentのコアエンジンとしても使用できます。

**💡 インテリジェントな「思考モード」で、多様なリクエストに柔軟に対応**

GLM-4.5-Airは**混合推論モード**をサポートしており、ユーザーは`thinking.type`パラメータを通じて深い思考の有効化を制御できます：

* `enabled`：思考を有効化。段階的な推論や計画が必要な複雑なタスクに適しています
* `disabled`：思考を無効化。簡単なクエリや即時応答に使用します
* デフォルト設定は**動的思考モード**で、モデルが自動的に深い分析が必要かどうかを判断します

| タスクタイプ | 例 |
| ------------------ | ----------------------------------------------- |
| **簡単なタスク**（思考の無効化を推奨） | <p>- 「Zhipu AIの設立時期」を照会<br>- 「I love you」を中国語に翻訳</p> |
| **中程度のタスク**（思考の有効化を推奨） | <p>- 北京から上海への飛行機と高速鉄道の優劣を比較<br>- 木星が多くの衛星を持つ理由を説明</p> |
| **複雑なタスク**（思考の有効化を強く推奨） | <p>- MoEモデルにおける専門家の協調方法を説明<br>- 市場情報に基づきETFの買い入れを検討</p> |
