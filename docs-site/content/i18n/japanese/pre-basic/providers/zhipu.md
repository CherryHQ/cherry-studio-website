# ZhiPu

ZhiPu AI の **GLM** シリーズ（マルチモーダル GLM-4V を含む）は、国内から直接接続でき、中国語の処理に優れています。Cherry Studio では ZhiPu が **Anthropic 互換エンドポイント** を使用するため、通常の対話だけでなく、**Cherry Agent** にも利用できます。

## API キーの取得

* ZhiPu オープンプラットフォームの [API Keys ページ](https://open.bigmodel.cn/apikey/platform) を開く（事前に登録/ログインが必要です）
* 新しい API キーを作成してコピーする

## Cherry Studio での設定

1. Cherry Studio の [モデルサービス設定](../settings/providers.md) を開き、組み込みリストから **ZhiPu** を見つける
2. 取得した API キーを入力する
3. **モデルリストの取得** をクリックし、必要な GLM モデルを追加して、右上のプロバイダーのスイッチをオンにすると使用できます

{% hint style="info" %}
ZhiPu のモデルには **Web 検索** 機能が組み込まれており、具体的な対応状況はモデルによる。プラットフォームの詳細なドキュメントは [ZhiPu 公式ドキュメント](https://docs.bigmodel.cn/) を参照してください。
{% endhint %}
