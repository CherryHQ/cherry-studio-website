# NewAPI

Cherry Studio には New API プロバイダーが組み込まれています。1 つの New API アドレスで OpenAI Chat、OpenAI Responses、Anthropic Messages、Gemini プロトコルを同時に接続でき、プロトコルごとにプロバイダーを追加する必要はありません。

## 設定手順

1. New API 管理コンソールでトークンを作成し、コピーします。
2. Cherry Studio の【設定】→【モデルサービス】→【New API】を開きます。
3. 【API キー】を入力します。
4. 【API アドレス】に New API のルートアドレスを入力します。例: `https://api.example.com`
5. モデルを取得または手動で追加し、【検出】完了後、右上の有効化スイッチをオンにします。

Cherry Studio は選択されたプロトコルに応じて、対応するバージョンパスを自動的に使用します。例: `/v1` または `/v1beta`。通常はルートアドレスを 1 回入力するだけで十分です。`/chat/completions` などの完全なインターフェースパスを貼り付けないでください。

{% hint style="warning" %}
テスト版を使用していて、他のプロトコルアドレスに `localhost:3000` などの旧値が残っている場合は、New API の設定画面で、デフォルト以外のプロトコルの旧アドレスを一度クリアしてから、再度検出を実行してください。そうしないと、一部のモデルがまだ旧アドレスにリクエストを送信する可能性があります。
{% endhint %}

<details>

<summary>中継ステーションがバージョンなしパスを使用する場合、どうすればよいですか？</summary>

中継ステーションが `/v1` または `/v1beta` を含まないパスの使用を明確に要求する場合のみ、対応する API アドレスの末尾に `#` を追加します。`#` はバージョンパスの自動連結を行わないことを示します。通常の New API デプロイメントでは使用しないでください。

</details>

{% hint style="info" %}
アドレスには、正しい `http://` または `https://` を保持する必要があります。IP とポートを使用する場合、`http://127.0.0.1:3000` のような形式のルートアドレスを入力できます。
{% endhint %}
