# ノート

ノートは Cherry Studio に組み込まれた Markdown エディターです。AI との対話以外でアイデアを整理し、段階的な成果物を保存し、AI やナレッジベースの機能を活用してさらに加工することができます。

### ノートの開き方

上部のタブバーで【ノート】をクリックするか、【ランチャー】内の【ノート】アプリアイコンをクリックしてください。

<figure><img src="../../../../assets/14e04a73fa23719ebd35dde4.webp" alt=""><figcaption><p>ノート画面：左側にディレクトリツリーとノート一覧、右側に Markdown エディター</p></figcaption></figure>

### 最初のノートの作成

1. 左上の最初の【新規ノート作成】アイコンをクリック
2. 右側のエディターに本文を入力します。Markdown 構文とリッチテキストのクイックツールバーに対応しています
3. ノート一覧内のノートを右クリックして、名前を付けます

### 既存の Markdown ファイルのインポート

* `.md` ファイル、または `.md` ファイルを含むディレクトリをノート領域に **ドラッグ＆ドロップ** すると、新しいノートまたは新しいフォルダーとしてインポートされます
* 左上の2番目の【新規フォルダー作成】アイコンをクリックして先にディレクトリを作成し、その中にドラッグ＆ドロップすることもできます

### エディター機能

ノートエディターの上部ツールバーには、一般的なリッチテキスト機能が提供されています：

* **書式設定**：太字（<kbd>B</kbd>）、斜体（<kbd>I</kbd>）、下線（<kbd>U</kbd>）、取り消し線
* **構造**：インラインコード / H1–H3 見出し / 箇条書きリスト / 番号付きリスト / コードブロック / 引用 / タスクリスト / 数式
* **埋め込み**：テーブル、ハイパーリンク

<figure><img src="../../../../assets/d391f5ca5d92cb8fdf22ca63.webp" alt=""><figcaption><p>新規ノートを作成し本文を入力した後のエディター</p></figcaption></figure>

下部のステータスバーには現在の **文字数** が表示されます。左下の **A✓** アイコンでスペルチェックのオン/オフを切り替え、右下のドロップダウンで **リアルタイムプレビュー**、**ソースモード**、または **閲覧モード** を切り替えることができます。

### ディレクトリ管理

左側サイドバーの上部には、【新規ノート作成】/【新規フォルダー作成】/【並べ替え】/【お気に入り】/【検索】が順に配置されています。

* **並べ替え**：6つのオプション——ファイル名 `A→Z` / `Z→A`、更新日時（新しい順 / 古い順）、作成日時（新しい順 / 古い順）
* **お気に入り**：スターボタンで「お気に入り」ビューに切り替え
* **検索**：拡大鏡ボタン。検索ボックスに入力すると検索されます。**検索はタイトルと本文の両方に一致します**。本文に一致した項目は、タイトルの横に「内容」または「名前+内容」のラベルが表示され、ソースを示します

### 右クリックメニュー（AI連携 + エクスポート）

左側のディレクトリツリーで任意のノートを **右クリック** すると、操作メニューが表示されます。これは AI 連携と複数形式のエクスポートのエントリポイントです：

<figure><img src="../../../../assets/fd4004b475c63d7c924304e8.webp" alt=""><figcaption><p>単一のノートを右クリックして表示されるメニュー</p></figcaption></figure>

* **ノート名を生成** ✨：AI が本文に基づいてタイトルを自動生成します（ファイルのみ利用可能）
* **名前の変更** / **外部で開く**（Finder / エクスプローラーで表示）
* **ノートをブックマーク** / **ブックマーク解除**
* **ノートをナレッジベースにエクスポート**：指定した [ナレッジベース](../../knowledge-base/knowledge-base.md) に送信
* **エクスポート ›** サブメニュー：Markdown / Word（.docx）/ Notion / 語雀 / Obsidian / Joplin / 思源、および「画像としてコピー / 画像としてエクスポート」——各項目の表示は【設定】→【データ設定】→【エクスポートメニュー設定】で個別にオン/オフにできます
* **削除**

> フォルダーの右クリックメニューはよりシンプルで、新規ノート作成 / 新規フォルダー作成 / 名前の変更 / 外部で開く / 削除 のみです。

### 右上の【⋯】メニュー（ビューとエクスポートのクイックアクセス）

ノートのタイトルの右上にある【⋯】は、**現在のノート** のビュー / エクスポートのクイックアクセスです。右クリックメニューと混同しないでください：

<figure><img src="../../../../assets/b9b3ab0b2050382f16409b48.webp" alt=""><figcaption><p>右上の【⋯】メニュー</p></figcaption></figure>

* **内容をコピー**：プレーンテキストとしてコピー
* **Word としてエクスポート**：`.docx` を素早く生成します（より多くの形式が必要な場合は、右クリックメニューの「エクスポート ›」を使用してください）
* **PDF としてエクスポート**：現在のノートを PDF ファイルとしてエクスポート
* **印刷**：システム印刷を呼び出して現在のノートを印刷
* **行幅を狭める**：1行あたりの最大文字数を制限
* **目次アウトラインを表示**：右側に現在のノートの見出しツリーを表示
* **フォント設定 ›**：デフォルト / セリフ体、3段階のフォントサイズ（小 / 中 / 大）
* **その他の設定**：ノート設定パネルを開く（データ / エディター / 表示の3つの設定グループ）

### 作業ディレクトリとバックアップ

ノートの内容はローカルファイルとして保存されます。**作業ディレクトリ** は、ノート設定パネルの【データ設定】で確認・変更できます（右上の【⋯】→【その他の設定】から開きます）。

* デフォルトでは Cherry Studio のアプリデータディレクトリ内に保存されます
* 先に【選択】でカスタムパスを指定し、【適用】をクリックして切り替えます（変更は既存ファイルを自動移行しないため、手動でコピーする必要があります）。【デフォルトにリセット】をクリックするとデフォルトディレクトリに戻ります
* バックアップは [WebDAV](../../pre-basic/data-settings/webdav.md) / [S3 互換ストレージ](../../pre-basic/data-settings/s3-compatible.md) と組み合わせることをお勧めします

### エディターと表示設定

右上の【⋯】→【その他の設定】からノート設定パネルを開くと、【データ設定】の他に2つのグループがあります：

**エディター設定**

* **デフォルトビュー**：新規ノートのデフォルトで【編集モード】に入るか【閲覧モード】に入るか
* **デフォルト編集ビュー**：編集モードでデフォルトとして【リアルタイムプレビュー】か【ソースモード】か

**表示設定**

* **フォント**：デフォルト / セリフ体
* **フォントサイズ**：10–30px の範囲
* **行幅を狭める**：1行あたりの文字数を制限し、長い行が画面全体に横に広がらないようにします
* **目次アウトラインを表示**：右側に現在のノートの見出しツリーを表示し、文内ナビゲーションを容易にします

> フォントとフォントサイズは、この表示設定パネルで調整するだけでなく、右上の【⋯】→【フォント設定】から素早く切り替えることもできます。

### ヒントとテクニック

* ノートはタスクリスト `- [ ]` の記法をサポートしており、日常の ToDo に使用できます
* `.md` ファイル（または `.md` を含むディレクトリ）をディレクトリツリーにドラッグ＆ドロップすると、一括インポートできます
* デバイス間で設定を復元した後、ノートディレクトリが空になっている場合は、表示されるパスに従ってファイルを手動でコピーしてください

{% hint style="info" %}
AI にノート内容に基づいて **直接** 回答させたい場合、最も便利な方法は、対象ノートを **ナレッジベースにエクスポート** し、対話中にそのナレッジベースを有効にすることです。
{% endhint %}
