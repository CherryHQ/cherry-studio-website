# 選択アシスタント

選択アシスタント（Selection Assistant）を使用すると、**任意のアプリケーションでテキストを選択**した後、フローティングツールバーから AI を呼び出して翻訳、解説、最適化、要約などの操作を実行できます。Cherry Studio に内容を貼り戻す必要はありません。

{% hint style="info" %}
**[クイックアシスタント](quick-assistant.md) との違い**：

* **クイックアシスタント**：グローバルショートカットキーで **能動的な入力** ウィンドウを呼び出し、キーボードで質問を入力します
* **選択アシスタント**：テキストを選択すると **選択した内容に対して** ツールバーが表示され、プリセットされた操作をワンクリックで実行できます
{% endhint %}

### プラットフォームサポート

* ✅ **macOS**：完全サポート。ただし、初回有効化時に **アクセシビリティ（Accessibility）権限** の付与が必要です
* ✅ **Windows**：完全サポート。特別な権限は不要です
* ⚠️ **Linux**：**X11** モードでのみ完全サポート。Wayland モードでは、ツールバーが選択テキストの位置に追従できない場合があります。また、キー入力監視権限を取得するために、現在のユーザーを `input` グループ（`sudo usermod -aG input $USER`）に追加する必要があります

### 選択アシスタントの有効化

【設定】→【選択アシスタント】を開きます：

<figure><img src="../../../../assets/9c1fa1dc2820ccee7bd169f3.webp" alt=""><figcaption><p>選択アシスタント設定パネル</p></figcaption></figure>

1. **有効化** スイッチをオンにします
2. **macOS** ユーザーは初回有効化時に **アクセシビリティ権限** を求めるポップアップが表示されます：

   <figure><img src="../../../../assets/ed99fa5f9b3118d263e09cd2.webp" alt=""><figcaption><p>初回有効化時のアクセシビリティ権限プロンプト</p></figcaption></figure>

   **設定へ** をクリック → 表示された【システム設定】→【プライバシーとセキュリティ】→【アクセシビリティ】で Cherry Studio を見つけてスイッチをオンにする → Cherry Studio に戻って再度有効化します。
3. （任意）【ツールバー】→【単語取得方法】でトリガー方式を選択します（プラットフォームによって選択肢が異なります）：
   * **選択**：テキストを選択するとすぐにツールバーが表示されます（デフォルト）
   * **Ctrl キー**（Windows のみ）：テキストを選択した後、**Ctrl キーを長押し** すると表示されます（誤操作の防止）
   * **ショートカットキー**：テキストを選択した後、ショートカットキーを押すと表示されます。ショートカットキーは【設定】→【ショートカットキー】で変更できます

<figure><img src="../../../../assets/f45f2fd96c9bb25af9825da7.webp" alt=""><figcaption><p>有効化後の設定パネル：単語取得方法 / コンパクトモード / ツールバー追従…</p></figcaption></figure>

### 組み込み操作

選択アシスタントには 7 つの組み込み操作があり、**デフォルトで 5 つが有効化** されています：翻訳 / 解説 / 要約 / 検索 / コピー。ツールバー左側の **Cherry アイコンは操作ボタンではありません**——これはツールバーのドラッグハンドルであり、押さえて移動することでツールバー全体を移動できます。

| 操作 | デフォルト有効化 | 用途 |
|---|---|---|
| **翻訳** | ✅ | スマート翻訳：優先的にターゲット言語へ翻訳。すでにターゲット言語の場合は代替言語へ翻訳 |
| **解説** | ✅ | AI にこの内容を解説させる |
| **要約** | ✅ | AI に選択した内容を 1 段落で要約させる |
| **検索** | ✅ | 選択したテキストで検索エンジンを呼び出してクエリを実行（デフォルトは Google、各行右側の ⋯ で変更可能） |
| **コピー** | ✅ | 選択したテキストをコピー |
| **最適化** | 有効化待ち | AI により流暢 / より専門的に書き直させる。設定で有効化エリアにドラッグして追加 |
| **引用** | 有効化待ち | 選択したテキストを引用形式で現在の会話に送信。設定で有効化エリアにドラッグして追加 |

<figure><img src="../../../../assets/29cffab07ecb8317865312ee.webp" alt=""><figcaption><p>設定パネルの【機能】エリア：上部は有効化済み、下部は一時保存エリア。上部にドラッグすると有効化</p></figcaption></figure>

### カスタム操作

【設定】→【選択アシスタント】→【機能】で以下が可能です：

* 組み込み操作のプロンプトを **編集**
* カスタム操作を **追加**（名前 + プロンプト + デフォルトモデル）
* **ドラッグ** してツールバー内の操作順序を調整
* 使用頻度の低い操作を下部の一時保存エリアにドラッグして「無効化」

### ツールバー / 結果ウィンドウの外観

ツールバー：
* **コンパクトモード**：アイコンのみ表示し、テキストを表示しないことで画面スペースを節約

結果ウィンドウ（【機能ウィンドウ】セクション）：
* **ツールバー追従**：ウィンドウがツールバーに密着して表示（デフォルトでオン）。オフにすると常に中央に表示
* **サイズを記憶**：今回手動で調整したウィンドウサイズを次回も保持
* **自動閉じる**：ウィンドウ外をクリックすると閉じる
* **常に前面表示**：常に他のアプリケーションの上に浮遊
* **透明度**：20%–100% で調整可能

### 検索エンジン

選択アシスタントの組み込み【検索】操作では、プリセットエンジン（Google、Bing、DuckDuckGo など）を選択できます。設定入口は【設定】→【選択アシスタント】→【機能】です：**検索** の行を見つけ、行の右端にある歯車アイコンをクリックすると【検索エンジンの設定】ダイアログが表示されます。プリセットから選択するか、カスタムエンジンを追加できます。URL 内で `{{queryString}}` を使用して検索語の位置を示します。

### アプリケーションフィルタ（高度）

【設定】→【選択アシスタント】→【高度】→【アプリケーションフィルタ】で **ブラックリスト / ホワイトリスト** を設定でき、選択アシスタントが指定されたアプリケーションでのみ有効（ホワイトリスト）になるか、指定されたアプリケーションでは表示されない（ブラックリスト）ようにできます。

* **macOS**：アプリケーションの Bundle ID を入力（例：`com.google.Chrome`、`com.apple.mail`）
* **Windows**：アプリケーションの実行ファイル名を入力（例：`chrome.exe`、`Cherry Studio.exe`）

### 使用するモデル

選択アシスタントはデフォルトで [グローバルデフォルト対話モデル](../../pre-basic/settings/default-models.md) を使用しますが、各操作ごとに個別にモデルを指定することもできます。

### ヒントとテクニック

* macOS でツールバーが表示されない場合は、【システム設定】→【プライバシーとセキュリティ】→【アクセシビリティ】で Cherry Studio がチェックされているか確認してください
* 誤ってテキストを選択してツールバーが表示される頻度が高い場合は、**Ctrl キー** トリガーモードに切り替えてください
* ツールバーのアイコンが多すぎて画面が狭い場合は、**コンパクトモード** をオンにしてください
* 「翻訳後にそのまま読み上げる」などのチェーン操作を行いたい場合は、「翻訳」の結果をコピーした後、[クイックアシスタント](quick-assistant.md) を呼び出して処理を継続してください
