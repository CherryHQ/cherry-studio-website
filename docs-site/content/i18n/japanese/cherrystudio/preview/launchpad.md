# 起動台

起動台では、Cherry Studio のよく使う機能へのアクセスを一元管理できます。上部のタブバー右側の **+** をクリックすると、新しい起動台タブが開きます。最後のタブを閉じると、自動的に起動台に戻ります。

![説明画像](../../../../assets/7521831e54a609b69a5fceeb.png)

## デフォルトアプリ

現在の起動台には、9つの組み込みアプリが含まれています。

| アプリ | 用途 |
| --------------------------------------- | ----------------------- |
| [対話](chat.md) | モデルとの対話、アシスタントと対話リストの管理 |
| [ワーク](../../advanced-basic/agent.md) | エージェントがツールを呼び出し、複数ステップのタスクを完了 |
| [描画](drawing.md) | 画像モデルを使用して画像を生成・管理 |
| [翻訳](translation.md) | テキストを翻訳し、原文と訳文を並べて確認 |
| [ミニプログラム](../../../../cherry-studio/preview/app) | Cherry Studio 内で Web アプリを使用 |
| [ナレッジベース](knowledge-base.md) | 資料をインポートし、検索と Q&A を実行 |
| [ファイル](files.md) | アプリ内で使用されるファイルの表示と管理 |
| [コーディングパートナー](code-cli.md) | AI プログラミング CLI ツールのインストール、設定、起動 |
| [メモ](notes.md) | Markdown メモの作成と整理 |

## アプリの順序を変更

アプリのアイコンを押しながら目的の位置にドラッグすると、組み込みアプリの並べ替えができます。Cherry Studio は新しい順序を自動的に保存します。

起動台とサイドバーは、それぞれ独自のアプリ順序を保存します。起動台での並べ替えは、サイドバーの並び順に影響しません。

## サイドバーにピン留め

よく使用するアプリは、サイドバーにピン留めできます。

1. 起動台でアプリを右クリックします。
2. **サイドバーに追加** を選択します。
3. ピン留めを解除するには、再度右クリックし、**サイドバーから削除** を選択します。

> **ヒント:** **対話** はサイドバーの必須エントリであり、削除できません。他のアプリはサイドバーにピン留めされていなくても、起動台から開くことができます。

## ミニプログラムの管理

[ミニプログラム](../../../../cherry-studio/preview/app) ページで Web アプリを起動台に追加すると、組み込みアプリの下にある「ミニプログラム」領域に表示されます。

* ミニプログラムのアイコンをドラッグして、表示順序を変更できます。
* ミニプログラムを右クリックすると、サイドバーに追加したり、起動台から削除したりできます。
* 起動台から削除しても、ショートカットエントリが解除されるだけで、ミニプログラム自体は削除されません。
