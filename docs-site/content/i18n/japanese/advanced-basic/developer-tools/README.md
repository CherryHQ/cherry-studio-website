# 開発と診断

この機能群は、プログラミング CLI の管理、ローカルプログラムからのモデル呼び出し、またはリクエストの問題調査が必要なユーザー向けです。日常のチャットやコンテンツ作成には、開発者モードを有効にする必要はありません。

### 2つのエントリポイント

| エントリポイント | 用途 | 使用前の確認事項 |
| ----------------- | ---------------------------- | -------------- |
| 起動台【コーディングパートナー】 | 一般的なプログラミング CLI のインストール、設定、起動 | インストールソース、モデル接続、作業ディレクトリ |
| 【設定】→【API ゲートウェイ】 | ローカルプログラムに互換 API を提供し、Agent の実行依存としても機能 | ステータス、ポート、キーのセキュリティ |
| 【設定】→【一般】→【開発者モード】 | 呼び出しチェーンを確認し、モデルおよびツールのエラーを特定 | ログに機密情報が含まれる可能性 |

<figure><img src="../../../../assets/1fc9d6c1360e640958305d57.webp" alt="開発と診断 — 説明画像"><figcaption><p>API ゲートウェイページでは、実行ステータス、アドレス、ポート、認証情報が集中表示されます。</p></figcaption></figure>

{% hint style="warning" %}
API ゲートウェイのキーや呼び出しチェーン内のリクエスト内容は、機密情報を含む可能性があります。スクリーンショット、Issue、グループチャットでは、マスク済みの必要な部分のみを共有してください。
{% endhint %}
