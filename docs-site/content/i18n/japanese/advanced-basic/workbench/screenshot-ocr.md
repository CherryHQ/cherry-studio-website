# スクリーンショット、アノテーション、OCR

Cherry Studio では、グローバルショートカットキーを使用して画面の領域をキャプチャし、矩形、矢印、ブラシ、テキスト、モザイクを追加して、結果をコピーまたは保存できます。ローカル OCR を有効にすると、スクリーンショット内のテキストを直接選択してコピーすることもできます。

### 目的と前提条件

* パス：【設定】→【スクリーンショット】；
* macOS では初回使用時に画面録画の許可が必要です。権限付与後、ページの指示に従ってアプリを再起動してください；
* OCR を使用するには、【設定】→【ローカルモデル】で文字認識モデルをダウンロードする必要があります；
* スクリーンショット機能はデフォルトで無効、テキストの自動認識はデフォルトで有効ですが、モデルが準備できていない場合は OCR が実行されません。

### 用語

| 用語 | 意味 |
| ----- | ------------------------------- |
| グローバルショートカットキー | 現在のフォーカスが Cherry Studio にない場合でもトリガーできるショートカットキー |
| OCR | 画像内のテキストを選択・コピー可能なテキストとして認識する技術 |
| モザイク | スクリーンショット内のアカウント、パス、キー、その他の機密領域を隠す処理 |

### 操作パス

【設定】→【スクリーンショット】→【スクリーンショットを有効にする】をオン→スクリーンショットショートカットキーを押す→領域を選択→アノテーションまたはテキスト認識→コピーまたは保存。

### 操作手順

{% stepper %}
{% step %}
#### 1. スクリーンショットの有効化と権限の確認

【設定】→【スクリーンショット】を開き、【スクリーンショットを有効にする】をオンにします。macOS で【画面録画権限】のプロンプトが表示された場合は【権限を付与する】を選択してください。権限付与が完了したら【今すぐ再起動】をクリックします。
{% endstep %}

{% step %}
#### 2. ショートカットキーの設定

デフォルトのショートカットキーは、macOS では `Command+Shift+A`、Windows と Linux では `Ctrl+Shift+A` です。【ショートカットキーを設定】をクリックすると、該当行にジャンプできます。システムまたは他のアプリケーションが既に使用している場合、ページに競合の警告が表示されます。
{% endstep %}

{% step %}
#### 3. 領域の選択とアノテーション

ショートカットキーを押した後、ドラッグして領域を選択します。【矩形】【矢印】【ブラシ】【テキスト】を使用して重点箇所をマークし、【モザイク】を使用して機密情報を隠します。プロパティパネルで色、線幅、フォントサイズを調整できます。
{% endstep %}

{% step %}
#### 4. テキストまたは画像のコピー

OCR モデルが準備できている場合、ページが自動的にテキストを認識します。【テキストを認識】をクリックすることもできます。テキストを直接選択するか、【すべてのテキストをコピー】を選択します。アノテーションが完了したら、【コピーして閉じる】または【画像を保存】を選択します。
{% endstep %}
{% endstepper %}

### 期待される結果

スクリーンショットは選択された領域のみを含みます。アノテーションが明確で、機密情報が隠されていることを確認してください。コピー後、対象アプリケーションで画像を貼り付けたり、OCR テキストを編集可能なテキストとして貼り付けたりできます。

### 設定の説明

| 設定項目 | プロダクトデフォルト値 | 推奨開始値 | 役割 | 適用シーン | 注意事項 |
| ------ | ---------------------- | ------------- | ----------- | ------------ | -------------- |
| スクリーンショットを有効にする | 無効 | 必要時にオンにする | グローバルスクリーンショットショートカットキーを登録する | 日常のスクリーンショット、チュートリアル、問題フィードバック | macOS では画面録画権限が必要 |
| スクリーンショットショートカットキー | `Command/Ctrl+Shift+A` | デフォルトを維持し、競合時にのみ変更 | 任意のアプリケーションからスクリーンショットをトリガーする | 高頻度でのアプリケーション間での使用 | 他のアプリケーションと競合するとトリガーされない |
| テキストの自動認識 | 有効 | スクリーンショットのテキストを頻繁にコピーする場合、有効のままにする | スクリーンショット後に自動的に OCR を実行する | エラースクリーンショット、テーブル、UI テキスト | ローカル OCR モデルのダウンロードが必要 |

### ユーザー事例

テスト担当者が設定エラーをスクリーンショットし、矩形でエラーメッセージを囲み、モザイクでアカウントとローカルパスを隠し、問題フィードバックアシスタントにコピーしました。その後、同じスクリーンショットからエラーコードをコピーし、再現手順に貼り付けて、手動入力による誤りを回避しました。

### よくある質問

<details>

<summary>ショートカットキーを押しても反応がない場合はどうすればよいですか？</summary>

【スクリーンショットを有効にする】がオンになっていることを確認し、ショートカットキーの横に競合の警告が表示されていないか確認してください。macOS では画面録画権限を確認し、権限付与後に再起動してください。Windows と Linux では、システムで使用されていない別の組み合わせを試すことができます。

</details>

<details>

<summary>テキストをコピーできないのはなぜですか？</summary>

【設定】→【ローカルモデル】を開き、OCR モデルのステータスが「準備完了」であることを確認してください。アノテーション中はテキストを認識できません。現在のアノテーションを完了または取り消してから、OCR を実行してください。

</details>
