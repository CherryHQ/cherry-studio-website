# 高効率ワークベンチ

Cherry Studio のメインウィンドウは、サイドバー、タブ、コンテンツエリアで構成されています。対話トピックと Agent タスクは複数のタブで同時に開くことができ、独立したウィンドウに分割することも可能です。また、入力エリアのツールバーは使用習慣に合わせて調整できます。

<figure><img src="../../../../assets/b695c03a2d68db6c3e947867.webp" alt="高効率ワークベンチ — 説明画像"><figcaption><p>資料とタスクを同時に確認する必要がある場合は、そのうちの1つのタブを新しいウィンドウで開き、メインウィンドウでは全体の流れを維持します。</p></figcaption></figure>

### 独立ウィンドウが適したシナリオ

* 資料の対話を維持しながら、Agent タスクを実行する
* 長期監視タスクを固定表示し、他のウィンドウに隠れないようにする
* 異なるモニターで対話、ファイル、タスクをそれぞれ配置する
* タスクをデモや共有する際、メインウィンドウ内の他のタブを露出させない

### ワークベンチの機能

| 機能 | アクセス方法 | 役割 |
| ------ | -------------------- | -------------- |
| 新しいタブ | トピックまたはタスクの右クリックメニュー→【新しいタブで開く】 | メインウィンドウ内で複数のコンテキストを並べて保持する |
| 独立ウィンドウ | トピック、タスク、またはタブの右クリック→【新しいウィンドウで開く】 | 現在のコンテンツを新しいウィンドウに分割する |
| タブ固定 | タブの右クリック→【タブを固定】 | よく使うページを固定する |
| ウィンドウ固定 | 独立ウィンドウ上部の【ウィンドウを固定】 | タスクを常に表示可能にする |
| メインウィンドウに戻る | 独立ウィンドウ上部の【メインウィンドウに戻る】 | タブをメインウィンドウに再接続する |
| カスタムツールバー | 入力エリアの【+】→【ツールバーをカスタマイズ】 | よく使う入力ツールの位置を調整する |

上記の図のタブメニューで【新しいウィンドウで開く】を選択すると、現在のコンテンツを独立ウィンドウに分割できます。

### 推奨レイアウト

オフィスでの執筆作業では、資料の対話をメインウィンドウに残し、「執筆」Agent を右側のスクリーンに分割します。コード作業では、Agent タスクを固定表示し、メインウィンドウにはファイルとドキュメントを保持します。長時間の監視タスクには独立ウィンドウを使用しますが、頻繁に権限確認が必要なタスクは、見えない場所に配置しないでください。

{% hint style="info" %}
独立ウィンドウも同じ Cherry Studio のデータ環境に属しています。新しいアカウントやプライバシー空間ではありません。同じトピックまたはタスクの内容は引き続き同期保存されます。
{% endhint %}
