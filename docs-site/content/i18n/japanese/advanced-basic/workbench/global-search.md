# グローバル検索

グローバル検索では、メッセージ、会話、タスク、アシスタント、Agent、ナレッジベースを単一の入口から検索できます。「内容は覚えているが、どこに保存したか覚えていない」場合に適しています。

<figure><img src="../../../../assets/c88f597e18a3b7eac541dbf7.webp" alt="グローバル検索 — 説明画像"><figcaption><p>識別しやすいキーワードを入力し、その後、会話やナレッジベースなどのタイプと更新日時で範囲を絞り込みます。</p></figcaption></figure>

## 使用方法

{% stepper %}
{% step %}
### 1. ウィンドウ上部の検索ボタンをクリック

【設定】→【ショートカットキー】で対応するショートカットキーを確認または変更することもできます。
{% endstep %}

{% step %}
### 2. 識別しやすいキーワードを入力

プロジェクト名、人名、ファイルの主題、または結論内のフレーズを優先的に使用してください。「設定」や「レポート」などの一般的な単語のみを入力すると、結果が多すぎる場合があります。
{% endstep %}

{% step %}
### 3. 検索範囲を絞り込む

【メッセージ】に切り替えるか、【会話】【タスク】【アシスタント】【エージェント】【ナレッジベース】で絞り込み、さらに更新日時で範囲を狭めます。
{% endstep %}

{% step %}
### 4. 結果を開いて作業を継続

検索により対応するコンテンツに戻ります。開く前にタイプを確認し、同名のアシスタントと Agent タスクを混同しないようにしてください。
{% endstep %}
{% endstepper %}

### 応用例：先月の顧客結論の検索

顧客プロジェクト名を検索し、タイプを【メッセージ】に絞り込み、更新日時を制限します。結論を見つけたら元の会話を開き、その後修正があるか確認します。結論を新しいタスクに使用する場合は、記憶にある断片的な情報に頼るのではなく、確認済みの要約をコピーしてください。

<details>

<summary>なぜディスク内のファイル内容は検索できないのですか？</summary>

グローバル検索は主に Cherry Studio に保存済みのコンテンツを検索します。ディスク上のファイルは、Agent の作業ディレクトリ、ナレッジベース、またはノートで対応するフローを経た後、それぞれの入口から検索できます。

</details>
