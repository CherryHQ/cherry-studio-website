# スキルと能力ライブラリ

スキルは再利用可能な作業手順と関連リソースのセットです。外部システムへの接続を担うのではなく、Agent がどのようなフロー、基準、フォーマットでタスクを完了すべきかを指示します。

{% hint style="success" %}
特定の作業方法が必要な場合は、まず【作業】で Agent に目標を伝え、適切なスキルの検索またはインストールを依頼してください。出所の確認、一括管理、ローカルからのインポートが必要な場合のみ、【設定】→【スキル】を開いてください。
{% endhint %}

<figure><img src="../../../../assets/cc38d8a6378ca8270ceda746.webp" alt="スキルと能力ライブラリ — 説明画像"><figcaption><p>繰り返し使用する手法はスキルとして定着させるのが適しています。資料、組み込み操作、外部システムにはそれぞれ対応するエントリポイントを使用してください。</p></figcaption></figure>

### スキルのインストール

手動パス：【設定】→【スキル】。

ページでは4つのソースに対応しています：

* オンラインでスキルレジストリを検索；
* オンライン検索で【GitHub】を選択し、特定のスキルの `SKILL.md` ファイルのリンクを貼り付け；
* ローカルの ZIP ファイルからインストール；
* `SKILL.md` を含むフォルダからインストール。

<figure><img src="../../../../assets/f0dcb151fa939ce15cda1e00.webp" alt="スキルと能力ライブラリ — 説明画像"><figcaption><p>① 【GitHub】を選択後、対象スキルの `SKILL.md` ファイルリンクを貼り付けます。ページはまず具体的なスキルを解析し、その後インストールを提供します。</p></figcaption></figure>

{% stepper %}
{% step %}
#### 1. 用途の確認

スキルに解決させたい問題を一言で説明してください。例：「会議記録を決定事項、責任者、締切日に整理する」。名称が似ていてもフローが同じとは限りません。説明を確認してからインストールしてください。
{% endstep %}

{% step %}
#### 2. ソースと内容の確認

スキル詳細を開き、Agent に何を要求するか、スクリプトが含まれるか、追加のツールや外部アカウントが必要かを確認してください。出所不明のスキルを機密ディレクトリに直接使用しないでください。
{% endstep %}

{% step %}
#### 3. Agent へのバインド

まず【設定】→【スキル】で、そのスキルのグローバルスイッチが有効になっていることを確認し、次に【作業】→ Agent メニュー→【編集】→【スキル】を開いて、この Agent に対して有効にしてください。スキルの切り替えは Agent の設定とともに自動保存され、次のメッセージから有効になります。
{% endstep %}

{% step %}
#### 4. 実際のタスクでの検証

Agent に小さなサンプルを与え、手順、出力フォーマット、境界条件が期待通りであることを確認してから、バッチタスクや定期タスクに使用してください。
{% endstep %}
{% endstepper %}

### グローバル有効化と Agent 有効化

<figure><img src="../../../../assets/a05d3125f16b5cb41dd2e05b.webp" alt="スキルと能力ライブラリ — 説明画像"><figcaption><p>① カード右側のスイッチは、スキルがすべての Agent で選択可能かどうかを制御します。オフにすると、Agent 編集ウィンドウにそのスキルが表示されなくなります。</p></figcaption></figure>

| 状態 | 作用 | 使用タイミング |
| -------- | ------------------------ | ------------------------- |
| グローバル有効化 | スキルを Agent の選択可能スキルディレクトリに表示する | スキルのソースが信頼でき、1つ以上の Agent で使用される可能性がある場合 |
| グローバル無効化 | すべての Agent によるスキルの使用を一時停止するが、インストール内容は保持する | 一時停止、トラブルシューティング、またはセキュリティチェック待ちの場合 |
| Agent 有効化 | 現在の Agent のみでそのスキルを読み込む | フローが現在の Agent の長期的な責務と一致する場合 |

<figure><img src="../../../../assets/f0dcb151fa939ce15cda1e00.webp" alt="スキルと能力ライブラリ — 説明画像"><figcaption></figcaption></figure>

グローバルスイッチをオフにしてもスキルはアンインストールされません。再度オンにした後、各 Agent の有効化状態を確認する必要があります。アンインストールすると、スキル内容が削除され、関連付けがクリーンアップされます。

### スキル、プロンプト、MCP の使い分け

| 必要事項 | 選択すべきもの | 理由 |
| -------------- | ----------- | ------------- |
| 一時的な要求 | 現在のタスクプロンプト | 長期的な設定を追加する必要がないため |
| 同じフローの複数回再利用 | スキル | 説明、テンプレート、リソースを同時に保存できるため |
| Agent の長期的な役割の設定 | Agent システムプロンプト | すべてのタスクで遵守する必要があるため |
| データベースや外部サービスへのアクセス | MCP | スキル自体には接続機能がないため |

### ユーザー事例：チーム週報スキル

チームは週報の欄、トーン、データチェック、禁止表現をスキルとして作成し、「週報整理」Agent にバインドしました。毎週は当週の資料を提供するだけで、Agent はスキルに従って固定構造で出力します。データが外部システムから取得される場合は、MCP を組み合わせ、アカウントやインターフェースの詳細をスキル本文に書き込まないでください。

{% hint style="danger" %}
スキルのアンインストールは、グローバル能力ライブラリから削除し、Agent ワークスペース内の関連付けをクリーンアップします。実行前に、そのスキルを使用しているタスクがないことを確認してください。チームカスタムスキルは、復元可能なソースファイルを保持してください。
{% endhint %}

<details>

<summary>インストール後、なぜ Agent がスキルを使用しないのですか？</summary>

まず、スキルがグローバルで無効化されていないことを確認し、次に Agent 編集ウィンドウの【スキル】で有効にしてください。または、Agent にバインドを完了させるよう依頼してください。その後、新しいメッセージを送信してテストしてください。

</details>

<details>

<summary>スキルにプログラムを含めることができますか？</summary>

スキルパッケージには、説明、リソース、スクリプトを含めることができます。スクリプトを実行できるかどうかは、Agent のツール、作業ディレクトリ、環境依存、権限モードにも依存します。

</details>
