# MCP と外部ツール

MCP は、Agent が外部ツールやリソースを利用するための接続方法です。Cherry Studio では、MCP サーバー、組み込みサーバー、サービスマーケット、および一部のサービスプロバイダーのエントリを管理し、接続済みのサーバーを特定の Agent にバインドできます。

<figure><img src="../../../../../assets/79e45524b78de312b0ea7d2b.webp" alt="MCP と外部ツール — 説明画像"><figcaption></figcaption></figure>

* Agent が Cherry Studio の組み込みツール以外のサービスを呼び出す必要がある場合
* チームがすでに MCP インターフェースを提供するデータベース、ブラウザ、または業務システムを持っている場合
* 複数の Agent で同じ外部機能を再利用したい場合
* ツール、リソース、プロンプトをモデルに統一した方法で提供したい場合

固定されたフローのみであればスキルを使用し、Cherry Studio のナレッジベースの検索のみであればナレッジベースを直接バインドしてください。「より高度にしたい」からといって、MCP を追加構築する必要はありません。

### サーバーの追加

パス：【設定】→【MCP】→【MCP サーバー】→【追加】。

{% stepper %}
{% step %}
#### 1. 接続方法の確認

ローカルコマンドは通常、標準入力/出力方式を使用します。リモートサービスは通常、SSE またはストリーミング可能な HTTP アドレスを提供します。サービスプロバイダーが提供する設定に従って入力し、名称を頼りに推測しないでください。
{% endstep %}

{% step %}
#### 2. 設定の入力と権限の確認

ローカルサーバーにはコマンド、引数、環境変数が必要です。リモートサーバーには URL が必要で、一部のサービスでは認可も必要です。保存前に、コマンドのソースとデータ範囲を確認してください。
{% endstep %}

{% step %}
#### 3. 起動とツールの確認

サーバーを有効化し、状態が正常になるのを待ってから、詳細を開いて提供されるツール、リソース、プロンプトを確認してください。接続に失敗した場合は、まずサーバーログを確認してください。

ツールリストで特定のツールを展開すると、完全な Markdown 説明、および階層別に表示されるパラメータ、型、必須マーク、列挙値を確認できます。呼び出す前に必須パラメータを確認してください。オブジェクトまたは配列のパラメータは、入力形式をツール名だけで推測しないよう、階層ごとに展開して確認してください。
{% endstep %}

{% step %}
#### 4. Agent へのバインド

【ワークスペース】→ Agent メニュー →【編集】→【MCP】を開き、そのサーバーを有効化してください。未起動のサーバーは正常にバインドして使用できません。
{% endstep %}
{% endstepper %}

### 組み込みサーバーとサービスマーケット

【組み込み MCP】では、直接インストールまたは有効化できる一般的な機能を提供します。【サービスマーケット】は、サードパーティのマーケットソースを管理するために使用します。インストール前に、説明、コマンド、環境変数、権限を確認してください。組み込みエントリであっても、外部サービスのすべての操作がリスクフリーであるわけではありません。

<figure><img src="../../../../../assets/3892f8eaa6ef4645921a382d.webp" alt="MCP と外部ツール — 説明画像"><figcaption><p>① 組み込みリストでは、アカウント、API Key、ディレクトリ設定が必要かどうかを示します。インストール後も設定を完了し、接続を検証してください。</p></figcaption></figure>

QVeris は【組み込みサーバー】にあり、Agent が外部機能を発見、確認、呼び出すために使用されます。インストール後は `QVERIS_API_KEY` の設定が必要です。キーを Agent のプロンプト、スキル、公開スクリーンショットに書き込まないでください。

### 入力エリアでの MCP プロンプトとリソースの使用

サーバーはツールに加えて、「プロンプト」と「リソース」を提供する場合があります。サーバーが現在のアシスタントまたは Agent にバインドされた後、入力エリアの【+】パネルを開きます：

* 【MCP プロンプト】を選択し、サーバーのテンプレートを入力欄に挿入します。テンプレート内の必須パラメータは入力可能な項目として表示されます。
* 【MCP リソース】を選択し、バインド済みのサーバーからファイル、レコード、その他のリソースを選択します。
* 短いテキストリソースは入力欄に直接挿入されます。大きいリソースまたはバイナリリソースは参照として扱われ、ツール呼び出しをサポートするモデルが必要に応じて読み取ります。

{% hint style="info" %}
パネルには、現在の会話範囲内で接続済みであり、実際に対応する機能を提供しているサーバーのみが表示されます。【MCP プロンプト】または【MCP リソース】が表示されない場合は、まずサーバーの詳細で対応するタブを確認し、次に現在のアシスタントまたは Agent がそのサーバーにバインドされていることを確認してください。
{% endhint %}

### 設定の推奨事項

| 設定項目 | 製品デフォルト値 | 推奨開始点 | 役割 | 適用シーン | 注意事項 |
| -------- | -------------- | ----------------- | --------- | ------------- | ------------ |
| サーバー状態 | 追加後、設定によって決定 | 一度に1つだけ有効化して検証 | サーバーの利用可否を制御 | 初回接続、トラブルシューティング | 複数のサービスが同時に失敗すると原因特定が困難 |
| Agent バインド | すべてのサーバーを自動バインドしない | 現在の Agent に必要なサーバーのみバインド | 機能範囲を制御 | 複数 Agent の分担 | 無関係なツールがコンテキストを占有するのを避ける |
| 環境変数 | キーを事前に入力しない | サービスが要求する最小権限の認証情報を使用 | 認証または実行パラメータを提供 | プライベートサービス | スクリーンショットやエクスポート前に機密情報を隠す |
| ツール承認 | Agent の権限モードによって決定 | 書き込みまたは課金ツールは確認を維持 | 意図しない操作を防ぐ | データベース、ファイル、外部 API | チャネルエントリではより厳格なモードを使用可能 |

### ユーザー事例：プロジェクトデータベースを分析 Agent に接続

管理者が読み取り専用の MCP 接続を提供し、ユーザーは【設定】→【MCP】でサーバーが正常であることを確認した後、「データ分析」Agent にのみバインドします。Agent は読み取り専用ツールを使用してデータを取得し、レポートをワークディレクトリに書き込みます。データ更新に関わるツールは有効化しません。これにより、プロンプトに誤解が生じても、業務データベースを直接変更することはありません。

<details>

<summary>MCP と API ゲートウェイの違いは何ですか？</summary>

MCP は外部ツールを Cherry Studio に接続するためのものです。API ゲートウェイは、Cherry Studio のモデル機能を互換性のある API として他のプログラムに提供するものです。データフローの方向は逆です。

</details>

<details>

<summary>サーバーは接続済みと表示されているが、Agent がツールを見つけられない場合はどうすればよいですか？</summary>

Agent がそのサーバーにバインドされているか、ツールが無効化されていないか、権限リクエストが保留されていないかを確認してください。Agent の設定を変更した後、新しいメッセージを送信してランタイムが新しいツールを読み込むようにしてください。

</details>
