# MCP トラブルシューティング

<details>

<summary>サーバーを削除して再追加すべきですか？</summary>

まずログを確認し、項目ごとに修正してください。設定が混乱しており、ソースを再取得できる場合のみ削除して再構築してください。削除前に、認証情報（シークレット）を含まない設定のコピーを保存してください。

</details>
