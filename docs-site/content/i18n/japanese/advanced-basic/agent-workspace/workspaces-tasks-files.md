# ワークスペース、タスク、ファイル


<details>

<summary>どのファイルを直接編集できませんか？</summary>

バイナリファイル、UTF-8 以外のテキスト、および大容量のファイルは、プレビューまたは外部アプリでの開きのみがサポートされます。これらのファイルは Agent ツールによって処理できますが、組み込みエディタで編集できる保証はありません。

</details>
