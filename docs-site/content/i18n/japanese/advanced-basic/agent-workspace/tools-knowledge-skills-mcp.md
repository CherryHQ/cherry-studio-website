# 組み込みツール、ナレッジベース、スキルと MCP

これら4つの機能はすべて Agent を強化しますが、解決する課題が異なります。組み込みツールは一般的な操作を担当し、ナレッジベースは検索可能な資料を限定し、スキルは作業方法を提供し、MCP は外部ツールやデータに接続します。

### 違いと組み合わせ

<figure><img src="../../../../assets/6be829efa6152cf0a3576cba.webp" alt="組み込みツール、ナレッジベース、スキルと MCP — 説明画像"><figcaption></figcaption></figure>

| 機能 | 解決する課題 | 例 |
| ---- | ----------------------------- | ------------------------- |
| 組み込みツール | Agent が Cherry Studio 内で直接実行できること | ファイルの読み書き、Web検索、画像生成、メモリ、通知、スケジュールタスク |
| ナレッジベース | Agent が検索できるプライベート資料 | 製品仕様、契約書テンプレート、チームマニュアル |
| スキル | Agent が従うべきプロセスと基準 | 週報の形式、コードレビューチェックリスト、ライティング規範 |
| MCP | Agent が接続できる外部ツールとリソース | データベース、ブラウザ、サードパーティの業務システム |

設定パス：左側ナビゲーション【作業】→ Agent メニューを開く →【編集】→【組み込みツール】。

### 組み込みツール

組み込みツールは、コンテキスト、ファイル、マルチメディア、オーケストレーション、検索、ターミナルに分類されています。よく使われる機能には以下が含まれます：

* 【画像生成】：設定済みの描画モデルを使用します；
* 【ナレッジベース検索】と【ナレッジベース管理】：ナレッジベースがバインドされた場合のみ表示されます；
* 【Web検索】と【Webスクレイピング】：Cherry Studio で設定済みのオンライン機能を使用します；
* 【メモリ】：タスク間で安定した情報を保存・検索します；
* 【スケジュールタスク】と【通知】：Agent が計画を管理し、チャンネルに結果を送信します；
* 【Task】と【ワークフロー】：サブエージェントまたはオーケストレーションを使用して複雑なタスクを処理します；
* 【ファイルを Markdown に変換】：作業ディレクトリまたは現在のセッションの添付ファイルにある PDF、Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV を読み取り、構造化された内容を Agent に渡して分割処理します；
* セッション調整ツール：既存の Agent セッションを検索し、新しい独立したセッションを作成し、タスクを送信して追跡可能な完了結果を受信します；
* ファイルと Bash ツール：ファイルの読み取り、作成、変更およびコマンドの実行。

{% hint style="info" %}
【ファイルを Markdown に変換】は元のファイルを書き換えず、スキャン版 PDF の OCR も提供しません。スキャン版は先に【OCR】またはドキュメント処理機能を使用し、その後 Agent に渡してください。
{% endhint %}

### ナレッジベースの範囲

【ナレッジベース】で選択したナレッジベースは、その Agent の検索境界です。未選択の場合、ナレッジベースツールは読み込まれません。複数選択した場合、Agent はこれらのナレッジベース内でのみ動作し、他の資料ライブラリを自動的に読み取りません。

### スキル

【スキル】でインストール済みのスキルを有効にします。スキルの内容は Agent の作業環境に入り、プロセスと出力を制約するために使用されます。新しいスキルが必要な場合は、【作業】で Agent に直接検索とインストールを依頼できます。手動管理のパスは【設定】→【スキル】です。

### MCP

まず【設定】→【MCP】でサーバーを接続して起動し、次に Agent の編集ウィンドウの【MCP】でバインドします。実行されていないサーバーは有効にできません。接続後、そのサーバーが提供するツールは Agent のツールディレクトリに入り、権限モードによる制御が続きます。サーバーがリソースやプロンプトも同時に提供する場合は、入力エリアの【+】パネルから直接選択して使用できます。

{% hint style="danger" %}
ツールを開くことは、承認をスキップすべきであることを意味しません。ファイル書き込み、ターミナル、外部データの修正、課金される可能性のある画像生成については、【逐次確認】を優先的に維持してください。信頼できるソースでリスクが明確なツールに対してのみ、より緩やかな権限を使用してください。
{% endhint %}

### 推奨組み合わせ

| タスクの要件 | 推奨組み合わせ | 追加するタイミング | 注意事項 |
| -------- | ------------- | ------------- | ------------- |
| ローカルファイルの処理 | ファイルツール + 専用作業ディレクトリ | 固定形式が必要な場合にスキルを追加 | まず【逐次確認】を維持 |
| 社内資料に基づく回答 | ナレッジベース + ナレッジベース検索 | 検索結果が安定してからチャンネルに渡す | まず回答がない問題のテストを行う |
| 固定プロセスの繰り返し実行 | スキル + 必要な組み込みツール | 外部データが必要な場合に MCP を追加 | スキルにアカウントキーを保存しない |
| 外部システムの呼び出し | MCP + 最小権限の認証情報 | タスクが安定してから承認を緩和 | 書き込み、削除、課金操作は確認する |

### ユーザー事例：市場調査 Agent

Agent に製品資料のナレッジベースをバインドし、「調査レポート」スキルを有効にし、信頼できる Web 検索 MCP を接続し、組み込みの Web スクレイピングとファイル書き込みツールを維持します。Agent はまず社内資料で製品範囲を確定し、次に外部情報を検索し、最後にスキルで規定された構造に従って作業ディレクトリに書き込みます。社内資料、外部ソース、出力形式それぞれに明確な帰属があり、後のメンテナンスが容易になります。

<details>

<summary>なぜナレッジベースをバインドしても検索結果がないのですか？</summary>

ナレッジベースが処理完了しており、検索可能な内容を含むことを確認し、次に Agent の編集ウィンドウでのバインドがまだ存在するか確認してください。ナレッジベースが削除されると、関連するバインドは自動的に削除されます。

</details>

<details>

<summary>スキルを有効にした後、タスクを再開する必要がありますか？</summary>

タスクを閉じる必要はありません。Agent を編集した後、次のメッセージから新しいスキル設定が読み込まれます。生成中の返信は中断されません。

</details>
