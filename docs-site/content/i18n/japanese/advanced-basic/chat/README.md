# チャット高度化

【チャット】は、対話しながら思考を整理するのに適しています。単一モデルの質問応答だけでなく、複数のモデルを並べて比較したり、任意のメッセージから分岐を作成したり、長い会話のコンテキストを管理したり、返信内のファイル、画像、コード、引用を成果物として引き続き利用したりできます。

{% hint style="info" %}
タスクにローカルファイルの連続的な読み書き、複数のツールの呼び出し、長時間の実行が必要な場合は、【ワーク】の Agent を使用してください。チャットは議論、比較、最終化に適しており、Agent は実行に適しています。
{% endhint %}

<figure><img src="../../../../assets/5c0f5f563432facacf7942d6.webp" alt="チャット高度化 — 説明画像"><figcaption><p>質問と出力要件は最初に完全に記述してください。相互検証が必要な場合のみ、モデル比較やメッセージ分岐を追加してください。</p></figcaption></figure>

## 目的に応じた機能の選択

| 目的 | 推奨アクション |
| ------------- | --------------------- |
| 異なるモデルの視点の比較 | 入力欄で複数のモデルを選択し、同じ質問を送信する |
| 元の議論を保持しつつ別のアプローチを探索する | 重要なメッセージから分岐を作成する |
| 非常に長い議論を続ける | コンテキスト使用量を確認し、必要に応じて要約してから新しいトピックを開始する |
| 次の質問を後で送信する | メッセージキューを使用し、現在の返信を中断しない |
| 返信内のファイルやコードを処理し続ける | 成果物プレビューを開き、ダウンロード、コピー、または新しいタスクで続行する |

<figure><img src="../../../../assets/290e0288048d57cd868cb443.webp" alt="チャット高度化 — 説明画像"><figcaption><p>モデルセレクターでは、同じ質問に対して1つ以上のモデルを選択できます。</p></figcaption></figure>

## 推奨手順

{% stepper %}
{% step %}
### 1. まず質問を完全に記述する

目的、資料、制約、希望する出力形式を説明してください。複数のモデルは元の質問の差異を拡大するだけで、欠落した情報を自動的に補完するわけではありません。
{% endstep %}

{% step %}
### 2. 次に比較が必要かどうかを決定する

異なる視点が必要な場合にのみ複数のモデルを選択してください。日常的な質問応答では単一モデルを維持し、インターフェースを明確にし、使用量の管理を容易にしてください。
{% endstep %}

{% step %}
### 3. 有効な結論を蓄積する

再利用可能な資料はノートやナレッジベースに保存し、継続的な実行が必要な作業は Agent に引き継ぎ、確認済みの結論を添付してください。
{% endstep %}
{% endstepper %}
