# 自動化と外部連携

Cherry Studio の自動化は単一の「ロボット設定」ではありません。Agent がタスクを実行し、チャネルが外部プラットフォームからのメッセージの送受信を担当し、スケジュールタスクが指定時刻に Agent を起動し、ハートビートが Agent に継続的なタスクを周期的に確認させます。

<figure><img src="../../../../assets/c348e2cb27a028b3789ac09b.webp" alt="自動化と外部連携 — 説明画像"><figcaption><p>トリガー、実行、通知、実行履歴は異なる段階です。まず手動で Agent を正常に動作させ、その後段階的に連携を設定してください。</p></figcaption></figure>

## 4つの機能の連携

| 機能 | 役割 | 一般的な用途 |
| ----- | --------------- | ------------------ |
| Agent | タスクを実行し結果を生成 | 集計、チェック、執筆、ファイル処理 |
| チャネル | 外部メッセージを受信し通知を送信 | 飛書グループボット、Telegram プライベートチャット |
| スケジュールタスク | 明確な時刻に Agent を実行 | 日報、週報、一回限りのリマインダー |
| ハートビート | Agent が間隔を空けて継続タスクを確認 | 長時間フローの監視、未処理事項の確認 |

<figure><img src="../../../../assets/e2328ba60a3ff5012831c39e.webp" alt="自動化と外部連携 — 説明画像"><figcaption><p>チャネルは、Agent を飛書、Telegram、QQ、WeChat、Discord または Slack に接続する役割を担います。</p></figcaption></figure>

## 正しい設定手順

{% stepper %}
{% step %}
### 1. まず【ワークスペース】でタスクを実行する

Agent のモデル、プロンプト、作業ディレクトリ、ツールが期待通りの結果を安定して生成できることを確認してください。
{% endstep %}

{% step %}
### 2. 次に Agent にチャネル設定を案内させる

Agent の対話内でプラットフォームと用途を説明します。例：「この Agent を飛書グループに接続し、日報リクエストの受信に使用する」。指示に従ってボットの権限と認証情報を準備してください。
{% endstep %}

{% step %}
### 3. 手動設定で状態を確認する

【設定】→【チャネル】を開き、認証情報、バインドされた Agent、ワークスペース、許可されたセッション範囲、チャネル権限モードを確認し、テストメッセージを送信してください。
{% endstep %}

{% step %}
### 4. 最後にスケジュールタスクを作成する

Agent に直接作成させることも、【設定】→【スケジュールタスク】→【新規作成】を開くこともできます。検証済みの Agent、ワークスペース、時刻、通知チャネルを選択してください。
{% endstep %}
{% endstepper %}

## 公開前のチェックリスト

* チャネルは必要なセッションまたはチャネル ID のみを許可する；
* 外部入口は【エージェント設定を継承】またはより厳格な権限を使用する；
* スケジュールタスクのプロンプトに変動するシークレットやパスを含めない；
* まず手動で【実行】し、実行記録を確認する；
* 失敗時は Cherry Studio 内で対応するタスクを見つけ、「未送信」を「未実行」と誤認しない。

## ユーザー事例：平日の運営日報

「運営日報」Agent は作業ディレクトリからデータを読み取り、チームのスキルに基づいて日報を生成します。飛書チャネルが結果を指定グループに送信し、スケジュールタスクが各平日の朝に実行します。公開前にまず手動で実行し、次に飛書でボットにメッセージを送信して受信ターゲットを確立し、最後にスケジュールを有効にします。

<details>

<summary>ハートビートとスケジュールタスクの違いは何ですか？</summary>

ハートビートは Agent に間隔を空けて継続タスクを確認させ、「新しい状況があるか」に適しています。スケジュールタスクは明確な実行計画と実行記録を持ち、「毎日何時に何をやるか」に適しています。固定の日報にはスケジュールタスクを優先的に使用してください。

</details>
