# 定期タスク、ハートビートと実行履歴

<details>

<summary>タスクは実行されましたが、チャンネルにメッセージが届かない場合はどうすればよいですか？</summary>

まず【実行履歴】を確認し、Agent が正常に完了したかを確認してください。タスクが成功した場合は、チャンネルの受信先を確認してください。タスクが失敗した場合は、【会話を表示】をクリックし、モデル、権限、ワークスペース、ツールエラーを確認してください。

</details>
