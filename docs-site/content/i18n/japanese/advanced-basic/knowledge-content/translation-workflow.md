# ファイル、画像、長文の翻訳

【翻訳】では、直接入力したテキストだけでなく、画像やドキュメントも処理できます。画像はまず文字を認識し、ドキュメントはフォーマットと内容に基づいて処理されます。履歴はブックマーク、再オープン、再利用が可能です。

<figure><img src="../../../../assets/31b376b5d5a233eeb71ddf12.webp" alt="ファイル、画像、長文の翻訳 — 説明画像"><figcaption><p>翻訳はコンテンツワークフローの一部です。まず入力資料を確認し、用語を統一し、最終成果物をチェックします。</p></figcaption></figure>

### 入力方法の選択

| 資料 | 推奨手順 | チェックポイント |
| -------- | -------------------- | ---------------- |
| 短いテキスト | 直接貼り付け | トーン、固有名詞、文脈 |
| スクリーンショットまたはスキャン | 画像をアップロードして OCR を使用 | 認識誤り、表、数値 |
| PDF | ファイルをアップロードし、BabelDOC のインストールを選択 | 2カラムレイアウト、フォント、表、脚注、ページ数 |
| その他の長文ドキュメント | ファイルをアップロード | 見出し階層、段落、脚注、フォーマット |
| Markdown | プレビューで確認 | リンク、コードブロック、マークアップの保持 |

#### 例：短いテキストの翻訳

ソース言語に【自動検出】、ターゲット言語に【英語】を選択し、中国語を入力して【翻訳】をクリックします。結果が表示されたら、「グレースケール」「監視メトリクス」「ロールバック手順」などの重要な意味を確認し、コピーまたはノートに保存します。

<figure><img src="../../../../assets/5428125ff9f2c41e29e8c2ed.webp" alt="ファイル、画像、長文の翻訳 — 説明画像"><figcaption><p>① 左側に原文を保持；② 右側に訳文を表示。納品前にグレースケールリリース、監視メトリクス、ロールバック手順を項目ごとに照合します。</p></figcaption></figure>

#### 結果表示後のチェック項目

| チェック項目 | 例 |
| ----- | ------------------ |
| 重要な意味 | 「グレースケールリリース」は色のみで直訳しない |
| 固有名詞 | 製品名、チーム名、機能名を統一する |
| 数値と条件 | 日付、比率、金額、否定語を漏らさない |
| トーン | 通知、契約、マーケティングコピーに適切なトーンを採用 |

短いテキストは文ごとに照合できます。ファイルや長文は、見出し、表、数値、繰り返し用語を抜き出して確認し、全文納品するか判断します。

### レイアウトを保持した PDF 翻訳

テキスト抽出可能な PDF をアップロードすると、ページが BabelDOC を検出します。初回使用時は【BabelDOC をインストール】を選択します。依存関係が準備できると、左側に原文プレビュー、右側に訳文 PDF が表示され、リソースチェック、解析、翻訳、レイアウト、レンダリングの順に進捗が表示されます。

{% stepper %}
{% step %}
#### 1. PDF をアップロードし依存関係を確認

【ドラッグまたはクリックして画像/ドキュメントをアップロード】をクリックして PDF を選択します。ページで不足またはバージョンが古いと表示された場合は、BabelDOC をインストールまたは更新します。インストールは Cherry Studio の【環境依存】で一元管理されます。
{% endstep %}

{% step %}
#### 2. 翻訳モデルとターゲット言語を選択

PDF 翻訳には、現在のモデルがローカル API ゲートウェイ経由で呼び出せる必要があります。モデルが利用できない場合は、【設定】→【モデルサービス】で接続を確認し、BabelDOC を繰り返しインストールしないでください。
{% endstep %}

{% step %}
#### 3. 2カラムの結果を照合

翻訳が完了したら、ページごとに原文と訳文を比較し、表、図注、ヘッダー/フッター、脚注、改行を重点的に確認します。ダウンロードボタンをクリックして訳文 PDF を別名保存できます。
{% endstep %}

{% step %}
#### 4. 履歴から継続

PDF 翻訳は【翻訳履歴】と【ファイル】に記録されます。履歴から2カラムプレビューを再オープンし、訳文ファイルを特定または別名保存できます。履歴を削除すると、対応する訳文ファイルも一緒に削除されます。
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
スキャン版または画像のみ PDF は、レイアウトを保持した翻訳に対応していません。ページで OCR が必要と表示された場合は、まず画像の文字を校正可能なテキストに認識し、通常の翻訳フローを使用します。
{% endhint %}

### 翻訳手順

{% stepper %}
{% step %}
#### 1. ソース言語とターゲット言語を確認

自動認識は混合または不明な言語に適しています。契約書、技術文書などの正式な資料では、誤判定を減らすため、言語を手動で確認することをお勧めします。
{% endstep %}

{% step %}
#### 2. 翻訳方法を選択

文脈、トーン、用語の統一が必要な場合は、設定済みのモデルを使用します。通常の短い文句には、より軽量な方法を選択できます。利用可能な項目は現在のページを基準とします。
{% endstep %}

{% step %}
#### 3. 区切りごとに照合

まず名称、数値、日付、否定語、単位を確認します。画像翻訳では OCR 結果も照合します。認識が誤っていると、後の訳文も誤りが伝播します。
{% endstep %}

{% step %}
#### 4. 結果をブックマーク、エクスポート、または再利用

【翻訳履歴】でテキスト訳文を表示、ブックマーク、再利用します。PDF 結果は2カラムプレビュー、ファイルオープン、別名保存が可能です。正式納品前に、用語集と人手による修正をプロジェクト資料に保存します。
{% endstep %}
{% endstepper %}

#### 応用ケース：多言語製品資料の準備

まず、製品名、機能名、変更禁止の用語を説明書にまとめます。中国語のマニュアルをアップロードし、まず1章を翻訳して用語を確認し、その後全文を処理します。宣伝画像は個別にアップロードして OCR 翻訳を行います。完了後、確認済みの用語と訳文をプロジェクト作業ディレクトリに配置し、Agent に見出し、リンク、数値の統一チェックを行わせますが、法的声明の独自変更は行わせないでください。

{% hint style="danger" %}
医療、法律、財務、セキュリティ関連の内容は、専門家の再確認が必要です。自動翻訳は効率を向上させますが、責任主体による校正を代替することはできません。
{% endhint %}
