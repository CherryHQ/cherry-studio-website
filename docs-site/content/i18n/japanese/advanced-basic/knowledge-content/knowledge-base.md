# 知識ベースの構築とリコールテスト

知識ベースは、ファイル、Webページ、メモを検索可能なチャンクに処理します。「資料にどう書かれているか」への回答に適していますが、モデルが文書全体を永続的に記憶するものではありません。

## 新規作成と資料のインポート

{% stepper %}
{% step %}
### 1. 【知識ベース】→【新規知識ベース】を開く

識別しやすい名前を入力し、利用可能な埋め込みモデルを選択してください。埋め込みモデルは資料を検索可能な表現に変換する役割を担い、対話で使用するメインモデルとは異なります。
{% endstep %}

{% step %}
### 2. 資料ソースを選択

ファイル、フォルダ、メモ、URLを追加できます。一般的なドキュメント形式にはPDF、DOCX、Markdown、Excel、TXT、CSVが含まれます。スキャン版は文字を取得するためにOCRが必要な場合があります。
{% endstep %}

{% step %}
### 3. 処理完了を待つ

ファイル詳細を開いてプレビューとチャンクを確認してください。タイトルが欠落している、文字化けしている、またはテーブル構造が失われている場合は、まず元のファイルを整理してから再処理してください。
{% endstep %}

{% step %}
### 4. リコールテストを実施

実際のユーザーが質問する内容でテストし、ファイル名のみを入力しないでください。返されたチャンクが関連性を持ち、完全なコンテキストを含むかを確認してから、Agentへのバインドを決定してください。
{% endstep %}
{% endstepper %}

### 実際の質問でリコール結果を検証する

資料が【準備完了】と表示されたら、業務で実際に発生する質問で一度テストしてください。例えば、規程ベースでは「海外でのレンタカーは経費精算できますか？」と質問し、返された内容が正しい資料からのものであるか、十分なコンテキストを含むかを確認します。

| 確認できる結果 | 次のステップ |
| --------------- | ----------------------- |
| 正しい資料にヒットし、チャンクで質問に回答できる | Agentにバインドして使用可能 |
| 資料は正しいが、チャンクが切り詰められている | まず原文の構造を確認し、チャンク長を調整 |
| 古い規程や無関係な資料にヒット | 期限切れの資料を整理し、より明確なタイトルと内容を補完 |
| 結果が全くない | 資料の状態と質問の表現を確認し、まず返却数を盲目的に増やさない |

{% hint style="info" %}
リコールテストに合格した後、Agent内で完全なQ&Aを検証してください。これにより、「資料が見つからない」のか、「資料は見つかったが回答が不適切」なのかを区別できます。
{% endhint %}

## RAG設定の理解

RAGとは「まず資料を検索し、その後モデルに回答させる」ことを指します。一般的な設定には、チャンク長、重複範囲、返却数、関連度しきい値が含まれます。

| 設定 | 役割 | 推奨の初期値 | 調整タイミング |
| ----- | -------------- | -------- | ------------------- |
| チャンク長 | 各検索チャンクに含まれる内容量を決定 | まずページの初期値を使用 | チャンクが文を頻繁に切り詰めたり、多くのトピックが混在したりする場合 |
| チャンク重複 | 隣接チャンクの接続を保持 | 少量の重複を維持 | 条項がチャンクをまたぎ、コンテキストが頻繁に途切れる場合 |
| 返却数 | 一度に提供する候補チャンク数 | 少量の結果から開始 | 重要な資料を見逃した場合は増加、ノイズが多い場合は減少 |
| 関連度しきい値 | 無関係な内容をフィルタリング | リコールテストで決定 | 無関係な結果が多い場合は引き上げ、正しいチャンクがフィルタリングされる場合は引き下げ |

### 応用ケース：社内規程Q&Aベースの構築

現行の規程を部門別に整理し、ファイル名にトピックと適用範囲を含めます。インポート後、「出張宿泊の上限超過時の対応」「試用期間中の休暇承認者は誰か」などの実際の質問でリコールテストを実施します。チャンクの正確性を確認した後、この知識ベースを「規程Q&A」Agentにのみバインドし、回答時に資料名を明示するよう求めます。欠落内容がある場合は、見つからなかったことを明確に伝えます。

{% hint style="warning" %}
知識ベースは、ファイルの有効期限を自動的に判断しません。規程、価格、プロセスが変更された場合は、古い資料を更新または削除し、リコールテストを再実施してください。
{% endhint %}

<details>

<summary>インポート後も結果が表示されないのはなぜですか？</summary>

ファイルの処理状態、埋め込みモデルの接続、ドキュメントプレビューを確認してください。スキャン版PDFで抽出可能な文字がない場合は、先にOCRを設定するか、検索可能なバージョンに置き換える必要があります。

</details>
