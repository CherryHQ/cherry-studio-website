# 画像の生成、編集と強化

【ペインティング】はテキストから画像を生成するだけでなく、参照画像の使用、指定領域の編集、複数画像の統合、テンプレートの再利用、解像度の強化にも対応しています。まず画像の用途を決定し、その後生成または編集の方法を選択してください。

## 適切な開始点の選択

| 要件 | 推奨方法 |
| ------------ | ------------ |
| 視覚的な方向性をゼロから作成 | テキストから画像生成またはテンプレート |
| 被写体を維持し、背景やスタイルを変更 | 参照画像をアップロードして編集 |
| 画像の一部のみを変更 | マスクを使用して修正領域を指定 |
| 複数の素材を1枚の画像に統合 | 複数画像の統合と主次関係の説明 |
| 既存の画像をより鮮明にする | 強化/拡大機能を使用 |

### 例：説明から完成品へ

【ペインティング】を開き、現在のタスクに対応する画像モデルを選択し、被写体、環境、スタイル、光、構図、制約条件を入力して送信します。プロンプトの例は以下の通りです：

> 朝光の中のクリエイティブなワークベンチ、チェリーレッドのデスクライト、スケッチブック、カメラ、桜の枝、窓の外には静かな山々；柔らかな3Dイラスト風、暖かい朝光、ワイド構図、テキストなし。

1. 用途と構図を明確にし、ペインティングモデルを選択します。
2. 最初のバージョンを生成し、被写体、エッジ、サイズを確認します。
3. まだ使用できない場合は、1つの方向性のみを変更し、再生成して確認します。
4. 使用可能と確認後、拡大して確認し、エクスポートします。

{% hint style="info" %}
この例では【GPT-Image-2 | express】を使用してワイドなワークベンチイラストを生成しています。モデル、サイズ、利用可能な操作は現在のページに表示される内容に従ってください；表示されていないパラメータはそのまま使用しないでください。
{% endhint %}

生成後すぐに離れるのではなく、まず拡大して被写体、エッジ、余分な要素を確認し、左側の履歴からバージョンを切り替えます。調整が必要な場合は、有効な説明を維持し、1つの方向性のみを変更してください。

## 使用可能な画像の完成

{% stepper %}
{% step %}
### 1. モデルとモードの選択

異なる画像モデルは、サポートするサイズ、参照画像、編集機能が異なります。ページに表示されていないパラメータは経験に基づいて無理に入力しないでください。
{% endstep %}

{% step %}
### 2. 用途と構図を明確にする

被写体、環境、視点、トーン、比率、余白、表示しない内容を説明します。タイトルを配置する場合、通常はモデルに余白を残させ、テキストはデザインツールで追加します。
{% endstep %}

{% step %}
### 3. 一度に1つの方向性のみ検証する

まず小規模な結果を生成し、最も近い画像を選択して編集または強化します。同時に複数生成すると使用量が増え、どの要件が機能しているかを判断しにくくなります。
{% endstep %}

{% step %}
### 4. 詳細を確認してエクスポートする

拡大して人物の手、製品構造、テキスト、ブランドロゴ、エッジを確認します。商業利用が必要な場合は、素材の出所と関連する利用規約を確認してください。
{% endstep %}
{% endstepper %}

### Agentでの画像生成

まず【設定】→【デフォルトモデル】で【ペインティングモデル】を選択し、次にAgentの【組み込みツール】を開いて【画像生成】が有効になっていることを確認します。その後、【ワーク】でAgentに記事を読み、視覚的な方向性を抽出し、直接関連画像を生成させることができます。

### 応用例：ブランドキャンペーン画像セットの作成

まずテンプレートで統一されたトーン、レンズ、余白ルールを決定し、横長のヘッダー画像を生成します。方向性を決定した後、同じ参照画像を使用して正方形のソーシャル画像と縦長のストーリー画像をそれぞれ作成します；製品の外観が不一致の場合は局所編集で修正し、最後に配信が必要なバージョンを強化します。全過程でモデルにブランドテキストを生成させず、誤字や変形を避けます。

{% hint style="warning" %}
参照画像は選択したモデルサービスに送信される可能性があります。顧客資料、人物像、未公開の製品画像をアップロードする前に、使用を許可するサービス範囲を確認してください。
{% endhint %}
