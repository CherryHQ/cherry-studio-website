# 多言語資料の整理

マーケティングチームは、ドキュメント、スクリーンショット、製品用語を含む資料セットを受け取り、別の言語に翻訳する必要があると同時に、名称、数値、フォーマットの一貫性を保つ必要があります。用語集と小規模な試行翻訳により、資料全体のやり直しを減らすことができます。

## 操作手順

{% stepper %}
{% step %}
### 1. まず用語集を作成する

製品名、機能名、人名、単位、変更不可の法的表現をリストアップします。各用語について、対象言語での使い方を明記します。
{% endstep %}

{% step %}
### 2. 短い段落でスタイルを調整する

【翻訳】でまず代表的なセクションを処理し、フォーマル度、見出しの書き方、用語を確認してから、ファイル全体を翻訳します。
{% endstep %}

{% step %}
### 3. 画像は個別に OCR チェックを行う

スクリーンショットをアップロードした後、まず認識されたテキストを照合します。特に数値、ボタン名、テーブルに注意してください。認識エラーは翻訳前に修正する必要があります。
{% endstep %}

{% step %}
### 4. Agent に一貫性チェックを行わせる

原文、翻訳、用語集を作業ディレクトリに配置し、Agent に用語の不整合、漏訳、数値の差異、リンクの問題をリストアップさせます。法的な内容は直接置換しません。
{% endstep %}
{% endstepper %}

## 納品前チェック

* 製品名と UI パスが実際の UI と一致していること；
* 数値、日付、通貨、単位に変更がないこと；
* Markdown リンク、コードブロック、画像キャプションが保持されていること；
* 法的、医療的、安全関連の内容が専門家のレビューを受けていること。

## 推奨組み合わせと完了基準

| 項目 | 推奨做法 |
| ---- | --------------------------------- |
| 翻訳入口 | 短いテキストとスクリーンショットは【翻訳】を使用し、複数ファイルの整理は Agent に任せる |
| 用語 | まず製品名、固有名詞、翻訳しない用語リストを提供する |
| ファイル | 原文と翻訳を別ディレクトリに保存し、元のファイル名との対応関係を保持する |
| 完了基準 | 数値、リンク、固有名詞が一致していること；画像内のテキストがサンプリングチェックされていること；レイアウトの変更は納品説明にマークされていること |

{% hint style="warning" %}
履歴は再利用に便利ですが、翻訳内容も保存されます。機密資料を処理した後、データ管理要件に従って履歴を確認し、クリーンアップしてください。
{% endhint %}
