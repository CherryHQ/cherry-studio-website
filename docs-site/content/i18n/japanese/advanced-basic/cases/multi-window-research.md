# マルチウィンドウ研究ワークベンチ

研究者は、資料やモデル比較を保持しながら、Agent にファイルを整理しレポートを生成させる必要があります。研究タスクを独立したウィンドウに分割することで、メインウィンドウでは引き続き資料を調査でき、Agent の状態を中断しません。

## 推奨レイアウト

* メインウィンドウ：資料の対話とグローバル検索を保持
* 独立ウィンドウ：研究 Agent タスクを開き、常時前面表示に設定
* 2 つ目のタブ：ナレッジベースやノートを開き、いつでも元の資料を確認

## 操作手順

{% stepper %}
{% step %}
### 1. 【対話】で研究課題を比較

複数モデルの比較により、共通点、対立点、および要確認項目を特定します。最終レポートの生成は急ぎません。
{% endstep %}

{% step %}
### 2. 研究 Agent 用のディレクトリを準備

元の資料と出力ディレクトリを分離し、関連するナレッジベースをバインドします。外部情報についてはリンクの保持を要求します。
{% endstep %}

{% step %}
### 3. タスクを独立ウィンドウに分割

Agent タブを右クリックし【新しいウィンドウで開く】を選択します。必要に応じてウィンドウの常時前面表示を使用します。メインウィンドウでは引き続き資料を調査し、Agent の状態を中断しません。
{% endstep %}

{% step %}
### 4. 集約して再確認

Agent の右側にある【ファイル】でレポートを確認し、メインウィンドウで元の対話を開いて対立点を照合します。最終的に残すのは、資料や出典に遡れる結論のみです。
{% endstep %}
{% endstepper %}

## 推奨組み合わせと完了基準

| ウィンドウ | 推奨内容 |
| ----- | --------------------------------- |
| メインウィンドウ | 資料の対話、グローバル検索、ノート |
| 独立ウィンドウ | 実行中の Agent タスク 1 つ |
| 固定タブ | プロジェクトで最もよく使用するナレッジベースまたはタスク |
| 完了基準 | 資料の出典、タスクの状態、最終ノートが相互に対応；タスク終了後、ウィンドウは回収または閉じられている |

長時間のタスクを継続的に監視する必要がある研究に適しています。「より専門的に見える」ために多くのウィンドウを同時に開くことは推奨されません。

{% hint style="info" %}
マルチウィンドウは表示位置を変更するだけで、新しいアカウントや隔離空間を作成しません。同じタスクのデータと権限は依然として同一です。
{% endhint %}
