# ブランド画像キット

コンテンツチームが同一キャンペーン用に横長、正方形、縦長の画像を作成し、被写体、色調、ブランドルールの一貫性を保つ必要があります。まずメインビジュアルを確定してからサイズを拡張する方が、各画像をゼロから生成するよりも統一感を保ちやすくなります。

## 準備資料

* コンテンツのテーマと利用プラットフォーム；
* 使用可能なブランドカラーと参考画像；
* 表示禁止のテキスト、ロゴ、要素；
* 3 種類の画像アスペクト比と余白の要件。

## 操作手順

{% stepper %}
{% step %}
### 1. Agent にビジュアル方向性を抽出させる

記事またはキャンペーンの説明を作業ディレクトリに配置し、Agent に被写体、シーン、色調、カメラアングル、余白の提案のみを出力させます。この段階では画像を生成しません。
{% endstep %}

{% step %}
### 2. 【描画】でメインビジュアルを検証

適切なテンプレートとモデルを選択し、まず横長の小サンプルを生成します。製品の外観、人物の詳細、ブランドリスクを確認します。
{% endstep %}

{% step %}
### 3. 参考画像を使用してサイズを拡張

メインビジュアルを決定した後、それを参考として正方形と縦長をそれぞれ生成します。各回の指示では、保持すべき被写体と調整可能な構図を明確に示します。
{% endstep %}

{% step %}
### 4. 部分的な修正と強化

問題のある領域のみに対して編集またはマスクを使用し、最終版で強化処理を行います。ファイル名には用途とアスペクト比を含め、混乱を避けます。
{% endstep %}
{% endstepper %}

## 結果の確認

* 3 枚の画像の色調と被写体が一致している；
* モデルが生成した誤ったテキストが含まれていない；
* ブランドロゴ、人物、機密情報が意図せず表示されていない；
* サイズが公開プラットフォームの要件を満たしている；
* 参考画像の使用が許可されている。

## 推奨組み合わせと完了基準

| 項目 | 推奨事項 |
| ---- | ------------------------------- |
| 描画モデル | まず Agent でサンプル画像を 1 枚生成して接続を検証し、その後描画テンプレートを保存する |
| 入力資料 | ブランドカラー、フォント、サイズ、参考画像、禁止要素を同一プロジェクトディレクトリに配置する |
| バッチ方式 | まず 1 枚を確認し、その後同シリーズの画像を生成する |
| 完了基準 | サイズが正確、テキストが読みやすい、ブランド要素が一致、余計なマークがない、元の参考画像が保持されている |

記事の表紙、ソーシャルメディアの画像、キャンペーン素材に適しています。正確なレイアウトが必要な最終ポスターについては、デザインツールで最終校正を行うことをお勧めします。

{% hint style="info" %}
Agent の対話内で直接画像を出力したい場合は、まずグローバル【描画モデル】を設定し、Agent の【画像生成】ツールを有効にしてください。詳細な編集が必要な場合は、依然として【描画】ページに戻って作業することをお勧めします。
{% endhint %}
