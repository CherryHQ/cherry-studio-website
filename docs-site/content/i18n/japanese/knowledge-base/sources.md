# 資料の追加と整理

ナレッジベースでは、ファイル、Cherry Studio のノート、ローカルディレクトリ、および単一の Web ページ URL をサポートしています。インポート後は、処理状態、本文、およびチャンクを確認し、資料が更新された場合は再インデックスを作成してください。

{% hint style="info" %}
完了の基準は「ファイルがリストに表示されていること」ではなく、資料が読み取れ、チャンクが完全であり、実際の質問に対して正しいソースが検索（リコール）できることです。
{% endhint %}

## 適切な入口の選択

<figure><img src="../../../assets/4622da2093d43942d7ee443e.webp" alt="資料の追加と整理 — 説明画像"><figcaption><p>資料のソースに応じて入口を選択します：少量のファイルには【ファイル】、同種のファイル群には【ディレクトリ】、Cherry Studio のコンテンツには【ノート】、公開 Web ページには【リンク】を使用します。</p></figcaption></figure>

| 入口 | 適した資料 | インポート後の関係 | 主な注意事項 |
| -- | ----------------------- | ----------- | ------------------ |
| ファイル | PDF、Office、Markdown、テキストなど | ホストされたコピーを保存 | 1回あたりの選択は最大20件 |
| ノート | Cherry Studio で整理済みのコンテンツ | インポート時点のコンテンツスナップショット | 元のノートの後続の修正は自動同期されません |
| ディレクトリ | 同じテーマ配下のローカルファイル群 | ディレクトリの内容に基づいて資料エントリを作成 | 無関係なディレクトリをまとめてインポートしない |
| リンク | 公開アクセス可能な単一の Web ページ | 取得時点の Web ページスナップショットを保存 | ログインページ、スクリプトレンダリング、またはアクセス制限のあるページは不完全になる可能性があります |

{% hint style="warning" %}
サポートされるファイルには、PDF、DOCX、DOC、PPTX、XLSX、XLS、MD、TXT、CSV、HTML、EPUB が含まれます。スキャン版 PDF または画像ベースのコンテンツについては、OCR も確認する必要があります。
{% endhint %}

## 資料の追加と検収

{% stepper %}
{% step %}
### 1. 資料ソースの選択

ナレッジベースを開き、資料追加ボタンをクリックし、【ファイル】、【ノート】、【ディレクトリ】、または【リンク】を選択します。
{% endstep %}

{% step %}
### 2. 選択した内容の確認

ファイルとノートはバッチ選択が可能です。1回の対話的な追加は最大20件です。資料が多い場合は、分割して追加するか、ディレクトリ入口を使用してください。
{% endstep %}

{% step %}
### 3. 同名競合の処理

新しい資料が既存のエントリと同名の場合、【すべて保持】または【置換】を選択します。制度、マニュアル、ノートスナップショットを更新する場合は、通常【置換】を選択します。

{% hint style="warning" %}
【すべて保持】を選択すると、新旧のコンテンツが同時にリコールに参加します。異なるバージョンを並行して照会する必要がある場合のみこれを行い、名称に日付またはバージョンを明記してください。
{% endhint %}
{% endstep %}

{% step %}
### 4. 処理完了を待つ

資料は、コピー、読み取り、チャンク分割、インデックス作成などの段階を経ます。埋め込みモデルが設定されていない場合、ベクトルは作成されませんが、キーワードインデックスは作成されます。

<figure><img src="../../../assets/2414cfc005a860f127a4fd96.webp" alt="資料の追加と整理 — 説明画像"><figcaption><p>資料が利用可能な状態になったら、本文とチャンクを抜き出して確認してください。</p></figcaption></figure>
{% endstep %}

{% step %}
### 5. 本文とチャンクの抜き出し確認

資料を開いて本文を確認するか、資料行のメニューからチャンクを表示します。見出しの順序、テーブル、OCR テキスト、重要な文が誤って分割されていないことを重点的に確認してください。
{% endstep %}

{% step %}
### 6. リコールテストの実行

答えが明確な質問を使用して、正しいソースとチャンクを確認します。資料を更新した後でも、同じ質問セットを使用して再テストしてください。

<figure><img src="../../../assets/b44776524449cdefe62eaed3.webp" alt="資料の追加と整理 — 説明画像"><figcaption><p>最終的な検収では、ソース、チャンクの完全性、並び順を確認し、結果が返されたかどうかのみを見ないでください。</p></figcaption></figure>
{% endstep %}
{% endstepper %}

## 資料の状態と処理方法

| 現象 | 考えられる原因 | 処理方法 |
| ----------- | ------------------ | ------------------ |
| 長時間処理中 | ファイルが大きい、パーサーまたはモデルが利用不可 | 元のファイル、ドキュメント処理、埋め込みモデルを確認 |
| エラー表示 | コピー、読み取り、チャンク分割、またはインデックス作成の失敗 | エラーメッセージを開き、失敗した段階に応じて処理 |
| 本文が欠落または文字化け | ファイルプロセッサが非対応、スキャン内容が未 OCR | ドキュメント処理方法を変更するか、OCR を設定 |
| チャンクに重要な文がない | チャンク境界が不適切 | チャンクを調整し、【再インデックス】を実行 |
| 新旧バージョンが同時にヒット | 同名資料で【すべて保持】を選択 | 古いエントリを削除するか、再インポートして【置換】を選択 |

## 再インデックスと削除

チャンク分割、パーサー、または埋め込み設定を変更した後、古いエントリには新しい設定が自動適用されません。単一の資料に対して【再インデックス】を使用するか、資料をバッチ選択して再インデックスを作成してください。

{% hint style="danger" %}
エントリを削除すると、現在のナレッジベース内のホストされたコピーとインデックスが削除されます。元のファイルや元のノートは削除されませんが、削除前にナレッジベース内に唯一のコピーがあるかどうかを確認してください。
{% endhint %}

## 設定の説明

| 設定項目 | 製品デフォルト値 | 推奨される開始点 | 役割 | 適用シナリオ | 注意事項 |
| ------ | ------- | ---------- | --------------- | ---------- | ---------------- |
| 1回あたりの追加数 | 最大20件 | まず少量の代表的な資料を追加 | 1回のインポート規模を制御 | 初回構築またはトラブルシューティング | 大量インポート前に解析とリコールを検証 |
| 同名処理 | 競合発生時に選択 | 資料更新時は【置換】を優先 | 新旧エントリが併存するかどうかを決定 | 制度、マニュアル、ノートの更新 | 【すべて保持】は古いコンテンツがリコールに参加する可能性があります |
| 再インデックス | 手動実行 | 設定変更後に実行 | 古い資料に新しい解析、チャンク分割、またはモデルを適用 | 調整または資料の修正 | 完了後に必ずリコールテストを再実行 |

## ユーザー事例

小林さんは毎月出張制度を更新しています。新しいファイルを同じ名前でインポートし、【置換】を選択します。資料の処理が完了したら、本文とチャンクを抜き出して確認し、宿泊、交通、承認ルールについて固定の質問でテストします。

完了の基準は：古いルールがリコール結果に表示されず、新しいルールの条件と金額が安定してヒットすることです。

## よくある質問

<details>

<summary>元のノートを修正した後、ナレッジベースは自動更新されますか？</summary>

いいえ。ノートはインポート時点のコンテンツのスナップショットです。修正後は、再追加して【置換】を選択するか、該当する資料に対して【再インデックス】を実行する必要があります。

</details>

<details>

<summary>Web ページはなぜ一部しか取得できないのですか？</summary>

ログインが必要、スクリプトレンダリングに依存、またはアクセス制限がある Web ページは、完全に取得できない可能性があります。代わりに、ファイルやノートで本文を保存してからインポートしてください。

</details>

<details>

<summary>ナレッジベースのエントリを削除すると、元のファイルも削除されますか？</summary>

元のファイルや元のノートは削除されませんが、ナレッジベース内のホストされたコピーとインデックスは削除されます。

</details>
