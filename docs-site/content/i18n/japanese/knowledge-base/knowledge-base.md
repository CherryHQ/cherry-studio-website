# ナレッジベース入門

ファイル、ノート、フォルダー、Web ページをまとめ、繰り返し検索できるようにします。チャットや Agent で使う前に、必要な箇所を検索できることを確認してください。

{% hint style="info" %}
埋め込みモデルは必須ではありません。まず **使用しない（None）** を選び、BM25 キーワード検索を試せます。意味に基づく検索が必要になったら埋め込みモデルを設定します。リランクモデルも任意です。
{% endhint %}

## 最初のナレッジベースを作る

1. <a id="ナレッジベースの-zuo-cheng"></a><a id="ナレッジベースの作成"></a>左側の **ナレッジベース** を開き、一覧上部の追加ボタンを押します。「社員出張規程」など、範囲が明確な名前にします。

2. <a id="mai-め-yu-みモデルの-zhui-jia"></a><a id="埋め込みモデルの追加"></a>最初は **埋め込みモデル** を **使用しない（None）** に設定します。言い換えや同義語への対応が必要になったらモデルを追加します。

3. <a id="duo-yang-なソースからのデータ-zhui-jia"></a><a id="多様なソースからのデータ追加"></a><a id="ファイルの-zhui-jia-とベクトル-hua"></a><a id="ファイルの追加とベクトル化"></a>ナレッジベースを開き、**ファイル**、**ノート**、**フォルダー**、**リンク** から資料を追加します。少量の関連資料から始めます。

4. 処理完了後、本文と **Chunks** を確認し、文字化け、欠落、順序の乱れがないか調べます。

5. <a id="ナレッジベースの-jian-suo"></a><a id="ナレッジベースの検索"></a>**検索テスト（Retrieval Test）** を開き、答えを知っている実際の質問を入力します。正しい資料が上位に表示されることを確認します。

6. <a id="hui-hua-でのナレッジベース-can-zhao-による-hui-da-sheng-cheng"></a><a id="会話でのナレッジベース参照による回答生成"></a>安定して検索できたら、チャット入力欄でナレッジベースを選択します。継続的な処理には Agent の編集画面で紐付けます。

![ファイル、ノート、フォルダー、リンクの追加画面](../../../assets/4622da2093d43942d7ee443e.webp)

## 回答を利用する前に

実際の質問を 3～5 件用意し、資料や設定を変更するたびに再テストします。検索に失敗したら原文と Chunks を確認してください。検索されなかった重要情報をチャットモデルが補えるとは限りません。

クラウドの埋め込み・リランクモデルを使う場合、料金とデータ処理は提供元によって異なります。アクセス要件の異なる資料は別のナレッジベースに分けてください。
