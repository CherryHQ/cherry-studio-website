## この表の見方

* **ランキング / ランキング範囲**：Arena AI がエージェントタスクの対戦投票に基づいて推定した相対的な順位です。ランキング範囲は、信頼区間内の順位の変動を示します。
* **純粋な改善率**：ベースラインと比較して、マルチターンツール呼び出し / エージェントタスクにおける純粋な改善幅です。
* **確認成功率**：タスク完了後、ユーザーが成功を確認（高評価）した割合です。
* **高評価/低評価比**：ユーザーが回答に対して「高評価」と「低評価」を付けた比率で、主観的な満足度を反映します。
* **制御可能性**：指示に従い、安定した出力を維持する能力です。
* **Bash 回復率**：Bash / コマンドライン操作でエラーが発生した後、自己回復できる割合です。
* **ツール幻覚率**：存在しないツールを捏造または呼び出す割合です。低いほど良いです。
* **セッション数**：サンプルサイズの参考値です。サンプルが少ない場合、ランキングは通常より変動しやすくなります。

## モデル選択時に確認すべき3つのこと

1. プロバイダーが実際にそのモデルを提供しているか、およびあなたの地域とアカウントで利用可能か；
2. API の料金、レート制限、コンテキストがあなたのタスクに適しているか；
3. 総ランキングの順位だけでなく、3〜5つの実際のタスクで小規模なテストを行うこと。
