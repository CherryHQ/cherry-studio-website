## この表の見方

* **ランキング / ランキング範囲**：Arena AI が対戦投票に基づいて推定した相対的な順位です。ランキング範囲は、信頼区間内の順位の変動を示します。
* **スコア**：相対的な評価点です。同一時点のランキング内のモデル間の比較に適しています。
* **投票数 / セッション数**：サンプルサイズの参考値です。サンプル数が少ない場合、ランキングは通常より変動しやすくなります。
* **価格 $/100万Token**：入力 / 出力の100万Tokenあたりの参考価格です。
* **コンテキスト**：モデルがサポートする最大コンテキスト長です。

## モデル選択時に確認すべき3つのこと

1. プロバイダーが実際にこのモデルを提供しているか、およびあなたの地域とアカウントで利用可能か；
2. API価格、レート制限、コンテキストがあなたのタスクに適しているか；
3. 総ランキングの順位だけでなく、3〜5つの実際のタスクで小規模なテストを行うこと。
