# クイックスタート

以下の手順で、数分以内にモデルを設定して最初のメッセージを送信できます。

## 1. Cherry Studio をインストールする

[公式ダウンロードページ](https://cherryai.com/download)から、OS とプロセッサーに合うパッケージを入手します。権限やインストールに問題がある場合は、[ダウンロードとインストール](../cherry-studio/installation/README.md)を参照してください。

## 2. モデルプロバイダーを選ぶ

【設定】→【モデルサービス】を開きます。API Key をまだ持っていない場合は、[モデルサービス早見表](../pre-basic/providers/quick-reference.md)から、地域、モデル機能、プライバシー要件に合うサービスを選びます。

## 3. モデルを追加して有効にする

プロバイダー設定で API Key を入力し、【モデル一覧を取得】からチャットモデルを追加してプロバイダーを有効にします。詳細は[モデルサービス設定](../pre-basic/settings/providers.md)を参照してください。

## 4. 最初のメッセージを送る

【チャット】に戻り、アシスタントを作成または開いて、追加したモデルを選択してメッセージを送信します。返信が届けば基本設定は完了です。
