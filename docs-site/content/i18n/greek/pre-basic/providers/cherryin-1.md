# CherryIN


{% hint style="warning" %}
Αυτό το έγγραφο μεταφράστηκε από τα Κινεζικά με AI και δεν έχει ακόμη ελεγχθεί.
{% endhint %}




1. Κάντε κλικ στο «Πατήστε εδώ για να λάβετε το κλειδί» του πάροχου CherryIN

<figure><img src="../../../../assets/a224e8a38aa9bdffdf1a5263.webp" alt=""><figcaption></figcaption></figure>

2. Δημιουργήστε ένα κλειδί στην κονσόλα του CherryIN. Παρακαλούμε σημειώστε ότι κατά τη δημιουργία του κλειδιού, ο πολλαπλασιαστής μοντέλου (έκπτωση) διαφέρει ανάλογα με την ομάδα του token.

<figure><img src="../../../../assets/507ff0c40b171cb37566f85b.webp" alt=""><figcaption></figcaption></figure>

3. Κάντε κλικ στο κουμπί δίπλα στο κλειδί για να αντιγράψετε το κλειδί στο πρόχειρο

<figure><img src="../../../../assets/3ce6811927758bfe42ca364d.webp" alt=""><figcaption></figcaption></figure>

4. Εισαγάγετε το κλειδί στο Cherry Studio

<figure><img src="../../../../assets/1f557cb583abf303bf1e664d.webp" alt=""><figcaption></figcaption></figure>

5. Κάντε κλικ στο κουμπί διαχείρισης και προσθέστε ένα μοντέλο

<figure><img src="../../../../assets/6ce35222d00b2d9a6b8898b4.webp" alt=""><figcaption></figcaption></figure>

<figure><img src="../../../../assets/c9b537cef4a4aa28f442a374.webp" alt=""><figcaption></figcaption></figure>

6. Επιλέξτε το αντίστοιχο μοντέλο στο Cherry Studio για να ξεκινήσετε τη συνομιλία

<figure><img src="../../../../assets/5189719629c7f31d65fdc8ca.webp" alt=""><figcaption></figcaption></figure>
