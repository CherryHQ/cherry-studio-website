# Aliyun Bailian


1. Faça login no [Aliyun Bailian](https://bailian.console.aliyun.com/?tab=model#/api-key). Se você não tiver uma conta do Aliyun, precisará se registrar.

2. Clique no botão `Criar minha API-KEY` no canto superior direito.
  <figure><img src="../../../../assets/00b4cbef8a9bbea93bb4a9b6.webp" alt=""><figcaption>Criação de chave API no Aliyun Bailian</figcaption></figure>
  
3. Na janela pop-up, selecione o espaço de trabalho padrão (ou você pode personalizar) e preencha uma descrição se desejar.
  <figure><img src="../../../../assets/5d1d415f32559b716089d8c1.webp" alt=""><figcaption>Janela pop-up de criação de chave API no Aliyun Bailian</figcaption></figure>
  
4. Clique no botão `Confirmar` no canto inferior direito.

5. Você deverá ver uma nova linha na lista. Clique no botão `Ver` à direita.
   <figure><img src="../../../../assets/89f7665003a1634b74bedd69.webp" alt=""><figcaption>Visualização de chave API no Aliyun Bailian</figcaption></figure>
   
6. Clique no botão `Copiar`.
    <figure><img src="../../../../assets/e6c807e270fe736e6731c677.webp" alt=""><figcaption>Cópia de chave API no Aliyun Bailian</figcaption></figure>

7. Acesse o Cherry Studio, navegue para `Configurações` → `Serviços de modelos` → `Alibaba Cloud Bailian`, localize `chave API` e cole a chave API copiada.
    <figure><img src="../../../../assets/9f14346e4b15514c0730d7a6.webp" alt=""><figcaption>Preenchimento de chave API no Aliyun Bailian</figcaption></figure>
    
8. Você pode ajustar as configurações conforme descrito em [Serviço de Modelo](../../cherrystudio/preview/settings/providers.md) e começar a usar.
{% hint style="info" %}
Se os modelos do Aliyun Bailian não aparecerem na lista, verifique se você adicionou os modelos conforme as instruções em [Serviço de Modelo](../../cherrystudio/preview/settings/providers.md) e se ativou este provedor.
{% endhint %}
