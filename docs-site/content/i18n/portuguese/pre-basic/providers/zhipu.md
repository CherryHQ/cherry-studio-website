# ZhiPu

A série **GLM** da ZhiPu AI (incluindo o GLM-4V multimodal) oferece conexão direta na China e bom desempenho em chinês. A ZhiPu utiliza um **endpoint compatível com Anthropic** no Cherry Studio, portanto, além do chat padrão, também pode ser usada com o **Cherry Agent**.

## Obter a API Key

* Abra a [página de API Keys](https://open.bigmodel.cn/apikey/platform) da plataforma aberta da ZhiPu (é necessário registrar-se/fazer login primeiro)
* Crie e copie uma API Key

## Configurar no Cherry Studio

1. Abra as [Configurações de Serviço de Modelo](../settings/providers.md) do Cherry Studio e localize **ZhiPu** na lista integrada
2. Insira a API Key recém-obtida
3. Clique em **Obter lista de modelos**, adicione os modelos GLM necessários e ative o interruptor do provedor no canto superior direito para começar a usar

{% hint style="info" %}
Os modelos ZhiPu possuem a capacidade de **busca na web** integrada, sujeita ao suporte específico de cada modelo. Para mais documentação da plataforma, consulte a [documentação oficial da ZhiPu](https://docs.bigmodel.cn/).
{% endhint %}
