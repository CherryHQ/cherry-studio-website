# Perplexity

A série **Sonar** da Perplexity é focada em **conversas aprimoradas por busca** — as respostas combinam a busca em tempo real na web, sendo ideais para cenários que exigem a citação de informações mais recentes.

## Obter a Chave de API

* Abra a [página de configurações de API](https://www.perplexity.ai/settings/api) da Perplexity (é necessário registrar-se/fazer login primeiro)
* Gere e copie uma Chave de API

## Configurar no Cherry Studio

1. Abra as [Configurações de Serviço de Modelo](../settings/providers.md) do Cherry Studio e localize **Perplexity** na lista integrada
2. Insira a Chave de API recém-obtida
3. Clique em **Obter Lista de Modelos**, adicione modelos como Sonar e ative o interruptor do provedor no canto superior direito para começar a usar

{% hint style="info" %}
Os modelos da Perplexity possuem capacidade nativa de busca na web, sem necessidade de configurar o modo de conexão à internet. O acesso a partir da China geralmente requer a resolução independente de problemas de proxy de rede. Para mais informações, consulte a [Documentação Oficial da Perplexity](https://docs.perplexity.ai/home).
{% endhint %}
