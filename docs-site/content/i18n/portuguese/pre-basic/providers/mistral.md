# Mistral

A Mistral AI é uma referência em modelos de linguagem abertos na Europa, oferecendo séries como Mistral / Codestral, equilibrando desempenho e abertura.

## Obter a Chave de API

* Abra a [página de Chaves de API](https://console.mistral.ai/api-keys/) no console da Mistral (é necessário registrar-se/fazer login primeiro)
* Crie e copie uma Chave de API

## Configurar no Cherry Studio

1. Abra as [Configurações de Serviço de Modelo](../settings/providers.md) do Cherry Studio e localize **Mistral** na lista integrada
2. Insira a Chave de API recém-obtida
3. Clique em **Obter Lista de Modelos**, adicione os modelos necessários e ative o interruptor do provedor no canto superior direito para começar a usar

{% hint style="info" %}
O acesso à Mistral a partir da China geralmente requer a resolução independente de problemas de proxy de rede. Para mais informações, consulte a [Documentação Oficial da Mistral](https://docs.mistral.ai).
{% endhint %}
