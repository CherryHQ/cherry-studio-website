# MiniMax

A MiniMax é uma das principais desenvolvedoras de modelos de linguagem na China, destacando-se por suas notáveis **capacidades multimodais** (geração de texto, áudio, imagem e vídeo).

## Obter a Chave de API

* Acesse a [Plataforma Aberta da MiniMax](https://platform.minimaxi.com/) e registre uma conta
* Após concluir a verificação de identidade, acesse `Gerenciamento da conta → Chaves API` para criar a Chave de API

## Configuração no Cherry Studio

* Abra `Configurações → Serviços de modelos`, localize o Provider **MiniMax** e acesse a página de detalhes
* Insira a chave de API
* Mantenha o endereço da API com o valor padrão
* Clique em **Obter lista de modelos**

## Usos recomendados

| Modelo | Cenário adequado |
|---|---|
| `abab6.5s-chat` / `MiniMax-Text-01` | Conversas do dia a dia |
| `abab6.5-chat` | Textos longos de alta qualidade |

{% hint style="info" %}
* O acesso à MiniMax na China é conveniente, e novos usuários possuem uma cota gratuita limitada
* Usuários internacionais devem utilizar o **MiniMax Global** (aparece como um item independente na lista de Providers do Cherry Studio)
{% endhint %}
