# Zhipu GLM-4.5-Air

Para que todos os desenvolvedores e usuários possam experimentar facilmente as capacidades dos modelos de linguagem de ponta, **a Zhipu disponibilizou gratuitamente o modelo GLM-4.5-Air para os usuários do Cherry Studio**. Como um modelo base eficiente desenvolvido especificamente para aplicações de Agentes, o GLM-4.5-Air alcança um excelente equilíbrio entre desempenho e custo, sendo uma escolha ideal para a construção de aplicações inteligentes.

***

**🚀 O que é o GLM-4.5-Air?**

O GLM-4.5-Air é o mais recente modelo de linguagem de alto desempenho da Zhipu, que adota a avançada **arquitetura de Mixture-of-Experts (MoE)**, reduzindo significativamente o consumo de recursos computacionais ao mesmo tempo em que mantém uma capacidade de raciocínio excepcional.

* **Parâmetros totais: 106 bilhões**
* **Parâmetros ativados: 12 bilhões**

Através de um design otimizado, o GLM-4.5-Air atinge uma maior eficiência de inferência, sendo adequado para implantação em ambientes com recursos limitados, enquanto ainda é capaz de lidar com o processamento de tarefas complexas.

**📚 Fluxo de treinamento unificado, consolidando a base da inteligência**

O GLM-4.5-Air compartilha o mesmo fluxo de treinamento da série flagship, garantindo uma base sólida de capacidades gerais:

1. **Pré-treinamento em larga escala**: Treinado em um corpus geral de até **15 trilhões de tokens**, construindo uma ampla capacidade de compreensão do conhecimento;
2. **Otimização de áreas específicas**: Treinamento reforçado em tarefas-chave como geração de código, raciocínio lógico e interação de agentes;
3. **Suporte a contexto longo**: O comprimento do contexto foi expandido para **128K tokens**, permitindo o processamento de documentos longos, conversas complexas ou grandes projetos de código;
4. **Aprimoramento por aprendizado por reforço**: Otimização via RL da capacidade de decisão do modelo em raciocínio, planejamento e chamadas de ferramentas.

Este sistema de treinamento confere ao GLM-4.5-Air uma excelente capacidade de generalização e adaptabilidade às tarefas.

***

**⚙️ Capacidades centrais otimizadas especificamente para Agentes**

O GLM-4.5-Air foi profundamente adaptado para cenários de aplicação de Agentes, possuindo as seguintes capacidades práticas:

✅ **Suporte a chamadas de ferramentas**: Permite chamar ferramentas externas através de interfaces padronizadas, automatizando tarefas\
✅ **Navegação na web e extração de informações**: Pode ser usado em conjunto com plugins de navegador para compreender e interagir com conteúdo dinâmico\
✅ **Auxílio em engenharia de software**: Suporta análise de requisitos, geração de código, identificação e correção de defeitos\
✅ **Suporte a desenvolvimento front-end**: Possui boa compreensão e capacidade de geração para tecnologias front-end como HTML, CSS e JavaScript

Este modelo pode ser integrado flexivelmente a frameworks de agentes de código como **Claude Code, Roo Code**, ou usado como motor central de qualquer Agent personalizado.

***

**💡 Modo de "pensamento" inteligente, resposta flexível a diversos tipos de solicitações**

O GLM-4.5-Air suporta o **modo de raciocínio híbrido**, permitindo que os usuários controlem a ativação do pensamento profundo através do parâmetro `thinking.type`:

* `enabled`: Ativa o pensamento, adequado para tarefas complexas que exigem raciocínio passo a passo ou planejamento
* `disabled`: Desativa o pensamento, usado para consultas simples ou respostas imediatas
* A configuração padrão é o **modo de pensamento dinâmico**, onde o modelo decide automaticamente se é necessária uma análise aprofundada

| Tipo de tarefa | Exemplo |
| ------------------ | ----------------------------------------------- |
| **Tarefas simples** (recomenda-se desativar o pensamento) | <p>- Consultar "o ano de fundação da Zhipu AI"<br>- Traduzir "I love you" para o chinês</p> |
| **Tarefas médias** (recomenda-se ativar o pensamento) | <p>- Comparar as vantagens e desvantagens do avião e do trem-bala de Pequim a Xangai<br>- Explicar por que Júpiter tem muitos satélites</p> |
| **Tarefas complexas** (fortemente recomendado ativar o pensamento) | <p>- Explicar como os especialistas colaboram em modelos MoE<br>- Analisar com base em informações de mercado se deve comprar um ETF</p> |

***

**🌟 Alto desempenho e baixo custo, implantação mais fácil**

O GLM-4.5-Air alcança um excelente equilíbrio entre desempenho e custo, sendo particularmente adequado para implantação em negócios reais:

* ⚡ **Velocidade de geração superior a 100 tokens/segundo**, resposta rápida, suporta interação com baixa latência
* 💰 **Custo de API extremamente baixo**: Entrada apenas **0,8 CNY/milhão de tokens**, saída **2 CNY/milhão de tokens**
* 🖥️ Poucos parâmetros ativados, baixa exigência de poder computacional, fácil de executar com alta concorrência localmente ou na nuvem

Realmente oferece uma experiência de serviço de IA com "alto desempenho e baixa barreira de entrada".

**🧠 Foco em capacidades práticas: Geração inteligente de código**

Adequado para tarefas de desenvolvimento de alta frequência, como construção de protótipos rápidos, autocompletamento e correção de bugs.
