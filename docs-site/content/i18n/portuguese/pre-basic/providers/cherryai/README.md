# CherryAI (Gratuito)

**CherryAI** é a entrada oficial integrada no Cherry Studio para **modelos gratuitos** — não é necessário se registrar em plataformas de terceiros ou solicitar uma chave; basta abrir para usar uma cota de modelos gratuitos, ideal para usuários iniciantes que desejam testar as funcionalidades.

### Onde usar

Abra `Configurações → Serviços de modelos` e localize **CherryAI** na lista integrada. Ele já vem pré-configurado no software, geralmente não exigindo configurações adicionais; clique em **Obter lista de modelos** para ver os modelos gratuitos atualmente disponíveis.

### Modelos gratuitos disponíveis

{% hint style="warning" %}
**A oferta de modelos gratuitos é dinâmica.** Quais modelos estão disponíveis, suas respectivas cotas e limites de taxa são definidos em tempo real pelo servidor da Cherry e podem ser ajustados periodicamente; **considere apenas os resultados reais exibidos ao clicar em [Obter lista de modelos] no software**. As seções a seguir descrevem apenas alguns modelos gratuitos comuns e não representam a lista completa atual.
{% endhint %}

* [DeepSeek V3.2](free-deepseek.md)
* [Zhipu GLM-4.6V](free-glm46v.md)
* [Zhipu GLM-4.5-Air](free-glm45air.md)
* [Qwen3-8B](free-qwen.md)

Se precisar de modelos mais estáveis e potentes, você pode escolher [CherryIN](../cherryin-1.md) ou outros [provedores](../README.md).
