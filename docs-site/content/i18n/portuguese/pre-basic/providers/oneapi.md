* Faça login e acesse a página de tokens

* Crie um novo token (você também pode usar diretamente o token default↑)

<figure><img src="../../../../assets/b52ed2463a5c1ea3de393a3e.webp" alt="" width="563"><figcaption></figcaption></figure>

* Copie o token

<figure><img src="../../../../assets/e485ab0dd933dd974e8648e3.webp" alt="" width="563"><figcaption></figcaption></figure>

* Abra as configurações de provedores do CherryStudio e clique em `Adicionar` na parte inferior da lista de provedores
* Insira um nome de observação, selecione OpenAI como provedor e clique em OK

* Insira a chave copiada anteriormente
* Volte para a página de obtenção da API Key e copie o endereço raiz na barra de endereço do navegador correspondente, por exemplo:

<figure><img src="../../../../assets/15e84703b85e9e47c3de65e4.webp" alt=""><figcaption><p><strong>Copie somente a origem, como https://xxx.xxx.com; a barra e o caminho depois dela não são necessários.</strong></p></figcaption></figure>

{% hint style="info" %}
* Se o endereço usar IP e porta, informe apenas `http://IP:porta`, por exemplo: `http://127.0.0.1:3000`.
* Diferencie estritamente `http` e `https`; se o SSL não estiver ativado, não preencha https
{% endhint %}

* Adicione modelos (clique em Gerenciar para obter automaticamente ou insira manualmente). Ative o interruptor no canto superior direito para usar.

{% hint style="success" %}
Outros temas do OneAPI podem ter interfaces diferentes, mas o método de adição é o mesmo que o fluxo de operação descrito acima.
{% endhint %}
