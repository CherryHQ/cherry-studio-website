# Notificações

As configurações de notificação controlam **como o software o notifica quando está em segundo plano**. Quando você alterna para outra janela para trabalhar, o Cherry Studio pode exibir notificações do sistema quando eventos importantes forem concluídos, evitando que você fique aguardando ou perca resultados.

Abra `Configurações → Notificações`, onde há três interruptores independentes:

<figure><img src="../../../../assets/8f6458a65b2bb09759c9622f.webp" alt=""><figcaption><p>Painel de configurações de notificação</p></figcaption></figure>

| Interruptor | Quando você é notificado | Recomendação |
| --- | --- | --- |
| **Mensagens do assistente** | Notifica apenas quando a resposta da IA é **bem-sucedida** e a geração **leva mais de 30 segundos** (há uma explicação com ⓘ ao lado do interruptor) | **Ativar**. Ao usar modelos de raciocínio ou gerar textos longos, não é necessário ficar olhando a tela |
| **Backup** | Quando o backup automático / manual é concluído | **Ativar**. Confirme que os dados foram arquivados com segurança |
| **Base de conhecimento** | Notificação após a conclusão de tarefas relacionadas à base de conhecimento (como a construção de índices) | **Ativar**. A criação da base geralmente leva tempo; receber uma notificação ao final é mais conveniente |

{% hint style="info" %}
Essas notificações usam o centro de notificações do sistema operacional. Se você não receber nenhuma notificação, verifique se o sistema permite que o Cherry Studio envie notificações ("Notificações" no macOS, "Notificações e ações" no Windows).
{% endhint %}
