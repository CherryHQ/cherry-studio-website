# Launchpad

O Launchpad exibe de forma centralizada os principais pontos de acesso aos recursos do Cherry Studio. Clique em **+** na extremidade direita da barra de abas superior para abrir uma nova aba do Launchpad; ao fechar a última aba, o sistema retorna automaticamente ao Launchpad.

![Nove entradas de aplicativos integrados no Launchpad](../../../../assets/7521831e54a609b69a5fceeb.png)

## Aplicativos padrão

Atualmente, o Launchpad inclui 9 aplicativos integrados:

| Aplicativo | Uso |
| --------------------------------------- | ----------------------- |
| [Conversa](chat.md) | Conversar com modelos, gerenciar assistentes e listas de conversas |
| [Trabalho](../../advanced-basic/agent.md) | Permitir que agentes chamem ferramentas e executem tarefas em várias etapas |
| [Desenho](drawing.md) | Gerar e gerenciar imagens usando modelos de imagem |
| [Tradução](translation.md) | Traduzir texto e comparar o original com a tradução |
| [Mini Apps](../../cherry-studio/preview/app) | Usar aplicativos web no Cherry Studio |
| [Base de Conhecimento](knowledge-base.md) | Importar materiais e realizar buscas e perguntas e respostas |
| [Arquivos](files.md) | Visualizar e gerenciar arquivos usados no aplicativo |
| [Parceiro de Código](code-cli.md) | Instalar, configurar e iniciar ferramentas de CLI de programação com IA |
| [Notas](notes.md) | Criar e organizar notas em Markdown |

## Ajustar a ordem dos aplicativos

Segure o ícone do aplicativo e arraste-o para a posição desejada para reordenar os aplicativos integrados. O Cherry Studio salva automaticamente a nova ordem.

O Launchpad e a barra lateral mantêm ordens de aplicativos independentes. Reordenar no Launchpad não altera a disposição na barra lateral.

## Fixar na barra lateral

Aplicativos usados com frequência podem ser fixados na barra lateral:

1. Clique com o botão direito do mouse no aplicativo no Launchpad.
2. Selecione **Adicionar à barra lateral**.
3. Para remover a fixação, clique novamente com o botão direito e selecione **Remover da barra lateral**.

> **Dica:** **Conversa** é uma entrada obrigatória na barra lateral e não pode ser removida. Os outros aplicativos, mesmo sem fixação na barra lateral, ainda podem ser abertos pelo Launchpad.

## Gerenciar Mini Apps

Após adicionar um aplicativo web ao Launchpad na página [Mini Apps](../../cherry-studio/preview/app), ele aparecerá na área "Mini Apps", abaixo dos aplicativos integrados.

* Arraste o ícone do Mini App para ajustar a ordem de exibição.
* Clique com o botão direito do mouse no Mini App para adicioná-lo à barra lateral ou removê-lo do Launchpad.
* Remover do Launchpad apenas cancela o atalho de acesso; não exclui o próprio Mini App.
