# Área de trabalho eficiente

A janela principal do Cherry Studio é composta por uma barra lateral, abas e uma área de conteúdo. Tópicos de conversa e tarefas do Agent podem ser abertos simultaneamente em várias abas ou divididos em janelas independentes; a barra de ferramentas da área de entrada pode ser ajustada de acordo com os hábitos de uso.

### Cenários adequados para uso de janelas independentes

* Manter uma conversa de materiais enquanto executa tarefas do Agent;
* Fixar tarefas de monitoramento de longo prazo no topo, evitando que sejam ocultadas por outras janelas;
* Posicionar conversas, arquivos ou tarefas em monitores diferentes;
* Apresentar ou compartilhar uma tarefa específica sem expor as outras abas da janela principal.

### Capacidades da área de trabalho

| Capacidade | Acesso | Função |
| ------ | -------------------- | -------------- |
| Nova aba | Menu de contexto do tópico ou tarefa → [Abrir em nova aba] | Manter múltiplos contextos lado a lado na janela principal |
| Janela independente | Menu de contexto do tópico, tarefa ou aba → [Abrir em nova janela] | Separar o conteúdo atual em uma nova janela |
| Fixar aba | Menu de contexto da aba → [Fixar aba] | Fixar páginas de uso frequente |
| Janela no topo | [Janela no topo] na parte superior da janela independente | Manter a tarefa visível |
| Voltar à janela principal | [Voltar à janela principal] na parte superior da janela independente | Reintegrar a aba à janela principal |
| Barra de ferramentas personalizada | [+] na área de entrada → [Personalizar barra de ferramentas] | Ajustar a posição das ferramentas de entrada frequentes |

No menu de abas da imagem acima, selecione [Abrir em nova janela] para separar o conteúdo atual em uma janela independente.

### Layout recomendado

Para escrita profissional, mantenha a conversa de materiais na janela principal e separe o Agent de "Escrita" para a tela à direita; para trabalho com código, fixe as tarefas do Agent no topo e mantenha arquivos e documentos na janela principal; para tarefas de monitoramento de longa duração, use janelas independentes, mas não coloque tarefas que exigem confirmação frequente de permissões em posições invisíveis.

{% hint style="info" %}
Janelas independentes pertencem ao mesmo ambiente de dados do Cherry Studio. Não são novas contas ou espaços de privacidade; o conteúdo do mesmo tópico ou tarefa continua sendo sincronizado e salvo.
{% endhint %}
