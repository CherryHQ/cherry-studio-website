# Tarefas agendadas, heartbeat e registros de execução

<details>

<summary>O que fazer se a tarefa foi executada, mas o canal não recebeu a mensagem?</summary>

Primeiro, verifique o [Histórico de Execução] para confirmar se o Agent foi executado com sucesso. Se a tarefa foi bem-sucedida, verifique o destino de recebimento do canal. Se a tarefa falhou, clique em [Ver Conversa] para verificar erros de modelo, permissões, workspace e ferramentas.

</details>
