# Diretório de trabalho, tarefas e arquivos

<details>

<summary>Quais arquivos não podem ser editados diretamente?</summary>

Arquivos binários, textos não UTF-8 e arquivos de grande tamanho oferecem apenas visualização ou abertura externa. Eles ainda podem ser processados pelas ferramentas do Agent, mas nem sempre podem ser modificados no editor integrado.

</details>
