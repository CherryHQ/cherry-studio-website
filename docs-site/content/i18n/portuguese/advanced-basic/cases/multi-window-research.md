# Bancada de Pesquisa Multi-Janela

Os pesquisadores precisam manter materiais e comparações de modelos enquanto o Agent organiza arquivos e gera relatórios. Ao dividir as tarefas de pesquisa em janelas independentes, a janela principal continua consultando materiais sem interromper o estado do Agent.

## Layout Recomendado

* Janela principal: manter a conversa de materiais e a busca global;
* Janela independente: abrir a tarefa do Agent de pesquisa e mantê-la no topo;
* Segunda aba: abrir a base de conhecimento ou notas para verificar os materiais originais a qualquer momento.

## Fluxo de Operação

{% stepper %}
{% step %}
### 1. Comparar questões de pesquisa em [Conversa]

Use a comparação de múltiplos modelos para identificar consensos, conflitos e itens a verificar, sem pressa para gerar o relatório final.
{% endstep %}

{% step %}
### 2. Preparar o diretório para o Agent de pesquisa

Separe os materiais originais do diretório de saída, vincule a base de conhecimento relevante e exija que as informações externas mantenham os links.
{% endstep %}

{% step %}
### 3. Dividir a tarefa em uma janela independente

Clique com o botão direito na aba do Agent e selecione [Abrir em nova janela]. Use a opção de manter no topo quando necessário. A janela principal continua consultando materiais sem interromper o estado do Agent.
{% endstep %}

{% step %}
### 4. Consolidar e revisar

Verifique o relatório em [Arquivos] à direita do Agent e abra a conversa original na janela principal para conferir os conflitos. Mantenha apenas as conclusões que possam ser rastreadas até os materiais ou fontes.
{% endstep %}
{% endstepper %}

## Combinações Recomendadas e Critérios de Conclusão

| Janela | Conteúdo Sugerido |
| ----- | --------------------------------- |
| Janela principal | Conversa de materiais, busca global e notas |
| Janela independente | Uma tarefa do Agent em execução |
| Aba fixa | Base de conhecimento ou tarefa mais utilizada no projeto |
| Critério de conclusão | As fontes dos materiais, o estado da tarefa e as notas finais devem corresponder entre si; após o término da tarefa, a janela deve ser recolhida ou fechada |

Adequado para pesquisas que exigem observação contínua de tarefas longas. Não é recomendado abrir muitas janelas simultaneamente apenas para "parecer mais profissional".

{% hint style="info" %}
As janelas múltiplas alteram apenas a posição de exibição, não criando novas contas ou espaços isolados. Os dados e permissões da mesma tarefa permanecem os mesmos.
{% endhint %}
