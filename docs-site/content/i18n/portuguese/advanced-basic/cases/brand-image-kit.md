# Kit de Imagens de Marca

A equipe de conteúdo precisa criar imagens em formato paisagem, quadrado e retrato para o mesmo evento, mantendo a consistência no sujeito principal, na paleta de cores e nas regras da marca. Definir primeiro a visão principal e depois expandir os tamanhos é mais eficaz para manter a uniformidade do que gerar cada imagem do zero.

## Materiais de Preparação

* Tema do conteúdo e plataformas de uso;
* Cores da marca e imagens de referência permitidas;
* Textos, logotipos e elementos proibidos;
* Proporções das três imagens e requisitos de margens.

## Fluxo de Operação

{% stepper %}
{% step %}
### 1. Peça ao Agent para definir a direção visual

Coloque o artigo ou a descrição do evento no diretório de trabalho e peça ao Agent para sugerir apenas o sujeito principal, a cena, a paleta de cores, a lente e as margens, sem gerar imagens ainda.
{% endstep %}

{% step %}
### 2. Valide a visão principal em 【Desenho】

Selecione o modelo e o template adequados e gere primeiro uma amostra em formato paisagem. Verifique a aparência do produto, os detalhes das pessoas e os riscos para a marca.
{% endstep %}

{% step %}
### 3. Expanda os tamanhos usando a imagem de referência

Após selecionar a visão principal, use-a como referência para gerar as versões quadrada e retrato. Em cada instrução, especifique claramente o sujeito principal que deve ser mantido e a composição que pode ser ajustada.
{% endstep %}

{% step %}
### 4. Corrija áreas específicas e aprimore

Use edição ou máscara apenas nas áreas problemáticas e realize o aprimoramento na versão final. Inclua o uso e a proporção no nome do arquivo para evitar confusões.
{% endstep %}
{% endstepper %}

## Verificação dos Resultados

* As três imagens possuem paleta de cores e sujeito principal consistentes;
* Não contêm textos incorretos gerados pelo modelo;
* Não apresentam logotipos da marca, pessoas ou informações sensíveis de forma inesperada;
* Os tamanhos atendem aos requisitos da plataforma de publicação;
* O uso das imagens de referência está autorizado.

## Combinações Recomendadas e Critérios de Conclusão

| Item | Prática Recomendada |
| ---- | ------------------------------- |
| Modelo de Desenho | Use o Agent para gerar uma imagem de amostra e validar a conexão, depois salve o template de desenho |
| Materiais de Entrada | Cores da marca, fontes, tamanhos, imagens de referência e elementos proibidos devem estar no mesmo diretório do projeto |
| Método em Lote | Confirme uma imagem primeiro, depois gere as imagens da mesma série |
| Critério de Conclusão | Tamanhos corretos, textos legíveis, elementos da marca consistentes, sem logotipos extras e a imagem de referência original preservada |

Adequado para capas de artigos, imagens para redes sociais e materiais de eventos; para pôsteres finais que exigem layout preciso, recomenda-se a revisão final em ferramentas de design.

{% hint style="info" %}
Se desejar gerar imagens diretamente na conversa com o Agent, configure primeiro o 【Modelo de Desenho】 global e ative a ferramenta 【Gerar Imagem】 do Agent. Para edições detalhadas, recomenda-se retornar à página 【Desenho】.
{% endhint %}
