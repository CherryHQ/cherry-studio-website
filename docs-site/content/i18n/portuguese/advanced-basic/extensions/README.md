# Estendendo as capacidades do Agent

O Agent já possui ferramentas integradas para arquivos, pesquisa, imagens, memória, fluxos de trabalho e tarefas agendadas. Adicione habilidades quando precisar de métodos de trabalho fixos e adicione MCP quando precisar se conectar a sistemas externos. Eles resolvem problemas diferentes; não é necessário instalar tudo apenas para ter "mais recursos".

<figure><img src="../../../../assets/cc38d8a6378ca8270ceda746.webp" alt="Priorize o caminho mais curto; adicione MCP apenas quando o Agent realmente precisar acessar sistemas externos."><figcaption><p>Priorize o caminho mais curto; adicione MCP apenas quando o Agent realmente precisar acessar sistemas externos. </p></figcaption></figure>

## Primeiro, determine o que é necessário

| Necessidade | Escolha |
| ----------------- | ---------- |
| Definir um conjunto de etapas, modelos ou listas de verificação | Habilidades |
| Consultar bancos de dados, navegadores ou sistemas de terceiros | MCP |
| Recuperar seus próprios documentos e materiais | Base de conhecimento |
| Ler/escrever arquivos do projeto atual, gerar imagens ou enviar notificações | Ferramentas integradas do Agent |

{% hint style="success" %}
A abordagem mais conveniente é descrever diretamente o objetivo em [Trabalho], permitindo que o Agent ajude a determinar se falta uma habilidade, um MCP ou uma base de conhecimento. Quando precisar verificar fontes, parâmetros de conexão ou permissões, gerencie manualmente em [Configurações].
{% endhint %}

## Último passo após a instalação

A instalação global ou o sucesso da conexão não significam que todos os Agents possam usá-los. Abra [Trabalho] → Menu do Agent → [Editar] e selecione em [Habilidades], [MCP] ou [Base de conhecimento], respectivamente. A configuração passa a valer a partir da próxima mensagem.
