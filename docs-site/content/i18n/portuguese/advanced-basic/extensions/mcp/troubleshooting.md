# Solução de Problemas do MCP

<details>

<summary>Devo remover e readicionar o servidor?</summary>

Primeiro, verifique os logs e corrija os itens um a um. Remova e recrie o servidor apenas se a configuração estiver desorganizada e a fonte puder ser obtida novamente; antes de remover, salve uma cópia da configuração sem as chaves de segurança.
