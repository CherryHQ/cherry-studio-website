# Perguntas Frequentes

### 1. mcp-server-time

<figure><img src="../../../../assets/1520c1906faa98104f052666.jpg" alt=""><figcaption><p>Captura de tela do erro</p></figcaption></figure>

**Solução**

No campo "Parâmetros", preencha:

```
mcp-server-time
--local-timezone
<seu fuso horário padrão, por exemplo: Asia/Shanghai>
```
