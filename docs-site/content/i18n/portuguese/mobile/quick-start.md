# Início rápido

Conclua estes quatro passos para enviar sua primeira mensagem.

## 1. Adicionar um provedor

Abra os serviços de modelos nas configurações do aplicativo e escolha um provedor integrado. Para uma API compatível, crie um provedor personalizado e informe a Base URL.

## 2. Informar as credenciais

Informe a chave de API fornecida pelo provedor e salve ou teste a conexão conforme indicado. Nunca compartilhe a chave nem a cole em conversas públicas, capturas de tela ou relatos de erro.

## 3. Adicionar um modelo

Busque ou adicione os modelos do provedor e ative pelo menos um. O suporte a conversa, visão, ferramentas e geração de imagens varia conforme o modelo.

## 4. Enviar uma mensagem

Volte à conversa, abra o assistente padrão ou crie um, selecione um modelo e envie uma mensagem curta. Receber uma resposta confirma que a configuração básica está funcionando.

Em seguida, leia [Provedores e modelos](providers-and-models.md) ou conheça [Conversas e arquivos](chat-and-files.md).
