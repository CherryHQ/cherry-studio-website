# Cherry Studio Mobile

O Cherry Studio Mobile é um cliente de IA criado para Android, iPhone e iPad. Conecte seus próprios serviços de modelos para conversar, configurar agentes e gerar imagens a partir de um dispositivo móvel.

## Situação atual

O aplicativo móvel está em fase **beta**:

* O Android é distribuído como APK oficial.
* iPhone e iPad são distribuídos pelo Apple TestFlight.
* Telas e recursos podem mudar rapidamente. Siga o comportamento da versão instalada no seu dispositivo.

Abra a [opção móvel da página de download](https://cherryai.com/download?platform=mobile) ou leia primeiro o [guia de instalação](installation.md).

## O que é possível fazer

* Adicionar provedores de modelos integrados ou personalizados e organizar os modelos que você usa.
* Trocar de modelo dentro de uma conversa e enviar texto, imagens ou arquivos.
* Criar agentes com instruções próprias, modelo e ferramentas de sistema permitidas.
* Gerar e visualizar imagens com um modelo de imagem configurado.
* Usar uma interface pensada para toque em celulares Android, iPhone e iPad.
