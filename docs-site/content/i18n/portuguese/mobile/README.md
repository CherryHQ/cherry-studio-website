# Cherry Studio Mobile

Cherry Studio Mobile é um cliente de IA projetado para Android, iPhone e iPad. Conecte seus próprios serviços de modelo para conversar, configurar agentes e gerar imagens a partir de um dispositivo móvel.

## Estado atual

O aplicativo móvel está atualmente em **beta**:

* Android é distribuído como um APK oficial.
* As compilações iPhone e iPad são distribuídas pela Apple TestFlight.
* As telas e os recursos podem mudar rapidamente. Acompanhe o comportamento da versão instalada no seu dispositivo.

Abra a [opção móvel na página de download](https://cherryai.com/download?platform=mobile) ou leia primeiro o [Download e instalação](installation.md).
