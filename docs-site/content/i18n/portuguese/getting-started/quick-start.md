# Início rápido

Siga estas etapas para configurar um modelo e enviar sua primeira mensagem em poucos minutos.

## 1. Instalar o Cherry Studio

Baixe o pacote correspondente ao seu sistema e processador na [página oficial](https://cherryai.com/download). Consulte [Download e instalação](../cherry-studio/installation/README.md) caso encontre algum problema.

## 2. Escolher um provedor de modelos

Abra **Configurações → Serviços de modelos**. Se ainda não tiver uma chave de API, use a [referência rápida de provedores](../pre-basic/providers/quick-reference.md) para escolher conforme sua região, os recursos do modelo e suas necessidades de privacidade.

## 3. Adicionar e ativar um modelo

Abra as configurações do provedor, informe a chave de API, obtenha a lista de modelos, adicione um modelo de chat e ative o provedor. Consulte [Configurações do serviço de modelos](../pre-basic/settings/providers.md) para mais detalhes.

## 4. Enviar a primeira mensagem

Volte para **Chat**, crie ou abra um assistente, selecione o modelo adicionado e envie uma mensagem. Receber uma resposta confirma que a configuração básica funciona.
