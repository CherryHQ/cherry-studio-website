# 圖片生成、編輯與增強

【繪畫】不僅可以從文字生成圖片，也可以使用參考圖、編輯指定區域、合併多張圖片、重用模板和增強解析度。先確定圖片用途，再選擇生成或編輯方式。

## 選擇合適的起點

| 需求 | 建議方式 |
| ------------ | ------------ |
| 從零製作視覺方向 | 文生圖或模板 |
| 保留主體、改變背景或風格 | 上傳參考圖後編輯 |
| 只改圖片中的一部分 | 使用遮罩標出修改區域 |
| 把多個素材合成一張圖 | 多圖合併，並說明主次關係 |
| 已有圖片需要更清晰 | 使用增強/放大功能 |

### 範例：從一句描述到成品

開啟【繪畫】，選擇支援目前任務的圖片模型，輸入主體、環境、風格、光線、構圖和限制條件，然後傳送。範例提示詞是：

> 晨光下的創意工作台，櫻桃紅檯燈、速寫本、相機與一枝櫻花，窗外是寧靜群山；柔和 3D 插畫風，暖色晨光，寬幅構圖，無文字。

1. 寫清用途和構圖，選擇繪畫模型。
2. 生成第一版，檢查主體、邊緣和尺寸。
3. 如果還不能使用，只修改一個方向，再次生成並檢查。
4. 確認可用後，放大檢查並匯出。

{% hint style="info" %}
範例使用【GPT-Image-2 | express】生成寬幅工作台插畫。模型、尺寸和可用操作以你目前頁面顯示為準；看不到的參數不要照搬。
{% endhint %}

生成後不要立刻離開：先放大檢查主體、邊緣和多餘元素，再從左側歷史切換版本。需要調整時，保留有效描述，只修改一個方向。

## 完成一張可用圖片

{% stepper %}
{% step %}
### 1. 選模型和模式

不同圖片模型支援的尺寸、參考圖和編輯能力不同。頁面沒有顯示的參數不要憑經驗強行填寫。
{% endstep %}

{% step %}
### 2. 寫清用途和構圖

說明主體、環境、視角、色調、比例、留白和不要出現的內容。要放標題時，通常讓模型留白，文字再由設計工具添加。
{% endstep %}

{% step %}
### 3. 一次只驗證一個方向

先生成小批結果，選中最接近的圖片再編輯或增強。多次同時生成會增加用量，也不利於判斷哪條要求起作用。
{% endstep %}

{% step %}
### 4. 檢查細節後匯出

放大檢查人物手部、產品結構、文字、品牌標誌和邊緣。需要商業使用時，再確認素材來源和相應服務條款。
{% endstep %}
{% endstepper %}

### 在 Agent 中畫圖

先到【設定】→【預設模型】選擇【繪畫模型】，再開啟 Agent 的【內建工具】確認【生成圖片】已啟用。之後可以在【工作】裡讓 Agent 先讀文章、提煉視覺方向，再直接生成配圖。

### 應用案例：製作一組品牌活動配圖

先在模板中確定統一的色調、鏡頭和留白規則，生成橫版頭圖。選定方向後，用同一參考圖分別製作方形社交圖和直式故事圖；產品外觀不一致時用局部編輯修正，最終再增強需要投放的版本。整個過程中不讓模型生成品牌文字，避免錯字和變形。

{% hint style="warning" %}
參考圖可能被傳送到所選模型服務。客戶資資、人像和未公開產品圖在上傳前，應確認允許使用的服務範圍。
{% endhint %}
