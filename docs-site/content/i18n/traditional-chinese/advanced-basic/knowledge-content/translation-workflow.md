# 文件、圖片與長文翻譯

【翻譯】可以處理直接輸入的文字，也可以上傳圖片或文件。圖片會先辨識文字，文件則依格式與內容處理；歷史記錄可以收藏、再次開啟與重用。

<figure><img src="../../../../assets/31b376b5d5a233eeb71ddf12.webp" alt="文件、圖片與長文翻譯 — 說明圖片"><figcaption><p>翻譯是內容工作流程的一環：先確認輸入素材，再統一術語並檢查最終交付物。</p></figcaption></figure>

### 選擇輸入方式

| 素材 | 建議做法 | 檢查重點 |
| -------- | -------------------- | ---------------- |
| 短文字 | 直接貼上 | 語氣、專有名詞、上下文 |
| 截圖或掃描件 | 上傳圖片並使用 OCR | 辨識錯字、表格與數字 |
| PDF | 上傳檔案並選擇是否安裝 BabelDOC | 雙欄版面、字型、表格、註腳與頁數 |
| 其他長文件 | 上傳檔案 | 標題層級、段落、註腳與格式 |
| Markdown | 使用預覽檢查 | 連結、程式碼區塊與標記是否保留 |

#### 範例：短文字翻譯

選擇【自動偵測】作為來源語言、【英文】作為目標語言，輸入中文後點擊【翻譯】。結果出現後先核對「灰階」、「監控指標」、「回滾流程」等關鍵含義，再複製或儲存到筆記。

<figure><img src="../../../../assets/5428125ff9f2c41e29e8c2ed.webp" alt="文件、圖片與長文翻譯 — 說明圖片"><figcaption><p>① 左側保留原文；② 右側顯示譯文。交付前逐項核對灰階發布、監控指標與回滾流程。</p></figcaption></figure>

#### 結果出現後檢查什麼

| 檢查項 | 例子 |
| ----- | ------------------ |
| 關鍵含義 | 「灰階發布」不能只按顏色直譯 |
| 專有名詞 | 產品名稱、團隊名稱與功能名稱保持統一 |
| 數字與條件 | 日期、比例、金額與否定詞不能遺漏 |
| 語氣 | 通知、合約、行銷文案分別採用合適語氣 |

短文字可以直接逐句核對；文件與長文先抽樣檢查標題、表格、數字與重複術語，再決定是否整篇交付。

### 保留版面翻譯 PDF

上傳可提取文字的 PDF 後，頁面會偵測 BabelDOC。首次使用時選擇【安裝 BabelDOC】；相依性就緒後，左側預覽原文，右側顯示譯文 PDF，並依檢查資源、解析、翻譯、排版與渲染顯示進度。

{% stepper %}
{% step %}
#### 1. 上傳 PDF 並檢查相依性

點擊【拖入或點擊上傳圖片/文件】選擇一個 PDF。頁面提示缺少或版本過舊時，安裝或更新 BabelDOC；安裝由 Cherry Studio 的【環境相依性】統一管理。
{% endstep %}

{% step %}
#### 2. 選擇翻譯模型與目標語言

PDF 翻譯需要目前模型能透過本機 API 閘道呼叫。模型不可用時先回到【設定】→【模型服務】檢查連線，不要反覆安裝 BabelDOC。
{% endstep %}

{% step %}
#### 3. 對照雙欄結果

翻譯完成後逐頁比較原文與譯文，重點檢查表格、圖說、頁首頁尾、註腳與換行。點擊下載按鈕可另存譯文 PDF。
{% endstep %}

{% step %}
#### 4. 從歷史記錄繼續

PDF 翻譯會進入【翻譯歷史】與【檔案】。歷史記錄可重新開啟雙欄預覽、定位譯文檔案或另存結果；刪除記錄時，對應譯文檔案也會一併回收。
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
掃描版或純圖片 PDF 暫不支援保留版面翻譯。頁面提示需要 OCR 時，先將圖片文字辨識為可校對文字，再使用一般翻譯流程。
{% endhint %}

### 翻譯步驟

{% stepper %}
{% step %}
#### 1. 先確認來源語言與目標語言

自動辨識適合混合或未知語言；合約、技術文件等正式素材建議手動確認語言，減少誤判。
{% endstep %}

{% step %}
#### 2. 選擇翻譯方式

需要上下文、語氣與術語一致時使用已設定的模型；一般短句可以選擇更輕量的方式。具體可用項目以目前頁面為準。
{% endstep %}

{% step %}
#### 3. 分段核對

先檢查名稱、數字、日期、否定詞與單位。圖片翻譯還要核對 OCR 結果；辨識錯了，後面的譯文也會跟著錯。
{% endstep %}

{% step %}
#### 4. 收藏、匯出或重用結果

在【翻譯歷史】中查看、收藏與再次使用文字譯文；PDF 結果可以雙欄預覽、開啟檔案或另存。正式交付前，將術語表與人工修訂儲存到專案資資中。
{% endstep %}
{% endstepper %}

#### 應用案例：準備多語言產品資資

先將產品名稱、功能名稱與禁止改寫的術語整理成一份說明。上傳中文說明書，先翻譯一個章節並確認術語，再處理全文；宣傳圖片單獨上傳做 OCR 翻譯。完成後將已確認的術語與譯文放入專案工作目錄，讓 Agent 統一檢查標題、連結與數字，但不讓它自行改寫法律聲明。

{% hint style="danger" %}
醫療、法律、財務及安全相關內容需要專業人員覆核。自動翻譯可以提高效率，不能替代有責任主體的校對。
{% endhint %}
