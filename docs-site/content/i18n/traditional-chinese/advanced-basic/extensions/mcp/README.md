# MCP 與外部工具

MCP 是讓 Agent 使用外部工具和資源的連接方式。Cherry Studio 可以管理 MCP 伺服器、內建伺服器、服務市場和部分服務商入口，再把已連接的伺服器綁定給指定 Agent。

### 什麼時候需要 MCP

<figure><img src="../../../../../assets/79e45524b78de312b0ea7d2b.webp" alt="MCP 與外部工具 — 說明圖片"><figcaption></figcaption></figure>

* Agent 需要調用 Cherry Studio 內建工具之外的服務；
* 團隊已經有提供 MCP 介面的資資庫、瀏覽器或業務系統；
* 希望同一套外部能力被多個 Agent 重用；
* 需要把工具、資源或提示詞以統一方式提供給模型。

只需要固定流程時用技能，只需要檢索 Cherry Studio 知識庫時直接綁定知識庫，不必為了「更進階」而額外搭建 MCP。

### 新增伺服器

路徑：【設定】→【MCP】→【MCP 伺服器】→【新增】。

{% stepper %}
{% step %}
#### 1. 確認連接方式

本機命令通常使用標準輸入輸出方式；遠端服務通常提供 SSE 或可串流傳輸的 HTTP 位址。按照服務提供方給出的設定填寫，不要憑名稱猜測。
{% endstep %}

{% step %}
#### 2. 填寫設定並檢查權限

本機伺服器需要命令、參數和環境變數；遠端伺服器需要 URL，部分服務還需要授權。儲存前確認命令來源和資資範圍。
{% endstep %}

{% step %}
#### 3. 啟動並檢視工具

啟用伺服器，等待狀態正常，再開啟詳情檢查它提供的工具、資源和提示詞。連接失敗時先檢視伺服器日誌。

在工具列表中展開某個工具，可以檢視完整的 Markdown 說明，以及按層級展示的參數、型別、必填標記和列舉值。調用前先核對必填參數；物件或陣列參數應逐層展開檢視，避免只按工具名稱猜測輸入格式。
{% endstep %}

{% step %}
#### 4. 綁定到 Agent

開啟【工作】→ Agent 選單→【編輯】→【MCP】，啟用該伺服器。未啟動的伺服器無法正常綁定使用。
{% endstep %}
{% endstepper %}

### 內建伺服器與服務市場

【內建 MCP】提供可以直接安裝或啟用的常用能力；【服務市場】用於管理第三方市場來源。安裝前仍要檢視說明、命令、環境變數和權限，內建入口不代表外部服務的所有操作都沒有風險。

<figure><img src="../../../../../assets/3892f8eaa6ef4645921a382d.webp" alt="MCP 與外部工具 — 說明圖片"><figcaption><p>① 內建列表會標明是否需要帳號、API Key 或目錄設定；安裝後仍要完成設定並驗證連接。</p></figcaption></figure>

QVeris 位於【內建伺服器】中，用於讓 Agent 發現、檢查和調用外部能力。安裝後需要設定 `QVERIS_API_KEY`；不要把金鑰寫進 Agent 提示詞、技能或公開截圖。

### 在輸入區使用 MCP 提示詞和資源

伺服器除工具外，還可能提供「提示詞」和「資源」。伺服器已綁定到當前助手或 Agent 後，開啟輸入區【+】面板：

* 選擇【MCP 提示詞】，把伺服器模板插入輸入框；模板中的必填參數會顯示為可填寫項；
* 選擇【MCP 資源】，從已綁定伺服器中選擇檔案、記錄或其他資源；
* 較短的文本資源會直接插入輸入框；較大或二進位資源會作為引用，由支援工具調用的模型在需要時讀取。

{% hint style="info" %}
面板只顯示當前對話範圍內已連接、並且真正提供對應能力的伺服器。看不到【MCP 提示詞】或【MCP 資源】時，先在伺服器詳情檢查對應分頁，再確認當前助手或 Agent 已綁定該伺服器。
{% endhint %}

### 設定建議

| 設定項 | 產品預設值 | 建議起點 | 作用 | 適用場景 | 注意事項 |
| -------- | -------------- | ----------------- | --------- | ------------- | ------------ |
| 伺服器狀態 | 新增後按設定決定 | 一次只啟用一個並驗證 | 控制伺服器是否可用 | 初次接入、排錯 | 多個服務同時失敗時難定位 |
| Agent 綁定 | 不自動綁定所有伺服器 | 只綁定當前 Agent 所需伺服器 | 控制能力範圍 | 多 Agent 分工 | 避免無關工具佔用上下文 |
| 環境變數 | 不預填金鑰 | 使用服務要求的最小權限憑證 | 提供認證或執行參數 | 私有服務 | 截圖和匯出前遮擋敏感內容 |
| 工具核准 | 由 Agent 權限模式決定 | 寫入或計費工具保持確認 | 防止意外操作 | 資資庫、檔案、外部 API | 頻道入口可使用更嚴格模式 |

### 使用者案例：把專案資資庫接給分析 Agent

管理員提供唯讀 MCP 連接，使用者在【設定】→【MCP】驗證伺服器正常，再只綁定給「資資分析」Agent。Agent 使用唯讀工具取得資資，將報告寫入工作目錄；涉及更新資資的工具不啟用。這樣即使提示詞出現誤解，也不會直接修改業務庫。

<details>

<summary>MCP 與 API 閘道有什麼區別？</summary>

MCP 是把外部工具接入 Cherry Studio；API 閘道是把 Cherry Studio 的模型能力以相容 API 提供給其他程式。資資流方向相反。

</details>

<details>

<summary>伺服器顯示已連接，Agent 仍找不到工具怎麼辦？</summary>

檢查 Agent 是否綁定了該伺服器、工具是否被關閉、權限請求是否待處理。修改 Agent 設定後，新發一條訊息讓執行時載入新工具。

</details>
