# 輸入工具列與效率工具

<details>

<summary>為什麼工具固定後在另一個輸入區沒有出現？</summary>

Chat、Agent、快捷助手和繪圖頁面支援的工具不同，Chat 與 Agent 的固定布局也分別儲存。請在目標輸入區重新開啟【自訂工具列】。

</details>
