# 截圖、標註與 OCR

Cherry Studio 可以透過全域快捷鍵截取螢幕區域，新增矩形、箭頭、畫筆、文字或馬賽克，並將結果複製或儲存。啟用本地 OCR 後，還可以直接選取並複製截圖中的文字。

### 目標與前置條件

* 路徑：【設定】→【截圖】；
* macOS 首次使用需要允許螢幕錄製，授權後依頁面提示重新啟動應用程式；
* OCR 需要在【設定】→【本地模型】下載文字識別模型；
* 截圖功能預設關閉，自動識別文字預設開啟，但模型未就緒時不會執行 OCR。

### 術語

| 術語 | 含義 |
| ----- | ------------------------------- |
| 全域快捷鍵 | 即使目前焦點不在 Cherry Studio，也能觸發的快捷鍵 |
| OCR | 將圖片中的文字識別為可選取、複製的文字 |
| 馬賽克 | 遮蔽截圖中的帳號、路徑、金鑰或其他敏感區域 |

### 操作路徑

【設定】→【截圖】→開啟【啟用截圖】→按截圖快捷鍵→框選區域→標註或識別文字→複製或儲存。

### 操作步驟

{% stepper %}
{% step %}
#### 1. 啟用截圖並檢查權限

開啟【設定】→【截圖】，開啟【啟用截圖】。macOS 出現【螢幕錄製權限】時選擇【去授權】；授權完成後點擊【立即重新啟動】。
{% endstep %}

{% step %}
#### 2. 設定快捷鍵

預設快捷鍵是 macOS 的 `Command+Shift+A`，Windows 和 Linux 的 `Ctrl+Shift+A`。點擊【設定快捷鍵】可以跳到對應行；如果系統或其他應用程式已經佔用，頁面會顯示衝突提示。
{% endstep %}

{% step %}
#### 3. 框選並標註

按下快捷鍵後拖動框選區域。使用【矩形】【箭頭】【畫筆】【文字】標出重點，使用【馬賽克】遮蔽敏感資訊；屬性面板可以調整顏色、線寬和字號。
{% endstep %}

{% step %}
#### 4. 複製文字或圖像

OCR 模型就緒時，頁面會自動識別文字；也可以點擊【識別文字】。直接選取文字或選擇【複製全部文字】；完成標註後選擇【複製並關閉】或【儲存圖像】。
{% endstep %}
{% endstepper %}

### 預期結果

截圖只包含框選區域；標註清晰且敏感資訊已經遮蔽；複製後可在目標應用程式貼上圖像，或將 OCR 文字貼上為可編輯文字。

### 設定說明

| 設定項 | 產品預設值 | 建議起點 | 作用 | 適用場景 | 注意事項 |
| ------ | ---------------------- | ------------- | ----------- | ------------ | -------------- |
| 啟用截圖 | 關閉 | 需要時開啟 | 註冊全域截圖快捷鍵 | 日常截圖、教學、問題回饋 | macOS 需要螢幕錄製權限 |
| 截圖快捷鍵 | `Command/Ctrl+Shift+A` | 保持預設，衝突時再改 | 從任意應用程式觸發截圖 | 高頻跨應用程式使用 | 與其他應用程式衝突時不會觸發 |
| 自動識別文字 | 開啟 | 經常複製截圖文字時保持開啟 | 截圖後自動執行 OCR | 報錯截圖、表格、介面文字 | 需要下載本地 OCR 模型 |

### 使用者案例

測試人員截取一個設定錯誤，使用矩形框住錯誤提示，用馬賽克遮蔽帳號和本地路徑，再複製到問題回饋助手。隨後從同一截圖複製錯誤碼，貼上到重現步驟中，避免手動輸入出錯。

### 常見問題

<details>

<summary>按快捷鍵沒有反應怎麼辦？</summary>

確認【啟用截圖】已開啟，再查看快捷鍵旁是否出現衝突提示。macOS 還要檢查螢幕錄製權限並在授權後重新啟動；Windows 和 Linux 可嘗試換一個沒有被系統佔用的組合。

</details>

<details>

<summary>為什麼不能複製文字？</summary>

開啟【設定】→【本地模型】，確認 OCR 模型狀態為就緒。標註過程中無法識別文字；先完成或撤銷目前標註，再執行 OCR。

</details>
