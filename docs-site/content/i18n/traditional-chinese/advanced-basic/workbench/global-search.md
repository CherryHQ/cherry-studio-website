# 全域搜尋

全域搜尋用於在單一入口中查找訊息、對話、任務、助手、Agent 和知識庫。它適合「記得內容，但不記得放在哪裡」的情況。

<figure><img src="../../../../assets/c88f597e18a3b7eac541dbf7.webp" alt="全域搜尋 — 說明圖片"><figcaption><p>先輸入具有辨識度的關鍵詞，再依對話、知識庫等類型和更新時間縮小範圍。</p></figcaption></figure>

## 使用方式

{% stepper %}
{% step %}
### 1. 點擊視窗頂部的搜尋按鈕

也可以在【設定】→【快捷鍵】中查看或修改對應的快捷鍵。
{% endstep %}

{% step %}
### 2. 輸入具有辨識度的關鍵詞

優先使用專案名稱、人名、檔案主題或結論中的短語。若只輸入「設定」、「報告」等常見詞，結果通常過多。
{% endstep %}

{% step %}
### 3. 縮小搜尋範圍

切換至【訊息】或使用【對話】【任務】【助手】【智能體】【知識庫】進行篩選，再依更新時間縮小範圍。
{% endstep %}

{% step %}
### 4. 開啟結果繼續工作

搜尋會帶您回到對應的內容。開啟前請先確認類型，避免將同名助手與 Agent 任務混淆。
{% endstep %}
{% endstepper %}

### 應用案例：找回上個月的客戶結論

搜尋客戶專案名稱，再將類型縮小至【訊息】並限制更新時間。找到結論後開啟原始對話，先確認後續是否有修訂；若需將結論用於新任務，請複製已確認的摘要，而不是讓新對話依賴記憶中的零散片段。

<details>

<summary>為什麼搜尋不到磁碟機中的檔案內容？</summary>

全域搜尋主要查找 Cherry Studio 中已儲存的內容。磁碟機檔案需在 Agent 工作目錄、知識庫或筆記中進入相應流程後，才能透過對應入口進行查找。

</details>
