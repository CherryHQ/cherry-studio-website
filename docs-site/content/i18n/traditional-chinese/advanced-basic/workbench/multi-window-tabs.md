# 多視窗與分頁

對話主題、Agent 任務和一般分頁都能從目前視窗拆出。操作不會複製內容，只是改變顯示位置。

<figure><img src="../../../../assets/b695c03a2d68db6c3e947867.webp" alt="多視窗與分頁 — 說明圖片"><figcaption><p>右鍵點選目標分頁選擇【從新視窗開啟】；經常使用的頁面可以先固定，避免誤關。</p></figcaption></figure>

## 從主題或任務開啟

{% stepper %}
{% step %}
### 1. 找到目標主題或 Agent 任務

在左側主題列表或 Agent 任務列表中右鍵點選目標項目。
{% endstep %}

{% step %}
### 2. 選擇開啟方式

選擇【在新分頁中開啟】會保留在主視窗；選擇【從新視窗開啟】會直接建立獨立視窗，目前列表仍可繼續使用。
{% endstep %}

{% step %}
### 3. 管理獨立視窗

點選頂部【視窗置頂】可保持在其他視窗前；點選【回到主視窗】會把目前內容接回主視窗並關閉獨立視窗。
{% endstep %}
{% endstepper %}

## 從分頁拆出

右鍵點選主視窗頂部分頁，選擇【從新視窗開啟】。這個操作會把該分頁移到獨立視窗，並從主視窗分頁列移除。

## 分頁常用操作

* 【移到最左側】：把目前分頁移到一般分頁最前；
* 【固定分頁】：縮成固定圖示並保留在分頁列左側；
* 【關閉其他分頁】：只保留目前頁面；
* 【關閉右側分頁】：整理一批臨時頁面；
* 拖動分頁：調整同類分頁順序。

## 使用情境：一邊查資資，一邊看任務

把資資對話留在主視窗，將正在執行的 Agent 任務【從新視窗開啟】，再把任務視窗置頂。資資仍在原對話中，任務也不會因拆視窗重新開始。任務結束後點選【回到主視窗】，避免長期堆積獨立視窗。

### 建議佈局

主視窗負責資資與搜尋，獨立視窗只保留一個需要持續觀察的任務；相同項目的常用分頁使用【固定分頁】，臨時頁面完成後及時關閉。

### 完成標準

資資仍能回到原對話，Agent 任務沒有因拆視窗重新開始，任務結束後已回到主視窗或關閉獨立視窗。

{% hint style="warning" %}
視窗置頂只改變顯示層級，不會提高任務優先順序，也不會阻止系統休眠。需要背景持續執行時，應檢查 Agent 狀態和系統電源設定。
{% endhint %}

<details>

<summary>為什麼獨立視窗中不能再開啟隱藏的內部分頁？</summary>

獨立視窗圍繞一個內容執行。要開啟其他主題或任務，使用右鍵選單新開視窗，或先點選【回到主視窗】再管理分頁。

</details>
