# 高效工作台

Cherry Studio 的主視窗由側邊欄、分頁與內容區組成。對話主題與 Agent 任務可以同時開啟在多個分頁，也可以拆分為獨立視窗；輸入區工具列則可依使用習慣進行調整。

<figure><img src="../../../../assets/b695c03a2d68db6c3e947867.webp" alt="高效工作台 — 說明圖片"><figcaption><p>需要同時查看資資與任務時，將其中一個分頁從新視窗開啟，主視窗繼續保留全局線索。</p></figcaption></figure>

### 適合使用獨立視窗的場景

* 一邊保留資資對話，一邊執行 Agent 任務；
* 將長期監控任務置頂，避免被其他視窗遮擋；
* 在不同顯示器上分別放置對話、檔案或任務；
* 展示或共享某個任務時，不暴露主視窗中的其他分頁。

### 工作台能力

| 能力 | 入口 | 作用 |
| ------ | -------------------- | -------------- |
| 新分頁 | 主題或任務右鍵選單→【在新分頁中開啟】 | 在主視窗中並排保留多個上下文 |
| 獨立視窗 | 主題、任務或分頁右鍵→【從新視窗開啟】 | 將目前內容拆分到新視窗 |
| 置頂分頁 | 分頁右鍵→【固定分頁】 | 固定常用頁面 |
| 視窗置頂 | 獨立視窗頂部【視窗置頂】 | 讓任務保持可見 |
| 回到主視窗 | 獨立視窗頂部【回到主視窗】 | 將分頁重新接回主視窗 |
| 自訂工具列 | 輸入區【+】→【自訂工具列】 | 調整常用輸入工具的位置 |

在上圖的分頁選單中選擇【從新視窗開啟】，即可將目前內容拆分到獨立視窗。

### 推薦佈局

辦公寫作可以將資資對話留在主視窗，將「寫作」Agent 拆分到右側螢幕；程式開發工作可以將 Agent 任務置頂，主視窗保留檔案與文件；長時間監控任務使用獨立視窗，但不要把需要頻繁確認權限的任務放在看不到的位置。

{% hint style="info" %}
獨立視窗仍然屬於同一個 Cherry Studio 資資環境。它不是新的帳號或隱私空間；同一主題或任務的內容仍會同步儲存。
{% endhint %}
