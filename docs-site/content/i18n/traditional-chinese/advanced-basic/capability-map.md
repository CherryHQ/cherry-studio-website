# 進階能力地圖

進階教程不按設定選單逐項羅列，而是從「想完成什麼工作」出發。先選最接近的目標，再進入對應教程。

<figure><img src="../../../assets/f99c1bfff81d92511c921169.webp" alt="進階能力地圖 — 說明圖片"><figcaption><p>先選主入口完成最小任務；結果穩定後，再加入知識庫、技能、MCP、頻道或排程任務。</p></figcaption></figure>

{% hint style="success" %}
需要配置一套教程、頻道、排程任務或擴展能力時，優先在【工作】中告訴 Agent 你的目標。Agent 可以幫助判斷缺少什麼並帶你完成常見配置；需要核對帳號、金鑰或精確參數時，再到【設定】手動調整。
{% endhint %}

<figure><img src="../../../assets/8fe4d938af469d667d4071df.webp" alt="進階能力地圖 — 說明圖片"><figcaption><p>左側啟動台提供九個主要入口，選擇與任務最接近的一個開始。</p></figcaption></figure>

圖表說明：先按目標選擇主要入口，流程穩定後再加入技能、MCP、頻道或排程任務。

### 按目標選擇入口

| 你想完成什麼 | 推薦入口 | 會用到的能力 |
| ------------- | ----------------------- | --------------------- |
| 比較多個回答、整理長討論 | 【對話】 | 多模型、訊息分支、上下文、引用與產物 |
| 處理檔案或完成多步驟任務 | 【工作】 | Agent、工作目錄、工具、權限與狀態面板 |
| 用自己的資資穩定問答 | 【知識庫】→召回測試，再綁定 Agent | 檔案/網頁/筆記、RAG、檢索範圍 |
| 從文章生成配圖或編輯圖片 | 【繪畫】，或在 Agent 中啟用【生成圖片】 | 模板、參考圖、局部編輯、增強 |
| 翻譯文本、截圖或長文件 | 【翻譯】 | OCR、文件處理、歷史和收藏 |
| 沉澱草稿並繼續加工 | 【筆記】 | Markdown、搜尋、匯出、加入知識庫 |
| 截取介面、標註並複製文字 | 【設定】→【截圖】啟用後使用全域快捷鍵 | 區域截圖、標註、馬賽克、OCR |
| 開啟常用網頁應用 | 【小程式】 | 內建網頁工具和已添加的站點 |
| 瀏覽、預覽和整理本機檔案 | 【檔案】 | 檔案列表、預覽和後續處理 |
| 連接外部工具或固定工作方法 | 先讓 Agent 判斷，再到【設定】核對 | 技能、MCP、內建工具 |
| 從外部平台使用 Agent | 先在【工作】中讓 Agent 引導配置 | 頻道、允許範圍、權限模式 |
| 按計畫生成日報或提醒 | 先跑通 Agent，再建立【排程任務】 | Agent、工作目錄、頻道、執行記錄 |
| 同時查看資資與任務 | 分頁右鍵→【從新視窗開啟】 | 多視窗、固定分頁、全域搜尋 |
| 管理程式設計命令列 | 啟動台【編碼搭檔】 | Code CLI、模型連接、目錄與終端機 |
| 讓本機程式呼叫模型或排錯 | 【設定】→【API 閘道】/【一般】 | 相容 API、呼叫鏈、開發者模式 |

### 推薦學習順序

{% stepper %}
{% step %}
#### 1. 先掌握 Agent 工作區

學會建立 Agent、選擇工作目錄、理解模型分工和權限。後面的擴展、自動化和專案案例都建立在這裡。
{% endstep %}

{% step %}
#### 2. 再接入資資與能力

長期資資用知識庫，重複方法用技能，外部系統用 MCP。每次只增加一種能力並用小任務驗證。
{% endstep %}

{% step %}
#### 3. 最後自動執行或對外連接

手動結果穩定後再配置頻道、排程任務、Code CLI 或外部 API。這樣出現問題時更容易找到是哪一環。
{% endstep %}
{% endstepper %}
