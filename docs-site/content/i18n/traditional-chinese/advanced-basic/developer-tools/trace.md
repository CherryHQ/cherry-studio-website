# 呼叫鏈與開發者模式

呼叫鏈用於檢視一次對話或 Agent 任務內部發生的模型請求、工具呼叫與 MCP 互動。它適合用於除錯與效能分析，並非日常聊天必須開啟的功能。

<figure><img src="../../../../assets/7cb797e89c5a180b57971c67.webp" alt="呼叫鏈與開發者模式 — 說明圖片"><figcaption><p>排查 MCP 呼叫時，先確認伺服器與驗證，再使用呼叫鏈判斷請求是否進入 Agent 與工具執行階段。</p></figcaption></figure>

### 開啟方式

{% stepper %}
{% step %}
#### 1. 開啟【設定】→【一般】

在【開發者模式】區域開啟【啟用開發者模式】。
{% endstep %}

{% step %}
#### 2. 重新啟動 Cherry Studio

開發者模式在重新啟動後生效。重新啟動前正在執行的 Agent 任務應先確認狀態。
{% endstep %}

{% step %}
#### 3. 重現一次問題

重新傳送最小測試訊息，僅保留必要的模型與工具，減少無關呼叫。
{% endstep %}

{% step %}
#### 4. 開啟呼叫鏈

在對話或 Agent 右側面板進入【呼叫鏈】，選擇節點檢視輸入、輸出、耗時與狀態。Agent 任務還能看到 Agent 名稱、操作與工具呼叫數量。
{% endstep %}
{% endstepper %}

### 常見節點如何判讀

| 節點 | 重點檢查 | 常見問題 |
| -------- | ------------------ | ---------------- |
| 模型請求 | 模型、輸入、輸出、Token 與狀態 | 服務供應商錯誤、上下文過長、輸出為空 |
| 工具呼叫 | 工具名稱、參數、結果 | 參數錯誤、權限等待、工具回傳異常 |
| MCP 呼叫 | 服務名稱、連線類型、輸入與輸出 | 伺服器中斷、驗證失敗、遠端錯誤 |
| Agent 執行 | Agent、操作、工具數量與狀態 | 子任務失敗、流程未結束 |
| HTTP 請求 | 方法、URL、狀態與回應 | 位址錯誤、網路或鑑權問題 |

{% hint style="danger" %}
呼叫鏈可能包含提示詞、檔案內容、請求標頭與工具參數。分享截圖或匯出資訊前，必須刪除 API Key、Authorization、Cookie、電子郵件、本機路徑與業務資資。
{% endhint %}

### 使用者案例：MCP 工具回傳空結果

先在 MCP 設定頁確認伺服器正常，再讓 Agent 僅呼叫一個工具。呼叫鏈顯示請求已到達伺服器但輸出為空，表示問題更可能在伺服器端資資或參數，而非 Agent 未綁定；若根本沒有 MCP 節點，則回到 Agent【MCP】檢查綁定。

<details>

<summary>為什麼開啟後仍看不到呼叫鏈？</summary>

確認已重新啟動應用程式，並在重新啟動後重新發起一次請求。啟用前產生的歷史訊息不會自動補齊呼叫資資。
