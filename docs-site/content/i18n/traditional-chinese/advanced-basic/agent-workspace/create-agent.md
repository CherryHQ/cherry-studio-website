# 建立 Agent 與模型分工

建立入口：左側導覽【工作】→【新增智能體】。

新增精靈分為【基本資訊】、【系統提示詞】、【技能】和【知識庫】四個步驟。第一步還需選擇執行模式；執行模式會決定 Agent 可用的模型分工、權限模式和部分工具，建立後無法切換。

### 執行模式如何選擇

| 執行模式 | 主要特點 | 模型設定 | 權限與限制 |
| ------------------ | ------------------- | -------------------- | ------------------------------------ |
| 【增強：Claude Agent】 | 能力面完整，適合複雜、多步驟任務 | 主模型、Plan 模型、Small 模型 | 支援全部權限模式與心跳偵測 |
| 【快速：Pi】 | 回應快、開銷低，適合日常檔案和編碼任務 | 僅設定主模型 | 不提供【僅規劃】；新增時預設【智慧核准】 |
| 【DeepSeek Harness】 | 相容多種模型服務，支援目標驅動執行 | 僅設定主模型 | 不提供【智慧核准】和心跳偵測；支援 `/compact`、`/goal` |

{% hint style="warning" %}
執行模式建立後不可變更。如果目標、模型相容性或權限需求發生根本變化，請新增一個 Agent，而不是繼續修改舊 Agent。
{% endhint %}

### 四個步驟如何填寫

{% stepper %}
{% step %}
#### 1. 基本資訊

名稱寫成崗位或任務類型，例如「合約檢查」「內容策劃」。先選擇執行模式，再選擇頁面列出的相容模型。描述僅用於幫助識別用途；主模型負責主要推理和執行。
{% endstep %}

{% step %}
#### 2. 撰寫系統提示詞

寫清角色、目標、邊界和輸出方式。與其堆砌形容詞，不如給出可執行規則：先列風險，再引用原文，最後給出修改建議；遇到資資不足時明確標記，不要猜測。
{% endstep %}

{% step %}
#### 3. 選擇技能

僅選擇與這個 Agent 長期工作方式有關的技能。技能可以在【設定】→【技能】安裝，也可以之後讓 Agent 幫你查找和安裝。
{% endstep %}

{% step %}
#### 4. 綁定知識庫

僅綁定 Agent 確實需要檢索的知識庫。未綁定知識庫時，知識庫搜尋和管理工具不會出現在該 Agent 的工具列表中。
{% endstep %}
{% endstepper %}

### 建立後繼續設定

在 Agent 列表開啟選單並選擇編輯，可以調整以下內容：

* 【基本】：檢視執行模式，並調整該模式支援的模型、權限和心跳設定；
* 【提示詞】：角色說明、處理規則和行為邊界；
* 【內建工具】：檔案、搜尋、圖片、通知、排程任務、記憶、子智能體和工作流等；
* 【知識庫】：限制 Agent 可以存取的知識庫；
* 【MCP】：綁定已連接的 MCP 伺服器；
* 【技能】：選擇已安裝技能；
* 【進階】：為確實需要的工具設定環境變數。

{% hint style="info" %}
目前編輯視窗會自動儲存修改。關閉視窗前若仍有待儲存內容，應用程式會先完成儲存；儲存失敗時視窗會保持開啟並顯示錯誤。
{% endhint %}

### 建議起點

| 設定項 | 產品預設值 | 建議起點 | 作用 | 適用場景 | 注意事項 |
| --------------- | ----------------------------- | ----------------------- | -------------- | ------------------ | ---------------------------------- |
| 執行模式 | 【增強：Claude Agent】 | 不確定時先用【增強：Claude Agent】 | 決定模型分工、權限和工具範圍 | 所有 Agent | 建立後無法切換 |
| 主模型 | 使用建立時選擇的模型 | 選擇一個已驗證能穩定呼叫工具的模型 | 主要推理和執行 | 所有 Agent | 選擇器會依執行模式過濾不相容模型 |
| Plan / Small 模型 | 與主模型相同 | 先保持與主模型一致 | 任務拆解、簡單判斷和格式化 | 僅【增強：Claude Agent】 | Pi 與 DeepSeek Harness 不顯示這兩個欄位 |
| 權限模式 | Claude/DSH 為【逐次確認】；Pi 為【智慧核准】 | 真實專案目錄優先使用【逐次確認】 | 決定工具是否需要核准 | 檔案、終端機和網路任務 | 【完全存取】可能刪除檔案或存取網路 |
| 心跳偵測 | 支援的執行模式初始開啟，間隔 30 分鐘 | 沒有持續任務時可關閉 | 讓 Agent 定期檢查工作 | Claude Agent、Pi | DeepSeek Harness 不提供心跳偵測；固定時間用排程任務 |

### 使用者案例：合約檢查 Agent

建立「合約檢查」Agent，主模型選擇已驗證的模型，在提示詞中要求按「風險條款、原文位置、影響、建議」輸出，綁定公司制度知識庫，權限保持【逐次確認】。每份合約新增一個任務並選擇對應檔案目錄，避免不同客戶資資混在同一上下文中。

<details>

<summary>為什麼建立時沒有看到 MCP 和權限的完整設定？</summary>

建立精靈僅保留常用步驟。建立完成後開啟 Agent 編輯視窗，可在【基本】【內建工具】【知識庫】【MCP】【技能】和【進階】中繼續設定；具體標籤會隨執行模式能力變化。

</details>
