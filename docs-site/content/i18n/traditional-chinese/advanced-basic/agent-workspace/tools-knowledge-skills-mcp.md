# 內建工具、知識庫、技能與 MCP

這四類能力都能增強 Agent，但解決的問題不同：內建工具負責常見操作，知識庫限定可檢索資資，技能提供工作方法，MCP 連接外部工具和數據。

### 區別與組合

<figure><img src="../../../../assets/6be829efa6152cf0a3576cba.webp" alt="內建工具、知識庫、技能與 MCP — 說明圖片"><figcaption></figcaption></figure>

| 能力 | 解決的問題 | 例子 |
| ---- | ----------------------------- | ------------------------- |
| 內建工具 | Agent 在 Cherry Studio 內能直接做什麼 | 讀寫檔案、網頁搜尋、生成圖片、記憶、通知、排程任務 |
| 知識庫 | Agent 可以檢索哪些私有資資 | 產品規範、合約範本、團隊手冊 |
| 技能 | Agent 應按什麼流程和標準工作 | 週報格式、程式碼審查清單、寫作規範 |
| MCP | Agent 可以連接哪些外部工具與資源 | 資資庫、瀏覽器、第三方業務系統 |

設定路徑：左側導覽【工作】→ 開啟 Agent 選單→【編輯】→【內建工具】。

### 內建工具

內建工具依上下文、檔案、多媒體、編排、搜尋和終端機分組。常用能力包括：

* 【生成圖片】：使用已設定的繪圖模型；
* 【知識庫搜尋】與【知識庫管理】：只在綁定知識庫後出現；
* 【網頁搜尋】與【網頁抓取】：使用 Cherry Studio 已設定的聯網能力；
* 【記憶】：跨任務儲存和檢索穩定資訊；
* 【排程任務】與【通知】：讓 Agent 管理計畫並向頻道發送結果；
* 【Task】與【工作流】：用子智能體或編排處理複雜任務；
* 【檔案轉 Markdown】：讀取工作目錄或目前對話附件中的 PDF、Word、PowerPoint、Excel、OpenDocument、RTF、EPUB 和 CSV，並將結構化內容交給 Agent 分段處理；
* 對話協調工具：查找已有 Agent 對話、新建獨立對話、發送任務並接收可追蹤的完成結果；
* 檔案和 Bash 工具：讀取、建立、修改檔案並執行命令。

{% hint style="info" %}
【檔案轉 Markdown】不會改寫原始檔案，也不提供掃描版 PDF 的 OCR。掃描件先使用【OCR】或文件處理能力，再交給 Agent。
{% endhint %}

### 知識庫範圍

在【知識庫】中選擇的知識庫，是該 Agent 的檢索邊界。未選擇時，知識庫工具不會載入；選擇多個時，Agent 也只會在這些知識庫內工作，不會自動讀取其他資資庫。

### 技能

在【技能】中啟用已經安裝的技能。技能內容會進入 Agent 的工作環境，用於約束流程和輸出。需要新技能時，可以在【工作】中直接讓 Agent 幫你查找和安裝；手動管理路徑是【設定】→【技能】。

### MCP

先在【設定】→【MCP】連接並啟動伺服器，再回到 Agent 編輯視窗的【MCP】綁定。未執行的伺服器不能啟用；連接後，它提供的工具會進入 Agent 的工具目錄，並繼續受權限模式控制。伺服器若同時提供資源或提示詞，還可以從輸入區【+】面板直接選擇使用。

{% hint style="danger" %}
開啟工具不等於應該跳過核准。對檔案寫入、終端機、外部數據修改和可能計費的圖片生成，優先保持【逐次確認】；只對來源可信、風險明確的工具使用更寬鬆權限。
{% endhint %}

### 推薦組合

| 任務需要 | 建議組合 | 什麼時候再增加 | 注意事項 |
| -------- | ------------- | ------------- | ------------- |
| 處理本機檔案 | 檔案工具 + 專用工作目錄 | 需要固定格式時加技能 | 先保留【逐次確認】 |
| 根據內部資資回答 | 知識庫 + 知識庫搜尋 | 召回穩定後再交給頻道 | 先做沒有答案的問題測試 |
| 重複執行固定流程 | 技能 + 必要的內建工具 | 需要外部數據時再加 MCP | 技能不要存帳號金鑰 |
| 呼叫外部系統 | MCP + 最小權限憑證 | 任務穩定後再放寬核准 | 寫入、刪除和計費操作應確認 |

### 使用者案例：市場研究 Agent

給 Agent 綁定產品資資知識庫，啟用「研究報告」技能，連接一個可信的網頁檢索 MCP，並保留內建網頁抓取和檔案寫入工具。Agent 先從內部資資確定產品範圍，再搜尋外部資訊，最後按技能規定的結構寫入工作目錄。內部資資、外部來源和輸出格式各有明確歸屬，後續更容易維護。

<details>

<summary>為什麼綁定知識庫後還是沒有檢索結果？</summary>

確認知識庫已經完成處理且包含可檢索內容，再檢查 Agent 編輯視窗中的綁定是否仍然存在。知識庫被刪除後，相關綁定會自動移除。

</details>

<details>

<summary>開啟技能後需要重開任務嗎？</summary>

不需要關閉任務。編輯 Agent 後，從下一則訊息開始會載入新的技能設定；正在生成的回覆不會被打斷。
