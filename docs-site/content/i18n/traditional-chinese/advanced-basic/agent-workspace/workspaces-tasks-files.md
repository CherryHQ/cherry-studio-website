# 工作目錄、任務與檔案

<details>

<summary>哪些檔案不能直接編輯？</summary>

二進位檔案、非 UTF-8 文字以及體積較大的檔案僅提供預覽或外部開啟功能。這些檔案仍可由 Agent 工具處理，但不一定能在內建編輯器中修改。

</details>
