# 多模型比較與訊息分支

多模型比較適合處理沒有唯一答案的問題，例如方案評審、文案方向和資資交叉檢查。訊息分支則讓你從某個節點嘗試另一條路線，不必複製整段對話。

## 同時比較多個模型

{% stepper %}
{% step %}
### 1. 開啟【對話】並點擊模型名稱

在模型選擇器中勾選要比較的模型。第一次使用前，應先確認這些模型所屬的服務都能正常連線。
{% endstep %}

{% step %}
### 2. 發送同一個問題

把評價標準寫進問題，例如「從可執行性、風險和成本三個角度比較」。不要只問「哪個更好」。
{% endstep %}

{% step %}
### 3. 比較差異，而不是只挑最長的答案

重點看事實是否一致、假設是否明確、遺漏了什麼，以及哪一項更符合你的限制。重要事實仍要回到原始資資核對。
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
一次選擇多個模型會分別發起請求。涉及費用、速度或敏感資資時，先用短問題確認連線和效果，再處理長材資。
{% endhint %}

## 從訊息建立分支

找到想重新探索的那條訊息，開啟訊息選單並選擇分支操作。新分支會保留此前上下文，之後的訊息與原路線分開記錄。使用分支管理器可以在不同路線之間切換、比較和返回。

也可以在分支畫布中建立一個空分支。空分支建立後會立即儲存，重新啟動應用程式後仍會保留，並繼續停留在分支畫布；下一次在輸入框發送內容時，該分支會被填入。暫時不需要的空分支，可從節點的右鍵選單中刪除。

### 應用案例：評審兩個發布方案

先讓模型找出方案中的風險和缺口，再從同一條回覆分別追問「補充上線前檢查清單」和「改為快速試點角度評估」。開啟分支管理器後，兩條路線會並排保留，可以分別繼續追問，也可以隨時回到另一條路線核對結論。

<details>

<summary>什麼時候不適合開多個模型？</summary>

只是查一個明確事實、整理短文字，或材資包含不宜發送給多個服務商的内容時，使用單模型更合適。

</details>

<details>

<summary>分支會修改原來的訊息嗎？</summary>

不會。分支從選定節點繼續，原路線仍然保留，可以隨時返回。

</details>
