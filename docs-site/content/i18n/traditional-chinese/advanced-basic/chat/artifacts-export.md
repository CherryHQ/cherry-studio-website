# 產物、引用與匯出

一段回覆中可能同時出現正文、程式碼、檔案、圖片、引用以及可繼續編輯的內容。請先檢查產物，再決定複製、下載、匯出或交給 Agent 繼續處理。

<figure><img src="../../../../assets/5c0f5f563432facacf7942d6.webp" alt="產物、引用與匯出 — 說明圖片"><figcaption><p>到達最終產物後，請先檢查內容、來源和檔案，再決定複製、匯出或交給 Agent 繼續整理。</p></figcaption></figure>

### 先預覽，再交付

點擊訊息或 Agent 檔案面板中的產物，可在右側開啟對應預覽。HTML 可檢查頁面佈局與互動；PDF、Word、PowerPoint、圖片和文字依格式顯示；`.xlsx` 電子試算表可直接檢視工作表、儲存格樣式、合併儲存格、公式結果、圖片和圖表。

<figure><img src="../../../../assets/4e1d6cc47405edfe8d6fe315.webp" alt="產物、引用與匯出 — 說明圖片"><figcaption><p>① 預覽區用於核對完整內容；② 工具列可縮放、下載、最大化或切換檢視。</p></figcaption></figure>

1. 在對話中說明產物格式，開啟右側預覽。
2. 檢查內容和佈局是否完整。
3. 如果有缺漏，回到對話補充修改要求，再開啟預覽檢查。
4. 確認完整後，下載、複製或交給 Agent 儲存。

預覽的作用是提前發現缺漏，而不是只確認「已經生成」。如果頁面要交給同事使用，至少點開連結、按鈕和下載檔案各檢查一次。

{% hint style="info" %}
如果結果只是程式碼區塊而沒有出現預覽，可在同一輪對話中補充「請輸出一個完整、可直接預覽的 HTML 產物」，並寫清頁面需要包含的區域。
{% endhint %}

#### 應用案例：發布前檢查頁

輸入「把發布前檢查清單做成一個可直接預覽的完整 HTML 產物，包含上線準備、監控與驗收、回滾條件三個區域」。預覽開啟後，先檢查三部分是否完整，再下載或交給 Agent 儲存到專案目錄。

#### 應用案例：檢查資資表

開啟 Agent 生成的 `.xlsx` 預算表，先切換每個工作表，再檢查合併標題、金額格式、公式結果和圖表。儲存格內容較長時點擊展開；需要看清圖片或圖表時使用縮放。預覽用於驗收，不會取代 Excel 中的完整編輯和重算能力。

### 先做三項檢查

1. **內容**：數字、日期、專有名詞和結論是否與原始資資一致。
2. **來源**：聯網結果是否保留可開啟的連結；引用是否真的支持對應說法。
3. **檔案**：檔案名稱、格式和內容是否能正常開啟，是否包含不應分享的資訊。

### 常見去向

| 結果 | 推薦做法 |
| ---------------- | ------------------------------------- |
| 一段定稿文字 | 複製到目標應用程式，或儲存為筆記 |
| 需要持續修改的 Markdown | 放入 Agent 工作目錄，在【檔案】面板繼續編輯 |
| 可重用的資資 | 整理後加入知識庫，不要把臨時討論整段匯入 |
| 圖片 | 開啟原圖檢查尺寸與細節，再下載使用 |
| `.xlsx` 試算表 | 在內建預覽中檢查工作表、樣式、公式結果、圖片和圖表，再用試算表軟體做最終編輯 |
| 程式碼或指令 | 先閱讀並在可恢復環境驗證，不直接執行未知指令 |

{% hint style="warning" %}
「生成成功」只說明模型返回了內容，不代表檔案可直接發布。對外材資仍要檢查事實、版權、隱私和品牌要求。
{% endhint %}

#### 應用案例：把討論整理成可交付文件

團隊先在【對話】中討論活動方案，確認受眾、時間和預算邊界後，讓模型輸出結構化大綱。隨後把大綱交給【工作】中的內容 Agent，在指定目錄生成 `campaign-plan.md`。最終在右側【檔案】中修訂，避免把幾十輪討論原樣複製到正式文件。
