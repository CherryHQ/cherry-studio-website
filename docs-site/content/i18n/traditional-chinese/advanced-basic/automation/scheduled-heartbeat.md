# 排程任務、心跳與執行記錄

<details>

<summary>任務執行了但頻道沒有收到訊息怎麼辦？</summary>

先查看【執行歷史】確認 Agent 是否成功。如果任務成功，再檢查頻道接收目標；如果任務失敗，點擊【檢視對話】檢查模型、權限、工作區和工具錯誤。

</details>
