# 自動化與外部觸發

Cherry Studio 的自動化不是單獨的一組「機器人設定」。Agent 負責完成工作，頻道負責從外部平台收發訊息，排程任務負責在指定時間啟動 Agent，心跳則用於讓 Agent 週期性檢查自己的持續工作。

<figure><img src="../../../../assets/c348e2cb27a028b3789ac09b.webp" alt="自動化與外部觸發 — 說明圖片"><figcaption><p>觸發、執行、通知和執行歷史是不同環節；先手動跑通 Agent，再逐步接入。</p></figcaption></figure>

## 四者如何配合

| 能力 | 負責什麼 | 典型用途 |
| ----- | --------------- | ------------------ |
| Agent | 執行任務並產生結果 | 彙總、檢查、寫作、檔案處理 |
| 頻道 | 接收外部訊息並發送通知 | 飛書群機器人、Telegram 私訊 |
| 排程任務 | 在明確時間執行 Agent | 日報、週報、一次性提醒 |
| 心跳 | Agent 按間隔檢查持續工作 | 監控長流程、檢查待處理事項 |

## 正確的設定順序

{% stepper %}
{% step %}
### 1. 先在【工作】中跑通任務

確認 Agent 的模型、提示詞、工作目錄和工具可以穩定產生預期結果。
{% endstep %}

{% step %}
### 2. 再讓 Agent 引導設定頻道

在 Agent 對話中說明平台和用途，例如「將這個 Agent 接到飛書群，用於接收日報請求」。按照提示準備機器人權限和憑證。
{% endstep %}

{% step %}
### 3. 用手動設定核對狀態

開啟【設定】→【頻道】，檢查憑證、綁定 Agent、工作區、允許的對話範圍和頻道權限模式，並發送一條測試訊息。
{% endstep %}

{% step %}
### 4. 最後建立排程任務

可以直接讓 Agent 建立，也可以開啟【設定】→【排程任務】→【新增】。選擇已經驗證的 Agent、工作區、時間和通知頻道。
{% endstep %}
{% endstepper %}

## 上線前檢查

* 頻道只允許需要的對話或頻道 ID；
* 外部入口使用【繼承智能體設定】或更嚴格的權限；
* 排程任務提示詞不包含會變動的密鑰和路徑；
* 先手動【執行】一次並查看執行記錄；
* 失敗時能在 Cherry Studio 內找到對應任務，不把「未發送」誤判成「未執行」。

## 使用者案例：工作日營運日報

「營運日報」Agent 從工作目錄讀取資資，按團隊技能生成日報。飛書頻道負責將結果送到指定群組，排程任務在每個工作日早上執行。上線前先手動執行，再在飛書中給機器人發送訊息以建立接收目標，最後才啟用排程。

<details>

<summary>心跳和排程任務有什麼區別？</summary>

心跳按間隔讓 Agent 檢查持續工作，適合「有沒有新情況」；排程任務有明確的執行計畫和執行記錄，適合「每天幾點做什麼」。固定日報優先使用排程任務。

</details>
