# 頻道

頻道將一個 Agent 連接到外部訊息平台。目前可設定飛書、Telegram、QQ、WeChat、Discord 和 Slack；各平台所需的機器人憑證與對話識別碼不同。

{% hint style="success" %}
建議先在【工作】中告訴 Agent：「為目前 Agent 設定飛書頻道，用於接收群組訊息並發送任務結果。」Agent 會依用途詢問必要資訊，比直接面對所有平台欄位更快。需要精確修改時，再使用【設定】→【頻道】。
{% endhint %}

## 手動設定路徑

【設定】→【頻道】→選擇平台→【新增】。

{% stepper %}
{% step %}
### 1. 準備平台帳號

依照平台規則建立機器人或應用程式。飛書和 WeChat 支援掃碼相關流程時，可在啟用頻道後依介面提示完成；其他平台填寫對應 Token 或應用程式憑證。
{% endstep %}

{% step %}
<figure><img src="../../../../assets/c074e4e1278ff6cd86f433ed.webp" alt="頻道 — 說明圖片"><figcaption><p>先綁定經過測試的 Agent，並限制允許的聊天範圍；憑證與權限只開放完成任務所需的部分。</p></figcaption></figure>

### 2. 綁定 Agent 和工作區

選擇已驗證可用的 Agent，並為頻道訊息指定工作區。外部訊息會在此上下文中執行，不要選擇包含無關敏感檔案的目錄。
{% endstep %}

{% step %}
### 3. 限制訊息來源

填寫允許的 Chat ID、頻道 ID 或使用者 ID。留空可能表示允許所有，具體以目前平台欄位說明為準。可以先向機器人發送 `/whoami` 取得正確格式的識別碼。
{% endstep %}

{% step %}
### 4. 選擇權限模式並啟用

預設使用【繼承智能體設定】。公開群組、多人群組或不可信來源應使用更嚴格的模式。啟用後先發送無副作用的測試訊息。
{% endstep %}
{% endstepper %}

## 建議設定

| 設定項 | 產品預設值 | 建議起點 | 作用 | 適用情境 | 注意事項 |
| -------- | --------- | --------------- | ------------ | --------- | ---------------- |
| 綁定 Agent | 需要選擇 | 為頻道單獨準備一個 Agent | 決定訊息由誰處理 | 群組聊天、機器人私訊 | 不與高權限開發 Agent 混用 |
| 工作區 | 需要選擇 | 使用不含私人資資的專用目錄 | 限定可處理檔案 | 群組內收集、日報交付 | 不選擇使用者主目錄 |
| 允許的訊息來源 | 依平台欄位而定 | 先只允許測試帳號或測試群組 | 限制誰能觸發 Agent | 內測、團隊群組 | 留空前先閱讀欄位說明 |
| 權限模式 | 【繼承智能體設定】 | 外部入口使用更嚴格的核准 | 控制工具操作 | 公開群組、多人群組 | 不建議使用【完全存取】 |

## 使用情境：團隊值班群組

建立一個只處理值班手冊的 Agent，綁定經過召回測試的知識庫和專用工作區，只允許值班群組觸發。先測試「查一條制度」和「找不到答案」兩類訊息，再測試生成不含敏感資訊的交接摘要。

### 完成標準

非允許來源不能觸發任務；回答能回到指定群組；知識庫沒有內容時明確說明；檔案寫入仍會請求核准。

## 平台設定重點

| 平台 | 主要憑證 | 對話範圍重點 |
| --------- | ----------------------- | ------------------ |
| 飛書 / Lark | App ID、App Secret，或掃碼流程 | 聊天 ID 與國內/國際網域 |
| Telegram | Bot Token | Chat ID |
| QQ | App ID、Client Secret | 私訊、群組或頻道識別碼格式 |
| WeChat | 掃碼登入或憑證路徑 | 允許的使用者 ID |
| Discord | Bot Token | 頻道或私訊 ID |
| Slack | Bot Token、App Token | Socket Mode 與頻道 ID |

{% hint style="danger" %}
機器人 Token、App Secret 和驗證令牌等同帳號密碼。不要寫入 Agent 長期記憶、任務提示詞、截圖或公開 Issue；洩漏後應立即在平台端撤銷並重新產生。
{% endhint %}

<details>

<summary>排程任務選不到頻道接收目標怎麼辦？</summary>

先在對應平台主動給機器人發送一條訊息，讓 Cherry Studio 記錄可用的 Chat ID，再回到排程任務選擇通知目標。

</details>

<details>

<summary>頻道已連接但不回覆怎麼辦？</summary>

檢查允許的對話 ID、綁定 Agent、工作區和權限模式，再查看頻道日誌。平台收到了訊息但 Agent 未執行時，繼續檢查 API 閘道和 Agent 任務狀態。

</details>
