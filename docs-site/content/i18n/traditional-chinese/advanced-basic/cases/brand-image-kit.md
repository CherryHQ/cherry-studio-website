# 品牌配圖套件

內容團隊要為同一場活動製作橫版、方形和直式配圖，並保持主體、色調和品牌規則一致。先確定主視覺，再擴展尺寸，比每張圖從頭生成更容易保持統一。

## 準備材資

* 內容主題與使用平台；
* 允許使用的品牌色和參考圖；
* 不可出現的文字、標誌和元素；
* 三種圖片比例與留白要求。

## 操作流程

{% stepper %}
{% step %}
### 1. 讓 Agent 提煉視覺方向

把文章或活動說明放入工作目錄，讓 Agent 只輸出主體、場景、色調、鏡頭和留白建議，先不生成圖片。
{% endstep %}

{% step %}
### 2. 在【繪圖】中驗證主視覺

選擇合適模板和模型，先生成橫版小樣。檢查產品外觀、人物細節和品牌風險。
{% endstep %}

{% step %}
### 3. 用參考圖擴展尺寸

選定主視覺後，將它作為參考，分別生成方形和直式。每次說明必須保留的主體與可調整的構圖。
{% endstep %}

{% step %}
### 4. 局部修正並增強

只對問題區域使用編輯或遮罩，最終版本再做增強。檔案名稱包含用途和比例，避免混淆。
{% endstep %}
{% endstepper %}

## 結果檢查

* 三張圖的色調與主體一致；
* 不包含模型生成的錯誤文字；
* 不意外出現品牌標誌、人物或敏感資訊；
* 尺寸滿足發布平台要求；
* 參考圖的使用得到許可。

## 推薦組合與完成標準

| 項目 | 建議做法 |
| ---- | ------------------------------- |
| 繪圖模型 | 先用 Agent 生成一張樣圖驗證連接，再儲存繪圖模板 |
| 輸入材資 | 品牌色、字型、尺寸、參考圖和禁用元素放在同一專案目錄 |
| 批量方式 | 先確認一張，再生成同系列圖片 |
| 完成標準 | 尺寸正確、文字可讀、品牌元素一致、沒有多餘標識，原參考圖仍保留 |

適合文章封面、社群媒體配圖和活動素材；需要精確排版的最終海報，建議在設計工具中做最後校對。

{% hint style="info" %}
如果希望直接在 Agent 對話中出圖，先配置全域【繪圖模型】並啟用 Agent 的【生成圖片】工具。需要細緻編輯時，仍建議回到【繪圖】頁面。
{% endhint %}
