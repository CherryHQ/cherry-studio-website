# 多語言資資整理

市場團隊收到一套包含文件、截圖和產品術語的資資，需要翻譯成另一種語言，同時保持名稱、數字和格式一致。術語表和小範圍試譯能減少整份材資返工。

## 操作流程

{% stepper %}
{% step %}
### 1. 先建立術語表

列出產品名、功能名、人名、單位和不可改寫的法律表述。為每個詞寫明目標語言用法。
{% endstep %}

{% step %}
### 2. 用一小段校準風格

在【翻譯】中先處理一個代表性章節，確認正式程度、標題寫法和術語，再翻譯整份文件。
{% endstep %}

{% step %}
### 3. 圖片單獨做 OCR 檢查

上傳截圖後先核對識別文字，尤其是數字、按鈕名和表格。識別錯誤要在翻譯前修正。
{% endstep %}

{% step %}
### 4. 讓 Agent 做一致性檢查

把原文、譯文和術語表放入工作目錄，讓 Agent 列出術語不一致、漏譯、數字差異和連結問題，不直接替換法務內容。
{% endstep %}
{% endstepper %}

## 交付前檢查

* 產品名稱和介面路徑與實際介面一致；
* 數字、日期、貨幣和單位沒有變化；
* Markdown 連結、程式碼區塊和圖片說明保留；
* 法律、醫療或安全內容經過專業審校。

## 推薦組合與完成標準

| 項目 | 建議做法 |
| ---- | --------------------------------- |
| 翻譯入口 | 短文本和截圖用【翻譯】，多文件整理交給 Agent |
| 術語 | 先提供產品名、專有名詞和不翻譯詞表 |
| 文件 | 原文與譯文分目錄儲存，保留原檔名對應關係 |
| 完成標準 | 數字、連結和專有名詞一致；圖片文字已抽樣檢查；版式變化在交付說明中標記 |

{% hint style="warning" %}
歷史記錄便於重用，但也會儲存翻譯內容。處理敏感材資後，按照你的資資管理要求檢查並清理記錄。
{% endhint %}
