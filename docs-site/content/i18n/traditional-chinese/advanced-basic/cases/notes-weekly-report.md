# 筆記生成週報

專案負責人一週內累積了會議筆記、進度更新和零散待辦，希望週五整理成結構穩定、事實可核對的週報。關鍵是先統一記錄方式，再讓 Agent 彙總，而不是讓它猜測缺失狀態。

## 操作流程

{% stepper %}
{% step %}
### 1. 統一記錄方式

每天在同一筆記資資夾記錄事項，至少包含日期、結果、負責人和狀態。未完成事項不要寫成已經交付。
{% endstep %}

{% step %}
### 2. 週五先人工整理

合併重複事項，補齊關鍵數字和連結。長期背景放進知識庫，本週變化留在當前筆記。
{% endstep %}

{% step %}
### 3. 交給 Agent 生成草稿

要求按「本週完成、進行中、風險、下週計畫」輸出，並在資資缺失時列出待補項。
{% endstep %}

{% step %}
### 4. 檢查並匯出

確認狀態、數字和責任人，再在【筆記】中定稿並匯出。穩定格式可以做成技能，下週繼續重用。
{% endstep %}
{% endstepper %}

## 示例任務

```
讀取本週筆記並產生週報草稿。合併相同事項，但保留不同日期的狀態變化；不要推測完成情況。缺少負責人、數字或下一步時，列入「待補充」。
```

## 推薦組合與完成標準

| 項目 | 建議做法 |
| ----- | --------------------------------- |
| 日常輸入 | 筆記按日期或專案記錄，只寫事實和待辦 |
| Agent | 使用固定的週報結構，讀取本週筆記後再生成 |
| 輸出 | 週報寫入獨立檔案，不覆蓋原始筆記 |
| 完成標準 | 每條進展能回到原筆記；未完成事項有負責人或下一步；沒有憑空增加數據 |

適合把已經記錄的工作整理成週報，不適合讓 Agent 根據零散記憶猜測一週成果。

{% hint style="info" %}
固定時間自動生成週報前，先手動執行幾週。只有輸入格式穩定、缺失資訊處理可靠後，再建立排程任務。
{% endhint %}
