# 頻道與定時日報

營運團隊希望每個工作日上午自動彙整指定資資，生成日報並傳送至團隊頻道。在自動化之前，先手動執行一次以確保流程順暢，能及早發現資資缺失、路徑錯誤及通知目標問題。

## 先準備什麼

* 一個已在【工作】中驗證過的日報 Agent；
* 明確的資資來源，以及僅包含所需資資的工作目錄；
* 固定格式可製作為技能；
* 已連接並限制訊息範圍的頻道；
* 一個工作日定時任務。

## 設定步驟

{% stepper %}
{% step %}
### 1. 手動生成一份日報

要求 Agent 輸出「進展、指標、風險、待辦」四部分。檢查資資缺失時是否明確說明，而不是編造內容。
{% endstep %}

{% step %}
### 2. 設定通知頻道

優先在 Agent 對話中說明要連接的平台和群組，再到【設定】→【頻道】核對憑證、允許的會話 ID、工作區和權限模式。
{% endstep %}

{% step %}
### 3. 建立定時任務

讓 Agent 建立工作日計畫，或開啟【設定】→【定時任務】→【新建】。選擇日報 Agent、工作目錄、執行時間和通知頻道。
{% endstep %}

{% step %}
### 4. 立即測試

儲存後點擊【執行】，查看生成的會話、執行歷史和頻道訊息。不要等到第二天才發現路徑或接收目標錯誤。
{% endstep %}

{% step %}
### 5. 觀察並調整

前幾次執行檢查耗時、用量和失敗原因。當資資來源或團隊格式變化時，更新技能或任務提示詞，不要在多個位置維護衝突規則。
{% endstep %}
{% endstepper %}

## 示例任務提示詞

```
讀取目前工作目錄中昨天新增的資資，產生中文營運日報。固定包含進度、關鍵指標、異常和今日待辦。找不到資資時寫「暫無資資」並列出缺少的檔案，不得自行補寫數值。將結果傳送到已設定的團隊頻道，並在工作目錄保留一份 Markdown 檔案。
```

## 失敗處理

| 現象 | 檢查位置 |
| ------ | --------------------- |
| 沒有執行 | 定時任務狀態、下一次執行時間、系統休眠 |
| 執行失敗 | 【執行歷史】→【查看會話】 |
| 檔案沒有生成 | 工作目錄、權限請求和 Agent 檔案工具 |
| 訊息沒有送達 | 頻道狀態、接收目標和平台日誌 |
| 內容重複 | 是否同時啟用了心跳和多個相同計畫 |

## 推薦組合與完成標準

| 項目 | 建議做法 |
| ----- | ---------------------------------- |
| Agent | 先手動跑通同一份日報，再交給定時任務 |
| 計畫 | 優先使用【每天】或【工作日】，確認下一次執行時間 |
| 頻道 | 先發送到測試會話，再切換正式群組 |
| 完成標準 | 執行歷史成功；報告檔案可開啟；頻道只收到一條；缺少資資時不會編造結果 |

{% hint style="warning" %}
定時任務會在無人值守時執行。上線前保持最小檔案範圍和合適權限，避免將高風險寫入或外部修改交給完全存取模式。
{% endhint %}

{% hint style="info" %}
截圖中的演示環境沒有綁定外部頻道，所以只展示已經儲存並啟用的任務。正式使用時還要點擊【執行】，確認【執行歷史】成功，並在測試頻道看到一條真實訊息後再投入日常執行。
{% endhint %}
