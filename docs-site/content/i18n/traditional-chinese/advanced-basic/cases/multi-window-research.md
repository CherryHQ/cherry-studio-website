# 多視窗研究工作台

研究人員需要一邊保留資資和模型比較，一邊讓 Agent 整理檔案並產生報告。將研究任務拆分到獨立視窗後，主視窗仍能繼續查資資，不會打斷 Agent 的狀態。

## 建議佈局

* 主視窗：保留資資對話和全域搜尋；
* 獨立視窗：開啟研究 Agent 任務並置頂；
* 第二個分頁：開啟知識庫或筆記，隨時核對原始資資。

## 操作流程

{% stepper %}
{% step %}
### 1. 在【對話】中比較研究問題

使用多模型對比找出共識、衝突和待查證項目，不急著產生最終報告。
{% endstep %}

{% step %}
### 2. 為研究 Agent 準備目錄

將原始資資與輸出目錄分開，綁定相關知識庫，並要求外部資訊保留連結。
{% endstep %}

{% step %}
### 3. 將任務拆分到獨立視窗

右鍵 Agent 分頁選擇【從新視窗開啟】，必要時使用視窗置頂。主視窗繼續查資資，不打斷 Agent 狀態。
{% endstep %}

{% step %}
### 4. 彙總並覆核

在 Agent 右側【檔案】檢查報告，在主視窗開啟原始對話核對衝突。最終只保留能回溯到資資或來源的結論。
{% endstep %}
{% endstepper %}

## 建議組合與完成標準

| 視窗 | 建議內容 |
| ----- | --------------------------------- |
| 主視窗 | 資資對話、全域搜尋和筆記 |
| 獨立視窗 | 一個正在執行的 Agent 任務 |
| 固定分頁 | 專案最常用的知識庫或任務 |
| 完成標準 | 資資來源、任務狀態和最終筆記能互相對應；任務結束後視窗已收回或關閉 |

適合需要持續觀察長任務的研究，不建議為了「看起來更專業」同時開啟很多視窗。

{% hint style="info" %}
多視窗只改變顯示位置，不會建立新的帳號或隔離空間。同一任務的資資和權限仍然相同。
{% endhint %}
