# 位置與健康記錄

位置工具可以讀取手機當前的位置；健康工具可以彙總 iOS 健康中已有的記錄。它們各自需要智能體能力開關與系統授權，不會因為開啟“自動批准”就獲得權限。

## 檢視和管理權限

在智能體編輯頁的 **系統** 區域開啟本次需要的 **位置** 或 **健康**，再按提示授權。也可以開啟 **設定 → 系統權限**，檢視支援的專案與當前狀態。

只想暫停某個智能體使用這些能力，可以關閉它的能力開關；要撤銷 App 的系統權限，需按權限頁面指引到系統設定中處理。

## 獲取位置，再查詢周邊

先做一個簡單查詢：

> 獲取我現在的位置，告訴我大致在哪個區域，以及這次定位的時間。

需要周邊或路線資訊時，可以結合已連線的高德外掛：

> 獲取我當前的位置，再用高德查詢附近的地鐵站，列出名稱和地址。

兩步需要各自的條件：讀取手機位置需要系統定位權限，查詢地圖需要連線高德外掛。僅連線高德不會自動讀取手機定位。

### 不想授權位置，也能查路線嗎？

可以直接給出起點和終點：

> 用高德查詢從上海人民廣場到虹橋站的公共交通路線，比較換乘次數和預計時間，不需要讀取手機位置。

內建位置工具進行的是一次當前位置讀取，不提供持續跟蹤、後臺定位或逐段導航。路線說明來自地圖服務，不能把一次定位當成即時導航。

### 定位失敗，或只有座標沒有地址

* 先確認系統定位服務和 Cherry Studio 的定位權限已開啟，並讓 App 保持在前臺。
* 室內訊號、裝置和系統提供的位置精度會影響結果；定位超時不一定是權限被拒絕。
* 座標轉成文字地址可能單獨失敗。拿到座標但沒有地址，不表示整次定位都失敗。
* 處理提示中的原因後再主動重試；也可以直接提供城市、地標或出發地址。

## 彙總健康記錄（僅 iOS）

當前支援讀取這些已記錄的資料：

| 類別 | 可以得到的內容 |
| --- | --- |
| 日常活動 | 步數、活動能量、步行與跑步距離 |
| 心率 | 心率、靜息心率、心率變異性 |
| 睡眠 | 已記錄的睡眠時長 |
| 體能訓練 | 指定日期範圍內的運動記錄 |

你可以只授權需要的資料類型。例如只整理步數時，不必同時開放心率和睡眠。當前工具用於讀取，不能向系統健康寫入或刪除記錄；Android 當前不提供這些健康工具。

可以這樣提問：

> 讀取最近七天已記錄的步數和步行跑步距離，按天列出。沒有資料的日期標為“無可用記錄”，不要填成零。

> 彙總上週的睡眠時長，並說明哪些日期缺少記錄。

> 列出本月已記錄的體能訓練，說明本次返回了多少條；如果可能不完整，請說明。

單次查詢時間跨度最多 90 天。未指定日期時，工具預設查詢最近七天；運動列表預設取 20 條，單次最多 50 條。記錄較多時按較短時間段分別查詢。

## 為什麼健康資料為空或只有部分指標？

可能是系統健康中沒有對應記錄、沒有授權該類型、系統沒有提供可讀取的歷史記錄，或某一指標讀取失敗。**空結果不等於步數為零，也不等於沒有運動。** iOS 不會完整披露使用者是否拒絕了某類健康資料的讀取，App 不能僅憑空結果區分這些情況。

先開啟系統健康確認日期與記錄，再檢查對應類型的授權；也可以縮短日期範圍，只查詢一個指標。讓智能體明確寫出缺失項，避免把不完整的資料解釋成完整趨勢。

位置與健康結果可能隨對話交給你選擇的模型服務處理。瞭解授權和資料用途，見[資料、隱私與權限](data-privacy.md)。
