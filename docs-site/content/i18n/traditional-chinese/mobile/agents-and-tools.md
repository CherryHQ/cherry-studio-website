# 智能體與工具

智能體是一套儲存下來的工作設定：名稱、頭像、任務說明、預設模型和工具審批方式。你可以為寫作、學習、工作資料整理分別建立智能體，再為每個話題開啟獨立對話。

## 建立一個常用智能體

1. 開啟智能體列表，點選新增；也可以從對話頂部的智能體選擇器新建。
2. 填寫名稱，選擇頭像，寫清希望它如何工作。
3. 選擇預設模型。需要搜尋、呼叫外掛或操作日曆時，選擇支援工具呼叫的文字模型。
4. 選擇工具審批方式，在“系統”區域按需開啟網路搜尋、圖片生成或裝置能力。自訂工具可在儲存後新增。
5. 點選 **儲存**。從對話選擇器建立後會進入這個智能體的新對話；從管理列表建立後返回列表。

可以從這個簡單的說明開始：

> 你幫我整理工作材料。先用三句話概括，再列出待辦。沒有給出負責人與截止時間時寫“待確認”，不要自行編造。回答使用中文。

把常用規則寫進說明，把本次要處理的檔案和問題放進對話。不要把 API Key 或帳號密碼當作任務說明儲存。

## 修改後需要點儲存嗎？

**新建智能體需要儲存，編輯已有智能體會自動儲存。**

名稱和說明在短暫停止輸入後儲存，頭像、模型和審批方式等選擇會立即儲存。如果出現儲存失敗提示，當前編輯頁會保留草稿並提供重試，請處理後再離開。

未選擇模型的智能體可以儲存，但不能開始對話。為它選擇可用模型後再傳送。

## “需要時確認”和“自動批准”有什麼區別？

| 模式 | 實際行為 |
| --- | --- |
| 需要時確認 | 只有工具規則要求確認時才詢問，部分讀取操作仍可直接進行 |
| 自動批准 | 自動透過符合條件的工具審批，仍受系統權限、工具啟用狀態和可訪問資料範圍限制 |

當前新建智能體，包括初始 Cherry 智能體，預設使用 **自動批准**；已有智能體保留原設定。希望修改日曆、刪除提醒或呼叫外部工具前先確認，可以改為 **需要時確認**。

工具審批只決定是否詢問，不能讓沒有權限的工具變得可用。透過文字模型呼叫的**圖片生成工具每次仍需確認**，因為會使用模型服務額度；這與直接選擇圖片模型並主動點選生成不同。

出現待審批提示時，閱讀將進行的操作，然後允許或拒絕。拒絕後工具不會執行，智能體可能改用已有資訊回答。批准以後若還出現系統權限彈窗，需要另外完成系統授權。

## 手機能提供哪些系統工具？

在智能體編輯頁的 **系統** 區域，選擇這個智能體可以使用哪些能力。開關包括網路搜尋、圖片生成、日曆、提醒事項、健康和位置；只顯示當前平台與裝置支援的專案。

* 從編輯頁新建智能體時，日曆、提醒事項、健康和位置預設關閉，按需開啟；已有智能體保留自己的設定。
* 這裡的開關只控制當前智能體。關閉網路搜尋後，它不會呼叫內建搜尋或網頁閱讀工具；關閉圖片生成後，它不會透過文字對話呼叫內建繪圖工具。外掛與自訂 MCP 工具需在各自配置中單獨管理。
* 開啟開關不會直接授予系統權限。實際操作時按提示授權，也可以點選 **管理系統權限**，或進入 **設定 → 系統權限** 檢視。
* 開關更改會隨已有智能體自動儲存，之後的新請求使用新的設定；正在進行的操作不會因此自動撤銷。

| 能力 | 可以怎樣提問 | 可用範圍 |
| --- | --- | --- |
| 日曆 | “列出我明天的日程”；“明天下午三點建一個 30 分鐘會議” | iOS、Android，受日曆讀寫權限和系統支援限制 |
| 提醒事項 | “明天上午九點提醒我寄快遞” | iOS 的提醒事項權限；Android 當前不提供此係統工具 |
| 健康記錄 | “彙總本週已記錄的步數和運動” | iOS，按系統實際授權的資料類型讀取；Android 當前不提供 |
| 當前位置 | “獲取我現在的位置，再幫我規劃路線” | iOS、Android，需要定位權限 |
| 應用內檔案 | “把剛才的內容整理成一個檔案” | 處理本次對話可訪問的附件或生成檔案 |

Android 某些日曆寫入操作會開啟系統日曆表單，需要在系統頁面完成；僅開啟表單不表示日程已經儲存。健康資料為空也不一定是應用出錯，可能沒有記錄或未授權該資料類型。

系統工具不能隨意訪問手機中所有檔案、接管其他 App，或遠端操作你的電腦。可用能力以實際工具和授權為準。

## 聯網、外掛和自訂工具從哪裡配置？

* **聯網搜尋**：在設定中配置搜尋與網頁閱讀服務，然後在訊息裡提出搜尋需求，詳見[聯網搜尋與網頁閱讀](web-search.md)。
* **外掛**：從側邊欄連線飛書、Notion 等帳號，連線後可在對話中直接使用，也可透過 **＋ → 外掛** 指定。詳見[外掛與外部工具](plugins.md)。
* **自訂 MCP（給智能體連線額外工具服務的方式）**：先在設定中新增伺服器，再在已儲存智能體的編輯頁中開啟對應伺服器。詳見[自訂工具步驟](plugins.md)。
* **繪圖工具**：在 **設定 → 預設模型** 選擇繪圖模型，並開啟當前智能體的 **圖片生成** 後，支援工具呼叫的文字模型才有可用的繪圖工具。也可以直接選擇圖片模型進入影象對話。

## 為什麼已經授權，智能體仍然不會使用工具？

先確認選中的模型支援工具呼叫，再檢查當前智能體的能力開關、工具連線、伺服器和具體工具是否啟用，以及系統權限。外掛帳號還可能受企業管理員或目標文件權限限制。

提問時給出明確目標，例如文件連結、日期範圍或日曆名稱；僅說“幫我處理一下”通常不足以確定物件。可以先讓它讀取並列出內容，確認物件後再要求修改。
