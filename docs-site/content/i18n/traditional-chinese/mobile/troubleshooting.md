# 常見問題

先根據現象找到對應操作。連線錯誤可先用一條簡短、不帶附件的訊息縮小問題範圍。

## 安裝後為什麼不能直接聊天？

Cherry Studio 是客戶端，需要連線模型服務。先配置 API Key、新增模型並啟用服務商，再為智能體選擇模型。已有電腦配置可以[匯入](desktop-sync.md)，首次使用步驟見[快速開始](quick-start.md)。

平台的網頁聊天會員不一定包含 API（供應用呼叫模型的介面）額度，需要在平台單獨確認。

## 服務商已新增，為什麼模型選擇器為空？

確認服務商已啟用、模型可用，且不是僅供管理的嵌入或重排類型。圖片與文字入口也可能篩選不同類型。把選擇器篩選改為“全部”，並等首次模型資料下載完成。

模型還沒有新增時，先[同步列表或手動新增](model-management.md)。

## 模型資訊更新會改掉我的金鑰或自訂設定嗎？

不會。模型資料更新不修改服務商地址和金鑰，也不重寫手動儲存的模型改動。沒有覆蓋的預設欄位會跟隨新資料。

**從電腦同步所選服務商**則會更新其地址和金鑰，這兩種更新不同。詳見[模型更新](model-updates.md)和[電腦匯入](desktop-sync.md)。

## 同步模型失敗，為什麼仍能聊天？

服務商的模型列表介面與對話介面分開，可能只支援後者。用平台提供的模型 ID 手動新增並檢查連線即可；原有模型不會因同步失敗被清空。

“遠端未返回”也不代表模型下線，見[模型同步說明](model-updates.md)。

## 401、403、404、429 分別怎麼處理？

| 提示 | 優先檢查 |
| --- | --- |
| 401 / 未授權 | 金鑰是否完整、有效、已儲存並啟用 |
| 403 / 無權限 | 帳號、地區、目標模型或組織權限是否允許訪問 |
| 404 / 不存在 | 基礎地址、介面和模型 ID 是否正確，是否重複拼接了請求路徑 |
| 429 / 請求過多 | 等待限流恢復，檢查帳戶額度和請求限制，不要連續重複傳送 |
| 網路失敗 / 超時 | 當前網路能否訪問服務商，代理與平台服務是否正常 |
| 內容過長 / 請求過大 | 減少附件或歷史內容、換更合適的模型，不要只把上限數字調大 |

有些平台使用不同錯誤碼，結合錯誤詳情與平台說明判斷。配置項的填寫方法見[服務商與模型](providers-and-models.md)。

## 已經修改，為什麼沒有生效？

* 服務商地址和金鑰、手動模型新增或模型編輯：需要點選頁面儲存或新增。
* 已有智能體編輯、預設模型選擇、模型列表中的介面切換：自動或立即儲存，注意是否出現失敗提示。
* 更換服務商地址後檢查連線或同步列表：先儲存當前配置。
* 更改全域預設模型：不會改掉已有智能體自己的模型選擇。

詳見[模型管理](model-management.md)和[智能體編輯](agents-and-tools.md)。

## 為什麼不能刪除某個模型？

它可能正被設為全域預設模型。先到 **設定 → 預設模型** 更換或清除，再刪除。刪除智能體正在使用的其他模型後，需要為該智能體重新選模型。

## 圖片能預覽，為什麼不能發給模型？

預覽和模型輸入是不同能力。選擇支援視覺的文字模型，檢查圖片格式、張數和大小。給模型勾選“圖片能力”不會讓不支援視覺的模型看懂圖片。

文件解析為空、掃描 PDF 或大檔案的處理見[對話與檔案](chat-and-files.md)。

## 為什麼輸入框沒有聯網開關或外掛按鈕？

聯網搜尋開關位於當前智能體的編輯頁，不在輸入框中；開啟它並配置搜尋服務後，直接在訊息裡要求搜尋。外掛按鈕只在已有可用連線時出現；先去側邊欄連線外掛。

外掛已連線後可在對話中使用，也可透過 **＋ → 外掛** 明確指定。詳見[聯網搜尋](web-search.md)和[外掛連線](plugins.md)。

## 外掛授權完成後一直在等待，怎麼辦？

返回 Cherry Studio 檢查狀態，完成帳號或工作區確認。可以重新開啟授權頁或再次檢查；過期時重新發起。組織權限不足時，先在服務商側申請權限。

釘釘的額外行為授權完成後需要重新發起原操作；企業微信連結需在有效期內在企業微信中開啟。詳見[外掛連線](plugins.md)。

## 為什麼只剩最新回答能重新回答？

重新回答會原地替換最新回答，較早內容改換方向請建立分支。重試、刪除都不會撤銷已經執行的外部操作，重試也可能產生新費用。詳見[回答操作](chat-and-files.md)。

## “已壓縮上下文”會刪除聊天嗎？

不會刪除可見聊天記錄。這表示把早期資訊整理成摘要供模型繼續使用，摘要可能不包含所有原文細節。需要精確引用時重新提供關鍵材料，詳見[長對話說明](chat-and-files.md)。

## 匯出的圖片為什麼有多張、程式碼不完整？

長對話預設分頁，以保持閱讀清晰；也可以選單張長圖。圖片中的程式碼塊只展示有限區域，要儲存完整程式碼請選擇 HTML 或 Markdown。圖片格式轉換失敗時可能回退其他格式，分享前檢視預覽與格式名稱。

選擇範圍、水印、思考內容和檔案儲存說明見[分享與匯出](sharing-and-export.md)。

## 後臺沒有通知，或鎖屏後生成中斷

確認 **設定 → 通知** 中相關開關與系統通知權限。系統仍可能限制後臺執行；回到原對話或繪圖檢視狀態，再決定是否重新提交。詳見[後臺回覆與通知](settings-and-usage.md)。

## 手機與電腦會自動同步聊天記錄嗎？

當前不會。裝置互聯匯入的是選定服務商的配置與已啟用模型，不包含聊天記錄，也不持續自動同步。換機前另行儲存重要內容，見[電腦匯入](desktop-sync.md)和[資料說明](data-privacy.md)。

## Android 禁止安裝，或 TestFlight 無法加入

使用[官方下載入口](https://cherryai.com/download?platform=mobile)。Android 按系統提示允許當前下載應用安裝 APK；iPhone / iPad 先安裝 TestFlight，再開啟邀請。名額、測試版本有效期或平台服務異常也可能影響安裝。

完整步驟見[下載與安裝](installation.md)。

## 工具不執行、檔案沒有儲存，去哪裡查？

* 模型只回答文字、等待批准或提示權限不足：見[讓 AI 使用工具](using-tools.md)，逐項檢查模型、能力開關、連線與權限。
* Android 開啟系統日曆，或日程寫入結果不確定：見[日曆與提醒事項](calendar-and-reminders.md)，先核對已有記錄，避免重複新增。
* 定位失敗、健康記錄為空或只有部分資料：見[位置與健康記錄](location-and-health.md)。空結果不能直接理解為沒有記錄。
* 回答只有程式碼塊，沒有可以開啟的檔案，或修改沒有覆蓋原件：見[生成與修改檔案](file-generation.md)。
* 想要 PPT，但只有 HTML，或轉換後的文字無法單獨編輯：見[HTML 轉圖片與 PPT](html-export.md)。

## 如何提交仍未解決的問題？

提供版本、裝置與系統版本、復現步驟及錯誤提示，去 [App 倉庫的問題反饋](https://github.com/CherryHQ/cherry-studio-app/issues)提交。釋出前遮蓋金鑰、私人對話和檔案內容。
