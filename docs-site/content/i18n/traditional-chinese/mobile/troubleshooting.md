# 常見問題

## 為什麼安裝後不能直接對話？

Cherry Studio 是用戶端，不附帶模型額度。請先新增模型服務商、填寫 API Key，並啟用至少一個對話模型。

## 已新增服務商，但模型清單是空的

檢查 API Key、Base URL、帳戶權限與目前網路。部分服務商不會回傳完整的模型清單，需要手動填寫模型 ID。

## 為什麼圖片、工具或檔案能力無法使用？

這些能力同時取決於應用程式版本、模型能力、服務商介面與系統權限。先確認模型支援對應能力，再檢查智能體的工具開關與系統授權。

## Android 提示禁止安裝

請從官方下載頁重新取得 APK，並依系統提示允許目前的瀏覽器或檔案管理員安裝不明應用程式。安裝完成後可以撤銷該權限。

## TestFlight 連結打不開或無法加入

確認裝置已經安裝 TestFlight，並使用 Safari 或系統瀏覽器開啟邀請。測試名額已滿、版本過期或 Apple 服務異常時，需要稍後重試。

## 行動版會自動同步桌面版資料嗎？

不要預期會自動同步。服務商與模型設定可以在行動端重新新增，重要對話與檔案請依目前版本提供的匯出或分享功能個別儲存。

## 如何回報問題？

記錄應用程式版本、裝置型號、系統版本、重現步驟與錯誤提示。提交螢幕截圖前先遮蓋 API Key、個人檔案、對話內容等敏感資訊，再透過官網的回報入口聯絡專案團隊。
