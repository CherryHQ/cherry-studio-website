# 行事曆與提醒事項

日曆適合安排有開始和結束時間的活動；提醒事項適合記錄需要完成的事情。你可以讓智能體先查安排，再按要求建立或修改，不必記住工具名稱。

內建日曆使用手機系統可訪問的日曆，支援 iOS 和 Android；內建提醒事項當前只支援 iOS。飛書、釘釘等服務中的日程和任務使用各自的[外掛](plugins.md)，不會因為授權了手機日曆就自動接通。

## 使用前準備

1. 選擇支援工具呼叫的文字模型。
2. 編輯當前智能體，在 **系統** 區域開啟 **日曆** 或 **提醒事項**。
3. 按提示授權，或進入 **設定 → 系統權限** 檢視讀寫權限。
4. 希望建立、修改或刪除前先審批，將智能體的工具審批方式改為 **需要時確認**。

讀取權限與寫入權限可能不同。可以建立日程不代表能讀取全部日程；只讀日曆也不能用來建立或修改活動。

## 查明天的安排

先問清可用日曆，多個帳號或同名日曆時尤其有用：

> 列出手機中可用的日曆，以及哪些可以寫入。先不要做修改。

接著指定範圍：

> 讀取“工作”日曆中明天的日程，按時間排序，列出開始時間、結束時間、標題和地點。

查詢有時間範圍和條數限制：單次時間跨度最多 90 天，日程或提醒事項單次最多返回 200 條。需要更多內容時按周或按月分開查詢；一次返回的列表不一定就是全部記錄。

## 建立一個日程

> 在“個人”日曆中，明天北京時間 15:00 到 15:30 建立“整理旅行資料”，地點寫“家中”，備註寫“確認票券和住宿”。

說清 **日期、時區、開始與結束時間、日曆名稱**。跨時區旅行或遠端會議時，使用“北京時間”“東京當地時間”等明確表述。

儲存後可以繼續問：“重新讀取這個時間段，確認剛才的日程是否存在。”如果工具提示結果不確定，先檢視系統日曆，再決定是否重試。

### 能邀請參會人、設定重複或提前提醒嗎？

當前內建工具沒有參會人邀請、重複規則和獨立的提前提醒設定。建立帶有會議名稱的日程不會自動發出邀請。需要這些設定時，在系統日曆中完成，或使用支援對應操作的辦公外掛。

## 修改或刪除已有日程

先查詢，再描述唯一物件，避免只有“改一下明天的會議”：

> 找到明天“個人”日曆中 15:00 的“整理旅行資料”，先告訴我當前時間和地點。

核對後再發：

> 把剛才這條改到 16:00—16:30，地點和備註保持不變。

刪除也先核對標題、日期和所屬日曆。刪除聊天記錄不會恢復已經刪掉的日程。

## 用提醒事項管理待辦（iOS）

| 目標 | 可以這樣提問 |
| --- | --- |
| 選擇清單 | “列出我的提醒事項清單，告訴我哪些可以寫入。” |
| 新增事項 | “在‘個人’清單中新增‘寄快遞’，截止時間為明天北京時間上午九點，備註‘帶上退貨單’。” |
| 檢視未完成事項 | “列出這周‘個人’清單中未完成的提醒事項，按截止時間整理。” |
| 調整日期 | “找到剛才的‘寄快遞’，把截止時間改為明天下午兩點，其他內容不變。” |
| 標記完成 | “把剛才確認的‘寄快遞’標記為已完成。” |
| 刪除事項 | “刪除剛才確認的那一條‘寄快遞’，不要刪除同名的其他事項。” |

標記完成會保留事項並改變狀態，刪除會移除事項。工具可以設定開始時間、截止時間與文字備註；需要到點通知時，請在系統提醒事項中確認提醒設定和通知權限。

**地點文字只是備註，不是“到達某地時提醒”的觸發條件。** 複雜重複或地點觸發提醒請在系統提醒事項中設定。按日期查到的結果也不等於整個清單，沒有日期的事項可到系統 App 中核對。

## Android 為什麼跳到系統日曆？

部分 Android 裝置無法直接完成日曆操作時，App 會嘗試開啟系統日曆頁面：

* **新增頁面**：核對日期和內容，選擇目標日曆，手動儲存。
* **已有日程頁面**：檢查當前值，手動完成剩餘修改；你在聊天裡要求的改動不一定已填入。

頁面開啟後，Cherry Studio 無法僅憑這一動作確定你是否儲存。若提示“結果不確定”或寫入超時，原操作可能已經完成，先核對日曆，避免再次新增造成重複。

## 找不到日曆或事項

先在系統日曆或提醒事項 App 中確認帳號和目標記錄存在，再檢查 Cherry Studio 的權限、查詢日期和所選日曆。企業帳號、只讀訂閱日曆和未同步到手機的資料，可能不在可操作範圍內。

工具是否需要確認，見[讓 AI 使用工具](using-tools.md)；系統權限與資料用途，見[資料、隱私與權限](data-privacy.md)。
