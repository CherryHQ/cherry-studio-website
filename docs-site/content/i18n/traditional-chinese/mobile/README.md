# Cherry Studio 行動版

Cherry Studio 行動版是為 Android、iPhone 與 iPad 設計的 AI 用戶端。你可以連接自己的模型服務，在行動裝置上進行對話、設定智能體並生成圖片。

## 目前狀態

行動版目前處於 **Beta** 階段：

* Android 透過官方 APK 提供。
* iPhone 與 iPad 透過 Apple TestFlight 提供。
* 介面與功能可能隨版本快速調整，實際情況以你安裝的版本為準。

前往[下載頁的行動端選項](https://cherryai.com/download?platform=mobile)，或先閱讀[安裝指南](installation.md)。

## 可以做什麼

* 新增內建或自訂模型服務商，管理常用模型。
* 在助理中切換模型，傳送文字、圖片或檔案。
* 建立智能體，設定提示詞、模型與支援的系統工具。
* 使用已設定的圖片模型生成並預覽圖片。
* 在 iPhone、iPad 與 Android 裝置上使用針對觸控設計的介面。
