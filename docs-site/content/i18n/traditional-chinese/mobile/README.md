# Cherry Studio 行動版

Cherry Studio 行動版是為 Android、iPhone 與 iPad 設計的 AI 客戶端。你可以連線自己的模型服務，在移動裝置上進行對話、配置智能體並生成圖片。

## 當前狀態

行動版目前處於 **Beta** 階段：

* Android 透過官方 APK 提供。
* iPhone 與 iPad 透過 Apple TestFlight 提供。
* 介面與功能可能隨版本快速調整，具體以你安裝的版本為準。

前往[下載頁的行動版選項](https://cherryai.com/download?platform=mobile)，或先閱讀[下載與安裝](installation.md)。
