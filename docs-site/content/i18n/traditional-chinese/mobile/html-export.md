# HTML 轉圖片與 PPT

HTML 是可以帶有排版、顏色和圖片的網頁檔案。在 Cherry Studio 中儲存並開啟 HTML 後，可以把它分享成長圖或 PPT，適合展示方案、學習卡片或簡短演示稿。

## 先準備一個 HTML 檔案

可以上傳已有檔案，也可以讓支援工具呼叫的模型製作：

> 把剛才的專案介紹製作成一個可獨立開啟的 HTML 演示稿，三頁，分別介紹目標、計劃和下一步。每頁使用 16:9 比例，字號便於閱讀，不依賴網路圖片或字型，儲存為“專案介紹.html”。請為每頁使用 class="slide" 的獨立頁面容器。

最後一句是告訴模型如何標記頁面，你可以直接複製，不需要自己編寫程式碼。只要求一張資訊卡時，不必分頁。

等待檔案儲存完成，再點選檔案卡片，或從側邊欄 **檔案** 中開啟。只有聊天中的 HTML 程式碼塊時，需要先讓模型將其[儲存成檔案](file-generation.md)。

## 分享成長圖或 PPT

1. 開啟完整的 HTML 檔案，檢查文字、圖片和頁面佈局。
2. 點選右上角 **更多**。
3. 選擇 **分享為圖片** 或 **分享為 PPT**。
4. 等待準備、頁面捕獲和檔案寫入完成；需要停止時點選進度區域的 **取消**。
5. 在系統分享面板中選擇儲存或接收應用。

生成的 PNG 或 PPTX 也會保留在 **檔案** 中，之後可以再次開啟或分享。關閉系統分享面板不代表已經儲存到你選擇的其他位置。

## 兩種格式有什麼區別？

| 格式 | 適合什麼 | 輸出特點 |
| --- | --- | --- |
| 圖片（PNG） | 發給別人直接檢視，分享資訊卡 | 整份 HTML 合為一張圖片；多頁內容縱向排列 |
| PPT（PPTX） | 按頁展示或播放 | 每頁是一張畫面，放入 16:9 幻燈片中 |

**PPT 中的文字和圖表屬於頁面圖片，不能逐項編輯。** 需要修改內容時，先讓模型修改 HTML，再重新轉換。需要原始可編輯內容時，可以同時分享 HTML 檔案。

帶有明確頁面標記的 HTML 會按頁面轉換。普通長網頁則按高度切成 16:9 頁面，可能截斷段落或表格，並不會自動重新設計成演示稿。出現這種情況，可以讓模型重新整理為每頁獨立、內容較少的演示稿。

頁面比例不一致時，PPT 會保留比例並留白，不會強行拉伸。轉換使用較寬的頁面佈局，排版可能與手機上看到的窄屏預覽不同。

## 水印和檔案裡的互動會保留嗎？

轉換跟隨 **設定 → 通用 → 分享水印**：開啟時，圖片底部或 PPT 最後一頁會加入水印。設定影響新生成的檔案；已經儲存的轉換結果不會隨之後的開關變化而重做。

轉換重新開啟已儲存的 HTML，不會複製你剛才在預覽裡點選按鈕、展開摺疊區或填寫表單後的狀態。動畫與影片也不會變成可播放的 PPT 內容。需要展示某種狀態時，讓模型把它直接儲存為頁面的靜態內容。

## 為什麼看不到轉換入口，或轉換失敗？

* **檔案不是 HTML**：Markdown、普通文字或聊天程式碼塊不會顯示這兩個轉換入口。
* **檔案過長，只載入了部分內容**：無法轉換不完整的 HTML；請精簡或拆分。空內容也不能轉換。
* **圖片或字型載入失敗**：依賴網路的資源需要可訪問；可以讓模型改為不依賴外部資源的版本。
* **內容太長或頁面太多**：PPT 最多 64 頁，長圖也有尺寸限制。減少內容、分成多個檔案，或把長圖改為分頁演示稿。
* **佈局不斷變化或切到後臺**：複雜動態頁面可能失敗，轉換時保持 App 在前臺；必要時使用靜態排版。

失敗或取消後，原 HTML 檔案仍可繼續編輯。重新嘗試前按提示處理原因；重要檔案分享出去後，再用接收應用確認頁數和內容。
