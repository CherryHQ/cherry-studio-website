# 從電腦匯入設定

如果電腦上的 Cherry Studio 已經配置好模型服務，可以把支援的服務商配置和模型匯入手機，減少重複填寫地址和金鑰。

**當前匯入範圍是模型服務商配置和已啟用模型，不包含聊天記錄，也不是遠端控制電腦。** 配對成功後不會持續自動同步；需要更新配置時再主動同步。

## 連線電腦

1. 讓手機或平板與電腦連線同一區域網，例如同一家庭 Wi-Fi，並保持桌面端 Cherry Studio 執行。
2. 在桌面端開啟 **裝置互聯**，顯示配對二維碼。
3. 行動版開啟 **設定 → 裝置互聯 → 掃描二維碼**；首次使用允許相機和系統請求的區域網訪問權限。
4. 掃描後按頁面繼續選擇要同步的服務商。首次使用嚮導中的“從桌面端同步”也會進入這套流程。

不能使用相機時，可以使用頁面提供的手動輸入方式，貼上桌面端的配對二維碼內容。這裡需要的是配對內容，不是普通網頁連結。

## 選擇並匯入服務商

已配對裝置可以從裝置詳情中的 **從桌面端同步模型服務商** 進入；也可以從模型服務列表的更多選單選擇 **從桌面端同步**，再選擇來源電腦。

1. 等待讀取電腦上已啟用的服務商。
2. 勾選本次需要匯入的服務商。
3. 閱讀“將覆蓋所選服務商的地址和金鑰，已有模型保留”的提示。
4. 點選同步，檢視新增、更新與跳過的數量。
5. 返回對話選擇匯入的模型；首次使用嚮導會繼續讓你選擇聊天模型。

## 已在手機上配置過，會發生什麼？

| 專案 | 再次同步後的行為 |
| --- | --- |
| 選中的服務商 | 更新為電腦上的配置和金鑰，並在手機啟用 |
| 電腦已啟用、手機缺少的模型 | 新增到手機 |
| 手機上已經存在的同一模型 | 保留手機現有設定，不重複新增 |
| 手機獨有的服務商或模型 | 保留 |
| 電腦上已停用的服務商或模型 | 不在本次匯入範圍內 |
| 聊天記錄、外掛帳號授權 | 不透過此功能匯入 |

手機與電腦使用不同金鑰時，尤其要注意第一項。即使沒有新模型，選擇已有服務商同步仍可能替換其地址和金鑰。

## 為什麼有些服務商不能選？

檢視條目上的原因：

* **認證方式不支援**：例如電腦端登入的帳號沒有可匯出的、行動版可用的金鑰，需要在手機使用支援的方式單獨配置。
* **未配置可用金鑰**：先在電腦確認至少有一個有效且啟用的 API Key。
* **當前版本無法識別配置**：更新行動版，或先跳過該條目，匯入其他可用服務商。

電腦上的本地模型服務，例如 Ollama、LM Studio，不屬於當前匯入範圍。手機不能因為配對成功就把電腦裡的本地模型當作手機上的服務執行。

## 掃碼成功，但同步失敗

配對儲存的是連線憑據，後續讀取配置仍需要連得上電腦。確認桌面端執行、兩臺裝置在同一區域網，且路由器的訪客網路隔離、電腦防火牆或代理沒有阻斷連線。

iPhone 或 iPad 拒絕過區域網權限時，請到系統設定為 Cherry Studio 開啟。頁面顯示“需要重新配對”時，重新掃描電腦端生成的二維碼。

## 移除裝置會撤銷兩邊的授權嗎？

行動版的 **移除裝置** 只移除這臺手機儲存的連線憑據。需要撤銷桌面端授權時，還應在電腦的 **裝置互聯** 中移除這臺移動裝置。
