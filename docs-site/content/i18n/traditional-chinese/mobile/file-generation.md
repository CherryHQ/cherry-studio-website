# 產生與修改檔案

除了直接回答，智能體還能把文字儲存為檔案，讓你預覽、繼續修改，再分享出去。這適合清單、會議紀要、表格資料和簡單網頁。

## 把回答儲存成一個檔案

選擇支援工具呼叫的文字模型，在訊息中明確要求**儲存檔案**和檔名：

> 把剛才的出行建議整理成一份 Markdown 清單，儲存為“週末出行清單.md”，並提供可以開啟的檔案。

Markdown 是可以儲存標題、列表和表格的文字格式。只要簡單文字，也可以要求儲存為 `.txt`。

生成過程中顯示的文字預覽，是正在準備的檔案內容，不是已經儲存的檔案。等待操作完成，點選生成的檔案卡片開啟；也可以從側邊欄的 **檔案** 中找回。

如果回答只有程式碼塊，沒有可開啟的檔案，可以繼續說：“請把這些內容實際儲存到檔案中，不要只在回答裡展示。”

## 選擇什麼格式？

| 你要的結果 | 建議格式 | 示例 |
| --- | --- | --- |
| 普通文字 | TXT | “儲存為通話記錄.txt。” |
| 帶標題、清單和表格的文章 | Markdown | “儲存為會議紀要.md。” |
| 用表格軟體處理的資料 | CSV | “列為物品、數量、備註，儲存為採購清單.csv。” |
| 帶排版的頁面或演示稿 | HTML | “生成一個可獨立開啟的 HTML 檔案，儲存為專案介紹.html。” |

內建檔案寫入工具儲存的是文字，單個檔案最多 1 MB。**把檔名改成 `.docx`、`.xlsx` 或 `.pptx`，不會自動變成真正的 Office 文件。** CSV 可用表格軟體開啟，但不包含工作簿中的多個工作表、格式和圖表。

需要 PPT 時，可以先製作 HTML 演示稿，再使用[HTML 轉圖片與 PPT](html-export.md)。如果某個外掛提供其他文件建立能力，則以該外掛實際支援的功能為準。

## 讓 AI 讀取並修改已有檔案

1. 在對話中點選 **＋ → 檔案**，選擇已有檔案或上傳檔案。
2. 明確指出要改哪一部分、改成什麼，哪些內容保持不變。
3. 開啟修改後的檔案，核對結果。

例如：

> 修改我上傳的採購清單.csv，把“雨傘”這一行的數量從 1 改為 2，其他行保持不變。

> 將剛才生成的會議紀要.md 中“下週一交付”改為“下週三交付”，其他內容不變。

文字檔案可以直接修改；PDF、Word、Excel 等文件可以在支援範圍內提取內容供模型閱讀，但內建編輯工具不能直接修改它們原有的版式和檔案結構。可以要求“提取內容後整理成一份新的 Markdown 檔案”。附件格式和讀取限制見[對話與檔案](chat-and-files.md)。

### 修改會覆蓋原檔案嗎？

* 修改上傳的檔案或之前回答生成的檔案，會另存新版本，例如 `會議紀要 v2.md`，原檔案保留。
* 在同一次回答中，智能體可以反覆調整剛生成的草稿，最終顯示一個檔案，不會每改一句就生成一個新版本。

這不是持續同步：修改 Cherry Studio 中匯入的副本，不會同時修改手機其他位置或雲盤中的原檔案。

### 為什麼說找不到要替換的文字？

編輯需要匹配檔案中的原文。文字已經變化、同一句出現多次，或標點空格不同，都可能導致無法確定位置。讓智能體先重新讀取相關段落，再指定更完整的句子或上下文；只有確實要修改所有相同內容時，才要求全部替換。

## 讀了一部分，等於讀完整個檔案嗎？

不等於。大檔案可能分多次讀取，文件提取本身也有限制。需要全文檢查時，可以要求：“繼續讀取尚未覆蓋的部分，並說明還有哪些內容沒有讀到。”如果源文件已經被截斷，繼續讀取也不能恢復未提取的部分，應拆分檔案後重新提供。

工具讀取的是這段對話中可訪問的附件或生成檔案，不會自動搜尋手機中的全部檔案。在新對話繼續處理時，重新透過檔案入口選擇目標檔案。

## 找回、預覽和分享

從側邊欄開啟 **檔案**，可以切換列表或網格，按類型檢視檔案。點選檔案進入預覽；不支援內建預覽的格式可交給系統中的其他應用開啟。

預覽頁右上角 **更多** 選單提供分享、用其他應用開啟等操作；文字檔案還可複製文字。長檔案只顯示部分內容時，複製也只複製顯示的部分，分享則使用完整原檔案。

檔案儲存在本機。重要內容請透過系統分享儲存到手機檔案或其他儲存位置，再確認能夠開啟；清理本機檔案或解除安裝 App 前尤其如此。匯出聊天與分享檔案是不同入口，分享問答見[分享與匯出](sharing-and-export.md)。

內建讀取、建立和修改文字檔案通常直接執行，在 **需要時確認** 模式下也不逐次詢問。詳見[工具審批說明](using-tools.md)。
