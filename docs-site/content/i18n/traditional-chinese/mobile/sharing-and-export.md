# 分享與匯出

可以只分享一條回答，也可以把多輪問答整理成圖片、網頁檔案或可繼續編輯的文字檔案。分享前先選擇內容，再看預覽，最後選擇接收應用。

## 分享一條或多條訊息

1. 使用回答操作區的分享按鈕，或訊息選單中的分享入口。
2. 在訊息選擇頁勾選要分享的內容，最初會選中剛才那條訊息。
3. 點選確認，進入全屏預覽。
4. 按需要調整格式、圖片佈局，以及是否包含思考內容。
5. 點選分享，在系統面板選擇儲存位置或接收應用。

只會匯出**選中的訊息**，不會自動附上未選擇的問題。想讓接收者理解上下文，請同時勾選相關問題和回答。選擇順序不影響輸出，最終按對話時間排序。

一次最多選擇 128 條訊息，正在生成的訊息不能選擇。選擇頁裡的文字只是簡短摘要，實際匯出使用所選訊息的完整內容，並按格式處理程式碼、圖片等部分。

## 選哪種格式？

| 格式 | 適合用途 | 需要知道 |
| --- | --- | --- |
| 圖片（PNG） | 發到聊天、便於直接閱讀 | 預設分頁輸出；程式碼塊只顯示開頭的有限區域，需要完整程式碼時選其他格式 |
| HTML（可在瀏覽器開啟的網頁檔案） | 保留較豐富排版、完整程式碼和可展開內容 | 對方需要用瀏覽器或支援的應用開啟 |
| Markdown（方便繼續編輯的純文字排版檔案） | 儲存原文、程式碼與表格，繼續整理筆記 | 顯示效果受接收軟體支援程度影響 |

預設圖片模式會把長內容分成按順序排列的多張圖片，也可以切換為單張長圖。很長的單圖對裝置和接收應用要求更高，打不開時優先使用分頁圖片、HTML 或 Markdown。

圖片和 HTML 中的來源會簡化展示。需要仔細核對引用時，可以返回對話開啟原始來源；不要把圖片預覽當作完整的資料包。

## 選擇頁與預覽的格式提示不一致怎麼辦？

部分版本的訊息選擇頁仍顯示“多選僅支援 HTML 和 Markdown”的舊提示。當前預覽也支援把多條訊息生成圖片，以進入預覽後實際可選的格式為準；圖片準備失敗時，可使用 HTML 或 Markdown。

## 思考和工具過程會一起發出去嗎？

預設不包含。開啟 **包含思考內容** 後，會加入可見的思考、過程文字及可讀的工具名稱，不會把原始工具請求或診斷資料一併匯出。

HTML 中相關內容可以展開閱讀，圖片會展開已選擇包含的過程。分享給他人前，仍請在預覽中檢查是否包含不需要的中間內容。

## Markdown 裡的圖片能離線看嗎？

本地和生成的 PNG、JPEG 圖片會嵌入匯出的 Markdown 檔案，因此檔案可能變大。有些 Markdown 閱讀器會限制這類嵌入圖片，導致看不到；可換用 HTML 或圖片格式。

本地 GIF、WebP 等其他格式若無法嵌入，會顯示圖片不可用說明；普通附件也可能只保留檔名稱或說明，不會把附件原檔案全部打包進去。需要完整保留時，另外分享原檔案。

原本來自外部網址的圖片仍保留遠端連結，不會因此全部變為離線附件。

## 圖片匯出失敗怎麼辦？

應用會在圖片轉換失敗時嘗試準備 HTML；HTML 也無法預覽時保留 Markdown，並提示實際可分享的格式。檢視格式名稱再分享，避免把不同格式的檔案誤當作圖片。

退到後臺或主動取消會中斷轉換，不會因此自動改換格式。長內容建議保持應用在前臺，必要時減少選擇的訊息或使用分頁圖片。

關閉預覽可回到選擇頁繼續調整；關閉系統分享面板會返回對話。**開啟過系統分享面板不代表接收應用已經成功儲存或傳送。**

## 去掉分享水印

開啟 **設定 → 通用設定 → 分享水印**，關閉後再匯出。設定預設開啟，影響後續對話、圖片及相關檔案匯出；已經儲存或發出的檔案不會自動改變。

## 檔案庫與原檔案分享

從側邊欄進入 **檔案**，檢視匯入的附件和已儲存的生成、匯出檔案。支援的圖片、文字、Markdown 和 HTML 可以在應用中預覽，其他類型可交給系統或其他應用開啟。

* 圖片預覽支援縮放，以及分享、儲存到相簿等操作。
* 大文字的預覽可能只顯示一部分，複製也以顯示的內容為準；**分享原檔案會匯出完整原檔案**。
* HTML 預覽失敗時可以檢視原始碼，或分享給其他應用開啟。
* 刪除檔案前確認是否還需在原對話中使用，必要時先另存。已儲存到檔案庫的匯出檔案，不會僅因取消系統分享就自動刪除。

## 將 HTML 檔案轉為圖片或幻燈片

開啟可完整預覽的 HTML 檔案，可選擇 **分享為圖片** 或 **分享為 PPT**。等待轉換進度完成後，在系統分享面板儲存。

PPTX（可用演示軟體開啟的幻燈片檔案）中的頁面是圖片，適合保留頁面外觀，**不是可逐段編輯的文字、表格和圖形**。需要繼續改內容時，保留原始檔案。

解除安裝或清理應用前，把檔案儲存到 Cherry Studio 之外的位置或其他裝置，並確認能開啟；僅留在應用檔案庫中仍可能隨應用資料丟失。

匯出方便儲存和分享部分成果，不等同於可恢復整個應用的備份。電腦匯入配置的範圍見[從電腦匯入配置](desktop-sync.md)。

## 分享生成的檔案或演示稿

要分享已儲存的檔案，開啟檔案卡片，再使用右上角更多選單。步驟見[生成與修改檔案](file-generation.md)。HTML 檔案還提供[分享為圖片和分享為 PPT](html-export.md)；得到的 PPT 儲存頁面畫面，文字不能逐項編輯。
