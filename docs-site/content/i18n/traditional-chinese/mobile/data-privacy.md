## 裝置上的資料

應用程式設定、服務商設定與對話紀錄主要儲存在目前裝置。刪除應用程式、清除系統資料或更換裝置前，請先確認重要內容已經另行儲存；不要假設行動版會自動與桌面版同步。

## 傳送給服務商的資料

當你傳送訊息、檔案或生成圖片時，請求會依你的設定傳送給所選的模型服務商。服務商如何保留與處理資料，取決於其隱私政策、帳戶設定與介面條款。

## API Key

* 只在官方應用程式內填寫 API Key。
* 不要在螢幕截圖、記錄檔、聊天或回報內容中暴露完整的 Key。
* 懷疑外洩時，立即在服務商主控台撤銷並重新建立。
* 建議為行動端使用可單獨撤銷、額度受限的 Key。

## 系統權限

圖片、檔案、相機、行事曆或提醒事項等能力可能需要系統權限。應用程式會在實際使用相關功能時要求授權。你可以在 Android 或 iOS 的系統設定中隨時調整。

最小權限原則：不使用的能力不授權；涉及寫入或外部操作的工具保留人工確認。
