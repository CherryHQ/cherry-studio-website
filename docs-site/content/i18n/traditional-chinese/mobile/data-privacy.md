# 資料、隱私與權限

行動版把對話和配置儲存在當前裝置，但使用雲端模型或聯網工具時，完成任務所需的內容仍會傳送到對應服務。下面按用途說明。

## 不同資料去哪裡？

| 使用方式 | 需要處理的資料 |
| --- | --- |
| 雲端對話或圖片生成 | 所選模型服務商接收訊息、參與本次請求的歷史，以及相關圖片、解析後的文件內容或繪圖描述 |
| 聯網搜尋與網頁閱讀 | 搜尋或閱讀服務接收關鍵詞、網頁連結；返回的資料再參與模型回答 |
| 外掛或自訂工具 | 對應外部服務按授權處理請求；取回的資料可能提供給模型 |
| 日曆、提醒、位置等系統工具 | 在系統授權範圍內獲取或修改資料，相關結果可能用於模型回答 |
| 從電腦匯入配置 | 透過區域網讀取選中服務商的地址、金鑰和支援的模型配置 |

這些服務如何保留資料，以各自的帳號設定和隱私政策為準。“資料儲存在本機”不表示模型回答全程離線。

## 匿名使用資料與錯誤報告

首次使用或隱私政策更新後，應用會說明匿名資料用途，讓你選擇 **同意並繼續** 或 **不同意**。以後可在 **設定 → 隱私設定** 修改選擇。

* **共享匿名使用資料**：用於瞭解應用使用情況，包含安裝標識、應用與系統版本、所用模型及 Token 數量等，不包含對話正文、檔案或 API Key。
* **匿名傳送錯誤報告**：用於排查崩潰和異常，與使用資料是獨立開關。

關閉匿名使用資料不等於阻止你主動向模型服務商傳送訊息，也不等於撤銷外掛帳號授權。需要停止某個連線時，到對應服務商或外掛設定處理。

## 保管金鑰與外掛授權

API Key 是呼叫模型服務的金鑰，不要寫進智能體說明、公開截圖或問題反饋。懷疑洩露時，到服務商撤銷舊金鑰，再回到應用填寫新金鑰。

內建外掛的授權憑據存放在裝置的系統安全儲存中，不透過電腦配置匯入同步到其他裝置。自訂 MCP 的靜態認證欄位隨伺服器配置儲存在本機，請同樣妥善保管。

## 系統權限怎麼管理？

開啟 **設定 → 系統權限**，檢視相機、照片、日曆、定位等狀態。首次用到某項能力時可能先出現應用內工具確認，再出現系統授權；需要分別處理。

| 現象 | 可以怎麼做 |
| --- | --- |
| 只能看到部分照片 | 系統可能只授權了選中的照片，重新選擇或調整照片訪問權限 |
| 拒絕後沒有再次彈窗 | 前往手機系統設定修改 Cherry Studio 的權限 |
| 可以看日曆但不能修改 | 檢查讀、寫權限是否分別滿足 |
| 健康資料為空 | 確認裝置中有相應記錄，且該資料類型已授權 |
| 掃碼能配對卻讀不到電腦配置 | 檢查區域網權限與網路，見[電腦匯入教程](desktop-sync.md) |

智能體編輯頁的能力開關決定這個智能體是否使用相關內建工具，系統權限決定應用是否有權訪問對應資料。外掛與自訂 MCP 工具需單獨管理。關閉智能體開關不會撤銷系統授權；需要撤銷時到系統設定處理。自動批准工具不會越過系統權限。Android 當前不提供 iOS 提醒事項、健康記錄這兩類系統工具。

## 換裝置、解除安裝和清理資料前

不要把電腦配對當作完整備份或自動同步。當前裝置互聯主要匯入服務商配置及模型，聊天記錄不在匯入範圍。

解除安裝、清除應用資料或更換裝置前，先把重要問答和檔案[分享或匯出](sharing-and-export.md)，儲存到應用之外的位置或其他裝置，並確認可以開啟。只儲存在 Cherry Studio 檔案庫裡仍可能隨應用資料一起被刪除。匯出的圖片、HTML 或 Markdown 用於儲存成果，並不是可恢復所有應用設定的備份檔案。

## 刪除記錄能撤銷已經執行的操作嗎？

不能。刪除一輪對話或重新回答，不會撤銷已經修改的日程、外部文件或發出的訊息，也不會退回模型費用。需要撤銷外部操作時，到相關服務檢視並處理實際結果。

## 反饋時提供什麼？

提供應用版本、裝置與系統版本、操作步驟、預期和實際結果，以及錯誤提示即可。截圖或錯誤詳情中如果有真實金鑰、帶憑據的地址、私人對話或檔案內容，先遮蓋再傳送。
