# 下載與安裝

請一律從[官方下載頁的行動端選項](https://cherryai.com/download?platform=mobile)取得安裝入口，不要安裝來源不明的安裝包。

## Android

目前提供適用於 ARM64 裝置的 APK。

1. 在下載頁選擇 **下載 APK**。
2. 下載完成後，從瀏覽器下載紀錄或檔案管理員開啟 APK。
3. 如果系統阻擋安裝，請依提示暫時允許目前的瀏覽器或檔案管理員「安裝不明應用程式」。
4. 返回安裝介面並完成安裝。

安裝完成後，可以關閉剛才授予的「安裝不明應用程式」權限。新版本發布時，重新從官方下載頁取得 APK 並覆蓋安裝；升級前請先查看版本說明。

## iPhone 與 iPad

iOS / iPadOS 目前透過 TestFlight 提供測試版。

1. 從 App Store 安裝 Apple 的 **TestFlight**。
2. 在行動版下載頁選擇 **加入 TestFlight**。
3. 在 TestFlight 中接受邀請並選擇 **安裝**。

TestFlight 名額與測試版本有效期限由 Apple 的測試機制管理。如果邀請暫時無法使用，請稍後重試或關注官方發布管道。

## 安裝之後

首次開啟應用程式後，繼續閱讀[快速開始](quick-start.md)，新增模型服務並傳送第一則訊息。
