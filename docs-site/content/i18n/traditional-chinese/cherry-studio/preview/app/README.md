# 小程式

【小程式】讓網頁服務和本地安裝的小工具在 Cherry Studio 中運行。除了開啟各家 AI 廠商的網頁版，你也可以安裝自訂的生成式小程式，讓它透過授權介面呼叫 Cherry Studio 已設定的 AI 模型。

### 先分清兩類小程式

| 類型 | 新增方式 | 能否呼叫 Cherry AI | 適合場景 |
| ----- | ---------------------------- | -------------- | ----------------------------------- |
| 網站 | 填寫名稱、URL 和 Logo | 不能 | 把常用網站固定到 Cherry Studio，保留各網站自己的登入狀態 |
| 本地小程式 | 安裝 `.miniapp` 包，或從開發者提供的網址安裝 | 可以，在安裝時授權 | 自訂 AI 寫作、摘要、翻譯、資訊擷取和垂直工作流 |

{% hint style="info" %}
如果你要製作「能呼叫 Cherry AI 的自訂小程式」，請使用【本地小程式】，而不是只填寫 URL 的【網站】。完整教學見 [生成式小程式](generative-mini-apps.md)。
{% endhint %}

### 進入小程式

{% stepper %}
{% step %}
### 開啟啟動台

頂部 Tab 列點擊 `+`，或直接開啟【啟動台】。
{% endstep %}

{% step %}
### 進入小程式

點擊【小程式】應用程式圖示。
{% endstep %}

{% step %}
### 選擇服務

在小程式網格中選擇需要開啟的服務。
{% endstep %}
{% endstepper %}

頁面中部有 **搜尋框**；右上角 `+` 用於新增自訂網頁，`☰` 開啟【小程式顯示設定】。

### 設定

在【設定】→【小程式】中可以對小程式進行如下調整：

* **顯示 / 隱藏小程式**：可以左右拖曳小程式到兩個區域，控制顯隱
* **排序小程式**：上下拖曳可以對小程式進行排序
* **小程式區域篩選**：根據你的選擇，自動隱藏你無法存取的小程式
* **小程式快取數量**：如果同時開啟的小程式數量超出此數量，則有一部分小程式會進入不活躍狀態

### 新增與管理

Cherry Studio 的小程式支援以下操作：

* **新增到啟動台**：把常用的小程式加入啟動台，方便從 `+` 入口快速開啟。可在【設定】→【小程式】中管理，或對小程式圖示右鍵選擇 **新增到啟動台**
* **新增到側邊欄**：把常用的小程式固定到左側邊欄，一鍵直達；右鍵小程式圖示即可選擇 **新增到側邊欄** 或 **從側邊欄移除**
* **保活（Keep Alive）**：讓小程式視窗在切走時不立即銷毀，再次進入無需重新登入或重新載入
* **新增網站**：點擊頁面右上角的 `+`，在【網站】中填寫名稱、URL、Logo，即可加入網格
* **安裝本地小程式**：點擊頁面右上角的 `+`，切換到【本地小程式】，選擇 `.miniapp` 包，或填寫開發者提供的安裝網址。確認權限後完成安裝
* **檢視本地小程式詳情**：右鍵本地小程式，選擇【檢視詳情】，可管理權限、AI 模型、儲存空間、活動日誌和更新
* **刪除 / 編輯**：網站型小程式可右鍵編輯或刪除；本地小程式可在【檢視詳情】中解除安裝

開啟某個小程式後，其視窗自帶一條工具列：**後退**、**前進**、**重新整理**、**在瀏覽器中開啟**。你還可以切換頁內連結是在預設視窗開啟，還是在系統瀏覽器開啟。

### 提示與技巧

* 網站型小程式使用服務的網頁版，登入狀態、Cookie、設定均儲存在本地，並與系統瀏覽器隔離
* 本地小程式運行在獨立沙箱中，不能讀取其他小程式或電腦上的任意檔案；只有你授權的能力可以被呼叫
* 若某個小程式載入失敗，可右鍵 → 重新整理，或檢查代理設定（參考 [一般設定](../../../pre-basic/settings/general.md)）
