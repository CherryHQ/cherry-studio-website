# Linux

## 1. 下載安裝包

開啟 [官方下載頁](https://cherryai.com.cn/download/v2)，選擇 **Linux**。官網會依系統與架構提供不同格式的安裝包：

| 使用情境 | 選擇建議 |
| ------------------------ | ----------------------- |
| Ubuntu、Debian、Linux Mint | 選擇與架構相符的 `.deb` 套件。 |
| Fedora、RHEL、openSUSE | 選擇與架構相符的 `.rpm` 套件。 |
| 其他發行版或需要便攜式執行 | 選擇與架構相符的 `.AppImage` 套件。 |

Intel / AMD 裝置通常選擇 x64（或 x86\_64）版本；ARM 裝置選擇 ARM64（或 aarch64）版本。若不清楚架構，請在終端機執行 `uname -m`：`x86_64` 對應 x64，`aarch64` 或 `arm64` 對應 ARM64。

## 2. 安裝並啟動

* `.deb` 和 `.rpm`：優先使用發行版的軟體安裝器或套件管理器開啟安裝包，再從應用程式選單啟動 Cherry Studio。
* `.AppImage`：為檔案授予可執行權限後，雙擊執行；也可以在終端機執行 `chmod +x 檔案名稱.AppImage` 後啟動。

## 無法啟動

先確認安裝包與系統架構相符。若 AppImage 無法啟動且出現 `FUSE` 或 `libfuse` 相關錯誤，請依照目前發行版的官方文件安裝相應的相容元件。

若仍無法啟動，請在回饋中附上發行版、桌面環境、裝置架構、安裝包名稱以及完整的錯誤訊息。

## 下一步

看到 Cherry Studio 主畫面後，請繼續完成快速入門。
