# 筆記

筆記是 Cherry Studio 內建的 Markdown 編輯器，方便您與 AI 對話之外整理靈感、保存階段性產出，並借助 AI 與知識庫能力進一步加工。

### 開啟筆記

頂部標籤欄點擊【筆記】，或在【啟動台】中點擊【筆記】應用圖示。

<figure><img src="../../../../assets/14e04a73fa23719ebd35dde4.webp" alt=""><figcaption><p>筆記介面：左側是目錄樹與筆記列表，右側是 Markdown 編輯器</p></figcaption></figure>

### 建立第一篇筆記

1. 點擊左上角第一個【新建筆記】圖示
2. 在右側編輯器中輸入正文，支援 Markdown 語法與富文字快捷工具列
3. 右鍵筆記列表中的筆記，為其命名

### 匯入現有 Markdown 檔案

* 直接將 `.md` 檔案或包含 `.md` 檔案的目錄 **拖曳** 到筆記區域，即可匯入為新筆記或新資資夾
* 也可點擊左上角第二個【新建資資夾】圖示先建好目錄，再向其中拖曳

### 編輯器功能

筆記編輯器頂部工具列提供常用富文字功能：

* **格式化**：粗體（<kbd>B</kbd>）、斜體（<kbd>I</kbd>）、底線（<kbd>U</kbd>）、刪除線
* **結構**：行內程式碼 / H1–H3 標題 / 無序列表 / 有序列表 / 程式碼區塊 / 引用 / 任務清單 / 公式
* **嵌入**：表格、超連結

<figure><img src="../../../../assets/d391f5ca5d92cb8fdf22ca63.webp" alt=""><figcaption><p>新建筆記並寫入正文後的編輯器</p></figcaption></figure>

底部狀態列顯示目前 **字元數**，左下角的 **A✓** 圖示可開關拼字檢查，右下角下拉切換 **即時預覽**、**原始碼模式** 或 **閱讀模式**。

### 目錄管理

左側側欄頂部依序是：【新建筆記】/【新建資資夾】/【排序】/【收藏】/【搜尋】。

* **排序**：6 個選項——檔案名稱 `A→Z` / `Z→A`、更新時間從新到舊 / 從舊到新、建立時間從新到舊 / 從舊到新
* **收藏**：星號按鈕切換到「已收藏」檢視
* **搜尋**：放大鏡按鈕，搜尋框中輸入即可。**搜尋同時比對標題與正文**，命中正文的項目會在標題旁加「內容」或「名稱+內容」標籤提示來源

### 右鍵選單（AI 聯動 + 匯出）

在左側目錄樹 **右鍵** 任一筆記會彈出操作選單——這是 AI 聯動與多格式匯出的入口：

<figure><img src="../../../../assets/fd4004b475c63d7c924304e8.webp" alt=""><figcaption><p>右鍵單條筆記彈出的選單</p></figcaption></figure>

* **產生筆記名稱** ✨：讓 AI 根據正文自動產生一個標題（僅檔案可用）
* **重新命名** / **從外部開啟**（在 Finder / 資源管理器中顯示）
* **收藏筆記** / **取消收藏**
* **匯出筆記到知識庫**：傳送到指定 [知識庫](../../knowledge-base/knowledge-base.md)
* **匯出 ›** 二級選單：Markdown / Word（.docx）/ Notion / 語雀 / Obsidian / Joplin / 思源，以及「複製為圖片 / 匯出為圖片」——每一項的顯示可在【設定】→【資資設定】→【匯出選單設定】中單獨開關
* **刪除**

> 資資夾的右鍵選單更精簡，只有：新建筆記 / 新建資資夾 / 重新命名 / 從外部開啟 / 刪除。

### 右上角【⋯】選單（檢視與匯出快捷入口）

筆記標題右上角的【⋯】是 **目前筆記** 的檢視 / 匯出快捷入口，不要和右鍵選單混淆：

<figure><img src="../../../../assets/b9b3ab0b2050382f16409b48.webp" alt=""><figcaption><p>右上角【⋯】選單</p></figcaption></figure>

* **複製內容**：純文字複製
* **匯出為 Word**：快速產生 `.docx`（需要更多格式請走右鍵選單的「匯出 ›」）
* **匯出為 PDF**：將目前筆記匯出為 PDF 檔案
* **列印**：呼叫系統列印目前筆記
* **縮減欄寬**：限制每行最大字數
* **顯示目錄大綱**：右側顯示目前筆記的標題樹
* **字型設定 ›**：預設 / 襯線字型，三檔字級（小 / 中 / 大）
* **更多設定**：開啟筆記設定面板（資資 / 編輯器 / 顯示三組設定）

### 工作目錄與備份

筆記內容儲存為本機檔案。**工作目錄** 在筆記設定面板的【資資設定】中檢視與修改（從右上角【⋯】→【更多設定】開啟）。

* 預設存放於 Cherry Studio 應用資資目錄下
* 先【選擇】自訂路徑，再點【套用】切換（變更不會自動遷移現有檔案，需手動複製）；點【重設為預設】可還原到預設目錄
* 備份建議結合 [WebDAV](../../pre-basic/data-settings/webdav.md) / [S3 相容儲存](../../pre-basic/data-settings/s3-compatible.md)

### 編輯器與顯示設定

從右上角【⋯】→【更多設定】開啟筆記設定面板，除【資資設定】外還有兩組：

**編輯器設定**

* **預設檢視**：新筆記預設進入【編輯模式】還是【閱讀模式】
* **預設編輯檢視**：編輯模式下預設採用【即時預覽】還是【原始碼模式】

**顯示設定**

* **字型**：預設 / 襯線字型
* **字型大小**：10–30px 之間
* **縮減欄寬**：限制每行字數，讓長行不至於橫鋪整屏
* **顯示目錄大綱**：在右側顯示目前筆記的標題樹，便於文內導覽

> 字型與字級既可在此顯示設定面板調整，也能從右上角【⋯】→【字型設定】快速切換。

### 提示與技巧

* 筆記支援任務清單 `- [ ]` 寫法，可用於日常待辦
* 拖曳 `.md` 檔案（或包含 `.md` 的目錄）到目錄樹即可批次匯入
* 跨裝置恢復設定後若發現筆記目錄為空，按提示路徑手動複製檔案即可

{% hint style="info" %}
若要让 AI **直接** 基於筆記內容回答問題，最方便的做法是把目標筆記 **匯出到知識庫**，然後在對話中開啟該知識庫。
{% endhint %}
