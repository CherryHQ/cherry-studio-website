# 選取助手

選取助手（Selection Assistant）讓您在 **任意應用程式中選取文字** 後，透過浮動工具列呼叫 AI 進行翻譯、解釋、優化、總結等操作，無需將內容貼回 Cherry Studio。

{% hint style="info" %}
**與 [快捷助手](quick-assistant.md) 的區別**：

* **快捷助手**：使用全域快捷鍵喚起一個 **主動輸入** 視窗，您輸入文字提問
* **選取助手**：選取文字後 **針對所選內容** 彈出工具列，一鍵執行預設操作
{% endhint %}

### 平台支援

* ✅ **macOS**：完整支援，但首次啟用需授予 **輔助功能（Accessibility）權限**
* ✅ **Windows**：完整支援，無需特殊權限
* ⚠️ **Linux**：僅在 **X11** 模式下完整支援；Wayland 模式下工具列可能無法跟隨選取文字定位。同時需要將目前使用者加入 `input` 組（`sudo usermod -aG input $USER`）以取得按鍵監聽權限

### 啟用選取助手

開啟【設定】→【選取助手】：

<figure><img src="../../../../assets/9c1fa1dc2820ccee7bd169f3.webp" alt=""><figcaption><p>選取助手設定面板</p></figcaption></figure>

1. 開啟 **啟用** 開關
2. **macOS** 使用者首次啟用會彈出視窗請求 **輔助功能權限**：

   <figure><img src="../../../../assets/ed99fa5f9b3118d263e09cd2.webp" alt=""><figcaption><p>首次啟用時的輔助功能權限提示</p></figcaption></figure>

   點擊 **前往設定** → 在彈出的【系統設定】→【隱私與安全性】→【輔助功能】中找到 Cherry Studio 並開啟開關 → 回到 Cherry Studio 再次啟用。
3. （可選）在【工具列】→【取詞方式】選擇觸發方式（不同平台可選項不同）：
   * **選取**：選取文字後立即彈出工具列（預設）
   * **Ctrl 鍵**（僅 Windows）：選取文字後 **再長按 Ctrl 鍵** 才彈出（避免誤觸）
   * **快捷鍵**：選取文字後按快捷鍵再彈出，快捷鍵在【設定】→【快捷鍵】中修改

### 內建操作

選取助手提供 7 個內建操作，**預設啟用 5 個**：翻譯 / 解釋 / 總結 / 搜尋 / 複製。工具列左側的 **Cherry 圖示不是操作按鈕**——它只是工具列的拖曳手柄，按住可移動整條工具列。

| 操作 | 預設啟用 | 用途 |
|---|---|---|
| **翻譯** | ✅ | 智慧翻譯：優先翻譯為目標語言；若已是目標語言則翻譯為備選語言 |
| **解釋** | ✅ | 讓 AI 解釋這段內容 |
| **總結** | ✅ | 讓 AI 用一段話總結所選內容 |
| **搜尋** | ✅ | 用所選文字呼叫搜尋引擎查詢（預設 Google，可在每項右側 ⋯ 修改） |
| **複製** | ✅ | 複製選取文字 |
| **優化** | 待啟用 | 讓 AI 改寫得更通順 / 更專業，需在設定中拖入啟用區 |
| **引用** | 待啟用 | 把選取文字以引用形式傳送至目前對話，需在設定中拖入啟用區 |

<figure><img src="../../../../assets/29cffab07ecb8317865312ee.webp" alt=""><figcaption><p>設定面板的【功能】區：上方為已啟用，下方暫存區拖到上方即啟用</p></figcaption></figure>

### 自訂操作

在【設定】→【選取助手】→【功能】中可：

* **編輯** 內建操作的提示詞
* **新增** 自訂操作（命名 + 提示詞 + 預設模型）
* **拖曳** 調整工具列中操作的順序
* 把不常用的操作拖到下方暫存區即可「停用」

### 工具列 / 結果視窗外觀

工具列：
* **緊湊模式**：僅顯示圖示，不顯示文字，節省螢幕空間

結果視窗（【功能視窗】節）：
* **跟隨工具列**：視窗貼著工具列彈出（預設開啟），關閉則始終置中
* **記住大小**：本次手動調整過的視窗尺寸，下次保留
* **自動關閉**：點擊視窗外即關閉
* **自動置頂**：始終懸浮在其他應用程式之上
* **透明度**：20%–100% 可調

### 搜尋引擎

選取助手內建的【搜尋】操作可選預設引擎（Google、Bing、DuckDuckGo 等）。設定入口在【設定】→【選取助手】→【功能】：找到 **搜尋** 這一項，點擊行末右側的齒輪圖示彈出【設定搜尋引擎】對話框，可在預設中挑選或新增自訂引擎，URL 中用 `{{queryString}}` 表示搜尋詞位置。

### 應用程式篩選（進階）

可在【設定】→【選取助手】→【進階】→【應用程式篩選】中設定 **黑名單 / 白名單**，讓選取助手僅在指定應用程式中生效（白名單）或不在指定應用程式中彈出（黑名單）。

* **macOS**：填入應用程式的 Bundle ID（如 `com.google.Chrome`、`com.apple.mail`）
* **Windows**：填入應用程式的可執行檔名稱（如 `chrome.exe`、`Cherry Studio.exe`）

### 使用的模型

選取助手預設使用 [全域預設對話模型](../../pre-basic/settings/default-models.md)，也可針對每個操作單獨指定模型。

### 提示與技巧

* macOS 上若工具列不出現，檢查【系統設定】→【隱私與安全性】→【輔助功能】中 Cherry Studio 是否已勾選
* 頻繁因誤觸選取文字而彈出工具列？切換到 **Ctrl 鍵** 觸發模式
* 工具列圖示過多擠佔螢幕？開啟 **緊湊模式**
* 想做「翻譯完直接朗讀」等鏈式操作？把「翻譯」結果複製後呼叫 [快捷助手](quick-assistant.md) 繼續處理
