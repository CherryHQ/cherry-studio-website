# Perplexity

Perplexity 的 **Sonar** 系列主打 **搜尋增強對話**——回答會結合即時聯網檢索，適合需要引用最新資訊的場景。

## 取得 API Key

* 開啟 Perplexity 的 [API 設定頁](https://www.perplexity.ai/settings/api)（需先註冊/登入）
* 產生並複製一個 API Key

## 在 Cherry Studio 中設定

1. 開啟 Cherry Studio 的 [模型服務設定](../settings/providers.md)，在內建清單中找到 **Perplexity**
2. 填入剛取得的 API Key
3. 點擊 **取得模型清單**，新增 Sonar 等模型，開啟右上角供應商開關即可使用

{% hint style="info" %}
Perplexity 模型自帶聯網檢索能力，無需額外設定聯網模式。國內存取通常需要自行解決網路代理問題。更多資訊請見 [Perplexity 官方文件](https://docs.perplexity.ai/home)。
{% endhint %}
