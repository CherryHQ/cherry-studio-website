# Mistral

Mistral AI 是歐洲開源大模型的代表，提供 Mistral / Codestral 等系列，兼顧效果與開放性。

## 取得 API Key

* 開啟 Mistral 控制台的 [API Keys 頁面](https://console.mistral.ai/api-keys/)（需先註冊/登入）
* 建立並複製一個 API Key

## 在 Cherry Studio 中設定

1. 開啟 Cherry Studio 的 [模型服務設定](../settings/providers.md)，在內建清單中找到 **Mistral**
2. 填入剛取得的 API Key
3. 點擊 **取得模型清單**，加入您需要的模型，開啟右上角供應商開關即可使用

{% hint style="info" %}
在中國大陸存取 Mistral 通常需要自行解決網路代理問題。更多資訊請參閱 [Mistral 官方文件](https://docs.mistral.ai)。
{% endhint %}
