# 智譜 ZhiPu

智譜 AI 的 **GLM** 系列（含多模態 GLM-4V），國內直連、中文表現好。智譜在 Cherry Studio 中走 **Anthropic 相容端點**，因此除普通對話外，也可用於 **Cherry Agent**。

## 取得 API Key

* 開啟智譜開放平台的 [API Keys 頁面](https://open.bigmodel.cn/apikey/platform)（需先註冊/登入）
* 建立並複製一個 API Key

## 在 Cherry Studio 中設定

1. 開啟 Cherry Studio 的 [模型服務設定](../settings/providers.md)，在內建清單中找到 **ZhiPu（智譜）**
2. 填入剛取得的 API Key
3. 點擊 **取得模型清單**，添加您需要的 GLM 模型，開啟右上角服務商開關即可使用

{% hint style="info" %}
智譜模型自帶 **聯網搜尋** 能力，具體以模型是否支援為準。更多平台文件見 [智譜官方文件](https://docs.bigmodel.cn/)。
{% endhint %}
