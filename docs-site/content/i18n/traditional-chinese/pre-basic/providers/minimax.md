# MiniMax

MiniMax 是國內大模型廠商之一，特點是具有相當出色的 **多模態能力**（涵蓋文本、語音、圖像、影片生成）。

## 取得 API Key

* 前往 [MiniMax 開放平台](https://platform.minimaxi.com/) 註冊帳號
* 完成實名認證後，進入 `账戶管理 → 接口密钥` 建立 API Key

## 在 Cherry Studio 中設定

* 開啟 `設定 → 模型服務`，找到 **MiniMax** Provider 並進入詳細頁面
* 填入 API 金鑰
* API 位址保持預設即可
* 點擊 **取得模型清單**

## 推薦用法

| 模型 | 適用情境 |
|---|---|
| `abab6.5s-chat` / `MiniMax-Text-01` | 日常對話 |
| `abab6.5-chat` | 高品質長文 |

{% hint style="info" %}
* MiniMax 在國內存取方便，新使用者享有一定免費額度
* 海外使用者請使用 **MiniMax Global**（在 Cherry Studio Provider 清單中為另一個獨立項目）
{% endhint %}
