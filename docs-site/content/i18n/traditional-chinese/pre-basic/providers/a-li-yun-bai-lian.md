# 阿裡雲百煉


{% hint style="warning" %}
此文件由 AI 從中文翻譯而來，尚未經過審閱。
{% endhint %}


1.  登入 [阿裡雲百煉](https://bailian.console.aliyun.com/?tab=model#/api-key)，如果沒有阿裡雲帳號需要先註冊。

2.  點擊右上角的 `建立我的 API-KEY` 按鈕。
    <figure><img src="../../../../assets/00b4cbef8a9bbea93bb4a9b6.webp" alt=""><figcaption>阿裡雲百煉建立API密鑰</figcaption></figure>
    
3.  在彈出視窗中選擇預設業務空間（或自定義），可選填描述資訊。
    <figure><img src="../../../../assets/5d1d415f32559b716089d8c1.webp" alt=""><figcaption>阿裡雲百煉建立API密鑰彈窗</figcaption></figure>
    
4.  點擊右下角的 `確定` 按鈕。

5.  在清單中找到新建立的項目，點擊右側的 `檢視` 按鈕。
    <figure><img src="../../../../assets/89f7665003a1634b74bedd69.webp" alt=""><figcaption>阿裡雲百煉檢視API密鑰</figcaption></figure>
    
6.  點擊 `複製` 按鈕。
    <figure><img src="../../../../assets/e6c807e270fe736e6731c677.webp" alt=""><figcaption>阿裡雲百煉複製API密鑰</figcaption></figure>

7.  前往 Cherry Studio，在 `設定` → `模型服務` → `阿裡雲百煉` 中找到 `API 密鑰` 欄位，貼上複製的 API 密鑰。
    <figure><img src="../../../../assets/9f14346e4b15514c0730d7a6.webp" alt=""><figcaption>阿裡雲百煉填入API密鑰</figcaption></figure>
    
8.  可依據 [模型服務](../../cherrystudio/preview/settings/providers.md) 說明調整設定，完成後即可使用。
{% hint style="info" %}
若模型清單中未顯示阿裡雲百煉的模型，請確認已依照 [模型服務](../../cherrystudio/preview/settings/providers.md) 說明新增模型並啟用此服務供應商。
{% endhint %}
