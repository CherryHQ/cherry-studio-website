# CherryAI（免費）

**CherryAI** 是 Cherry Studio 官方內建的 **免費模型** 入口——無需自行到第三方平台註冊、申請金鑰，開啟即可使用一批具有免費額度的模型，適合剛入門、想先將功能跑通的用戶。

### 在哪裡使用

開啟 `設定 → 模型服務`，在內建清單中找到 **CherryAI** 即可。它已隨軟體預設安裝，通常無需額外設定；點選 **取得模型清單** 即可查看目前可用的免費模型。

### 可用的免費模型

{% hint style="warning" %}
**免費模型陣容是動態變化的。** 具體有哪些型號、各自的額度與速率限制，均由 Cherry 伺服器端即時下發並會不定期調整，**一切以您在軟體內點選【取得模型清單】所看到的實際結果為準**。以下幾篇僅為部分常見免費模型的說明，不代表目前的完整清單。
{% endhint %}

* [DeepSeek V3.2](free-deepseek.md)
* [智譜 GLM-4.6V](free-glm46v.md)
* [智譜 GLM-4.5-Air](free-glm45air.md)
* [Qwen3-8B](free-qwen.md)

若需要更穩定、更強大的模型，可選擇 [CherryIN](../cherryin-1.md) 或其他 [服務供應商](../README.md)。
