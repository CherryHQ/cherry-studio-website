# 智譜 GLM-4.6V

Cherry Studio 使用者現在可以透過內建的 **CherryIN** 服務免費體驗 **智譜 GLM-4.6V**——由 Z.ai（智譜 AI）於 2025 年 12 月發布的視覺旗艦模型，採用 MoE 架構、128K 原生多模態上下文、原生多模態工具調用，是圖文理解與多模態 Agent 場景的首選。

***

## 什麼是 GLM-4.6V？

GLM-4.6V 是 Z.ai GLM-V 系列的最新一代視覺語言模型，原生支援文字 + 圖像統一建模，在 GLM-4.5V 的基礎上進一步擴展上下文與工具調用能力。

- 架構：Mixture-of-Experts（MoE）
- 總參數量：106B
- 激活參數量：約 12B
- 上下文長度：128K tokens
- 開源許可：MIT
- 發布時間：2025 年 12 月 8–9 日
- 視覺編碼器：支援多解析度圖像（最高 4K）

系列同時包含 **GLM-4.6V-Flash（9B）**，面向本地與低延遲場景，免費可商用。

## 延續 GLM-V 系列的多模態訓練體系

GLM-4.6V 沿用了 GLM-4.1V-Thinking / GLM-4.5V 的技術路線，並在視覺與 Agent 方向做了進一步強化：

1. **原生多模態建模**：文字與圖像聯合訓練，支援圖文混合輸入
2. **上下文擴展**：訓練上下文擴展至 128K tokens，單次可處理約 150 頁密集文件、200 頁簡報或 1 小時影片
3. **原生多模態工具調用**：工具可以直接接收與返回圖像，基於擴展的 MCP 協議以 URL 方式處理多模態產物
4. **強化學習增強**：沿用 GLM-V 系列的可擴展 RL 流程

## 如何在 Cherry Studio 中使用？

1. 開啟 Cherry Studio，進入 **設定 → 模型服務**。
2. 找到 **CherryIN** 服務供應商並開啟。
3. 在模型列表中選擇 **智譜 GLM-4.6V**。
4. 返回聊天介面，在頂部模型選擇處切換為 **GLM-4.6V**，即可在對話中直接上傳圖片進行圖文互動。
