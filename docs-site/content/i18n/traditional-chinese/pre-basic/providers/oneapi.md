* 建立新令牌（也可以直接使用 default 令牌↑）

<figure><img src="../../../../assets/b52ed2463a5c1ea3de393a3e.webp" alt="" width="563"><figcaption></figcaption></figure>

* 複製令牌

<figure><img src="../../../../assets/e485ab0dd933dd974e8648e3.webp" alt="" width="563"><figcaption></figcaption></figure>

* 開啟 CherryStudio 的服務商設定，點擊服務商列表最下方的 `添加`
* 輸入備註名稱，供應商選 OpenAI，點擊確定

* 填入剛剛複製的 key
* 回到取得 API Key 的頁面，在對應瀏覽器位址列複製根位址，例：

<figure><img src="../../../../assets/15e84703b85e9e47c3de65e4.webp" alt="" width="563"><figcaption><p><strong>只需要複製https://xxx.xxx.com即可，“/”及其之后的内容不需要</strong></p></figcaption></figure>

{% hint style="info" %}
* 當位址為 IP+埠號時填http://IP:端口即可，如：http://127.0.0.1:3000
* 嚴格區分 `http` 和 `https`，如果沒有開啟 SSL 就不要填 https
{% endhint %}

* 新增模型（點擊管理自動取得或手動輸入）開啟右上角開關即可使用。

{% hint style="success" %}
OneAPI 其他主題可能介面有所不同，但新增方法跟上述操作流程一致。
{% endhint %}
