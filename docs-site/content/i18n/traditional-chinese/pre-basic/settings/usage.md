# 用量統計

用量統計將您在 Cherry Studio 中的 **模型呼叫情況彙總成視覺化面板**：花了多少錢、用了多少 Token、發了多少請求、哪個模型用得最多，一目了然。它幫助您估算成本、發現異常消耗，也方便對不同模型的使用做取捨。

打開 `設定 → 用量統計`。頁面分 **概覽 / 探索 / 請求** 三塊，右上角可切換 **最近 30 天 / 最近 90 天 / 最近一年**，所有數據按所選區間統計。

### 概覽

頂部一組指標卡：

| 指標 | 含義 |
| --- | --- |
| **總成本** | 區間內的估算花費（按各模型公開定價折算，僅供參考） |
| **請求數** | 發起的請求總次數 |
| **總 Token 數** | 輸入 + 輸出的 Token 總量 |
| **快取命中率** | 命中提示詞快取的比例（命中的快取讀取 ÷ 可觀測輸入），越高越省錢 |
| **活躍天數 / 最長連續天數** | 有使用記錄的天數與連續使用的天數 |
| **高峰日** | 單日用量最高的日期及其 Token 量 |
| **用量最高模型** | 區間內消耗最多的模型 |
| **日均** | 平均每天的 Token 量與請求數 |

下方的 **每日活動** 熱力圖按天展示用量強度，可在 **Token / 成本** 兩個維度間切換，顏色越深代表當天用得越多。

### 探索 / 分析

切到 **探索** 可對用量做拆分分析：按 **分組**（供應商 / 模型 / API 金鑰 / 助手·Agent）拆開，選一個 **指標**，再用 **長條圖 / 折線圖 / 圓餅圖 / 分段** 等圖表查看分布與趨勢。

### 請求明細

**請求** 列出逐條請求記錄，便於定位是哪些請求產生了主要消耗。

> 想按某天看？在概覽的 **每日活動** 熱力圖上點選某一天，探索區（分析 + 請求）會 **下鑽** 到當天、標題變為「某日 明細」；點「清除日期篩選」返回。

{% hint style="info" %}
成本為 **估算值**：它按模型的公開定價折算，實際計費仍以各模型服務商的帳單為準。免費模型、本地模型不產生費用。
{% endhint %}
