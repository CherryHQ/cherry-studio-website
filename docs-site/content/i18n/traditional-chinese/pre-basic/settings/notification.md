# 通知

通知設定控制 **軟體在背景執行時如何提醒您**。當您切換到其他視窗工作時，Cherry Studio 可以在關鍵事件完成時彈出系統通知，避免您空等或錯過結果。

開啟 `設定 → 通知`，這裡有三個獨立開關：

<figure><img src="../../../../assets/8f6458a65b2bb09759c9622f.webp" alt=""><figcaption><p>通知設定面板</p></figcaption></figure>

| 開關 | 什麼時候提醒您 | 建議 |
| --- | --- | --- |
| **助手訊息** | AI 回覆 **成功**、且生成 **耗時超過 30 秒** 時才提醒（開關旁有 ⓘ 說明） | **開啟**。使用推理模型或生成長文時，不必盯著螢幕等待 |
| **備份** | 自動 / 手動備份完成時 | **開啟**。確認資資已安全存檔 |
| **知識庫** | 用於知識庫相關任務（如索引建置）完成後的提醒 | **開啟**。建庫通常較耗時，完成後收到提醒更省心 |

{% hint style="info" %}
這些通知走的是作業系統的通知中心。如果完全收不到提醒，請檢查系統層面是否允許 Cherry Studio 發送通知（macOS 的「通知」、Windows 的「通知和動作」）。
{% endhint %}
