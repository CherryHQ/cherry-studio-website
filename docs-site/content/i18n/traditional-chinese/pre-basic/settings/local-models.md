# 本地模型

本地模型是 Cherry Studio 內建、**下載後即可離線執行** 的小型模型：不透過任何服務商的 API，也不需要填寫 API Key。它們體積小、運行在您自己的電腦上，專門用來補足一些「不值得為它單獨配置一個雲端模型」的基本功能。

開啟 `設定 → 本機模型` 即可管理：

<figure><img src="../../../../assets/3ef4a2e692da5a39fccf7406.webp" alt=""><figcaption><p>本地模型：① 兩個內建本地模型——本地嵌入模型 + 本地 OCR 模型（圖中均為「已就緒」，可點右側刪除移除）</p></figcaption></figure>

目前內建兩類本地模型：

| 本地模型 | 底層 | 大小 | 用途 |
| ------------- | -------------------- | -------- | --------------------------------------------------------------- |
| **本地嵌入模型** | Qwen3 Embedding 0.6B | 約 614 MB | 將文字轉為向量，用於 [知識庫](../../knowledge-base/knowledge-base.md) 檢索、召回等場景 |
| **本地 OCR 模型** | PaddleOCR PP-OCRv6 | 約 140 MB | 離線識別圖片 / 掃描件中的文字，供 [OCR](ocr.md) 功能調用 |

### 下載與狀態

* 模型名稱旁會顯示狀態徽章：未下載的卡片 **底部** 有一條整寬「**下載**」按鈕，點擊開始下載；下載完成後徽章變為 **已就緒**。
* 已就緒的模型可點擊右側的 **刪除** 圖示移除，釋放磁碟空間；需要時可再次下載。（若嵌入模型仍被知識庫使用，刪除會被拒絕、權重保留。）
* 少數平台 / 架構不支援本地推理時，面板會顯示「**目前平台不支援本地模型**」，此時不提供下載。

下載時如果一個鏡像不可用，Cherry Studio 會自動嘗試其他下載來源。下載完成後，本地嵌入模型的推理過程在本機執行，不需要聯網。

{% hint style="warning" %}
如果頁面提示【模型檔案不完整，請重新下載修復。】，說明本地快取缺少必要檔案。刪除或重新下載該模型即可修復；不要手動拼接模型檔案。
{% endhint %}

{% hint style="info" %}
本地模型是 **可選項**。如果您已經在 [模型服務](providers.md) 裡配置了雲端嵌入模型，或用系統自帶 OCR 就夠用，可以不下載它們。
{% endhint %}

### 什麼時候用本地模型

* **沒有雲端嵌入模型 / 不想為知識庫單獨付費**：下載本地嵌入模型，知識庫就能在完全離線的情況下建立索引與檢索。
* **需要離線 OCR**：在沒有網路、或不希望圖片上傳到第三方的場景，下載本地 OCR 模型，配合 [OCR 設定](ocr.md) 選擇「本地 PaddleOCR」即可。
* **隱私優先**：所有計算都在本機完成，內容不會離開您的電腦。

{% hint style="warning" %}
本地模型是「夠用就好」的輕量方案。若對檢索精度或識別準確率要求很高，雲端的 [嵌入模型](../../knowledge-base/emb-models-info.md)、更強的 OCR 服務通常效果更好。
{% endhint %}
