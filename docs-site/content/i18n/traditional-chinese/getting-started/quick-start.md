# 快速開始

按照以下步驟，在幾分鐘內完成模型設定並傳送第一則訊息。

## 1. 安裝 Cherry Studio

從[官方下載頁](https://cherryai.com/download)取得符合系統與處理器的安裝檔。遇到權限或安裝問題時，請查看[下載與安裝](../cherry-studio/installation/README.md)。

## 2. 選擇模型服務

開啟【設定】→【模型服務】。如果還沒有 API Key，可先查看[模型服務快速參考](../pre-basic/providers/quick-reference.md)，依照地區、模型能力與隱私需求選擇服務商。

## 3. 新增並啟用模型

進入服務商設定，填入 API Key，點擊【取得模型清單】，新增一個對話模型並啟用服務商。詳細說明請見[模型服務設定](../pre-basic/settings/providers.md)。

## 4. 傳送第一則訊息

返回【對話】，建立或開啟助手，選擇剛新增的模型並傳送訊息。能正常收到回覆即代表基本設定完成。

## 接下來可以做什麼

* 瀏覽[功能總覽](../cherrystudio/preview/README.md)。
* 使用[工作 / Agent](../advanced-basic/agent.md)處理檔案與多步驟任務。
* 建立[知識庫](../knowledge-base/knowledge-base.md)，讓回答以自己的資料為依據。
