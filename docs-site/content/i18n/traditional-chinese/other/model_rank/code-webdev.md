## 如何解讀這張表

* **排名 / 排名區間**：Arena AI 根據對戰投票估算的相對名次；排名區間表示在置信範圍內的名次波動。
* **分數**：相對評分，適合比較同一時刻榜單中的模型。
* **票數 / 會話數**：樣本量參考；樣本較少時，排名通常更容易波動。
* **價格 $/百萬 Token**：輸入 / 輸出每百萬 Token 的參考價格。
* **上下文**：模型支援的最大上下文長度。

## 選模型時再確認三件事

1. Provider 是否實際提供這個模型，以及你的地區和帳戶是否可用；
2. API 價格、速率限制和上下文是否適合你的任務；
3. 用 3～5 個真實任務做小規模測試，不要只看總榜名次。
