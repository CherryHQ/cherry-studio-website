# ZhiPu

La série **GLM** de ZhiPu AI (y compris le modèle multimodal GLM-4V) offre une connexion directe en Chine et de bonnes performances en chinois. ZhiPu utilise une **extrémité compatible Anthropic** dans Cherry Studio, ce qui permet non seulement les conversations standard, mais aussi l'utilisation avec **Cherry Agent**.

## Obtenir une clé API

* Ouvrez la [page des clés API](https://open.bigmodel.cn/apikey/platform) de la plateforme ouverte de ZhiPu (inscription/connexion requise)
* Créez et copiez une clé API

## Configuration dans Cherry Studio

1. Ouvrez les [paramètres de service de modèle](../settings/providers.md) de Cherry Studio et localisez **ZhiPu** dans la liste intégrée
2. Saisissez la clé API obtenue
3. Cliquez sur **Obtenir la liste des modèles**, ajoutez les modèles GLM souhaités et activez l'interrupteur du fournisseur en haut à droite pour commencer à l'utiliser

{% hint style="info" %}
Les modèles ZhiPu intègrent la capacité de **recherche web**, selon la prise en charge par le modèle. Consultez la [documentation officielle de ZhiPu](https://docs.bigmodel.cn/) pour plus de détails sur la plateforme.
{% endhint %}
