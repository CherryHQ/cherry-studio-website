# Mistral

Mistral AI est un représentant des grands modèles open source européens, offrant des séries telles que Mistral / Codestral, alliant performance et ouverture.

## Obtenir une clé API

* Ouvrez la [page des clés API](https://console.mistral.ai/api-keys/) de la console Mistral (inscription/connexion requise)
* Créez et copiez une clé API

## Configuration dans Cherry Studio

1. Ouvrez les [paramètres de service de modèle](../settings/providers.md) de Cherry Studio et trouvez **Mistral** dans la liste intégrée
2. Saisissez la clé API obtenue
3. Cliquez sur **Obtenir la liste des modèles**, ajoutez les modèles souhaités et activez l'interrupteur du fournisseur en haut à droite pour commencer à l'utiliser

{% hint style="info" %}
L'accès à Mistral depuis la Chine nécessite généralement de résoudre vous-même les problèmes de proxy réseau. Pour plus d'informations, consultez la [documentation officielle de Mistral](https://docs.mistral.ai).
{% endhint %}
