# Perplexity

La série **Sonar** de Perplexity met en avant les **conversations enrichies par la recherche** — les réponses intègrent des recherches web en temps réel, ce qui convient aux scénarios nécessitant des informations à jour.

## Obtenir une clé API

* Ouvrez la [page de configuration de l'API](https://www.perplexity.ai/settings/api) de Perplexity (inscription/connexion requise)
* Générez et copiez une clé API

## Configuration dans Cherry Studio

1. Ouvrez les [paramètres de service de modèle](../settings/providers.md) de Cherry Studio et localisez **Perplexity** dans la liste intégrée
2. Saisissez la clé API obtenue
3. Cliquez sur **Obtenir la liste des modèles**, ajoutez des modèles tels que Sonar, puis activez l'interrupteur du fournisseur en haut à droite pour commencer à l'utiliser

{% hint style="info" %}
Les modèles Perplexity disposent nativement de la capacité de recherche web, sans configuration supplémentaire du mode en ligne requise. L'accès depuis la Chine continentale nécessite généralement de résoudre soi-même les problèmes de proxy réseau. Pour plus d'informations, consultez la [documentation officielle de Perplexity](https://docs.perplexity.ai/home).
{% endhint %}
