# CherryAI (gratuit)

**CherryAI** est l'entrée officielle intégrée de Cherry Studio pour les **modèles gratuits** — pas besoin de vous inscrire sur une plateforme tierce ni de demander une clé API : vous pouvez immédiatement utiliser les modèles disposant d'un quota gratuit, idéal pour les débutants souhaitant d'abord tester les fonctionnalités.

### Où l'utiliser

Ouvrez `Paramètres → Services de modèles` et repérez **CherryAI** dans la liste intégrée. Il est préinstallé avec le logiciel et ne nécessite généralement aucune configuration supplémentaire ; cliquez sur **Obtenir la liste des modèles** pour afficher les modèles gratuits actuellement disponibles.

### Modèles gratuits disponibles

{% hint style="warning" %}
**La gamme de modèles gratuits est dynamique.** Les modèles spécifiques, leurs quotas et leurs limites de débit sont fournis en temps réel par le serveur Cherry et peuvent être ajustés à tout moment. **Faites uniquement foi des résultats réels affichés lorsque vous cliquez sur [Obtenir la liste des modèles] dans le logiciel.** Les sections ci-dessous ne décrivent que certains modèles gratuits courants et ne constituent pas la liste complète actuelle.
{% endhint %}

* [DeepSeek V3.2](free-deepseek.md)
* [Zhipu GLM-4.6V](free-glm46v.md)
* [Zhipu GLM-4.5-Air](free-glm45air.md)
* [Qwen3-8B](free-qwen.md)

Si vous avez besoin de modèles plus stables et plus performants, vous pouvez choisir [CherryIN](../cherryin-1.md) ou d'autres [fournisseurs](../README.md).
