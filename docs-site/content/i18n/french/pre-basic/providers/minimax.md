# MiniMax

MiniMax est l'un des principaux fournisseurs de grands modèles en Chine, reconnu pour ses **capacités multimodales** remarquables (génération de texte, audio, images et vidéos).

## Obtenir une clé API

* Inscrivez-vous sur la [plateforme ouverte MiniMax](https://platform.minimaxi.com/)
* Après la vérification d'identité, accédez à `Gestion du compte → Clés API` pour créer votre clé API

## Configuration dans Cherry Studio

* Ouvrez `Paramètres → Services de modèles`, trouvez le fournisseur **MiniMax** et accédez à sa page de détails
* Saisissez votre clé API
* Laissez l'adresse API par défaut
* Cliquez sur **Obtenir la liste des modèles**

## Utilisations recommandées

| Modèle | Cas d'usage |
|---|---|
| `abab6.5s-chat` / `MiniMax-Text-01` | Conversations quotidiennes |
| `abab6.5-chat` | Longs textes de haute qualité |

{% hint style="info" %}
* L'accès à MiniMax est simple en Chine, avec un quota gratuit pour les nouveaux utilisateurs
* Les utilisateurs internationaux doivent utiliser **MiniMax Global** (entrée distincte dans la liste des fournisseurs de Cherry Studio)
{% endhint %}
