# Démarrage rapide

Suivez ces étapes pour configurer un modèle et envoyer votre premier message en quelques minutes.

## 1. Installer Cherry Studio

Téléchargez le paquet correspondant à votre système et à votre processeur depuis la [page officielle](https://cherryai.com/download). Consultez [Téléchargement et installation](../cherry-studio/installation/README.md) en cas de problème.

## 2. Choisir un fournisseur de modèles

Ouvrez **Paramètres → Services de modèles**. Si vous n’avez pas encore de clé API, consultez la [référence rapide des fournisseurs](../pre-basic/providers/quick-reference.md) pour choisir selon votre région, les capacités du modèle et vos besoins de confidentialité.

## 3. Ajouter et activer un modèle

Ouvrez les paramètres du fournisseur, saisissez la clé API, récupérez la liste des modèles, ajoutez un modèle de dialogue et activez le fournisseur. Consultez [Paramètres du service de modèles](../pre-basic/settings/providers.md) pour plus de détails.

## 4. Envoyer votre premier message

Revenez dans **Dialogue**, ouvrez ou créez un assistant, choisissez le modèle ajouté et envoyez un message. La réception d’une réponse confirme que la configuration fonctionne.
