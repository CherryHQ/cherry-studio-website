# Espace de travail de recherche multi-fenêtres

Les chercheurs doivent conserver leurs ressources et leurs comparaisons de modèles tout en permettant à l'Agent de trier les fichiers et de générer des rapports. En déplaçant les tâches de recherche dans des fenêtres indépendantes, la fenêtre principale peut continuer à consulter les ressources sans interrompre l'état de l'Agent.

## Disposition recommandée

* Fenêtre principale : conserver les conversations de ressources et la recherche globale ;
* Fenêtre indépendante : ouvrir la tâche de l'Agent de recherche et la maintenir au premier plan ;
* Deuxième onglet : ouvrir la base de connaissances ou les notes pour vérifier les ressources d'origine à tout moment.

## Processus opérationnel

{% stepper %}
{% step %}
### 1. Comparer les questions de recherche dans [Conversation]

Utilisez la comparaison multi-modèles pour identifier les consensus, les conflits et les points à vérifier, sans hâter la génération du rapport final.
{% endstep %}

{% step %}
### 2. Préparer le répertoire pour l'Agent de recherche

Séparez les ressources brutes du répertoire de sortie, liez les bases de connaissances pertinentes et exigez la conservation des liens vers les informations externes.
{% endstep %}

{% step %}
### 3. Déplacer la tâche dans une fenêtre indépendante

Cliquez avec le bouton droit sur l'onglet de l'Agent et sélectionnez [Ouvrir dans une nouvelle fenêtre]. Utilisez la fonction de maintien au premier plan si nécessaire. La fenêtre principale continue de consulter les ressources sans interrompre l'état de l'Agent.
{% endstep %}

{% step %}
### 4. Compiler et vérifier

Vérifiez le rapport dans [Fichiers] à droite de l'Agent et ouvrez la conversation d'origine dans la fenêtre principale pour vérifier les conflits. Ne conservez finalement que les conclusions qui peuvent être retracées jusqu'aux ressources ou aux sources.
{% endstep %}
{% endstepper %}

## Combinaisons recommandées et critères d'achèvement

| Fenêtre | Contenu suggéré |
| ----- | --------------------------------- |
| Fenêtre principale | Conversations de ressources, recherche globale et notes |
| Fenêtre indépendante | Une tâche d'Agent en cours d'exécution |
| Onglet épinglé | Base de connaissances ou tâche la plus utilisée pour le projet |
| Critère d'achèvement | Les sources des ressources, l'état de la tâche et les notes finales doivent être mutuellement cohérents ; après la fin de la tâche, la fenêtre doit être rétractée ou fermée |

Convient aux recherches nécessitant une observation continue de tâches longues. Il n'est pas recommandé d'ouvrir de nombreuses fenêtres simultanément simplement pour « paraître plus professionnel ».

{% hint style="info" %}
Les fenêtres multiples ne modifient que l'emplacement d'affichage, elles ne créent pas de nouveaux comptes ou d'espaces isolés. Les données et les autorisations de la même tâche restent identiques.
{% endhint %}
