# Kit d'images de marque

L'équipe de contenu doit créer des images en format paysage, carré et portrait pour la même campagne, tout en maintenant la cohérence du sujet, de la palette de couleurs et des règles de marque. Il est plus facile de garantir l'uniformité en définissant d'abord la vision principale, puis en adaptant les dimensions, plutôt que de générer chaque image à partir de zéro.

## Préparation des ressources

* Thème du contenu et plateformes de diffusion ;
* Couleurs de marque autorisées et images de référence ;
* Textes, logos et éléments interdits ;
* Trois ratios d'image et exigences de marges.

## Processus

{% stepper %}
{% step %}
### 1. Faire définir la direction visuelle par l'Agent

Placez l'article ou la description de la campagne dans le répertoire de travail. Demandez à l'Agent de ne fournir que des suggestions sur le sujet, la scène, la palette de couleurs, la prise de vue et les marges, sans générer d'image pour l'instant.
{% endstep %}

{% step %}
### 2. Valider la vision principale dans 【Dessin】

Sélectionnez le modèle et le gabarit appropriés, puis générez d'abord un petit échantillon en format paysage. Vérifiez l'apparence du produit, les détails des personnages et les risques liés à la marque.
{% endstep %}

{% step %}
### 3. Adapter les dimensions à partir d'une image de référence

Une fois la vision principale sélectionnée, utilisez-la comme référence pour générer séparément les versions carrée et portrait. Précisez à chaque fois les éléments à conserver et la composition ajustable.
{% endstep %}

{% step %}
### 4. Corrections locales et amélioration

Utilisez l'édition ou le masque uniquement sur les zones problématiques, puis améliorez la version finale. Incluez l'usage et le ratio dans le nom de fichier pour éviter toute confusion.
{% endstep %}
{% endstepper %}

## Vérification des résultats

* La palette de couleurs et le sujet sont cohérents sur les trois images ;
* Aucune fausse texte généré par le modèle ;
* Aucun logo de marque, personnage ou information sensible inattendu ;
* Les dimensions répondent aux exigences de la plateforme de publication ;
* L'utilisation des images de référence est autorisée.

## Combinaisons recommandées et critères de validation

| Élément | Pratique recommandée |
| ---- | ------------------------------- |
| Modèle de dessin | Générez d'abord une image d'échantillon via l'Agent pour valider la connexion, puis enregistrez le gabarit de dessin |
| Ressources d'entrée | Placez les couleurs de marque, les polices, les dimensions, les images de référence et les éléments interdits dans le même répertoire de projet |
| Méthode en série | Validez d'abord une image, puis générez les images de la même série |
| Critères de validation | Dimensions correctes, texte lisible, éléments de marque cohérents, aucun logo superflu, image de référence d'origine conservée |

Convient aux couvertures d'articles, aux images pour les réseaux sociaux et aux ressources de campagne. Pour les affiches finales nécessitant une mise en page précise, il est recommandé de faire une dernière relecture dans un outil de design.

{% hint style="info" %}
Si vous souhaitez générer des images directement dans la conversation avec l'Agent, configurez d'abord le 【Modèle de dessin】 global et activez l'outil 【Générer une image】 de l'Agent. Pour des éditions détaillées, il est toujours recommandé de revenir à la page 【Dessin】.
{% endhint %}
