# Notes, base de connaissances et Agent


<details>

<summary>Les modifications apportées à une note ajoutée à la base de connaissances sont-elles synchronisées immédiatement ?</summary>

Vérifiez d'abord l'état des données dans la base de connaissances. Si le contenu a changé mais que les résultats de recherche ne sont pas mis à jour, re-traitez le document concerné et effectuez à nouveau un test de récupération.

</details>
