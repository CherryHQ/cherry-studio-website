# Espace de travail efficace

La fenêtre principale de Cherry Studio est composée d'une barre latérale, d'onglets et d'une zone de contenu. Les sujets de conversation et les tâches Agent peuvent être ouverts simultanément dans plusieurs onglets ou séparés dans des fenêtres indépendantes ; la barre d'outils de la zone de saisie peut être ajustée selon vos habitudes d'utilisation.

### Scénarios adaptés aux fenêtres indépendantes

* Conserver une conversation de ressources tout en exécutant une tâche Agent ;
* Épingler une tâche de surveillance à long terme pour éviter qu'elle ne soit masquée par d'autres fenêtres ;
* Placer les conversations, les fichiers ou les tâches sur des moniteurs distincts ;
* Présenter ou partager une tâche spécifique sans exposer les autres onglets de la fenêtre principale.

### Fonctionnalités de l'espace de travail

| Fonctionnalité | Accès | Rôle |
| ------ | -------------------- | -------------- |
| Nouvel onglet | Menu contextuel du sujet ou de la tâche → [Ouvrir dans un nouvel onglet] | Conserver plusieurs contextes côte à côte dans la fenêtre principale |
| Fenêtre indépendante | Clic droit sur le sujet, la tâche ou l'onglet → [Ouvrir dans une nouvelle fenêtre] | Déplacer le contenu actuel dans une nouvelle fenêtre |
| Épingler l'onglet | Clic droit sur l'onglet → [Épingler l'onglet] | Fixer les pages fréquemment utilisées |
| Épingler la fenêtre | [Épingler la fenêtre] en haut de la fenêtre indépendante | Rendre la tâche toujours visible |
| Retour à la fenêtre principale | [Retour à la fenêtre principale] en haut de la fenêtre indépendante | Rattacher l'onglet à la fenêtre principale |
| Barre d'outils personnalisée | [+] dans la zone de saisie → [Personnaliser la barre d'outils] | Ajuster la position des outils de saisie fréquents |

Sélectionnez [Ouvrir dans une nouvelle fenêtre] dans le menu de l'onglet de l'image ci-dessus pour déplacer le contenu actuel dans une fenêtre indépendante.

### Disposition recommandée

Pour la rédaction professionnelle, conservez la conversation de ressources dans la fenêtre principale et déplacez l'Agent « Rédaction » sur l'écran de droite ; pour le développement, épinglez la tâche Agent et conservez les fichiers et documents dans la fenêtre principale ; utilisez une fenêtre indépendante pour les tâches de surveillance prolongée, mais ne placez pas les tâches nécessitant des confirmations de permissions fréquentes dans une position invisible.

{% hint style="info" %}
Une fenêtre indépendante appartient toujours au même environnement de données Cherry Studio. Ce n'est pas un nouveau compte ou un espace de confidentialité distinct ; le contenu du même sujet ou de la même tâche reste synchronisé et enregistré.
{% endhint %}
