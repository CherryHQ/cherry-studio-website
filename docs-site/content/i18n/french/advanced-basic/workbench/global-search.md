# Recherche globale

La recherche globale permet de rechercher des messages, des conversations, des tâches, des assistants, des Agents et des bases de connaissances depuis un seul point d'accès. Elle est idéale lorsque vous vous souvenez du contenu, mais pas de son emplacement.

## Mode d'emploi

{% stepper %}
{% step %}
### 1. Cliquez sur le bouton de recherche en haut de la fenêtre

Vous pouvez également consulter ou modifier le raccourci clavier correspondant dans [Paramètres] → [Raccourcis clavier].
{% endstep %}

{% step %}
### 2. Saisissez des mots-clés distinctifs

Privilégiez les noms de projet, les noms de personnes, les sujets de fichiers ou les phrases issues des conclusions. La saisie de termes génériques comme « paramètres » ou « rapport » produit généralement trop de résultats.
{% endstep %}

{% step %}
### 3. Restreignez le périmètre de la recherche

Basculez sur [Messages] ou utilisez les filtres [Conversations], [Tâches], [Assistants], [Agents] et [Bases de connaissances], puis affinez par date de mise à jour.
{% endstep %}

{% step %}
### 4. Ouvrez le résultat pour poursuivre le travail

La recherche vous ramène au contenu correspondant. Vérifiez le type avant d'ouvrir pour éviter de confondre un assistant et une tâche d'Agent portant le même nom.
{% endstep %}
{% endstepper %}

### Cas d'usage : retrouver une conclusion client du mois dernier

Recherchez le nom du projet client, puis restreignez le type à [Messages] et limitez la période de mise à jour. Une fois la conclusion trouvée, ouvrez la conversation d'origine pour vérifier s'il y a eu des révisions ultérieures. Si vous devez réutiliser cette conclusion dans une nouvelle tâche, copiez le résumé déjà validé plutôt que de vous fier aux fragments épars de la mémoire de la nouvelle conversation.

<details>

<summary>Pourquoi la recherche ne trouve-t-elle pas le contenu des fichiers sur le disque ?</summary>

La recherche globale cible principalement le contenu déjà enregistré dans Cherry Studio. Les fichiers sur disque doivent d'abord être intégrés au flux de travail de l'Agent, à la base de connaissances ou aux notes pour être accessibles via les points d'entrée correspondants.

</details>
