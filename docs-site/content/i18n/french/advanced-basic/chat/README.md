# Conversation avancée

【Conversation】est idéal pour organiser ses idées en discutant. Outre les questions-réponses avec un seul modèle, vous pouvez comparer plusieurs modèles côte à côte, créer des branches à partir de n'importe quel message, gérer le contexte des conversations longues et réutiliser les fichiers, images, code et citations des réponses comme des artefacts.

{% hint style="info" %}
Si la tâche nécessite des lectures/écritures continues de fichiers locaux, l'appel de plusieurs outils ou une exécution prolongée, utilisez plutôt l'Agent dans 【Travail】. La Conversation est plus adaptée à la discussion, à la comparaison et à la finalisation, tandis que l'Agent est plus adapté à l'exécution.
{% endhint %}

## Choisir les fonctionnalités selon l'objectif

| Objectif | Pratique recommandée |
| ------------- | --------------------- |
| Comparer les points de vue de différents modèles | Sélectionnez plusieurs modèles dans la zone de saisie puis envoyez la même question |
| Conserver la discussion originale et explorer une autre piste | Créez une branche à partir d'un message clé |
| Poursuivre une discussion très longue | Consultez l'utilisation du contexte, résumez si nécessaire puis ouvrez un nouveau sujet |
| Envoyer la question suivante plus tard | Utilisez la file d'attente des messages, sans interrompre la réponse en cours |
| Continuer à traiter les fichiers ou le code de la réponse | Ouvrez l'aperçu des artefacts, puis téléchargez, copiez ou poursuivez dans une nouvelle tâche |

## Ordre recommandé

{% stepper %}
{% step %}
### 1. D'abord, formuler la question de manière complète

Précisez l'objectif, les matériaux, les contraintes et le format de sortie souhaité. Plusieurs modèles n'amplifient que les différences de la question d'origine et ne comblent pas automatiquement les informations manquantes.
{% endstep %}

{% step %}
### 2. Ensuite, décider si une comparaison est nécessaire

Sélectionnez plusieurs modèles uniquement si vous avez besoin de perspectives différentes. Pour les questions-réponses quotidiennes, maintenez un seul modèle pour une interface plus claire et une meilleure maîtrise de l'utilisation.
{% endstep %}

{% step %}
### 3. Consolider les conclusions utiles

Enregistrez les ressources réutilisables dans les notes ou la base de connaissances ; confiez les travaux nécessitant une exécution continue à l'Agent, en joignant les conclusions déjà validées.
{% endstep %}
{% endstepper %}
