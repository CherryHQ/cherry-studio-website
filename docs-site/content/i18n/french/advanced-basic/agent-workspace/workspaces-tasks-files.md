# Répertoire de travail, tâches et fichiers


<details>

<summary>Quels fichiers ne peuvent pas être modifiés directement ?</summary>

Les fichiers binaires, les textes non UTF-8 et les fichiers de grande taille ne proposent que l’aperçu ou l’ouverture dans une application externe. Ils peuvent toujours être traités par les outils de l’Agent, mais ne sont pas nécessairement modifiables dans l’éditeur intégré.

</details>
