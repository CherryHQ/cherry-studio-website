# Tutoriel de configuration de SiYuan Note

Permet d'exporter des sujets et messages vers SiYuan Note.

## Étape 1

Ouvrez SiYuan Note et créez un carnet

<figure><img src="../../../assets/dd6bc4a7ef5d1aebb8b2d312.webp" alt=""><figcaption><p>Cliquez pour créer un nouveau carnet</p></figcaption></figure>

## Étape 2

Ouvrez les paramètres du carnet et copiez l'`ID du carnet`

<figure><img src="../../../assets/722fb2171c5a8f812383d0f8.webp" alt="" width="400"><figcaption><p>Ouvrir les paramètres du carnet</p></figcaption></figure>

<figure><img src="../../../assets/c312b9bc99f830ab1b41ac10.webp" alt=""><figcaption><p>Cliquez sur le bouton Copier l'ID du carnet</p></figcaption></figure>

## Étape 3

Collez l'ID du carnet dans les paramètres de Cherry Studio

<figure><img src="../../../assets/716b071bfad08d4a1da43518.webp" alt=""><figcaption><p>Entrez l'ID du carnet dans les paramètres des données</p></figcaption></figure>

## Étape 4

Entrez l'adresse de SiYuan Note

* **Local**\
  Généralement `http://127.0.0.1:6806`
* **Auto-hébergé**\
  Votre domaine `http://note.domain.com`

<figure><img src="../../../assets/81ebbe7310606969011d3c4c.webp" alt=""><figcaption><p>Saisissez votre adresse SiYuan Note</p></figcaption></figure>

## Étape 5

Copiez le `Jeton d'API` de SiYuan Note

<figure><img src="../../../assets/7279410a41255ae1b9eb7d42.webp" alt=""><figcaption><p>Copier le jeton SiYuan Note</p></figcaption></figure>

Collez-le dans les paramètres de Cherry Studio et vérifiez

<figure><img src="../../../assets/f2404dad4a63a2ef4c33556f.webp" alt=""><figcaption><p>Entrez l'ID de base de données et cliquez sur Vérifier</p></figcaption></figure>

## Étape 6

Félicitations, la configuration de SiYuan Note est terminée ✅ Vous pouvez maintenant exporter le contenu de Cherry Studio vers votre SiYuan Note

<figure><img src="../../../assets/bdf29a62e99f73745fadd772.webp" alt=""><figcaption><p>Exporter vers SiYuan Note</p></figcaption></figure>

<figure><img src="../../../assets/7e5e081609aca42b45bca666.webp" alt=""><figcaption><p>Voir le résultat de l'exportation</p></figcaption></figure>
