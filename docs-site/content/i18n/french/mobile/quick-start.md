# Démarrage rapide

Demandez d'abord à un modèle de répondre à un message simple, puis ajoutez d'autres fonctionnalités si nécessaire.

## 1. Choisissez comment configurer

* **Vous utilisez déjà Cherry Studio Desktop ?** [Importer la configuration depuis votre ordinateur](desktop-sync.md) et choisissez un modèle. Une fois l'importation réussie, passez à l'étape 4 ci-dessous.
* **Configuration sur mobile :** choisissez un fournisseur lors de l'intégration, ou ouvrez **Paramètres → Service modèle → Ajouter un fournisseur** et suivez les étapes 2 à 3.

Les fournisseurs intégrés incluent des paramètres de connexion courants. Utilisez un fournisseur personnalisé si votre plateforme est absente.

## 2. Entrez et enregistrez une clé

Saisissez le **Clé API** de la plateforme, l'identifiant utilisé pour appeler les modèles. Les fournisseurs personnalisés ont également besoin de l'adresse de base de la plateforme et du format API.

Enregistrez ou poursuivez l'intégration. Un mot de passe de connexion n'est pas une clé API, et l'abonnement au chat grand public d'une plateforme peut ne pas inclure de crédits API ; vérifiez votre compte là-bas.

## 3. Ajoutez un modèle et activez le fournisseur

Récupérez la liste des modèles et sélectionnez un modèle de texte. Si la découverte échoue, copiez l'ID de modèle exact depuis la plateforme et ajoutez-le manuellement.

Le téléchargement initial des informations sur les modèles peut prendre du temps. Vérifiez que le fournisseur est activé, ouvrez les réglages de l’agent depuis le haut de la conversation et sélectionnez un modèle activé. Consultez [fournisseurs et modèles](providers-and-models.md) pour plus de détails.

## 4. Envoyez un premier message

Utilisez l'agent Cherry initial, sélectionnez votre modèle et demandez « En trois phrases, décrivez ce que vous pouvez m'aider à faire ». Une réponse confirme que la configuration de base fonctionne.

Un agent est une configuration réutilisable contenant un nom, des instructions et un modèle. Vous pouvez démarrer des conversations distinctes avec le même agent pour différents sujets.

Si rien n'arrive, essayez un court message sans pièces jointes et suivez [dépannage](troubleshooting.md).
