# Agents et outils

Un agent est une configuration de travail réutilisable qui rassemble des instructions de rôle, un modèle et les outils disponibles. C'est utile pour les tâches récurrentes : aide à la rédaction, organisation d'informations ou gestion d'un agenda.

## Créer un agent

1. Créez un agent et définissez son nom, son avatar et ses instructions de tâche.
2. Choisissez un modèle adapté à la tâche.
3. N'activez la recherche web, la génération d'images ou les outils système que si c'est nécessaire.
4. Vérifiez le mode d'approbation des outils, puis enregistrez l'agent.

Les instructions doivent énoncer clairement l'objectif, le format de sortie et les contraintes. Ne placez jamais de clés API, de mots de passe ou d'autres identifiants durables dans les instructions d'un agent.

## Outils et autorisations système

Les outils système comme l'agenda et les rappels demandent un accès au système d'exploitation lors de leur première utilisation. N'accordez l'accès qu'aux fonctionnalités dont l'agent a réellement besoin. Vous pourrez consulter ou révoquer ces autorisations plus tard dans les réglages Android ou iOS.

Les outils peuvent lire des données ou effectuer des actions externes. Conservez une confirmation manuelle pour les événements d'agenda, les fichiers ou les contenus sortants importants, et vérifiez le résultat après exécution.
