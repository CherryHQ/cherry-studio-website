# Téléchargement et installation

Utilisez toujours [l'option mobile de la page de téléchargement officielle](https://cherryai.com/download?platform=mobile). N'installez pas de paquets provenant de sources inconnues.

## Android

L'APK actuel est fourni pour les appareils ARM64.

1. Sélectionnez **Télécharger l'APK** sur la page de téléchargement.
2. Ouvrez l'APK depuis les téléchargements de votre navigateur ou votre gestionnaire de fichiers.
3. Si Android bloque l'installation, suivez l'invite du système pour autoriser temporairement votre navigateur ou votre gestionnaire de fichiers à installer des applications inconnues.
4. Revenez à l'installateur et terminez l'installation.

Vous pouvez révoquer l'autorisation « installer des applications inconnues » après l'installation. À chaque nouvelle version, téléchargez le nouvel APK depuis la page officielle et installez-le par-dessus l'application existante. Consultez les notes de version avant de mettre à jour.

## iPhone et iPad

Les versions iOS et iPadOS sont actuellement disponibles via TestFlight.

1. Installez **TestFlight** d'Apple depuis l'App Store.
2. Sélectionnez **Rejoindre TestFlight** sur la page de téléchargement mobile.
3. Acceptez l'invitation dans TestFlight et sélectionnez **Installer**.

Le nombre de places de test et l'expiration des builds sont gérés par le système bêta d'Apple. Si l'invitation est temporairement indisponible, réessayez plus tard ou suivez les canaux de publication officiels.

## Après l'installation

Poursuivez avec le [démarrage rapide](quick-start.md) pour ajouter un service de modèles et envoyer votre premier message.
