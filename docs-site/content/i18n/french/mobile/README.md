# Cherry Studio Mobile

Cherry Studio Mobile est un client IA conçu pour Android, iPhone et iPad. Connectez vos propres services modèles pour discuter, configurer des agents et générer des images à partir d'un appareil mobile.

## Statut actuel

L'application mobile est actuellement en **bêta** :

* Android est distribué en tant qu'APK officiel.
* Les versions iPhone et iPad sont distribuées via Apple TestFlight.
* Les écrans et les fonctionnalités peuvent changer rapidement. Suivez le comportement de la version installée sur votre appareil.

Ouvrez l'[option mobile sur la page de téléchargement](https://cherryai.com/download?platform=mobile) ou lisez d'abord le [Téléchargement et installation](installation.md).
