# Разработка и диагностика

Этот набор функций предназначен для пользователей, которым необходимо управлять CLI для программирования, вызывать модели из других локальных программ или устранять проблемы с запросами. Для повседневного общения и работы с контентом режим разработчика не требуется.

### Два входа

| Вход | Назначение | Что проверить перед использованием |
| ----------------- | ---------------------------- | -------------- |
| Пусковая панель [Партнёр по кодированию] | Установка, настройка и запуск популярных CLI для программирования | Источник установки, подключение модели и рабочая директория |
| [Настройки] → [API-шлюз] | Предоставление совместимого API локальным программам, а также зависимость для работы Agent | Состояние, порт и безопасность ключей |
| [Настройки] → [Общие] → [Режим разработчика] | Просмотр цепочки вызовов, локализация ошибок моделей и инструментов | В журналах могут содержаться конфиденциальные данные |

{% hint style="warning" %}
Ключи API-шлюза и содержимое запросов в цепочке вызовов могут содержать конфиденциальную информацию. В скриншотах, Issue и групповых чатах делитесь только необходимыми фрагментами с замаскированными данными.
{% endhint %}
