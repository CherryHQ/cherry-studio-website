# Многострочные окна и вкладки

Диалоги, задачи Agent и обычные вкладки можно вынести из текущего окна. Это действие не дублирует содержимое, а лишь изменяет место отображения.

## Открытие из диалога или задачи

{% stepper %}
{% step %}
### 1. Найдите целевой диалог или задачу Agent

Щелкните правой кнопкой мыши нужный элемент в списке диалогов слева или в списке задач Agent.
{% endstep %}

{% step %}
### 2. Выберите способ открытия

Выбор «Открыть в новой вкладке» оставляет элемент в главном окне; выбор «Открыть в новом окне» сразу создает отдельное окно, при этом текущий список остается доступным.
{% endstep %}

{% step %}
### 3. Управление отдельным окном

Нажмите «Закрепить окно», чтобы оно оставалось поверх других окон; нажмите «Вернуть в главное окно», чтобы переместить текущее содержимое обратно в главное окно и закрыть отдельное окно.
{% endstep %}
{% endstepper %}

## Вынос из вкладки

Щелкните правой кнопкой мыши вкладку в верхней части главного окна и выберите «Открыть в новом окне». Это действие перемещает вкладку в отдельное окно и удаляет ее из панели вкладок главного окна.

## Основные операции с вкладками

* «Переместить в самый левый угол»: перемещает текущую вкладку в начало списка обычных вкладок;
* «Закрепить вкладку»: сворачивает вкладку в закреплённую иконку и сохраняет её слева на панели вкладок;
* «Закрыть другие вкладки»: оставляет только текущую страницу;
* «Закрыть вкладки справа»: закрывает группу временных страниц;
* Перетаскивание вкладок: изменение порядка вкладок одного типа.

## Сценарий использования: просмотр материалов и мониторинг задач

Оставьте диалог с материалами в главном окне, вынесите выполняющуюся задачу Agent через «Открыть в новом окне» и закрепите окно задачи. Материалы остаются в исходном диалоге, а задача не перезапускается из-за выноса в отдельное окно. После завершения задачи нажмите «Вернуть в главное окно», чтобы избежать накопления отдельных окон.

### Рекомендуемая компоновка

Главное окно используется для материалов и поиска, в отдельном окне остаётся только одна задача, требующая постоянного наблюдения; для часто используемых вкладок одного проекта используйте «Закрепить вкладку», а временные страницы закрывайте сразу после завершения.

### Критерии завершения

Материалы можно вернуть в исходный диалог, задача Agent не перезапускалась из-за выноса в отдельное окно, а после завершения задачи окно возвращено в главное или отдельное окно закрыто.

{% hint style="warning" %}
«Закрепить окно» изменяет только уровень отображения, не повышает приоритет задачи и не предотвращает системный сон. Для непрерывной работы в фоновом режиме проверьте статус Agent и настройки электропитания системы.
{% endhint %}

<details>

<summary>Почему в отдельном окне нельзя открывать скрытые внутренние вкладки? </summary>

Отдельное окно работает с одним содержимым. Чтобы открыть другие диалоги или задачи, используйте контекстное меню для создания нового окна или сначала нажмите «Вернуть в главное окно», а затем управляйте вкладками.

</details>
