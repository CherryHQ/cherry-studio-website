# Скриншоты, разметка и OCR

Cherry Studio позволяет захватывать область экрана с помощью глобальной горячей клавиши, добавлять прямоугольники, стрелки, рисовать кистью, вставлять текст или применять эффект пикселизации, а затем копировать или сохранять результат. При включенном локальном OCR можно также выделять и копировать текст непосредственно со скриншота.

### Цель и предварительные условия

* Путь: [Настройки] → [Скриншоты];
* При первом использовании на macOS необходимо разрешить запись экрана; после предоставления разрешения перезапустите приложение в соответствии с подсказкой на странице;
* Для OCR необходимо скачать модель распознавания текста в разделе [Настройки] → [Локальные модели];
* Функция скриншотов по умолчанию отключена, автоматическое распознавание текста включено, но OCR не выполняется, если модель не готова.

### Термины

| Термин | Значение |
| ----- | ------------------------------- |
| Глобальная горячая клавиша | Горячая клавиша, срабатывающая даже если фокус не находится в Cherry Studio |
| OCR | Распознавание текста на изображении в виде текста, который можно выделить и скопировать |
| Пикселизация | Маскировка учетных данных, путей, ключей или других конфиденциальных областей на скриншоте |

### Путь к действию

[Настройки] → [Скриншоты] → включить [Включить скриншоты] → нажать горячую клавишу скриншота → выделить область → добавить разметку или распознать текст → скопировать или сохранить.

### Шаги выполнения

{% stepper %}
{% step %}
#### 1. Включение скриншотов и проверка разрешений

Откройте [Настройки] → [Скриншоты] и включите [Включить скриншоты]. Если на macOS появляется запрос [Разрешение на запись экрана], выберите [Перейти к авторизации]; после завершения авторизации нажмите [Перезапустить сейчас].
{% endstep %}

{% step %}
#### 2. Настройка горячей клавиши

Горячая клавиша по умолчанию: `Command+Shift+A` для macOS, `Ctrl+Shift+A` для Windows и Linux. Нажмите [Настроить горячую клавишу], чтобы перейти к соответствующей строке; если комбинация уже используется системой или другим приложением, на странице появится предупреждение о конфликте.
{% endstep %}

{% step %}
#### 3. Выделение области и разметка

Нажмите горячую клавишу и перетащите курсор, чтобы выделить область. Используйте [Прямоугольник], [Стрелка], [Кисть], [Текст], чтобы отметить важные места, и [Пикселизация], чтобы скрыть конфиденциальную информацию; в панели свойств можно изменить цвет, толщину линии и размер шрифта.
{% endstep %}

{% step %}
#### 4. Копирование текста или изображения

Если модель OCR готова, страница автоматически распознает текст; также можно нажать [Распознать текст]. Выделите текст напрямую или выберите [Скопировать весь текст]; после завершения разметки выберите [Скопировать и закрыть] или [Сохранить изображение].
{% endstep %}
{% endstepper %}

### Ожидаемый результат

Скриншот содержит только выделенную область; разметка четкая, конфиденциальная информация скрыта; после копирования изображение можно вставить в целевое приложение, а текст OCR — вставить как редактируемый текст.

### Описание конфигурации

| Параметр | Значение по умолчанию | Рекомендуемая начальная настройка | Назначение | Сценарии применения | Примечания |
| ------ | ---------------------- | ------------- | ----------- | ------------ | -------------- |
| Включить скриншоты | Отключено | Включать при необходимости | Регистрация глобальной горячей клавиши скриншота | Ежедневные скриншоты, учебные материалы, обратная связь по проблемам | На macOS требуется разрешение на запись экрана |

### Пример использования

Тестировщик делает скриншот ошибки в настройках, обводит сообщение об ошибке прямоугольником, маскирует учетные данные и локальный путь с помощью пикселизации, затем копирует результат в помощник по обратной связи. После этого он копирует код ошибки с того же скриншота и вставляет его в шаги воспроизведения, чтобы избежать ошибок при ручном вводе.

### Частые вопросы

<details>

<summary>Что делать, если горячая клавиша не работает? </summary>

Убедитесь, что [Включить скриншоты] включено, и проверьте, нет ли предупреждения о конфликте рядом с горячей клавишей. На macOS также проверьте разрешение на запись экрана и перезапустите приложение после авторизации; на Windows и Linux попробуйте другую комбинацию, не используемую системой.

</details>

<details>

<summary>Почему нельзя скопировать текст? </summary>

Откройте [Настройки] → [Локальные модели] и убедитесь, что статус модели OCR — «Готова». Распознавание текста невозможно во время процесса разметки; сначала завершите или отмените текущую разметку, затем запустите OCR.

</details>
