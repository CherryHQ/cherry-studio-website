# Эффективная рабочая область

Главное окно Cherry Studio состоит из боковой панели, вкладок и области контента. Темы диалогов и задачи Agent можно одновременно открывать в нескольких вкладках или выносить в отдельные окна; панель инструментов в области ввода можно настраивать в соответствии с привычками использования.

### Сценарии для использования отдельных окон

* Одновременно вести диалог с материалами и выполнять задачи Agent;
* Закрепить задачу длительного мониторинга, чтобы она не перекрывалась другими окнами;
* Разместить диалоги, файлы или задачи на разных мониторах;
* При демонстрации или общем доступе к задаче не раскрывать другие вкладки главного окна.

### Возможности рабочей области

| Возможность | Вход | Назначение |
| ------ | -------------------- | -------------- |
| Новая вкладка | Контекстное меню темы или задачи → [Открыть в новой вкладке] | Держать несколько контекстов рядом в главном окне |
| Отдельное окно | Контекстное меню темы, задачи или вкладки → [Открыть в новом окне] | Вынести текущий контент в новое окно |
| Закрепить вкладку | Контекстное меню вкладки → [Закрепить вкладку] | Закрепить часто используемые страницы |
| Закрепить окно | [Закрепить окно] в верхней части отдельного окна | Держать задачу видимой |
| Вернуться в главное окно | [Вернуться в главное окно] в верхней части отдельного окна | Вернуть вкладку в главное окно |
| Настройка панели инструментов | [+] в области ввода → [Настроить панель инструментов] | Изменить расположение часто используемых инструментов ввода |

В меню вкладки на рисунке выше выберите [Открыть в новом окне], чтобы вынести текущий контент в отдельное окно.

### Рекомендуемая компоновка

Для работы с текстами оставьте диалог с материалами в главном окне, а Agent «Написание» вынесите на правый монитор; для работы с кодом закрепите задачу Agent, оставив в главном окне файлы и документацию; для задач длительного мониторинга используйте отдельное окно, но не размещайте задачи, требующие частого подтверждения прав, в невидимом месте.

{% hint style="info" %}
Отдельное окно по-прежнему принадлежит одной и той же среде данных Cherry Studio. Это не новый аккаунт или пространство приватности; содержимое той же темы или задачи по-прежнему синхронизируется и сохраняется.
{% endhint %}
