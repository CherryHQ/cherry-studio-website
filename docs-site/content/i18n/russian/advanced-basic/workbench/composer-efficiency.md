# Панель инструментов ввода и инструменты повышения эффективности

<details>

<summary>Почему закреплённый инструмент не появился в другой области ввода?</summary>

Страницы Chat, Agent, Быстрых помощников и Рисования поддерживают разные наборы инструментов. Настройки закреплённого макета для Chat и Agent сохраняются отдельно. Пожалуйста, повторно откройте пункт [Пользовательская панель инструментов] в целевой области ввода.

</details>
