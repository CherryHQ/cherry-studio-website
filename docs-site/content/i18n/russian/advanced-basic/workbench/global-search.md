# Глобальный поиск

Глобальный поиск позволяет находить сообщения, диалоги, задачи, ассистентов, Agent и базы знаний через единый интерфейс. Он подходит для случаев, когда вы помните содержание, но не знаете, где оно хранится.

## Способ использования

{% stepper %}
{% step %}
### 1. Нажмите кнопку поиска в верхней части окна

Также можно просмотреть или изменить соответствующую горячую клавишу в разделе [Настройки] → [Горячие клавиши].
{% endstep %}

{% step %}
### 2. Введите характерное ключевое слово

Приоритетно используйте имена проектов, имена людей, темы файлов или фразы из выводов. Если ввести только общие слова, такие как «настройки» или «отчет», результаты будут слишком многочисленными.
{% endstep %}

{% step %}
### 3. Сузьте область поиска

Переключитесь на [Сообщения] или используйте фильтры [Диалоги], [Задачи], [Ассистенты], [Агенты], [Базы знаний], а затем сузьте поиск по времени обновления.
{% endstep %}

{% step %}
### 4. Откройте результат и продолжите работу

Поиск приведет вас к соответствующему содержимому. Перед открытием проверьте тип, чтобы не перепутать ассистента с задачей Agent с тем же названием.
{% endstep %}
{% endstepper %}

### Пример применения: восстановление выводов по клиенту за прошлый месяц

Найдите имя клиентского проекта, затем сузьте тип до [Сообщения] и ограничьте период обновления. Найдя вывод, откройте исходный диалог и сначала проверьте, были ли внесены исправления. Если вывод нужен для новой задачи, скопируйте подтвержденное резюме, а не полагайтесь на фрагментарные воспоминания в новом диалоге.

<details>

<summary>Почему поиск не находит содержимое файлов на диске? </summary>

Глобальный поиск в первую очередь находит сохраненное содержимое в Cherry Studio. Файлы на диске можно найти только после их добавления в рабочую директорию Agent, базу знаний или заметки, используя соответствующий интерфейс.

</details>
