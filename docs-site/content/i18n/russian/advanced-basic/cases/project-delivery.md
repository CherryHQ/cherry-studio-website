# Передача файлов проекта Agent

Коллеги из отдела операций должны систематизировать разрозненные материалы в виде каталога, резюме и файла для передачи. Чтобы избежать случайного изменения исходных файлов, необходимо заранее определить рабочую директорию Agent, допустимый объём изменений и порядок приёмки.

## Подходящие задачи

* Систематизация разрозненных материалов в каталог и индекс;
* Генерация нескольких документов по шаблону;
* Изменение кода с оставлением описания изменений;
* Массовое переименование, конвертация или проверка файлов.

## Порядок действий

{% stepper %}
{% step %}
### 1. Выберите минимальную рабочую директорию

Выбирайте только текущую директорию проекта. Для важных файлов заранее создайте резервную копию или запись версии. Начните с режима [Подтверждение каждого действия].
{% endstep %}

{% step %}
### 2. Определите допустимые и недопустимые изменения

Чётко укажите, какие файлы доступны только для чтения, где размещать результаты, какие операции требуют предварительного подтверждения, а также критерии завершения.
{% endstep %}

{% step %}
### 3. Сначала попросите Agent составить план

Для задач с высоким риском используйте режим [Только планирование]. После подтверждения списка файлов и шагов переключитесь в режим, разрешающий редактирование, и выполните задачу.
{% endstep %}

{% step %}
### 4. Проверяйте статус и файлы справа

Для длительных задач сначала проверьте [Статус]: ожидает ли задача одобрения. После генерации результата просмотрите его в разделе [Файлы]. Передавайте результат только после проверки, не принимая «завершение задачи» как подтверждение приёмки.
{% endstep %}
{% endstepper %}

## Пример задачи

```
Упорядочьте текущий каталог. Файлы в raw/ доступны только для чтения; создайте в deliverables/ индекс, сводку и список недостающих материалов. Перед удалением, перезаписью или массовым переименованием запросите подтверждение. В конце перечислите добавленные и изменённые файлы.
```

## Рекомендуемые настройки

| Возможность | Рекомендуемое использование | Причина |
| ---- | ------------ | ----------------- |
| Рабочая директория | Используйте отдельную директорию для каждого проекта | Чёткие границы файлов и место передачи |
| Права доступа | Для изменения файлов сохраняйте режим [Подтверждение каждого действия] | Легче обнаружить случайное удаление, перезапись или запись вне границ |
| Панель статуса | Проверяйте результат и шаги с ошибками перед завершением | Не полагайтесь только на «Agent сообщил о завершении» |
| Новая задача | Создавайте новую задачу для нового этапа или нового клиента | Избегайте влияния предыдущих требований на текущую передачу |

{% hint style="danger" %}
[Полный доступ] снижает количество подтверждений, но увеличивает последствия случайных действий. Рассматривайте его временное использование только в изолированных, доверенных и восстанавливаемых директориях.
{% endhint %}
