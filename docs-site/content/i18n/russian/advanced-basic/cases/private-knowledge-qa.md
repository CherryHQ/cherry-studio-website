# Вопросы и ответы по частной базе знаний

Команда по управлению персоналом хочет, чтобы коллеги могли искать действующие правила, но не хочет, чтобы Agent дополнял ответы на основе общих знаний. В этом примере объединены определение области данных, тестирование извлечения и правила формирования ответов; если контент не найден, Agent должен явно это указать.

## Порядок действий

{% stepper %}
{% step %}
### 1. Создание базы знаний по одной теме

Соберите действующие материалы в одном месте, удалите дубликаты и устаревшие версии. В именах файлов четко указывайте тему и область действия.
{% endstep %}

{% step %}
### 2. Тестирование извлечения с помощью реальных вопросов

Тестируйте как минимум легко путающиеся пункты, разговорные формулировки и вопросы, на которые нет ответа. Настройте материалы или параметры RAG, пока возвращаемые фрагменты не станут стабильными.
{% endstep %}

{% step %}
### 3. Создание специализированного Agent

Привяжите только эту базу знаний и в промпте укажите: «Приоритетно ссылайтесь на материалы; если ответ не найден, явно сообщите об этом; не дополняйте правила на основе общих знаний». Ограничьте права доступа минимально необходимым.
{% endstep %}

{% step %}
### 4. Начните с ограниченного использования

Сначала используйте для внутреннего поиска, не заменяя напрямую процессы утверждения или профессиональные решения. Собирайте вопросы с неверными ответами и корректируйте материалы и тесты извлечения.
{% endstep %}
{% endstepper %}

## Правила для примеров вопросов

```
Сначала дайте вывод, затем укажите название материала и соответствующий фрагмент. Если источники противоречат друг другу, перечислите расхождения, не делая выбор за нас. Если ответа нет в базе знаний, явно напишите: «В текущих материалах не найдено».
```

## Рекомендуемые комбинации и критерии завершения

| Элемент | Рекомендуемый подход |
| ----- | --------------------------- |
| База знаний | Один набор материалов на одну тему, удаление дубликатов и устаревших версий |
| Тестирование извлечения | Одновременное тестирование стандартных формулировок, разговорных вопросов и вопросов без ответа |
| Agent | Привязка только необходимых баз знаний, требование ссылаться на материалы и не дополнять ответы |
| Критерий завершения | Нахождение правильного фрагмента; перечисление конфликтующих материалов; явное указание об отсутствии ответа |

{% hint style="danger" %}
Контент в частной базе знаний обрабатывается выбранными вами моделями эмбеддингов и диалоговой моделью. Перед использованием проверьте требования к конфиденциальности материалов и область действия сервиса; не импортируйте ключи и учетные данные как материалы базы знаний.
{% endhint %}
