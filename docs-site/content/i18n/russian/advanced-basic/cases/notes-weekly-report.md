# Генерация еженедельного отчёта из заметок

Руководитель проекта в течение недели накапливает заметки о встречах, обновления статуса и разрозненные задачи. Цель — в пятницу сформировать еженедельный отчёт со стабильной структурой и проверяемыми фактами. Ключевой момент — сначала унифицировать способ ведения записей, а затем поручить Agent агрегацию, а не догадывание о недостающих статусах.

## Порядок действий

{% stepper %}
{% step %}
### 1. Унификация способа записи

Ежедневно фиксируйте события в одной папке заметок, включая как минимум дату, результат, ответственного и статус. Не указывайте незавершённые задачи как выполненные.
{% endstep %}

{% step %}
### 2. Ручная подготовка в пятницу

Объедините дублирующиеся пункты, дополните ключевые цифры и ссылки. Долгосрочный контекст перенесите в базу знаний, изменения текущей недели оставьте в текущей заметке.
{% endstep %}

{% step %}
### 3. Генерация черновика через Agent

Запросите вывод по разделам «Выполнено на этой неделе», «В работе», «Риски», «План на следующую неделю». При отсутствии данных Agent должен перечислить недостающие пункты.
{% endstep %}

{% step %}
### 4. Проверка и экспорт

Проверьте статусы, цифры и ответственных, затем утвердите финальную версию в разделе [Заметки] и экспортируйте. Стабильный формат можно оформить как навык для повторного использования на следующей неделе.
{% endstep %}
{% endstepper %}

## Пример задачи

```
Прочитайте заметки за эту неделю и подготовьте черновик еженедельного отчёта. Объедините одинаковые пункты, сохранив изменения статуса по датам, и не делайте предположений о завершении. Отсутствующих ответственных, числа или следующие шаги поместите в раздел «Требует дополнения».
```

## Рекомендуемые комбинации и критерии готовности

| Элемент | Рекомендуемый подход |
| ----- | --------------------------------- |
| Ежедневный ввод | Заметки по датам или проектам, только факты и задачи |
| Agent | Использование фиксированной структуры еженедельного отчёта, генерация после чтения заметок за неделю |
| Вывод | Еженедельный отчёт записывается в отдельный файл, не заменяя исходные заметки |
| Критерий готовности | Каждый пункт прогресса можно проследить до исходной заметки; незавершённые задачи имеют ответственного или следующий шаг; отсутствие вымышленных данных |

Подходит для структурирования уже зафиксированной работы в еженедельный отчёт. Не подходит для того, чтобы Agent догадывался о результатах недели на основе разрозненных воспоминаний.

{% hint style="info" %}
Перед автоматической генерацией еженедельного отчёта по расписанию вручную выполните процесс несколько недель. Создавайте запланированную задачу только после того, как формат ввода стабилизируется, а обработка недостающей информации станет надёжной.
{% endhint %}
