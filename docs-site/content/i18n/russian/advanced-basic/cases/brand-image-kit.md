# Комплект изображений для бренда

Команде контента необходимо создать горизонтальные, квадратные и вертикальные изображения для одного и того же мероприятия, сохраняя единый стиль, цветовую палитру и соблюдение правил бренда. Сначала определите основной визуальный образ, а затем адаптируйте его под разные размеры — это проще, чем генерировать каждое изображение с нуля.

## Подготовка материалов

* Тема контента и целевые платформы;
* Допустимые фирменные цвета и референсы;
* Запрещенные тексты, логотипы и элементы;
* Три соотношения сторон и требования к отступам.

## Порядок действий

{% stepper %}
{% step %}
### 1. Пусть Agent определит визуальное направление

Поместите статью или описание мероприятия в рабочую директорию. Попросите Agent только предложить объект, сцену, цветовую палитру, ракурс и отступы, не генерируя изображения.
{% endstep %}

{% step %}
### 2. Проверьте основной визуальный образ в [Рисовании]

Выберите подходящий шаблон и модель, сначала сгенерируйте небольшой горизонтальный образец. Проверьте внешний вид продукта, детали персонажей и риски для бренда.
{% endstep %}

{% step %}
### 3. Адаптируйте размеры с помощью референса

После выбора основного визуального образа используйте его как референс для генерации квадратного и вертикального форматов. В каждом запросе указывайте, какие объекты должны остаться неизменными, а какие элементы композиции можно изменить.
{% endstep %}

{% step %}
### 4. Локальная коррекция и улучшение

Используйте редактирование или маски только для проблемных областей. Улучшайте качество только в финальной версии. Включайте назначение и соотношение сторон в имена файлов, чтобы избежать путаницы.
{% endstep %}
{% endstepper %}

## Проверка результата

* Цветовая палитра и объект на всех трех изображениях согласованы;
* Отсутствуют ошибочные тексты, сгенерированные моделью;
* Не появляются случайно логотипы, персонажи или конфиденциальная информация;
* Размеры соответствуют требованиям платформ публикации;
* Получено разрешение на использование референсов.

## Рекомендуемые комбинации и критерии готовности

| Элемент | Рекомендуемый подход |
| ---- | ------------------------------- |
| Модель рисования | Сначала сгенерируйте одно тестовое изображение через Agent для проверки соединения, затем сохраните шаблон рисования |
| Входные материалы | Фирменные цвета, шрифты, размеры, референсы и запрещенные элементы храните в одной директории проекта |
| Массовое производство | Сначала подтвердите одно изображение, затем генерируйте остальные в той же серии |
| Критерии готовности | Корректные размеры, читаемый текст, согласованные элементы бренда, отсутствие лишних логотипов, исходные референсы сохранены |

Подходит для обложек статей, изображений для социальных сетей и материалов мероприятий. Для финальных постеров, требующих точной вёрстки, рекомендуется выполнить последнюю проверку в графическом редакторе.

{% hint style="info" %}
Если вы хотите генерировать изображения непосредственно в диалоге с Agent, сначала настройте глобальную [Модель рисования] и включите инструмент [Генерация изображений] в Agent. Для детального редактирования по-прежнему рекомендуется использовать страницу [Рисование].
{% endhint %}
