# Карта расширенных возможностей

Расширенные руководства не перечисляют пункты меню настроек по порядку, а исходят из задачи, которую нужно решить. Сначала выберите ближайшую к вам цель, затем перейдите к соответствующему руководству.

<figure><img src="../../../assets/f99c1bfff81d92511c921169.webp" alt="Сначала выберите основной вход и выполните минимальную задачу; когда результат станет стабильным, добавляйте базу знаний, навыки, MCP, каналы или запланированные задачи."><figcaption><p>Сначала выберите основной вход и выполните минимальную задачу; когда результат станет стабильным, добавляйте базу знаний, навыки, MCP, каналы или запланированные задачи. </p></figcaption></figure>

{% hint style="success" %}
Если нужно настроить набор из руководств, каналов, запланированных задач или расширенных возможностей, сначала сообщите Agent в разделе «Работа» о своей цели. Agent поможет определить, чего не хватает, и проведет вас через типовые настройки; если требуется проверить учетные данные, ключи или точные параметры, переходите в «Настройки» для ручной корректировки.
{% endhint %}

<figure><img src="../../../assets/8fe4d938af469d667d4071df.webp" alt="Панель запуска слева предлагает девять основных входов, выберите тот, который ближе всего к вашей задаче."><figcaption><p>Панель запуска слева предлагает девять основных входов, выберите тот, который ближе всего к вашей задаче. </p></figcaption></figure>

Описание диаграммы: сначала выберите основной вход в соответствии с целью, а после стабилизации процесса добавляйте навыки, MCP, каналы или запланированные задачи.

### Выбор входа по цели

| Что вы хотите сделать | Рекомендуемый вход | Используемые возможности |
| ------------- | ----------------------- | --------------------- |
| Сравнить несколько ответов, структурировать длинную дискуссию | «Диалог» | Несколько моделей, ветвление сообщений, контекст, цитаты и артефакты |
| Обработать файлы или выполнить многошаговую задачу | «Работа» | Agent, рабочая директория, инструменты, разрешения и панель состояния |
| Стабильно отвечать на вопросы по собственным материалам | «База знаний» → тестирование извлечения, затем привязка к Agent | Файлы/веб-страницы/заметки, RAG, область поиска |
| Создать иллюстрации по статье или отредактировать изображение | «Рисование», или включить «Генерация изображений» в Agent | Шаблоны, референсы, локальная правка, улучшение |
| Перевести текст, скриншот или длинный документ | «Перевод» | OCR, обработка документов, история и избранное |
| Сохранить черновик и продолжить доработку | «Заметки» | Markdown, поиск, экспорт, добавление в базу знаний |
| Сделать скриншот интерфейса, пометить и скопировать текст | «Настройки» → «Скриншоты», включите и используйте глобальную горячую клавишу | Скриншот области, пометки, пикселизация, OCR |
| Открыть часто используемые веб-приложения | «Мини-приложения» | Встроенные веб-инструменты и добавленные сайты |
| Просматривать, предпросматривать и упорядочивать локальные файлы | «Файлы» | Список файлов, предпросмотр и последующая обработка |
| Подключить внешние инструменты или закрепить метод работы | Сначала пусть Agent оценит, затем проверьте в «Настройках» | Навыки, MCP, встроенные инструменты |
| Использовать Agent из внешних платформ | Сначала пусть Agent в «Работе» поможет с настройкой | Каналы, разрешенный диапазон, режим разрешений |
| Генерировать ежедневные отчеты или напоминания по расписанию | Сначала настройте Agent, затем создайте «Запланированную задачу» | Agent, рабочая директория, каналы, журнал выполнения |
| Одновременно просматривать материалы и задачи | Правый клик по вкладке → «Открыть в новом окне» | Несколько окон, закрепленные вкладки, глобальный поиск |
| Управлять командной строкой для программирования | «Партнер по коду» на панели запуска | Code CLI, подключение моделей, директории и терминал |
| Позволить локальным программам вызывать модель или диагностировать ошибки | «Настройки» → «API-шлюз» / «Общие» | Совместимый API, цепочка вызовов, режим разработчика |

### Рекомендуемый порядок изучения

{% stepper %}
{% step %}
#### 1. Сначала освоите рабочее пространство Agent

Научитесь создавать Agent, выбирать рабочую директорию, понимать распределение ролей моделей и разрешения. Все последующие расширения, автоматизация и примеры проектов строятся на этой основе.
{% endstep %}

{% step %}
#### 2. Затем подключите материалы и возможности

Для долгосрочных материалов используйте базу знаний, для повторяемых методов — навыки, для внешних систем — MCP. Каждый раз добавляйте только одну возможность и проверяйте ее на небольшой задаче.
{% endstep %}

{% step %}
#### 3. В конце настройте автоматическое выполнение или внешнее подключение

Настройте каналы, запланированные задачи, Code CLI или внешний API только после того, как ручные результаты станут стабильными. Так будет проще определить, на каком этапе возникла проблема.
{% endstep %}
{% endstepper %}
