# Генерация, редактирование и улучшение изображений

Раздел «Рисование» позволяет не только создавать изображения по текстовому описанию, но и использовать референсы, редактировать определённые области, объединять несколько изображений, повторно использовать шаблоны и повышать разрешение. Сначала определите назначение изображения, затем выберите способ генерации или редактирования.

## Выбор подходящего подхода

| Задача | Рекомендуемый способ |
| ------------ | ------------ |
| Создание визуального направления с нуля | Генерация по тексту или использование шаблона |
| Сохранение объекта, смена фона или стиля | Загрузка референса и последующее редактирование |
| Изменение только части изображения | Использование маски для выделения области правки |
| Объединение нескольких материалов в одно изображение | Слияние нескольких изображений с указанием главного и второстепенного изображения |
| Улучшение чёткости существующего изображения | Использование функции улучшения/увеличения |

### Пример: от описания к готовому результату

Откройте раздел «Рисование», выберите модель изображений, поддерживающую текущую задачу, введите описание объекта, окружения, стиля, освещения, композиции и ограничений, затем отправьте запрос. Пример промпта:

> Творческий рабочий стол в утреннем свете: настольная лампа цвета вишни, альбом для эскизов, камера и ветка сакуры; за окном — спокойные горы. Мягкий 3D-иллюстративный стиль, тёплый утренний свет, широкий формат, без текста.

1. Чётко опишите назначение и композицию, выберите модель рисования.
2. Сгенерируйте первый вариант, проверьте объект, края и размеры.
3. Если результат ещё не подходит, измените только один аспект, сгенерируйте снова и проверьте.
4. После подтверждения пригодности увеличьте изображение для проверки и экспортируйте.

{% hint style="info" %}
В примере для генерации широкой иллюстрации рабочего стола использована модель 【GPT-Image-2 | express】. Доступные модели, размеры и действия зависят от отображения на вашей текущей странице; не копируйте параметры, которые не видны.
{% endhint %}

После генерации не закрывайте окно сразу: сначала увеличьте изображение, чтобы проверить объект, края и лишние элементы, затем переключайте версии в истории слева. При необходимости корректировки сохраняйте рабочие описания и изменяйте только один аспект.

## Создание пригодного изображения

{% stepper %}
{% step %}
### 1. Выбор модели и режима

Разные модели изображений поддерживают различные размеры, референсы и возможности редактирования. Не заполняйте параметры, которые не отображаются на странице, на основе предположений.
{% endstep %}

{% step %}
### 2. Чёткое описание назначения и композиции

Укажите объект, окружение, ракурс, цветовую гамму, пропорции, свободное пространство и то, чего не должно быть. Если нужно добавить заголовок, обычно лучше попросить модель оставить свободное пространство, а текст добавить с помощью графического редактора.
{% endstep %}

{% step %}
### 3. Проверка одного аспекта за раз

Сначала сгенерируйте небольшую партию результатов, выберите изображение, наиболее близкое к цели, затем отредактируйте или улучшите его. Одновременная генерация множества вариантов увеличивает расход ресурсов и затрудняет оценку того, какое требование сработало.
{% endstep %}

{% step %}
### 4. Проверка деталей перед экспортом

Увеличьте изображение, чтобы проверить руки людей, структуру продукта, текст, логотипы и края. При коммерческом использовании дополнительно подтвердите источник материалов и соответствующие условия обслуживания.
{% endstep %}
{% endstepper %}

### Рисование в Agent

Сначала в разделе 【Настройки】 → 【Модель по умолчанию】 выберите 【Модель рисования】, затем откройте 【Встроенные инструменты】 в Agent и убедитесь, что включена функция 【Генерация изображений】. После этого в разделе 【Работа】 можно попросить Agent прочитать статью, выделить визуальное направление и сразу сгенерировать иллюстрации.

### Пример применения: создание набора изображений для брендового мероприятия

Сначала в шаблоне определите единые правила цветовой гаммы, ракурса и свободного пространства, сгенерируйте горизонтальную шапку. После выбора направления используйте тот же референс для создания квадратных изображений для соцсетей и вертикальных историй. Если внешний вид продукта не соответствует, исправьте это с помощью локального редактирования, а в конце улучшите версии, предназначенные для публикации. На протяжении всего процесса не позволяйте модели генерировать брендовый текст, чтобы избежать опечаток и искажений.

{% hint style="warning" %}
Референсы могут быть отправлены в сервис выбранной модели. Перед загрузкой клиентских данных, портретов и изображений непубличных продуктов убедитесь, что это разрешено условиями использования сервиса.
{% endhint %}
