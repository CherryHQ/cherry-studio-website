# Заметки, база знаний и Agent

<details>

<summary>После добавления заметки в базу знаний изменения синхронизируются немедленно?</summary>

Сначала проверьте состояние данных в базе знаний. Если содержимое изменилось, а результаты поиска не обновлены, повторно обработайте соответствующий материал и выполните тест извлечения.

</details>
