# Рабочий процесс «Знания и контент»

База знаний, заметки, рисование и перевод — это не изолированные инструменты. Они отвечают за организацию материалов, накопление контента, создание визуальных ресурсов и обработку многоязычных файлов, и все они могут передаваться Agent для дальнейшего использования.

## Как распределены функции четырёх модулей

| Модуль | Для чего подходит | Типичный следующий шаг |
| ----- | ---------------------- | -------------- |
| 【База знаний】 | Позволяет искать материалы по вопросам | Привязка к чат-ассистенту или Agent |
| 【Заметки】 | Написание, структурирование и долгосрочное ведение контента в Markdown | Экспорт документа или добавление в базу знаний |
| 【Рисование】 | Генерация, редактирование, объединение и улучшение изображений | Скачивание или передача в контентные задачи |
| 【Перевод】 | Обработка текста, изображений и документов | Сохранение результата, повторное использование истории или продолжение редактирования |

{% hint style="success" %}
Если цель — «создать готовый продукт на основе этих материалов», сразу укажите в модуле 【Работа】 Agent, где находятся материалы и что нужно получить. Заходите в соответствующие модули, когда требуется ручная организация базы данных, корректировка изображений или поабзацная проверка перевода.
{% endhint %}

## От материалов к готовому продукту

{% stepper %}
{% step %}
### 1. Сначала организуйте источники

Добавьте долгосрочные справочные материалы в базу знаний, а черновики, над которыми вы работаете, храните в заметках или рабочей директории. Не импортируйте в базу знаний все непроверенные временные чаты.
{% endstep %}

{% step %}
### 2. Проверьте возможность извлечения ключевой информации

Используйте тест поиска в базе знаний, чтобы убедиться, что реальные вопросы находят нужные фрагменты. Если поиск не работает, сначала исправьте материалы и настройки, не заставляя Agent догадываться.
{% endstep %}

{% step %}
### 3. Затем создайте текст, перевод и изображения

Попросите Agent составить черновик контента на основе материалов; изображения и переводы дорабатывайте в модулях 【Рисование】 и 【Перевод】 соответственно. В конце человек проверяет факты и формулировки.
{% endstep %}
{% endstepper %}
