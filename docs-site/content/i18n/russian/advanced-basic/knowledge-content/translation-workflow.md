# Перевод файлов, изображений и длинных текстов

Функция [Перевод] позволяет обрабатывать как текст, введённый напрямую, так и загруженные изображения или документы. Для изображений сначала выполняется распознавание текста, а документы обрабатываются с учётом их формата и содержания. В истории переводов можно сохранять записи в избранное, повторно открывать и использовать их.

### Выбор способа ввода

| Материал | Рекомендуемый подход | На что обратить внимание |
| -------- | -------------------- | ---------------- |
| Короткий текст | Вставить напрямую | Тон, собственные имена, контекст |
| Скриншоты или сканы | Загрузить изображение и использовать OCR | Ошибки распознавания, таблицы и числа |
| PDF | Загрузить файл и выбрать, устанавливать ли BabelDOC | Двухколоночная вёрстка, шрифты, таблицы, сноски и количество страниц |
| Другие длинные документы | Загрузить файл | Уровни заголовков, абзацы, сноски и форматирование |
| Markdown | Проверить в режиме предпросмотра | Сохранение ссылок, блоков кода и разметки |

#### Пример: перевод короткого текста

Выберите [Автоопределение] в качестве исходного языка, [Английский] в качестве целевого языка, введите текст на китайском и нажмите [Перевести]. После получения результата сначала проверьте ключевые значения, такие как «серая зона» (canary), «метрики мониторинга» и «процедура отката», затем скопируйте или сохраните в заметки.

#### Что проверить после получения результата

| Пункт проверки | Пример |
| ----- | ------------------ |
| Ключевые значения | «Серый релиз» нельзя переводить буквально как цвет |
| Собственные имена | Названия продуктов, команд и функций должны быть единообразными |
| Числа и условия | Даты, пропорции, суммы и отрицания не должны теряться |
| Тон | Для уведомлений, договоров и маркетинговых текстов используйте соответствующий тон |

Короткие тексты можно проверять построчно. Для файлов и длинных текстов сначала выборочно проверьте заголовки, таблицы, числа и повторяющуюся терминологию, а затем решите, сдавать ли весь документ целиком.

### Перевод PDF с сохранением вёрстки

После загрузки PDF с извлекаемым текстом страница проверяет наличие BabelDOC. При первом использовании выберите [Установить BabelDOC]. После подготовки зависимостей слева отображается предпросмотр исходного текста, справа — PDF с переводом, а прогресс отображается по этапам: проверка ресурсов, анализ, перевод, вёрстка и рендеринг.

{% stepper %}
{% step %}
#### 1. Загрузка PDF и проверка зависимостей

Нажмите [Перетащите или нажмите, чтобы загрузить изображение/документ], чтобы выбрать PDF. Если страница сообщает об отсутствии или устаревшей версии, установите или обновите BabelDOC; установка управляется через [Зависимости среды] в Cherry Studio.
{% endstep %}

{% step %}
#### 2. Выбор модели перевода и целевого языка

Для перевода PDF текущая модель должна быть доступна через локальный API-шлюз. Если модель недоступна, сначала вернитесь в [Настройки] → [Сервисы моделей] и проверьте подключение, не повторяя установку BabelDOC.
{% endstep %}

{% step %}
#### 3. Сравнение двухколоночного результата

После завершения перевода сравнивайте исходный текст и перевод постранице, уделяя особое внимание таблицам, подписям к рисункам, колонтитулам, сноскам и переносам строк. Нажмите кнопку загрузки, чтобы сохранить PDF с переводом.
{% endstep %}

{% step %}
#### 4. Продолжение из истории

Переводы PDF попадают в [Историю переводов] и [Файлы]. В истории можно повторно открыть двухколоночный предпросмотр, найти файл с переводом или сохранить результат; при удалении записи соответствующий файл с переводом также удаляется.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
Сканированные или чисто графические PDF пока не поддерживают перевод с сохранением вёрстки. Если страница сообщает о необходимости OCR, сначала распознайте текст на изображениях в редактируемый текст, а затем используйте стандартный процесс перевода.
{% endhint %}

### Шаги перевода

{% stepper %}
{% step %}
#### 1. Сначала подтвердите исходный и целевой языки

Автоопределение подходит для смешанных или неизвестных языков; для официальных материалов, таких как договоры и техническая документация, рекомендуется вручную подтверждать язык, чтобы снизить риск ошибок.
{% endstep %}

{% step %}
#### 2. Выбор способа перевода

Используйте настроенную модель, если важны контекст, тон и единообразие терминологии; для обычных коротких фраз можно выбрать более лёгкий способ. Доступные варианты зависят от текущей страницы.
{% endstep %}

{% step %}
#### 3. Проверка по разделам

Сначала проверьте имена, числа, даты, отрицания и единицы измерения. Для перевода изображений также проверяйте результаты OCR; если распознавание ошибочно, перевод тоже будет неверным.
{% endstep %}

{% step %}
#### 4. Сохранение, экспорт или повторное использование результата

В [Истории переводов] просматривайте, сохраняйте в избранное и повторно используйте текстовые переводы; результаты PDF можно просматривать в двух колонках, открывать файлы или сохранять. Перед официальной сдачей сохраните глоссарий и внесённые вручную правки в материалы проекта.
{% endstep %}
{% endstepper %}

#### Пример применения: подготовка многоязычных материалов продукта

Сначала составьте список с названиями продуктов, функций и терминами, которые нельзя изменять. Загрузите инструкцию на китайском, сначала переведите один раздел и подтвердите терминологию, затем обработайте весь текст; рекламные изображения загрузите отдельно для перевода через OCR. После завершения поместите подтверждённые термины и переводы в рабочую директорию проекта, чтобы Agent единообразно проверил заголовки, ссылки и числа, но не позволял ему самостоятельно изменять юридические оговорки.

{% hint style="danger" %}
Медицинские, юридические, финансовые и связанные с безопасностью материалы требуют проверки специалистами. Автоматический перевод повышает эффективность, но не заменяет вычитку, ответственность за которую несёт конкретное лицо.
{% endhint %}
