# Артефакты, ссылки и экспорт

В одном ответе могут одновременно присутствовать основной текст, код, файлы, изображения, ссылки и редактируемый контент. Сначала проверьте артефакты, затем решите, нужно ли копировать, скачивать, экспортировать или передать Agent для дальнейшей обработки.

### Сначала предпросмотр, затем передача

Нажмите на артефакт в сообщении или на панели файлов Agent, чтобы открыть соответствующий предпросмотр справа. Для HTML можно проверить макет страницы и интерактивность; PDF, Word, PowerPoint, изображения и текст отображаются в соответствии с форматом; `.xlsx` в электронных таблицах можно напрямую просматривать листы, стили ячеек, объединённые ячейки, результаты формул, изображения и диаграммы.

<figure><img src="../../../../assets/4e1d6cc47405edfe8d6fe315.webp" alt="① Область предпросмотра используется для проверки полного содержимого; ② на панели инструментов можно масштабировать, скачивать, разворачивать на весь экран или переключать вид."><figcaption><p>① Область предпросмотра используется для проверки полного содержимого; ② на панели инструментов можно масштабировать, скачивать, разворачивать на весь экран или переключать вид. </p></figcaption></figure>

1. Укажите формат артефакта в диалоге и откройте предпросмотр справа.
2. Проверьте, является ли содержимое и макет полными.
3. Если есть пропуски, вернитесь к диалогу, добавьте требования к исправлениям и снова откройте предпросмотр для проверки.
4. После подтверждения полноты скачайте, скопируйте или передайте Agent для сохранения.

Цель предпросмотра — заранее обнаружить пропуски, а не просто убедиться, что «контент сгенерирован». Если страницу планируется передать коллегам, проверьте как минимум по одному разу ссылки, кнопки и скачиваемые файлы.

{% hint style="info" %}
Если в результате отображается только блок кода, а предпросмотр отсутствует, добавьте в том же диалоге запрос: «Выведите полный HTML-артефакт, готовый к предпросмотру», и укажите области, которые должна содержать страница.
{% endhint %}

#### Пример применения: проверка перед публикацией

Введите: «Создайте полный HTML-артефакт, готовый к предпросмотру, на основе чек-листа перед публикацией, включающий три области: подготовка к запуску, мониторинг и приёмка, условия отката». После открытия предпросмотра сначала проверьте полноту трёх частей, затем скачайте файл или передайте Agent для сохранения в каталог проекта.

#### Пример применения: проверка таблицы данных

Откройте бюджетную таблицу `.xlsx`, сгенерированную Agent. Сначала переключите каждый лист, затем проверьте объединённые заголовки, форматирование сумм, результаты формул и диаграммы. Если содержимое ячейки длинное, нажмите для раскрытия; для детального просмотра изображений или диаграмм используйте масштабирование. Предпросмотр предназначен для приёмки и не заменяет возможности полного редактирования и пересчёта в Excel.

### Сначала выполните три проверки

1. **Содержимое**: соответствуют ли цифры, даты, собственные имена и выводы исходным материалам.
2. **Источник**: сохранены ли рабочие ссылки на результаты из интернета; действительно ли ссылки подтверждают соответствующие утверждения.
3. **Файлы**: можно ли нормально открыть файл с учётом имени, формата и содержимого; не содержит ли он информации, которую не следует распространять.

### Частые варианты использования

| Результат | Рекомендуемое действие |
| ---------------- | ------------------------------------- |
| Готовый текст | Скопируйте в целевое приложение или сохраните как заметку |
| Markdown, требующий постоянного редактирования | Поместите в рабочий каталог Agent и продолжайте редактирование в панели [Файлы] |
| Повторно используемые материалы | После оформления добавьте в базу знаний; не импортируйте временные обсуждения целиком |
| Изображения | Откройте исходное изображение, проверьте размер и детали, затем скачайте |
| Таблица `.xlsx` | Проверьте листы, стили, результаты формул, изображения и диаграммы во встроенном предпросмотре, затем выполните финальное редактирование в табличном редакторе |
| Код или команды | Сначала прочитайте и проверьте в восстанавливаемой среде; не запускайте неизвестные команды напрямую |

{% hint style="warning" %}
«Успешная генерация» означает лишь, что модель вернула контент, но не гарантирует, что файл готов к публикации. Для внешних материалов всё равно проверяйте факты, авторские права, конфиденциальность и требования к бренду.
{% endhint %}

#### Пример применения: превращение обсуждения в готовый документ

Сначала команда обсуждает план мероприятия в [Диалоге]. После подтверждения целевой аудитории, сроков и бюджетных ограничений попросите модель вывести структурированный план. Затем передайте план контент-агенту в [Рабочем процессе], чтобы он сгенерировал `campaign-plan.md` в указанном каталоге. Внесите правки в панели [Файлы] справа, чтобы избежать копирования десятков раундов обсуждения в официальный документ.

<summary>Почему ссылка на источник не открывается? </summary>

Ссылка могла устареть, требовать входа в систему, либо результаты поиска предоставляют только аннотацию. Используйте первоисточник для повторной проверки; не используйте недоступные источники как единственное обоснование ключевых выводов.
