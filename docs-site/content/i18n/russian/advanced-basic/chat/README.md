# Продвинутые функции чата

Раздел «Чат» подходит для структурирования мыслей в процессе общения. Помимо вопросов к одной модели, здесь можно сравнивать несколько моделей параллельно, создавать ветви от любого сообщения, управлять контекстом длинных диалогов и продолжать работу с файлами, изображениями, кодом и цитатами из ответов как с артефактами.

{% hint style="info" %}
Если задача требует последовательного чтения и записи локальных файлов, вызова различных инструментов или длительного выполнения, используйте Agent в разделе «Работа». Чат лучше подходит для обсуждения, сравнения и финализации, а Agent — для выполнения задач.
{% endhint %}

## Выбор функций по цели

| Цель | Рекомендуемый подход |
| ------------- | --------------------- |
| Сравнение мнений разных моделей | Выберите несколько моделей в области ввода и отправьте один и тот же вопрос |
| Сохранение исходного обсуждения и исследование другого пути | Создайте ветвь от ключевого сообщения |
| Продолжение длинного обсуждения | Проверьте использование контекста; при необходимости суммируйте и начните новую тему |
| Отправка следующего вопроса позже | Используйте очередь сообщений, чтобы не прерывать текущий ответ |
| Продолжение работы с файлами или кодом из ответа | Откройте предпросмотр артефактов, затем скачайте, скопируйте или продолжите в новой задаче |

## Рекомендуемый порядок

{% stepper %}
{% step %}
### 1. Сначала сформулируйте вопрос полностью

Опишите цель, материалы, ограничения и желаемый формат вывода. Несколько моделей лишь усилят различия в исходном вопросе, но не заполнят недостающую информацию автоматически.
{% endstep %}

{% step %}
### 2. Затем решите, нужно ли сравнение

Выбирайте несколько моделей, когда нужны разные точки зрения. Для повседневных вопросов используйте одну модель: интерфейс будет чище, а использование ресурсов — проще контролировать.
{% endstep %}

{% step %}
### 3. Зафиксируйте полезные выводы

Сохраняйте переиспользуемые материалы в заметках или базе знаний; передайте задачи, требующие дальнейшего выполнения, Agent, приложив уже подтверждённые выводы.
{% endstep %}
{% endstepper %}
