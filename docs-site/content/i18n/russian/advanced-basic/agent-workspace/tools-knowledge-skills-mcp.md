# Встроенные инструменты, базы знаний, навыки и MCP

Эти четыре типа функций расширяют возможности Agent, но решают разные задачи: встроенные инструменты обеспечивают выполнение типовых операций, базы знаний ограничивают доступ к извлекаемым материалам, навыки задают методы работы, а MCP подключает внешние инструменты и данные.

| Базы знаний | Какие частные материалы может извлекать Agent | Спецификации продукта, шаблоны договоров, руководства команды |
| Навыки | По каким процессам и стандартам должен работать Agent | Формат еженедельных отчетов, чек-листы ревью кода, правила написания текстов |
| MCP | К каким внешним инструментам и ресурсам может подключаться Agent | Базы данных, браузеры, сторонние бизнес-системы |

Путь настройки: левая навигация [Работа] → открыть меню Agent → [Редактировать] → [Встроенные инструменты].

### Встроенные инструменты

Встроенные инструменты сгруппированы по контексту, файлам, мультимедиа, оркестрации, поиску и терминалу. Основные возможности включают:

* [Генерация изображений]: использование настроенной модели рисования;
* [Поиск в базе знаний] и [Управление базой знаний]: появляются только после привязки базы знаний;
* [Веб-поиск] и [Извлечение веб-страниц]: использование настроенных в Cherry Studio возможностей доступа в интернет;
* [Память]: сохранение и извлечение стабильной информации между задачами;
* [Запланированные задачи] и [Уведомления]: позволяют Agent управлять расписанием и отправлять результаты в каналы;
* [Task] и [Workflow]: обработка сложных задач с помощью суб-агентов или оркестрации;
* [Конвертация файлов в Markdown]: чтение PDF, Word, PowerPoint, Excel, OpenDocument, RTF, EPUB и CSV из рабочей директории или вложений текущего сеанса и передача структурированного содержимого Agent для пофрагментной обработки;
* Инструменты координации сеансов: поиск существующих сеансов Agent, создание независимых сеансов, отправка задач и получение отслеживаемых результатов выполнения;
* Инструменты файлов и Bash: чтение, создание, модификация файлов и выполнение команд.

{% hint style="info" %}
[Конвертация файлов в Markdown] не изменяет исходный файл и не предоставляет OCR для сканированных PDF. Для сканов сначала используйте [OCR] или функции обработки документов, затем передайте результат Agent.
{% endhint %}

### Область базы знаний

Выбранная в [База знаний] база является границей извлечения для данного Agent. Если база не выбрана, инструменты базы знаний не загружаются; при выборе нескольких баз Agent работает только внутри них и не извлекает данные из других хранилищ автоматически.

### Навыки

Активируйте установленные навыки в разделе [Навыки]. Содержимое навыков попадает в рабочую среду Agent и используется для ограничения процессов и вывода. Если требуется новый навык, можно попросить Agent найти и установить его непосредственно в разделе [Работа]; путь ручного управления: [Настройки] → [Навыки].

### MCP

Сначала подключите и запустите серверы в [Настройки] → [MCP], затем вернитесь в окно редактирования Agent и привяжите их в разделе [MCP]. Не запущенные серверы нельзя активировать; после подключения предоставленные ими инструменты попадают в каталог инструментов Agent и продолжают контролироваться режимом разрешений. Если сервер также предоставляет ресурсы или подсказки, их можно выбрать и использовать непосредственно из панели [+] в области ввода.

{% hint style="danger" %}
Открытие инструментов не означает, что следует пропускать утверждение. Для записи файлов, работы в терминале, изменения внешних данных и генерации изображений, которая может тарифицироваться, рекомендуется сохранять режим [Подтверждение каждого действия]; более широкие разрешения используйте только для инструментов с надежным источником и понятным уровнем риска.
{% endhint %}

### Рекомендуемые комбинации

| Требование задачи | Рекомендуемая комбинация | Когда добавлять | Примечания |
| -------- | ------------- | ------------- | ------------- |
| Обработка локальных файлов | Инструменты файлов + выделенная рабочая директория | Добавить навык при необходимости фиксированного формата | Сначала сохраняйте [Подтверждение каждого действия] |
| Ответы на основе внутренних материалов | База знаний + Поиск в базе знаний | Передавать в каналы после стабилизации извлечения | Сначала протестируйте вопросы без ответа |
| Повторное выполнение фиксированного процесса | Навык + необходимые встроенные инструменты | Добавить MCP при необходимости внешних данных | Не храните учетные данные и ключи в навыках |
| Вызов внешних систем | MCP + минимальные учетные данные | Ослабить утверждение после стабилизации задачи | Операции записи, удаления и тарифицируемые действия требуют подтверждения |

### Пример пользователя: Agent для рыночных исследований

Привяжите к Agent базу знаний с материалами о продукте, активируйте навык «Исследовательский отчет», подключите надежный MCP для веб-поиска и оставьте встроенные инструменты извлечения веб-страниц и записи файлов. Agent сначала определяет продуктовый охват по внутренним материалам, затем ищет внешнюю информацию и, наконец, записывает результат в рабочую директорию согласно структуре, заданной навыком. Внутренние материалы, внешние источники и формат вывода имеют четкую принадлежность, что упрощает последующее обслуживание.

<details>

<summary>Почему после привязки базы знаний нет результатов извлечения?</summary>

Убедитесь, что база знаний обработана и содержит извлекаемое содержимое, затем проверьте, сохраняется ли привязка в окне редактирования Agent. После удаления базы знаний соответствующие привязки удаляются автоматически.

</details>

<summary>Нужно ли перезапускать задачу после активации навыка?</summary>
