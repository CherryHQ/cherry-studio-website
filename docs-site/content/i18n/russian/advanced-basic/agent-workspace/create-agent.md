# Создание Agent и распределение ролей моделей

Точка входа: левая навигация [Рабочая область] → [Добавить агента].

Мастер создания состоит из четырёх шагов: [Основная информация], [Системный промпт], [Навыки] и [База знаний]. На первом шаге также необходимо выбрать режим работы; режим работы определяет доступное распределение ролей моделей, режим прав и часть инструментов для Agent. После создания режим работы изменить нельзя.

### Как выбрать режим работы

| Режим работы | Основные особенности | Конфигурация моделей | Права и ограничения |
| ------------------ | ------------------- | -------------------- | ------------------------------------ |
| [Усиленный: Claude Agent] | Полный набор возможностей, подходит для сложных многошаговых задач | Основная модель, модель Plan, модель Small | Поддерживает все режимы прав и проверку активности (heartbeat) |
| [Быстрый: Pi] | Быстрый отклик, низкие затраты, подходит для повседневных файловых и кодинг-задач | Настраивается только основная модель | Не предоставляет [Только планирование]; при создании по умолчанию [Умное одобрение] |
| [DeepSeek Harness] | Совместим с различными сервисами моделей, поддерживает целеориентированное выполнение | Настраивается только основная модель | Не предоставляет [Умное одобрение] и проверку активности (heartbeat); поддерживает `/compact`, `/goal` |

{% hint style="warning" %}
Режим работы нельзя изменить после создания. Если цели, совместимость моделей или требования к правам фундаментально меняются, создайте нового Agent, а не продолжайте редактировать старого.
{% endhint %}

### Как заполнить четыре шага

{% stepper %}
{% step %}
#### 1. Основная информация

Название должно отражать роль или тип задачи, например «Проверка контрактов», «Контент-планирование». Сначала выберите режим работы, затем выберите совместимые модели из списка на странице. Описание используется только для помощи в идентификации назначения; основная модель отвечает за основное рассуждение и выполнение.
{% endstep %}

{% step %}
#### 2. Написание системного промпта

Чётко укажите роль, цели, границы и формат вывода. Вместо набора прилагательных лучше дать исполнимые правила: сначала перечислите риски, затем приведите цитаты из оригинала, в конце дайте рекомендации по исправлению; при недостатке данных явно отметьте это, не догадывайтесь.
{% endstep %}

{% step %}
#### 3. Выбор навыков

Выбирайте только те навыки, которые связаны с долгосрочным способом работы этого Agent. Навыки можно установить через [Настройки] → [Навыки], а также позже попросить Agent найти и установить их.
{% endstep %}

{% step %}
#### 4. Привязка базы знаний

Привязывайте только те базы знаний, которые действительно нужны Agent для поиска. Если база знаний не привязана, инструменты поиска и управления базой знаний не появятся в списке инструментов этого Agent.
{% endstep %}
{% endstepper %}

### Продолжение настройки после создания

В списке Agent откройте меню и выберите «Редактировать», чтобы настроить следующие параметры:

* [Основное]: просмотр режима работы, а также настройка моделей, прав и параметров проверки активности (heartbeat), поддерживаемых этим режимом;
* [Промпт]: описание роли, правила обработки и поведенческие границы;
* [Встроенные инструменты]: файлы, поиск, изображения, уведомления, запланированные задачи, память, суб-агенты и рабочие процессы;
* [База знаний]: ограничение баз знаний, доступных Agent;
* [MCP]: привязка уже подключённых серверов MCP;
* [Навыки]: выбор установленных навыков;
* [Дополнительно]: настройка переменных окружения для действительно необходимых инструментов.

{% hint style="info" %}
Текущее окно редактирования автоматически сохраняет изменения. Если перед закрытием окна есть несохранённый контент, приложение сначала завершит сохранение; при неудаче сохранения окно останется открытым и отобразит ошибку.
{% endhint %}

### Рекомендуемая стартовая точка

| Параметр | Значение по умолчанию | Рекомендуемая стартовая точка | Назначение | Сценарии применения | Примечания |
| --------------- | ----------------------------- | ----------------------- | -------------- | ------------------ | ---------------------------------- |
| Режим работы | [Усиленный: Claude Agent] | При неопределённости сначала используйте [Усиленный: Claude Agent] | Определяет распределение ролей моделей, права и диапазон инструментов | Все Agent | Нельзя переключить после создания |
| Основная модель | Используется модель, выбранная при создании | Выберите модель, проверенную на стабильный вызов инструментов | Основное рассуждение и выполнение | Все Agent | Селектор фильтрует несовместимые модели в зависимости от режима работы |
| Модели Plan / Small | Те же, что и основная модель | Сначала оставьте совпадающими с основной моделью | Декомпозиция задач, простые решения и форматирование | Только [Усиленный: Claude Agent] | Pi и DeepSeek Harness не отображают эти поля |
| Режим прав | Для Claude/DSH — [Подтверждение по каждому действию]; для Pi — [Умное одобрение] | Для реальных проектных каталогов предпочтительно [Подтверждение по каждому действию] | Определяет, требуется ли одобрение для инструментов | Файловые, терминальные и сетевые задачи | [Полный доступ] может удалить файлы или получить доступ к сети |
| Проверка активности (heartbeat) | В поддерживаемых режимах работы включена по умолчанию, интервал 30 минут | Можно отключить, если нет постоянных задач | Позволяет Agent периодически проверять работу | Claude Agent, Pi | DeepSeek Harness не предоставляет проверку активности (heartbeat); для фиксированного времени используйте запланированные задачи |

### Пример пользователя: Agent проверки контрактов

Создайте Agent «Проверка контрактов», выберите проверенную основную модель, в промпте потребуйте вывод по структуре «Рискованные пункты, местоположение в оригинале, влияние, рекомендации», привяжите корпоративную базу знаний, оставьте права на уровне [Подтверждение по каждому действию]. Для каждого контракта создавайте новую задачу и выбирайте соответствующий каталог файлов, чтобы избежать смешивания данных разных клиентов в одном контексте.

<details>

<summary>Почему при создании я не увидел полные настройки MCP и прав? </summary>

Мастер создания содержит только часто используемые шаги. После завершения создания откройте окно редактирования Agent, где можно продолжить настройку в разделах [Основное], [Встроенные инструменты], [База знаний], [MCP], [Навыки] и [Дополнительно]; конкретные вкладки меняются в зависимости от возможностей режима работы.

</details>
