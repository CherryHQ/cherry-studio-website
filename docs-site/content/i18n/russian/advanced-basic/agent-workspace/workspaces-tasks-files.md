# Рабочая директория, задачи и файлы

<details>

<summary>Какие файлы нельзя редактировать напрямую?</summary>

Двоичные файлы, текстовые файлы, не являющиеся UTF-8, и файлы большого размера доступны только для просмотра или открытия во внешних приложениях. Их по-прежнему можно обрабатывать с помощью инструментов Agent, но они не всегда поддерживают редактирование в встроенном редакторе.

</details>
