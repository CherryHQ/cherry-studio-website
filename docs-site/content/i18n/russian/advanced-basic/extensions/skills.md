# Навыки и библиотека возможностей

Навык — это набор переиспользуемых инструкций и сопутствующих ресурсов. Он не отвечает за подключение к внешним системам, а указывает Agent, какой процесс, стандарты и формат следует использовать для выполнения задачи.

{% hint style="success" %}
Если вам нужен определённый метод работы, сначала сообщите Agent в разделе [Работа] о вашей цели и попросите его найти или установить подходящий навык. Открывайте [Настройки] → [Навыки] только в том случае, если нужно проверить источник, управлять навыками в пакетном режиме или импортировать их из локального хранилища.
{% endhint %}

### Установка навыков

Ручной путь: [Настройки] → [Навыки].

Страница поддерживает четыре источника:

* Поиск в онлайн-реестре навыков;
* Выбор [GitHub] в онлайн-поиске и вставка ссылки на файл `SKILL.md` конкретного навыка;
* Установка из локального ZIP-файла;
* Установка из папки, содержащей `SKILL.md`.

<figure><img src="../../../../assets/f0dcb151fa939ce15cda1e00.webp" alt="① После выбора [GitHub] вставьте ссылку на файл SKILL.md целевого навыка; страница сначала проанализирует конкретный навык, а затем предложит его установить."><figcaption><p>① После выбора [GitHub] вставьте ссылку на файл `SKILL.md` целевого навыка; страница сначала проанализирует конкретный навык, а затем предложит его установить. </p></figcaption></figure>

{% stepper %}
{% step %}
#### 1. Сначала определите назначение

Опишите одной фразой, какую проблему должен решить навык, например: «структурировать протоколы совещаний в решения, ответственных и сроки». Схожие названия не означают одинаковый процесс, поэтому сначала ознакомьтесь с описанием, прежде чем устанавливать.
{% endstep %}

{% step %}
#### 2. Проверьте источник и содержимое

Откройте детали навыка, чтобы убедиться, что вы понимаете, какие действия он требует от Agent, содержит ли он скрипты, нужны ли дополнительные инструменты или внешние аккаунты. Не используйте навыки неизвестного происхождения для работы с чувствительными каталогами.
{% endstep %}

{% step %}
#### 3. Привяжите к Agent

Сначала убедитесь, что глобальный переключатель этого навыка включён в [Настройки] → [Навыки], затем откройте [Работа] → меню Agent → [Редактировать] → [Навыки] и включите его для этого Agent. Переключение навыков автоматически сохраняется вместе с конфигурацией Agent и вступает в силу с следующего сообщения.
{% endstep %}

{% step %}
#### 4. Проверьте на реальной задаче

Дайте Agent небольшой образец данных, проверьте, соответствуют ли шаги, формат вывода и граничные случаи ожиданиям, прежде чем использовать навык для пакетных или запланированных задач.
{% endstep %}
{% endstepper %}

### Глобальное включение и включение для Agent

<figure><img src="../../../../assets/a05d3125f16b5cb41dd2e05b.webp" alt="① Переключатель справа от карточки управляет тем, доступен ли навык для всех Agent; при выключении этот навык больше не отображается в окне редактирования Agent."><figcaption><p>① Переключатель справа от карточки управляет тем, доступен ли навык для всех Agent; при выключении этот навык больше не отображается в окне редактирования Agent. </p></figcaption></figure>

| Состояние | Действие | Когда использовать |
| -------- | ------------------------ | ------------------------- |
| Глобально включено | Навык появляется в списке доступных навыков Agent | Источник навыка доверен, и он может использоваться одним или несколькими Agent |
| Глобально выключено | Приостанавливает использование навыка всеми Agent, но сохраняет установленное содержимое | Временное отключение, устранение неполадок или ожидание проверки безопасности |
| Включено для Agent | Загружает навык только для текущего Agent | Процесс соответствует долгосрочным обязанностям текущего Agent |

<figure><img src="../../../../assets/f0dcb151fa939ce15cda1e00.webp" alt="Навыки и библиотека возможностей — Иллюстрация"><figcaption></figcaption></figure>

Выключение глобального переключателя не удаляет навык; после повторного включения всё равно необходимо проверить состояние включения для каждого Agent. Удаление же стирает содержимое навыка и очищает связанные записи.

### Как выбрать между навыками, промптами и MCP

| Потребность | Что выбрать | Причина |
| -------------- | ----------- | ------------- |
| Одноразовое требование | Промпт текущей задачи | Не нужно добавлять долгосрочную конфигурацию |
| Многократное переиспользование одного процесса | Навык | Позволяет одновременно хранить инструкции, шаблоны и ресурсы |
| Определение долгосрочной роли Agent | Системный промпт Agent | Должен соблюдаться в каждой задаче |
| Доступ к базе данных или внешним сервисам | MCP | Сам по себе навык не предоставляет возможности подключения |

### Пример от пользователя: навык для еженедельного отчёта команды

Команда оформила разделы еженедельного отчёта, тон, проверку данных и запрещённые формулировки в виде навыка и привязала его к Agent «Составление еженедельного отчёта». Еженедельно достаточно предоставлять материалы за неделю, и Agent выводит фиксированную структуру согласно навыку; если данные поступают из внешних систем, используется MCP, а учётные данные и детали API не записываются в текст навыка.

{% hint style="danger" %}
Удаление навыка убирает его из глобальной библиотеки возможностей и очищает связанные записи в рабочей области Agent. Перед выполнением убедитесь, что нет активных задач, использующих этот навык; для пользовательских навыков команды рекомендуется сохранять исходные файлы для возможности восстановления.
{% endhint %}
