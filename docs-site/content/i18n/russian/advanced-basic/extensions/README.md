# Расширение возможностей Agent

Agent уже оснащён встроенными инструментами для работы с файлами, поиска, изображений, памяти, рабочих процессов и запланированных задач. Добавляйте навыки, если вам нужен фиксированный метод работы, и MCP, если требуется подключение к внешним системам. Они решают разные задачи, поэтому не обязательно устанавливать всё ради «большего количества функций».

## Сначала определите, что нужно

| Потребность | Выбор |
| ----------------- | ---------- |
| Фиксированный набор шагов, шаблонов или чек-листов | Навыки |
| Запросы к базе данных, браузеру или сторонним системам | MCP |
| Поиск по собственным документам | База знаний |
| Чтение/запись файлов текущего проекта, генерация изображений или отправка уведомлений | Встроенные инструменты Agent |

{% hint style="success" %}
Самый удобный способ — описать цель в разделе 【Работа】, чтобы Agent помог определить, чего не хватает: навыков, MCP или базы знаний. Если нужно проверить источники, параметры подключения или права доступа, перейдите в 【Настройки】 для ручного управления.
{% endhint %}

## Последний шаг после установки

Глобальная установка или успешное подключение не означают, что каждый Agent может этим пользоваться. Откройте 【Работа】 → меню Agent → 【Редактировать】 и выберите нужные элементы в разделах 【Навыки】, 【MCP】 или 【База знаний】. Настройки вступают в силу с следующего сообщения.
