# Диагностика проблем MCP

<details>

<summary>Стоит ли удалить и повторно добавить сервер?</summary>

Сначала изучите журналы и исправьте ошибки по отдельности. Удаляйте и пересоздавайте сервер только в том случае, если конфигурация сильно повреждена и исходные данные можно получить заново. Перед удалением сохраните копию конфигурации без секретных ключей.

</details>
