# Автоматизация и внешние взаимодействия

Автоматизация в Cherry Studio — это не отдельный набор «настроек роботов». Agent выполняет работу, каналы обеспечивают приём и отправку сообщений с внешних платформ, запланированные задачи запускают Agent в заданное время, а heartbeat позволяет Agent периодически проверять свои фоновые процессы.

## Как эти компоненты взаимодействуют

| Компонент | Назначение | Типовые сценарии |
| ----- | --------------- | ------------------ |
| Agent | Выполняет задачи и формирует результаты | Сводки, проверки, написание текстов, обработка файлов |
| Канал | Принимает внешние сообщения и отправляет уведомления | Групповой бот Feishu, личные сообщения в Telegram |
| Запланированная задача | Запускает Agent в определённое время | Ежедневные и еженедельные отчёты, одноразовые напоминания |
| Heartbeat | Agent периодически проверяет фоновые процессы | Мониторинг длительных процессов, проверка ожидающих задач |

## Правильный порядок настройки

{% stepper %}
{% step %}
### 1. Сначала протестируйте задачу в разделе «Рабочая область»

Убедитесь, что модель, промпт, рабочая директория и инструменты Agent стабильно дают ожидаемый результат.
{% endstep %}

{% step %}
### 2. Затем попросите Agent помочь с настройкой канала

В диалоге с Agent укажите платформу и назначение, например: «Подключи этого Agent к группе Feishu для приёма запросов на ежедневный отчёт». Подготовьте права и учётные данные бота согласно инструкциям.
{% endstep %}

{% step %}
### 3. Проверьте статус через ручные настройки

Откройте «Настройки» → «Каналы», проверьте учётные данные, привязку к Agent, рабочую область, допустимый диапазон сессий и режим прав канала, затем отправьте тестовое сообщение.
{% endstep %}

{% step %}
### 4. Наконец, создайте запланированную задачу

Вы можете попросить Agent создать её или открыть «Настройки» → «Запланированные задачи» → «Создать». Выберите проверенного Agent, рабочую область, время и канал для уведомлений.
{% endstep %}
{% endstepper %}

## Проверка перед запуском

* Канал разрешает только необходимые сессии или ID каналов;
* Внешние точки входа используют «Наследовать настройки агента» или более строгие права;
* Промпт запланированной задачи не содержит изменяемых ключей и путей;
* Сначала выполните задачу вручную через «Запустить» и просмотрите запись о выполнении;
* При сбое вы можете найти соответствующую задачу в Cherry Studio, чтобы не путать «не отправлено» с «не выполнено».

## Пример использования: ежедневный операционный отчёт в рабочие дни

Agent «Ежедневный операционный отчёт» читает данные из рабочей директории и формирует отчёт на основе навыков команды. Канал Feishu доставляет результат в указанную группу, а запланированная задача запускается каждое утро в рабочие дни. Перед запуском сначала выполните задачу вручную, затем отправьте сообщение боту в Feishu для установки цели приёма, и только после этого активируйте расписание.

<details>

<summary>В чём разница между heartbeat и запланированной задачей? </summary>

Heartbeat заставляет Agent периодически проверять фоновые процессы, что подходит для сценария «есть ли новые события». Запланированная задача имеет чёткий план выполнения и историю запусков, что подходит для сценария «что делать в определённое время каждый день». Для регулярных ежедневных отчётов предпочтительнее использовать запланированные задачи.

</details>
