# Использование с Agent

После привязки базы знаний к Agent, он может искать и читать авторизованные материалы в многошаговых задачах. При необходимости обновления материалов можно включить управление базой знаний.

{% hint style="info" %}
Обычный диалог подходит для разовых вопросов и ответов, а Agent — для непрерывных исследований, сравнений, генерации файлов и пошаговой проверки. Agent имеет доступ только к базам знаний, привязанным в конфигурации.
{% endhint %}

## Различия между обычным диалогом и Agent

| Обычный диалог | Agent |
| ------------ | --------------- |
| Временный выбор базы знаний перед каждым сообщением | Долгосрочная привязка в конфигурации Agent |
| Подходит для мгновенных ответов и кратких сравнений | Подходит для многошаговых исследований и передачи файлов |
| Ответы в основном на основе извлеченных фрагментов | Может искать материалы и управлять базой знаний в соответствии с правами доступа |
| Диапазон материалов определяется текущим диалогом | Диапазон доступа определяется конфигурацией Agent |

## Настройка Agent с только для чтения доступом к базе знаний

{% stepper %}
{% step %}
### 1. Сначала проверьте готовность базы знаний

Убедитесь, что целевые материалы готовы, и выполните тест извлечения с реальными вопросами. Agent не может исправить отсутствие текста или ошибки в сегментации.
{% endstep %}

{% step %}
### 2. Откройте окно редактирования Agent

Перейдите в раздел [Рабочая область], выберите целевой Agent и откройте [Редактировать агента] в меню.
{% endstep %}

{% step %}
### 3. Привяжите минимально необходимые базы знаний

Откройте вкладку [Базы знаний] и нажмите [Добавить базу знаний]. Привязывайте только те базы, которые нужны для данной задачи, чтобы избежать взаимного влияния материалов из разных отделов или версий.
{% endstep %}

{% step %}
### 4. Включите поиск по базе знаний

Откройте [Встроенные инструменты] и включите [Поиск по базе знаний]. Для исследований только для чтения, ответов на вопросы, резюме и сравнений этого обычно достаточно.

<figure><img src="../../../assets/39a4ea66c712c2736e5ccf34.webp" alt="Поиск используется для чтения, управление — для изменения материалов; по умолчанию начинайте с минимальных прав."><figcaption><p>Поиск используется для чтения, управление — для изменения материалов; по умолчанию начинайте с минимальных прав. </p></figcaption></figure>
{% endstep %}

{% step %}
### 5. Тестируйте с четко ограниченными задачами

Попросите Agent сначала перечислить источники, а затем дать выводы. Если материалы не поддерживают утверждение, это должно быть явно указано; заполнение пробелов на основе общих знаний не допускается.
{% endstep %}

{% step %}
### 6. Проверьте источники и результаты

Проверьте, из какой базы знаний получен каждый вывод, разделены ли факты и рекомендации в файлах, и отмечены ли части, lacking доказательств.
{% endstep %}
{% endstepper %}

## Поиск и управление базой знаний

| Возможность | Что можно делать | Применимые задачи | Рекомендация по умолчанию |
| ----- | -------------- | ----------- | ----------- |
| Поиск по базе знаний | Поиск, перечисление и чтение привязанных баз знаний | Ответы на вопросы, исследования, резюме, сравнения | Оставить включенным |
| Управление базой знаний | Добавление, удаление или обновление документов в базе знаний | Утвержденное обслуживание материалов | По умолчанию выключено, включать временно по необходимости |

{% hint style="warning" %}
Привязка базы знаний предоставляет только диапазон доступа, не создает копию базы знаний. После обновления материалов или повторного индексирования Agent будет использовать обновленное содержимое при следующем поиске.
{% endhint %}

{% hint style="danger" %}
После включения [Управление базой знаний] добавление, удаление и обновление изменят материалы или индексы. Перед утверждением подтвердите целевую базу знаний, конкретные записи, способ разрешения конфликтов с одинаковыми именами и план отката.
{% endhint %}

## Рекомендуемые шаблоны задач

### Исследование и генерация отчета

> Найдите все правила, касающиеся утверждения командировок за рубежом и страхования, в привязанных базах знаний. Сначала перечислите источники и противоречия, затем сгенерируйте контрольный список в формате Markdown. Не заполняйте содержимое, не поддерживаемое материалами.

### Обновление часто задаваемых вопросов

> Найдите существующие записи о возмещении расходов на проживание, сравните последние правила со старыми FAQ. Сначала предоставьте список предполагаемых изменений; после утверждения обновите соответствующие документы.

### Сравнение нескольких баз знаний

> Найдите доказательства в базах знаний «Справочник по продукту» и «Кейсы послепродажного обслуживания», оформите их в три столбца: «Официальные правила / Реальные кейсы / Рекомендуемые формулировки». Сохраняйте название источника для каждого вывода.

## Пояснения к настройкам

| Параметр | Рекомендуемая начальная точка | Когда увеличивать | Контроль рисков |
| ----- | ---------- | ------------ | ------------- |
| Привязка баз знаний | 1 связанная с задачей база | При реальной необходимости сравнения между базами | Четко укажите назначение каждой базы в промпте |
| Поиск по базе знаний | Включено | Если задача требует поиска материалов | Проверьте, что источники находятся в привязанном диапазоне |
| Управление базой знаний | Выключено | При явной необходимости добавления, удаления или обновления | Утверждайте по пунктам, сначала сделайте резервную копию важных материалов |
| Требования к выводу | Разделяйте факты, выводы и рекомендации | При необходимости генерации отчетов или файлов | Сохраняйте название источника для каждого факта |

## Пример использования

Сяо Линь привязал [Официальный справочник] и [Кейсы проверки] к Agent послепродажного обслуживания, включив только поиск по базе знаний. Он потребовал, чтобы Agent перечислил предупреждения о безопасности, официальные шаги и рекомендации из кейсов по моделям устройств, разделяя эти три категории. Когда обнаружил, что старые кейсы требуют обновления, он временно включил инструмент управления, сначала просмотрел список предполагаемых изменений, а затем утвердил их.

Критерии завершения: Agent не имеет доступа к непривязанным материалам, не записывает рекомендации из кейсов как официальные правила, все операции записи имеют четкую цель и результат проверки.

## Проверка результатов

* Источники получены только из баз знаний, привязанных к текущему Agent.
* Результаты поиска покрывают все условия задачи.
* В результатах разделены факты из материалов, выводы Agent и рекомендации.
* Операции управления описывают цель, влияние и результат.
* После обновления материалов повторно выполните фиксированные вопросы для проверки извлечения.

## Часто задаваемые вопросы

<details>

<summary>Обычный диалог находит результаты, почему Agent не находит? </summary>

Проверьте, привязана ли целевая база знаний к текущему Agent, и включен ли [Поиск по базе знаний]. Диапазоны привязки разных Agent не наследуются друг от друга.

</details>

<details>

<summary>Когда не следует включать управление базой знаний? </summary>

Для исследований только для чтения, общих для команды баз знаний и баз с сохранением исторических версий по умолчанию включается только поиск. При необходимости обновления временно включите управление и утверждайте по пунктам.

</details>

<details>

<summary>Что делать, если Agent хочет работать с непривязанной базой знаний? </summary>

Не расширяйте доступ до всех баз знаний. Убедившись, что задача действительно этого требует, добавьте целевую базу к текущему Agent или используйте Agent, к которому эта база уже привязана.

</details>
