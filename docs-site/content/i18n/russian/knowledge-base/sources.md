# Добавление и организация материалов

База знаний поддерживает файлы, заметки Cherry Studio, локальные каталоги и отдельные веб-адреса. После импорта необходимо проверить статус обработки, текст и Chunks, а при обновлении материалов — пересоздать индекс.

{% hint style="info" %}
Критерием готовности является не просто наличие файла в списке, а возможность чтения материала, целостность Chunks и способность системы возвращать правильные источники на реальные вопросы.
{% endhint %}

## Выбор правильного способа добавления

<figure><img src="../../../assets/4622da2093d43942d7ee443e.webp" alt="Выбирайте способ добавления в зависимости от источника: для небольшого количества файлов используйте [Файлы], для набора однотипных файлов — [Каталог], для контента Cherry Studio — [Заметки], для публичных веб-страниц — [Ссылка]."><figcaption><p>Выбирайте способ добавления в зависимости от источника: для небольшого количества файлов используйте [Файлы], для набора однотипных файлов — [Каталог], для контента Cherry Studio — [Заметки], для публичных веб-страниц — [Ссылка].</p></figcaption></figure>

| Способ | Для каких материалов подходит | Связь после импорта | Основные моменты |
| -- | ----------------------- | ----------- | ------------------ |
| Файлы | PDF, Office, Markdown, текст и т. д. | Сохраняется управляемая копия | Максимум 20 элементов за один раз |
| Заметки | Уже структурированный контент в Cherry Studio | Импортируется снимок содержимого на момент импорта | Последующие изменения исходной заметки не синхронизируются автоматически |
| Каталог | Набор локальных файлов по одной теме | Создаются записи на основе содержимого каталога | Не импортируйте каталоги с нерелевантным содержимым целиком |
| Ссылка | Отдельная публично доступная веб-страница | Сохраняется снимок страницы на момент получения | Страницы с авторизацией, рендерингом через скрипты или ограничениями доступа могут быть неполными |

{% hint style="warning" %}
Поддерживаемые файлы: PDF, DOCX, DOC, PPTX, XLSX, XLS, MD, TXT, CSV, HTML и EPUB. Для сканированных PDF или изображений также необходимо проверить OCR.
{% endhint %}

## Добавление и проверка материалов

{% stepper %}
{% step %}
### 1. Выбор источника материалов

Откройте базу знаний, нажмите кнопку добавления материалов и выберите [Файлы], [Заметки], [Каталог] или [Ссылка].
{% endstep %}

{% step %}
### 2. Подтверждение выбранного содержимого

Файлы и заметки можно выбирать пакетно; при интерактивном добавлении за один раз допускается не более 20 элементов. Если материалов много, добавляйте их партиями или используйте способ [Каталог].
{% endstep %}

{% step %}
### 3. Разрешение конфликтов имен

Если новое материал имеет то же имя, что и существующая запись, выберите [Сохранить все] или [Заменить]. При обновлении регламентов, руководств и снимков заметок обычно выбирают [Заменить].

{% hint style="warning" %}
Выбор [Сохранить все] приводит к тому, что старые и новые версии одновременно участвуют в поиске. Делайте это только если действительно нужно параллельно искать разные версии, и указывайте дату или версию в имени.
{% endhint %}
{% endstep %}

{% step %}
### 4. Ожидание завершения обработки

Материалы проходят этапы копирования, чтения, разбивки и индексации. Если модель эмбеддингов не настроена, векторы не создаются, но ключевой индекс формируется.

<figure><img src="../../../assets/2414cfc005a860f127a4fd96.webp" alt="После того как материал перейдет в статус «доступен», проверьте текст и Chunks выборочно."><figcaption><p>После того как материал перейдет в статус «доступен», проверьте текст и Chunks выборочно. </p></figcaption></figure>
{% endstep %}

{% step %}
### 5. Выборочная проверка текста и Chunks

Откройте материал для просмотра текста или посмотрите Chunks через меню строки материала. Особое внимание уделяйте порядку заголовков, таблицам, тексту OCR и тому, не разорваны ли важные предложения.
{% endstep %}

{% step %}
### 6. Проведение теста поиска

Используйте вопрос с однозначным ответом, чтобы проверить правильность источника и фрагмента. После обновления материалов повторите тест с тем же набором вопросов.

<figure><img src="../../../assets/b44776524449cdefe62eaed3.webp" alt="Итоговая проверка должна оценивать источник, полноту фрагмента и порядок выдачи, а не только наличие результата."><figcaption><p>Итоговая проверка должна оценивать источник, полноту фрагмента и порядок выдачи, а не только наличие результата. </p></figcaption></figure>
{% endstep %}
{% endstepper %}

## Статус материалов и способы обработки

| Симптом | Возможная причина | Способ решения |
| ----------- | ------------------ | ------------------ |
| Долгая обработка | Большой размер файла, недоступность парсера или модели | Проверьте исходный файл, обработку документов и модель эмбеддингов |
| Отображается ошибка | Сбой копирования, чтения, разбивки или индексации | Откройте сообщение об ошибке и устраните проблему на соответствующем этапе |
| Отсутствие текста или нечитаемый текст | Несоответствие обработчика документов, сканированный контент без OCR | Смените способ обработки документов или настройте OCR |
| В Chunks отсутствуют важные предложения | Неправильные границы разбивки | Отрегулируйте разбивку и выполните [Пересоздать индекс] |
| Одновременно выдаются старые и новые версии | Для материалов с одинаковым именем выбрано [Сохранить все] | Удалите старые записи или импортируйте заново, выбрав [Заменить] |

## Пересоздание индекса и удаление

После изменения настроек разбивки, парсера или эмбеддингов старые записи не обновляются автоматически. Используйте [Пересоздать индекс] для отдельного материала или выберите несколько материалов и пересоздайте индекс пакетно.

{% hint style="danger" %}
Удаление записи удаляет управляемую копию и индекс из текущей базы знаний. Это не удаляет исходные файлы или исходные заметки, но перед удалением убедитесь, что в базе знаний нет единственной копии.
{% endhint %}

## Пример пользователя

Сяо Линь ежемесячно обновляет правила командировок. Он импортирует новый файл с тем же именем и выбирает [Заменить]. После завершения обработки он выборочно проверяет текст и Chunks, затем тестирует правила проживания, транспорта и согласования с помощью фиксированных вопросов.

Критерием готовности является: старые правила больше не появляются в результатах поиска, а условия и суммы новых правил стабильно находятся.

## Частые вопросы

<details>

<summary>Обновится ли база знаний автоматически после изменения исходной заметки? </summary>

Нет. При импорте заметки сохраняется снимок содержимого на тот момент. После изменения необходимо заново добавить материал и выбрать [Заменить] или выполнить [Пересоздать индекс] для соответствующего материала.

</details>

<details>

<summary>Почему с веб-страницы извлекается только часть содержимого? </summary>

Страницы, требующие входа, зависящие от рендеринга скриптами или имеющие ограничения доступа, могут быть извлечены не полностью. Можно сохранить текст в файл или заметку и затем импортировать.

</details>

<details>

<summary>Удаление записи из базы знаний удалит исходный файл? </summary>

Исходные файлы и исходные заметки не удаляются, но управляемая копия и индекс удаляются из базы знаний.

</details>
