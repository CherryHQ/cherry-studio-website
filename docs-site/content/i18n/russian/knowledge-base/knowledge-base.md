# Начало работы с базами знаний

База знаний объединяет файлы, заметки, папки и веб-страницы для повторного поиска. Перед использованием в чате или с Agent убедитесь, что поиск находит нужные фрагменты.

{% hint style="info" %}
Модель эмбеддингов необязательна. Выберите **Не использовать (None)**, чтобы начать с поиска по ключевым словам BM25. Для поиска по смыслу можно добавить модель позже. Модель переранжирования также необязательна.
{% endhint %}

## Создайте первую базу

1. <a id="создание-базы-знаний"></a>Откройте **База знаний** в левой навигации и нажмите кнопку добавления над списком. Укажите конкретную тему, например «Правила командировок сотрудников».

2. <a id="добавление-модели-встраивания"></a>Для первого теста установите **Модель эмбеддингов** в **Не использовать (None)**. Добавьте модель, если поиск должен учитывать синонимы и переформулированные вопросы.

3. <a id="добавление-данных-из-различных-источников"></a><a id="добавление-файлов-и-их-векторизация"></a>Откройте базу и добавьте **Файл**, **Заметку**, **Папку** или **Ссылку**. Начните с небольшого объёма подходящих материалов.

4. Дождитесь завершения обработки. Проверьте извлечённый текст и **Chunks**: нет ли нечитаемых символов, пропущенных страниц или неверного порядка.

5. <a id="поиск-в-базе-знаний"></a>Откройте **Тест поиска (Retrieval Test)** и задайте реальный вопрос с известным ответом. Убедитесь, что правильный источник появляется среди первых результатов.

6. <a id="использование-базы-знаний-в-диалогах"></a>Когда поиск работает надёжно, выберите базу в области ввода чата или привяжите её на странице редактирования Agent.

![Источники: файлы, заметки, папки и ссылки](../../../assets/4622da2093d43942d7ee443e.webp)

## Проверка перед использованием ответов

Сохраните 3–5 реальных вопросов и повторяйте тест после изменения данных или настроек. Если поиск неудачен, сначала проверьте текст и Chunks. Чат-модель не может восстановить важные сведения, которые поиск не нашёл.

Стоимость и обработка данных облачных моделей эмбеддингов и переранжирования зависят от провайдера. Материалы с разными требованиями доступа храните в отдельных базах.
