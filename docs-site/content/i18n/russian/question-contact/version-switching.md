# Обновление и откат версии

При переключении между V1 и V2 сначала выберите соответствующее руководство:

* [Различия в функциях](../cherry-studio/installation/v1-v2-feature-differences.md)
* [Обновление с V1 до V2](../cherry-studio/installation/v1-to-v2-migration.md)
* [Откат с V2 до V1](../cherry-studio/installation/v2-to-v1-downgrade.md)

{% hint style="danger" %}
Перед переключением версии сначала создайте полный резервный копию в приложении, затем полностью выйдите из Cherry Studio и скопируйте весь каталог данных. Резервные копии V1 и V2 несовместимы между собой.
{% endhint %}

## Миграция данных с V1 на V2

В версии V2.0.2 поддерживается прямая миграция с V1.9.13, промежуточная версия V2.0.0 больше не требуется.

| Текущая ситуация | Рекомендуемые действия |
| --------------- | ---------------------------------- |
| Вы все еще используете V1 и хотите сохранить данные | Обновите V1 до 1.9.13, затем установите V2.0.2 для завершения миграции. |
| Вы уже используете V2 | Просто обновите до V2.0.2 и продолжайте использовать текущие данные V2. |
| Предыдущая миграция с V1 завершилась ошибкой или данные были потеряны | Только после создания полного резервного копирования текущих данных V2 используйте функцию [Повторная миграция]. |
| Данные V1 не нужны | Можно выбрать [Игнорировать и использовать значения по умолчанию], но данные V1 не будут импортированы. |

{% hint style="danger" %}
Функция [Повторная миграция] в разделе [Настройки] → [Данные] безвозвратно удаляет текущие данные V2 и повторно импортирует их из исходных данных V1. Она не объединяет данные с обеих сторон; не нажимайте на эту кнопку, если миграция с V1 не завершилась ошибкой и данные не были потеряны.
{% endhint %}
