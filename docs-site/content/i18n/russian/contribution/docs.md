# Участие в подготовке документации

## Как предложить изменения

1. Нажмите **Edit on GitHub** внизу страницы, чтобы открыть [репозиторий сайта](https://github.com/CherryHQ/cherry-studio-website). Редактируйте исходник в своей ветке или форке.

2. Исходники находятся в `docs-site/content/`, переводы — в языковых каталогах `i18n/`. При добавлении, перемещении или удалении страницы обновите `SUMMARY.md` соответствующего языка. Изображения храните в `docs-site/content/assets/` и используйте относительные пути.

3. После предпросмотра и проверки создайте Pull Request в `main`. Опишите проблему, изменённые страницы и способ проверки. Документация поддерживается только в репозитории сайта; запрашивать доступ к GitBook и менять старый репозиторий документации больше не нужно.

Можно также [создать issue](https://github.com/CherryHQ/cherry-studio-website/issues), указав URL страницы и предлагаемое исправление. Скройте API-ключи и личные данные на снимках экрана.

## Локальный просмотр и проверка

Выполните команды из корня репозитория и откройте `/docs/ru/` на локальном сервере. Перед отправкой выполните также команды проверки ниже.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

```sh
pnpm docs:test
pnpm build:cn
pnpm docs:verify
```

Исправляйте ошибки из `docs-site/generated/report.json` в исходниках `content/`, а не в сгенерированных файлах. Проверьте ссылки, изображения, мобильный вид и реальные действия в продукте. Сверяйте переводы с актуальным китайским оригиналом.
