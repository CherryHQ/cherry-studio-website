# Быстрый старт

Выполните эти шаги, чтобы за несколько минут настроить модель и отправить первое сообщение.

## 1. Установите Cherry Studio

Скачайте пакет для вашей операционной системы и процессора с [официальной страницы](https://cherryai.com/download). При проблемах обратитесь к разделу [Скачивание и установка](../cherry-studio/installation/README.md).

## 2. Выберите поставщика моделей

Откройте **Настройки → Сервисы моделей**. Если у вас еще нет API-ключа, воспользуйтесь [кратким справочником поставщиков](../pre-basic/providers/quick-reference.md), учитывая регион, возможности моделей и требования к конфиденциальности.

## 3. Добавьте и включите модель

Откройте настройки поставщика, введите API-ключ, получите список моделей, добавьте модель для чата и включите поставщика. Подробнее см. в разделе [Настройка сервиса моделей](../pre-basic/settings/providers.md).

## 4. Отправьте первое сообщение

Вернитесь в **Чат**, создайте или откройте ассистента, выберите добавленную модель и отправьте сообщение. Полученный ответ подтверждает, что базовая настройка работает.
