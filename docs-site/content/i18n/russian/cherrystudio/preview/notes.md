# Заметки

Заметки — это встроенный в Cherry Studio редактор Markdown, который позволяет организовывать идеи, сохранять промежуточные результаты и дополнительно обрабатывать их с помощью возможностей ИИ и базы знаний.

### Открытие заметок

Нажмите на вкладку [Заметки] в верхней панели вкладок или на значок приложения [Заметки] в [Панели запуска].

<figure><img src="../../../../assets/14e04a73fa23719ebd35dde4.webp" alt=""><figcaption><p>Интерфейс заметок: слева — дерево каталогов и список заметок, справа — редактор Markdown</p></figcaption></figure>

### Создание первой заметки

1. Нажмите на первый значок [Создать заметку] в левом верхнем углу
2. Введите текст в редакторе справа; поддерживается синтаксис Markdown и панель инструментов для форматирования
3. Щелкните правой кнопкой мыши по заметке в списке и задайте ей имя

### Импорт существующих файлов Markdown

* Просто **перетащите** файл `.md` или каталог, содержащий файлы `.md`, в область заметок, чтобы импортировать их как новую заметку или новую папку
* Также можно сначала создать структуру каталогов, нажав на второй значок [Создать папку] в левом верхнем углу, а затем перетащить файлы в нужную папку

### Возможности редактора

Верхняя панель инструментов редактора заметок предоставляет основные функции форматирования:

* **Форматирование**: жирный (<kbd>B</kbd>), курсив (<kbd>I</kbd>), подчёркивание (<kbd>U</kbd>), зачёркивание
* **Структура**: код в строке / заголовки H1–H3 / маркированный список / нумерованный список / блок кода / цитата / список задач / формулы
* **Вставка**: таблицы, гиперссылки

<figure><img src="../../../../assets/d391f5ca5d92cb8fdf22ca63.webp" alt=""><figcaption><p>Редактор после создания заметки и ввода текста</p></figcaption></figure>

В нижней строке состояния отображается текущее **количество символов**. Значок **A✓** в левом нижнем углу включает или отключает проверку орфографии. В правом нижнем углу можно переключиться между режимами **живого предпросмотра**, **редактирования исходного кода** или **режима чтения**.

### Управление каталогами

В верхней части левой боковой панели расположены кнопки: [Создать заметку] / [Создать папку] / [Сортировка] / [Избранное] / [Поиск].

* **Сортировка**: 6 вариантов — по имени файла `A→Z` / `Z→A`, по времени обновления (от новых к старым / от старых к новым), по времени создания (от новых к старым / от старых к новым)
* **Избранное**: кнопка со звездой переключает на вид «Избранное»
* **Поиск**: кнопка с лупой; введите запрос в поле поиска. **Поиск совпадает как по заголовкам, так и по тексту**. Для записей, найденных по тексту, рядом с заголовком отображается метка «Содержимое» или «Имя + Содержимое» для указания источника

### Контекстное меню (интеграция с ИИ + экспорт)

Щелчок правой кнопкой мыши по любой заметке в дереве каталогов слева открывает меню действий — это входная точка для интеграции с ИИ и экспорта в различные форматы:

<figure><img src="../../../../assets/fd4004b475c63d7c924304e8.webp" alt=""><figcaption><p>Меню, открывающееся при щелчке правой кнопкой мыши по одной заметке</p></figcaption></figure>

* **Сгенерировать название заметки** ✨: ИИ автоматически генерирует заголовок на основе текста (доступно только для файлов)
* **Переименовать** / **Открыть во внешней программе** (показать в Finder / Проводнике)
* **Добавить в избранное** / **Убрать из избранного**
* **Экспортировать заметку в базу знаний**: отправить в указанную [базу знаний](../../knowledge-base/knowledge-base.md)
* **Экспорт ›** подменю: Markdown / Word (.docx) / Notion / Yuque / Obsidian / Joplin / Siyuan, а также «Копировать как изображение / Экспортировать как изображение» — отображение каждого пункта можно индивидуально включать или отключать в [Настройки] → [Настройки данных] → [Настройки меню экспорта]
* **Удалить**

> Контекстное меню папок более лаконичное, содержит только: Создать заметку / Создать папку / Переименовать / Открыть во внешней программе / Удалить.

### Меню [⋯] в правом верхнем углу (быстрый доступ к виду и экспорту)

Кнопка [⋯] в правом верхнем углу заголовка заметки — это **быстрый доступ** к настройкам вида и экспорта **текущей заметки**. Не путайте её с контекстным меню:

<figure><img src="../../../../assets/b9b3ab0b2050382f16409b48.webp" alt=""><figcaption><p>Меню [⋯] в правом верхнем углу</p></figcaption></figure>

* **Копировать содержимое**: копирование в виде обычного текста
* **Экспортировать в Word**: быстрое создание файла `.docx` (для большего выбора форматов используйте пункт «Экспорт ›» в контекстном меню)
* **Экспортировать в PDF**: экспорт текущей заметки в файл PDF
* **Печать**: вызов системной печати текущей заметки
* **Сужение ширины колонки**: ограничение максимального количества символов в строке
* **Показать оглавление**: отображение дерева заголовков текущей заметки справа
* **Настройки шрифта ›**: по умолчанию / шрифт с засечками, три размера (малый / средний / крупный)
* **Дополнительные настройки**: открытие панели настроек заметок (три группы: данные / редактор / отображение)

### Рабочий каталог и резервное копирование

Содержимое заметок хранится в виде локальных файлов. **Рабочий каталог** можно просмотреть и изменить в разделе [Настройки данных] панели настроек заметок (открывается через [⋯] в правом верхнем углу → [Дополнительные настройки]).

* По умолчанию файлы хранятся в каталоге данных приложения Cherry Studio
* Сначала выберите [Путь] для кастомного расположения, затем нажмите [Применить] для переключения (изменения не перемещают существующие файлы автоматически, их нужно скопировать вручную); нажмите [Сбросить по умолчанию], чтобы вернуть стандартный каталог
* Для резервного копирования рекомендуется использовать [WebDAV](../../pre-basic/data-settings/webdav.md) / [S3-совместимое хранилище](../../pre-basic/data-settings/s3-compatible.md)

### Настройки редактора и отображения

Откройте панель настроек заметок через [⋯] в правом верхнем углу → [Дополнительные настройки]. Помимо [Настроек данных], доступны две другие группы:

**Настройки редактора**

* **Вид по умолчанию**: новый режим для новых заметок — [Режим редактирования] или [Режим чтения]
* **Вид редактирования по умолчанию**: в режиме редактирования используется [Живой предпросмотр] или [Режим исходного кода]

**Настройки отображения**

* **Шрифт**: по умолчанию / шрифт с засечками
* **Размер шрифта**: от 10 до 30 px
* **Сужение ширины колонки**: ограничение количества символов в строке, чтобы длинные строки не растягивались на весь экран
* **Показать оглавление**: отображение дерева заголовков текущей заметки справа для навигации по тексту

> Шрифт и его размер можно настроить как в этой панели настроек отображения, так и быстро переключить через [⋯] в правом верхнем углу → [Настройки шрифта].

### Советы и рекомендации

* Заметки поддерживают синтаксис списков задач `- [ ]`, что удобно для ведения ежедневных списков дел
* Перетащите файлы `.md` (или каталог, содержащий `.md`) в дерево каталогов для пакетного импорта
* Если после восстановления настроек на другом устройстве каталог заметок пуст, просто скопируйте файлы вручную по указанному пути

{% hint style="info" %}
Чтобы ИИ мог **напрямую** отвечать на вопросы на основе содержимого заметок, самый удобный способ — **экспортировать** нужную заметку **в базу знаний**, а затем включить эту базу знаний в диалоге.
{% endhint %}
