# Быстрый старт

Выполните эти четыре шага, чтобы отправить первое сообщение.

## 1. Добавьте провайдера

Откройте раздел сервисов моделей в настройках приложения и выберите встроенного провайдера. Для совместимого API создайте своего провайдера и укажите его Base URL.

## 2. Укажите учётные данные

Введите API-ключ, выданный провайдером, затем сохраните настройку или проверьте подключение, как указано на экране. Никогда не передавайте ключ другим и не вставляйте его в публичные диалоги, снимки экрана или отчёты об ошибках.

## 3. Добавьте модель

Получите или добавьте модели провайдера и включите хотя бы одну. Поддержка диалога, распознавания изображений, инструментов и генерации изображений зависит от конкретной модели.

## 4. Отправьте сообщение

Вернитесь к диалогу, откройте ассистента по умолчанию или создайте нового, выберите модель и отправьте короткое сообщение. Полученный ответ подтверждает, что базовая настройка работает.

Далее прочитайте [Провайдеры и модели](providers-and-models.md) или познакомьтесь с разделом [Диалоги и файлы](chat-and-files.md).
