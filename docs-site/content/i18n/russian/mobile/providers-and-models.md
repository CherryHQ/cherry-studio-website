# Провайдеры и модели

Поставщик — это платформа, предоставляющая услуги ИИ; Модель — это конкретный ИИ, который вы используете на этой платформе. Одна и та же модель может быть доступна у нескольких поставщиков, каждый из которых имеет свои учетные данные.

Для начала введите **API ключ**, добавьте модель и включите провайдера. Ключ API — это учетные данные, которые провайдер выдает для доступа к своему сервису из приложения. Cherry Studio не предоставляет средства для оплаты использования моделей; доступность и стоимость зависят от вашей учетной записи у провайдера.

## Добавить встроенного провайдера

1. Откройте **Настройки → Модельный сервис** и нажмите кнопку «Добавить».
2. Найдите провайдера и нажмите **Добавить**. Встроенные записи предоставляют общие настройки подключения.
3. Введите ключ API этого провайдера. Сохраните предложенный адрес и опцию API, если поставщик не укажет иное.
4. Сохраните, получите список моделей, выберите нужные модели и подтвердите. Если список недоступен, добавьте модель вручную.
5. Завершите настройку и проверьте переключатель провайдера в списке сервисов модели. Включите его, если он остается отключенным, затем выберите модель в разговоре.

Отредактируйте существующего поставщика вместо того, чтобы добавлять его снова. Вы можете временно отключить поставщика и включить его позже.

## Добавить собственного поставщика

Используйте специального поставщика, если ваша платформа отсутствует в каталоге или предоставляет выделенный адрес.

1. Выберите **Пользовательский поставщик** и введите узнаваемое имя.
2. Выберите формат API, документированный платформой. OpenAI, Anthropic и Gemini описывают форматы подключения; выберите тот, который поддерживает ваша платформа.
3. Введите **Базовый URL**, базовый адрес, используемый для подключения к службе, и его ключ API.
4. Просмотрите отображаемый **URL запроса** и сохраните.
5. Получите модели или вручную добавьте точный идентификатор модели с платформы. Вернитесь к списку провайдеров и при необходимости включите его переключатель.

### Какой адрес входит в базовый URL?

Используйте базовый адрес провайдера, например `https://api.example.com/v1`. Не используйте страницу входа/панель управления и не вставляйте полный URL-адрес запроса, заканчивающийся на `/chat/completions`. Приложение добавляет путь запроса; включение его дважды приводит к неправильному адресу. Для распознанных полных URL-адресов отображается подсказка по исправлению.

Некоторым шлюзам требуется адрес без автоматически вставленной версии API. Если поставщик требует этого, добавьте `#`, например `https://api.example.com#`, и проверьте предварительный просмотр URL-адреса запроса. В остальных случаях не добавляйте `#`.

Поставщик, поддерживающий несколько API, может иметь отдельные адреса и значение по умолчанию API. Изменение значения по умолчанию может повлиять на модели, следующие ему; прочитайте подтверждение, прежде чем продолжить.

## Изменение провайдера и управление ключами

Откройте вкладку **Конфигурация** провайдера, чтобы отредактировать его имя, адрес и ключи. Дополнительные ключевые примечания, такие как «Личное» или «Резервное копирование», являются идентификационными метками и не меняют разрешения.

* Добавьте один ключ для каждой записи. Ключи можно редактировать, включать, отключать или удалять отдельно; не вставляйте несколько в одно поле.
* Закрытие редактора ключа оставляет изменения в черновике страницы. Нажмите **Сохранить** на странице провайдера, чтобы сохранить адрес и ключи вместе.
* Держите включенным хотя бы один действительный ключ. Провайдер, у которого отключены все ключи, не может делать обычные запросы.
* Подсказка об отмене изменений означает, что еще есть несохраненные изменения.

Поддерживаемые запросы чата могут попробовать использовать другой активированный ключ после ошибки авторизации или ограничения скорости, при условии, что ответ не начался. Это не распространяется на все ошибки, запросы создания изображений или списка моделей и не увеличивает кредиты на счете.

## Проверьте соединение

Сначала сохранитесь, откройте **Проверка модели**, выберите модель и запустите проверку. На странице отображается адрес запроса и результат.

Успех распространяется на эту конфигурацию и выбранную модель, а не на каждую модель на платформе. Проверка соединения не включает провайдера; проверьте его переключатель в списке провайдеров.

## Выберите модели и настройки по умолчанию

Средство выбора модели разговора меняет модель текущего агента. Поставщик должен быть включен, а модель доступна. Найдите или используйте фильтры **Все**, **Бесплатные** и **Визуальные**, чтобы сузить список. Если модели исчезнут, вернитесь к **Все**.

Фильтр «Визуальные» отражает сведения о поддержке ввода изображений, а «Бесплатные» — сведения о цене. Фактические возможности, бесплатные лимиты и квоты зависят от провайдера.

В **Настройки → Модель по умолчанию** выберите модель по умолчанию и модель чертежа. Выбор или очистка сохраняется немедленно. Существующие агенты сохраняют свой собственный выбор моделей; изменение глобального значения по умолчанию не приводит к обновлению каждого агента.
