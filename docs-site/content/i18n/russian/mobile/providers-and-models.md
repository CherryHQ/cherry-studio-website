# Провайдеры и модели

Мобильное приложение обращается к моделям через провайдеров, которых вы настраиваете. Cherry Studio отвечает за работу клиента: оно не перепродаёт кредиты на модели и не изменяет тарифы и правила обработки данных провайдера.

## Добавление встроенного провайдера

1. Откройте настройки сервиса моделей и выберите **Добавить провайдера**.
2. Найдите и выберите нужного провайдера.
3. Введите API-ключ и другие значения, которые требует этот провайдер.
4. Получите или добавьте модели, затем включите те, которые собираетесь использовать.

## Использование собственного провайдера

Если сервис реализует поддерживаемый формат API, выберите **Собственный провайдер** и укажите название, Base URL, API-ключ и идентификатор модели. В качестве Base URL используйте адрес API из документации провайдера, а не адрес его панели управления.

## Выбор модели

Откройте выбор модели в диалоге или у агента, чтобы переключаться между включёнными моделями. Поддержка распознавания изображений, вызова инструментов и генерации изображений зависит от провайдера и конкретной модели.

## Частые ошибки подключения

* **401 / не авторизовано**: проверьте, что API-ключ указан полностью, не истёк и у учётной записи есть нужные права.
* **404 / модель не найдена**: проверьте Base URL и идентификатор модели; не подставляйте отображаемое имя вместо идентификатора.
* **429 / слишком много запросов**: дождитесь сброса ограничения частоты и проверьте баланс и квоты у провайдера.
* **Тайм-аут или сетевая ошибка**: убедитесь, что из текущей сети доступен провайдер, и проверьте настройки прокси.
