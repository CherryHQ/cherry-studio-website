# Создание и редактирование файлов

Агент может сохранить текст в виде файла, чтобы вы могли просмотреть, изменить и поделиться им. Это подходит для контрольных списков, заметок о встречах, табличных данных и простых веб-страниц.

## Сохранить ответ в файл

Выберите текстовую модель, поддерживающую вызовы инструментов, и явно запросите **сохраненный файл** с именем файла:

> Превратите приведенные выше советы для туристов в контрольный список Markdown. Сохраните его как Weekend-packing-list.md и предоставьте файл, который я смогу открыть.

Markdown — текстовый формат заголовков, списков и таблиц. Для обычного текста запросите файл `.txt`.

Текст, отображаемый во время генерации, — это готовящийся контент, а не уже сохраненный файл. Дождитесь завершения, затем откройте полученную карточку файла. Вы также можете найти его под **Файлы** на боковой панели.

Если ответ содержит только блок кода, добавьте следующее: «Пожалуйста, сохраните это содержимое как реальный файл, а не просто отображайте его в ответе».

## Какой формат мне выбрать?

| Желаемый результат | Формат | Пример |
| --- | --- | --- |
| Обычный текст | TXT | «Сохраните его как call-notes.txt». |
| Статья с заголовками, списками и таблицами. | Markdown | «Сохраните его как Meeting-Notes.md». |
| Данные для приложения для работы с электронными таблицами | CSV | «Используйте столбцы «Товар», «Количество» и «Примечания»; сохраните как Shopping-list.csv». |
| Оформленная страница или презентация | HTML | «Создайте отдельный файл HTML с именем project-overview.html». |

Встроенный инструмент записи файлов сохраняет текст размером до 1 МБ на файл. **Название файла `.docx`, `.xlsx` или `.pptx` не превращает его в настоящий документ Office.** CSV открывается в приложениях для работы с электронными таблицами, но не содержит листов книги, стилей или диаграмм.

Для PPT создайте презентацию HTML и используйте [Преобразование HTML в изображение или PPT](html-export.md). Подключенный плагин может предлагать другие функции создания документов; его фактические возможности определяют то, что доступно.

## Чтение и редактирование существующего файла

1. В разговоре выберите **＋ → Файл** и выберите или загрузите файл.
2. Укажите, что конкретно нужно изменить, заменить, а что должно остаться неизменным.
3. Откройте исправленный файл и проверьте результат.

Например:

> В прикрепленном файле Shopping-list.csv измените количество для зонта с 1 на 2. Все остальные строки оставьте без изменений.

> В файле Meeting-notes.md, который вы только что создали, замените «Доставить в следующий понедельник» на «Доставить в следующую среду». Оставьте все остальное.

Текстовые файлы можно редактировать напрямую. Поддерживаемые документы PDF и Office могут предоставлять извлеченное содержимое для чтения модели, но встроенный редактор не может напрямую изменять их исходный макет и структуру файлов. Вместо этого попросите его извлечь и организовать содержимое в новый файл Markdown. См. [Чат и файлы](chat-and-files.md) для получения информации о форматах вложений и ограничениях на чтение.

### Редактирование перезаписывает оригинал?

* При редактировании загруженного файла или файла, созданного предыдущим ответом, сохраняется новая версия, например `meeting-notes v2.md`, при этом исходный файл сохраняется.
* В рамках одного ответа агент может неоднократно уточнять текущий черновик и заканчивать одним файлом вместо того, чтобы создавать новую версию для каждого изменения.

Это не непрерывная синхронизация. Редактирование импортированной копии в Cherry Studio не приводит к обновлению оригинала где-либо еще на вашем телефоне или в облачном хранилище.

### Почему он не может найти текст для замены?

Редактирование соответствует исходному тексту. Измененные формулировки, повторяющиеся предложения, а также различия в пробелах и пунктуации могут помешать четкому совпадению. Попросите агента перечитать соответствующий отрывок и определить более длинное предложение или окружающий контекст. Запрашивайте замену каждого вхождения только тогда, когда вы этого хотите.

## Означает ли чтение части файла, что он прочитал все?

Нет. Большие файлы могут потребовать многократного чтения, а извлечение документов имеет свои ограничения. Для полной проверки попросите агента продолжить просмотр непрочитанных разделов и указать любые пробелы. Если при извлечении уже пропущена часть источника, дальнейшие чтения не смогут восстановить ее; разделить документ и предоставить его снова.

Инструменты чтения используют в этом разговоре доступные вложения или созданные файлы. Они не сканируют каждый файл на вашем телефоне. Чтобы продолжить новый разговор, выберите файл еще раз через меню вложений.

## Находите, просматривайте и делитесь файлами

Откройте **Файлы** на боковой панели для просмотра по типу и переключения между списком и сеткой. Коснитесь файла, чтобы просмотреть его. Форматы без внутреннего предварительного просмотра можно открыть в другом системном приложении.

Меню **Подробнее** в правом верхнем углу предварительной версии предлагает возможность совместного использования и открытия с другими приложениями. Текстовые файлы также можно копировать. Если длинный файл отображается только частично, копирование включает только эту видимую часть; при совместном использовании используется полный исходный файл.

Файлы хранятся на этом устройстве. Сохраните важные материалы в системном приложении «Файлы» или в другом хранилище посредством общего доступа и подтвердите, что можете открыть их, прежде чем очищать локальные файлы или удалять Cherry Studio. Для экспорта сообщений чата используется отдельный рабочий процесс: [Общий доступ и экспорт](sharing-and-export.md).

Встроенные функции чтения, создания и редактирования текстовых файлов обычно выполняются напрямую, в том числе в режиме **Спрашивайте при необходимости**. См. [Одобрение инструмента](using-tools.md).
