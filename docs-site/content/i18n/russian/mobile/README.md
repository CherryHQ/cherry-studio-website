# Cherry Studio для мобильных устройств

Cherry Studio Mobile — это клиент AI, разработанный для Android, iPhone и iPad. Подключите свои собственные модельные сервисы к чату, настройте агентов и создавайте изображения с мобильного устройства.

## Текущий статус

Мобильное приложение в настоящее время находится на стадии **бета**:

* Android распространяется как официальный APK.
* Сборки iPhone и iPad распространяются через Apple TestFlight.
* Экраны и возможности могут быстро измениться. Следите за поведением версии, установленной на вашем устройстве.

Откройте [мобильную опцию на странице загрузки](https://cherryai.com/download?platform=mobile) или сначала прочитайте [Загрузка и установка](installation.md).
