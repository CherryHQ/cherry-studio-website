# Cherry Studio для мобильных устройств

Cherry Studio Mobile — это ИИ-клиент для Android, iPhone и iPad. Подключите свои сервисы моделей, чтобы вести переписку, настраивать агентов и генерировать изображения с мобильного устройства.

## Текущий статус

Мобильное приложение находится в стадии **бета-версии**:

* Android распространяется в виде официального APK.
* Сборки для iPhone и iPad распространяются через Apple TestFlight.
* Экраны и возможности могут быстро меняться. Ориентируйтесь на поведение установленной у вас версии.

Откройте [мобильный вариант на странице загрузки](https://cherryai.com/download?platform=mobile) или сначала прочитайте [руководство по установке](installation.md).

## Что можно делать

* Добавлять встроенных или собственных провайдеров моделей и управлять нужными моделями.
* Переключать модель прямо в диалоге и отправлять текст, изображения или файлы.
* Создавать агентов с собственными инструкциями, моделью и разрешёнными системными инструментами.
* Генерировать и просматривать изображения с помощью настроенной модели изображений.
* Работать в интерфейсе, рассчитанном на сенсорный ввод, на смартфонах Android, iPhone и iPad.
