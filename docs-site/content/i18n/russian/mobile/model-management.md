# Добавление, редактирование и управление моделями

Обычно достаточно получить список моделей провайдера и добавить те, которыми вы пользуетесь. Ручная настройка пригодится, если модели нет в списке, ей нужно более понятное имя или ее сведения отличаются от данных вашей платформы.

Откройте **Настройки → Модельный сервис → Нужный провайдер → Модели**.

## Добавить модель вручную

1. Нажмите кнопку «Добавить» на вкладке «Модели».
2. Введите **Идентификатор модели** — точный идентификатор, который использует ваша платформа. Скопируйте его из документации или каталога платформы, не переводя.
3. Выберите отображаемое имя, например «Ежедневные вопросы». Это меняет то, как вы распознаете модель, а не то, какая модель называется.
4. Проверьте тип модели и API. Если вы не уверены, оставьте другие параметры по умолчанию.
5. Нажмите **Добавить**. Если вы настраиваете провайдера впервые, завершите настройку и убедитесь, что его переключатель включен в списке провайдеров.

Ручной ввод добавляет по одной модели за раз. Используйте [синхронизацию модели](model-updates.md) для нескольких моделей. Дублирование идентификаторов в рамках одного и того же поставщика не допускается.

## Просмотр и редактирование

Коснитесь модели, чтобы просмотреть ее сведения и скопировать ее идентификатор, затем коснитесь **Редактировать** в правом верхнем углу. Вы также можете нажать и удерживать элемент списка для просмотра подробной информации, редактирования, выбора или удаления.

Редактор моделей использует **явное сохранение**. Разверните нужный раздел, внесите изменения, затем коснитесь **Сохранить**. Если сохранение не удалось, исправьте указанные поля и повторите попытку перед выходом.

Существующий **идентификатор модели нельзя изменить в редакторе**. Если это неправильно, добавьте модель с правильным идентификатором, переключите все агенты или значения по умолчанию на новую запись, а затем удалите старую.

## Что означают настройки?

| Настройка | Эффект | Когда не уверен |
| --- | --- | --- |
| Отображаемое имя, группа, примечания | Организация и распознавание моделей | Используйте свои собственные ярлыки |
| Идентификатор модели | Определяет модель, вызываемую на платформе | Сохраняйте точное значение, указанное платформой |
| Тип модели | Различает текст, генерацию изображений и другие цели. | Следуйте описанию платформы |
| API | Выбирает способ подключения запросов к модели. | Сохранить автоматический выбор/выбор по умолчанию |
| Рассуждение | Записывает поддержку функций, связанных с мышлением | Сохраняйте предоставленную информацию |
| Вызов инструмента | Указывает поддержку инструментов поиска, календаря и плагинов | Сопоставьте фактическую поддержку модели |
| Поддерживаемые входы | Указывает поддержку изображений, аудио и видео на входе | Не включайте неподдерживаемые входы |
| Потоковое вещание | Записывает поддержку прогрессивных ответов | Оставьте значение по умолчанию; сам по себе этот флаг не меняет выполнение |

**Флаги возможностей не добавляют возможностей.** Если пометить текстовую модель как поддерживающую изображения, она не сможет понимать фотографии. Флаги аудио/видео также не означают, что мобильное приложение может отправлять каждое такое вложение.

Встраивание и переранжирование — это категории моделей, используемые для поиска. Их информацией можно управлять, но в настоящее время они недоступны для обычного мобильного чата. Выберите текст для разговора или создание изображения для рисования.

## Ограничения контекста и ввода/вывода

**Токен** — это единица измерения, используемая моделями для измерения содержания, а не количества символов или слов.

* **Контекстное окно:** общее пространство для истории, результатов работы инструмента и нового ответа.
* **Максимальный ввод:** сколько контента может быть получено по запросу.
* **Максимальный результат**: сколько модель может выдать за один ответ.

Увеличение номера не обходит ограничения провайдера и может привести к отклонению запросов. Изменяйте эти значения только тогда, когда платформа предоставляет вам другие ограничения. Используйте положительные целые числа и устраняйте любые предупреждения о конфликтующих ограничениях.

Снимите переопределение ограничения и сохраните его, чтобы восстановить настройки каталога или приложения по умолчанию. Если длинный разговор все же выходит за рамки, сократите количество вложений, сократите материал или начните новый разговор.

## Ценообразование и смета расходов

Цены поддерживают оценки использования; **редактирование не приводит к изменению счета поставщика услуг**.

* Выберите USD или CNY. Цены за входные и выходные данные указываются **за миллион токенов**.
* Цены за чтение и запись кэша определяют стоимость повторно используемого контента на платформе. Если эти поля не заполнены, используется цена за входные данные.
* Неизвестное отличается от бесплатного. `0` явно означает нулевую ставку; не используйте его по неизвестной цене.
* Уровни ввода могут представлять более высокие цены для длинных запросов. Стартовые пороги должны увеличиться. Применимый уровень оценивает весь запрос, а не только часть, превышающую пороговое значение.

Сохраняйте значения по умолчанию, если у вас нет надежных цен. См. [настройки и использование](settings-and-usage.md) для ознакомления с ориентировочной и неполной стоимостью.

## Изменение API сохраняет сразу?

Изменение API модели непосредственно в списке управления сохраняется немедленно. Если выбрать его в **редакторе**, черновик изменится, пока вы не нажмете «Сохранить».

После значения по умолчанию используется текущее значение по умолчанию API поставщика. Если она становится недоступной, проверьте настроенное соединение провайдера, а не повторно переименовывайте модель.

## Удаление и упорядочение моделей

Нажмите и удерживайте, чтобы войти в режим выбора и удалить несколько моделей в текущем фильтре. При неудачном удалении выбор сохраняется, поэтому вы можете решить проблему и повторить попытку.

* Глобальная модель по умолчанию защищена: измените или очистите ее в **Настройки → Модель по умолчанию** перед удалением.
* Удаление модели, используемой агентом, означает, что агенту необходимо выбрать другую модель.
* Удаление локальной конфигурации не приводит к закрытию учетной записи поставщика или отмене платежей.

В случае временного прекращения использования отключите поставщика, а не перестраивайте его конфигурацию позже. См. [обновления модели](model-updates.md), чтобы узнать, что происходит с вашими изменениями при изменении удаленной информации.
