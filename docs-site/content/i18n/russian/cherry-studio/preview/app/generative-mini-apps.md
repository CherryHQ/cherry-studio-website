# Генеративные мини-приложения

Генеративные мини-приложения — это локальные веб-приложения, работающие в разделе «Мини-приложения» Cherry Studio. Их интерфейс и бизнес-процессы настраиваются пользователем, а через `window.cherry` они могут вызывать настроенные в Cherry Studio ИИ-модели, превращая универсальную модель в помощника по написанию текстов, инструмент извлечения информации, обучающий инструмент или специализированное бизнес-приложение.

Отличие от обычных веб-мини-приложений заключается не во внешнем виде, а в источнике возможностей: веб-мини-приложение просто открывает URL; генеративное мини-приложение должно быть упаковано в `.miniapp`, установлено и получить разрешения, чтобы иметь возможность вызывать ИИ Cherry, данные песочницы, файлы, уведомления, сеть и буфер обмена.

{% hint style="info" %}
Cherry Studio предоставляет среду выполнения, механизм авторизации и ИИ-интерфейсы. Вы можете самостоятельно разработать мини-приложение или сначала сгенерировать HTML, CSS и JavaScript с помощью ИИ-инструмента разработки, а затем упаковать и установить его в соответствии с инструкциями на этой странице.
{% endhint %}

## Цели и предварительные требования

После изучения этой страницы вы сможете:

* установить и использовать генеративное мини-приложение, предоставленное другим пользователем;
* создать собственный пакет `.miniapp` из простого требования;
* настроить мини-приложение для вызова «Модели по умолчанию» или «Быстрой модели» Cherry Studio;
* проверять разрешения, журнал активности, хранилище, обновления и статус удаления.

Для использования готового мини-приложения достаточно иметь надежный файл `.miniapp` или URL для установки. Для самостоятельной разработки также необходимо уметь редактировать веб-файлы и создавать ZIP-архивы; для тестирования ИИ-функций сначала настройте рабочую чат-модель в Cherry Studio.

### Выбор ИИ-модели для мини-приложения

1. В сетке «Мини-приложения» щелкните правой кнопкой мыши по нужному мини-приложению и выберите «Подробнее».
2. Переключитесь на «Настройки» и найдите «ИИ-модель».
3. Настройте «Модель по умолчанию» и «Быструю модель» в соответствии с назначением мини-приложения. Если поля оставлены пустыми, будут использоваться глобальная модель по умолчанию и глобальная быстрая модель Cherry Studio.
4. Перезапустите мини-приложение и выполните одно ИИ-действие. Если доступная модель отсутствует, мини-приложение должно отобразить сообщение о недоступности ИИ.

«Модель по умолчанию» подходит для основных задач, таких как генерация длинных текстов и сложный анализ; «Быстрая модель» подходит для задач с низкой задержкой, таких как предложения заголовков, перефразирование коротких фраз и извлечение меток. Какой именно слот будет использован, определяется архитектурой мини-приложения.

### Создание минимальной версии

По своей сути генеративное мини-приложение — это статический веб-проект. Для минимальной структуры каталога достаточно двух файлов:

```
my-writer/
├── manifest.json
└── index.html
```

Сначала создайте `manifest.json`, в котором объявите информацию о приложении и разрешения `ai.chat`:

```json
{
  "id": "com.example.my-writer",
  "name": { "zh": "Помощник по редактированию", "en": "Rewrite Helper" },
  "description": "Введите текст и перепишите его с помощью модели ИИ Cherry Studio.",
  "version": "1.0.0",
  "entry": "index.html",
  "permissions": ["ai.chat"]
}
```

Для `id` рекомендуется использовать формат обратного домена, которым вы управляете; он может содержать только строчные буквы, цифры, точки и дефисы. `com.cherrystudio.*` — это зарезервированный диапазон, его использовать нельзя.

Затем в `index.html` вызывайте ИИ через глобальный объект `cherry`. В примере ниже сначала проверяется доступность «Модели по умолчанию», а затем потоковый текст отображается по частям:

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <link rel="stylesheet" href="/__cherry/theme.css" />
    <title>Помощник по редактированию</title>
  </head>
  <body>
    <textarea id="source" placeholder="Введите текст для редактирования"></textarea>
    <button id="rewrite">Переписать</button>
    <pre id="result"></pre>

    <script>
      const button = document.querySelector('#rewrite')
      const source = document.querySelector('#source')
      const result = document.querySelector('#result')

      button.addEventListener('click', async () => {
        const capability = await cherry.ai.getCapabilities({ model: 'default' })
        if (!capability.available) {
          result.textContent = 'Сначала настройте доступную модель в сведениях о мини-приложении.'
          return
        }

        result.textContent = ''
        await cherry.ai.chat(
          {
            model: 'default',
            reasoning: 'off',
            messages: [
              { role: 'system', content: 'Вы редактор китайского текста. Сохраните смысл и сделайте формулировки яснее.' },
              { role: 'user', content: source.value }
            ]
          },
          {
            callId: `rewrite-${Date.now()}`,
            onChunk: (text) => {
              result.textContent += text
            }
          }
        )
      })
    </script>
  </body>
</html>
```

`window.cherry` и `cherry` указывают на один и тот же хостовый интерфейс, подключение SDK не требуется. Мини-приложение может отправлять только текстовые сообщения; на данный момент ввод изображений и вызов инструментов не поддерживаются. Оно указывает только на использование слота `default` или `quick` и не получает название модели, информацию о провайдере или API Key.

### Упаковка и тестирование

1. Убедитесь, что `manifest.json` находится в корне проекта, а входной файл соответствует `entry`.
2. Выполните сжатие внутри каталога проекта; в macOS или Linux можно использовать:

```bash
zip -r ../my-writer.miniapp . -x '.*' -x '__MACOSX/*'
```

В Windows PowerShell сначала создайте ZIP, а затем измените расширение на `.miniapp`:

```powershell
Compress-Archive -Path .\* -DestinationPath ..\my-writer.zip
Rename-Item ..\my-writer.zip my-writer.miniapp
```

3. В области установки «Локальное мини-приложение» Cherry Studio выберите созданный `my-writer.miniapp`.
4. Убедитесь, что на странице установки запрашиваются только ожидаемые разрешения, затем установите, откройте и протестируйте ввод, вывод ИИ, сообщения об ошибках и состояние после повторного входа.
5. Для отладки откройте «Инструменты разработчика» в панели инструментов мини-приложения и просмотрите ошибки страницы и заблокированные песочницей запросы.

{% hint style="warning" %}
Не сжимайте всю папку проекта из внешнего каталога; убедитесь, что в корне архива непосредственно виден `manifest.json`. Cherry Studio также распознает архивы с одной оберткой каталога, но ясная структура корневого каталога упрощает устранение неполадок.
{% endhint %}

## Ожидаемый результат

После установки вы должны увидеть новый значок в сетке «Мини-приложения». После открытия введите текст и нажмите кнопку; в области результатов будет непрерывно появляться текст, возвращаемый моделью. Щелкните правой кнопкой мыши по мини-приложению и выберите «Подробнее», чтобы увидеть запрошенное разрешение «Возможности ИИ», используемый слот модели и последние записи вызовов.

Если установка прошла успешно, но ИИ недоступен, сначала проверьте модель в «Подробнее» → «Настройки», затем убедитесь, что в «Разрешениях» разрешено «Возможности ИИ» → «Диалог».

### Какие еще возможности можно вызывать

| Возможность | Назначение | Способ объявления |
| --------------------- | ----------------------- | ---------------------------------- |
| `cherry.storage` | Сохранение настроек и состояния в виде строки | `storage.*` или конкретные методы |
| `cherry.file` | Сохранение, чтение и экспорт файлов в песочнице мини-приложения | `file.*` или конкретные методы |
| `cherry.notification` | Отправка системных уведомлений через Cherry Studio | `notification.show` |
| `cherry.network` | Доступ к HTTPS-доменам, объявленным в манифесте | `network.fetch`, с указанием списка доменов `network` |
| `cherry.clipboard` | Чтение и запись обычного текста, когда мини-приложение видимо и имеет фокус клавиатуры | `clipboard.read`, `clipboard.write` |
| `cherry.app` | Чтение версии приложения, языка и текущих разрешений | Не требуется |

Локальные мини-приложения не могут напрямую использовать `localStorage`, браузерные `fetch`, Cookie, всплывающие окна или внешние CDN. Для сохранения состояния используйте `cherry.storage`, для доступа в интернет — `cherry.network.fetch`, объявив разрешенные домены в манифесте.

## Частые вопросы

<details>

<summary>Почему я ввел URL веб-страницы, но не могу вызвать Cherry AI?</summary>

[Сайт] предназначен только для открытия веб-страниц и не внедряет `window.cherry` в страницу. Создайте приложение в виде пакета `.miniapp` и установите его из [Локальные мини-приложения].

</details>

<details>

<summary>Может ли мини-приложение видеть мой API Key или провайдера модели?</summary>

Нет. Мини-приложение обращается только к слотам [Модель по умолчанию] или [Быстрая модель]. Cherry Studio выполняет вызовы от вашего имени и не раскрывает мини-приложению название модели, информацию о провайдере или API Key.

</details>

<details>

<summary>Почему после установки появляется сообщение о недоступности ИИ?</summary>

Сначала откройте [Подробнее] → [Настройки] и убедитесь, что в соответствующем слоте модели доступна рабочая модель. Затем в [Разрешения] проверьте, что [Возможности ИИ] → [Диалог] разрешено. Если разрешение является обязательным, но вы больше не доверяете приложению, удалите его.

</details>

<details>

<summary>Как проверить, какие возможности использовало мини-приложение?</summary>

Откройте [Подробнее] → [Журнал активности]. Здесь фиксируются внешние вызовы ИИ, сети, буфера обмена, экспорта файлов, а также отклоненные запросы, но не записываются промпты, ответы модели, содержимое буфера обмена или файлов.

</details>

<details>

<summary>В чем разница между обновлением, откатом и очисткой данных?</summary>

При обновлении данные песочницы сохраняются, а при добавлении новых разрешений запрашивается подтверждение; после обновления возможен откат к предыдущей версии. Очистка данных удаляет сохраненные данные и файлы этого мини-приложения, но сохраняет само приложение; удаление стирает приложение, разрешения и данные.

</details>
