# Различия в функциональности

В версии V2 изменены структура данных и расположение ряда функций. Перед обновлением проверьте элементы, требующие повторной настройки; подробные инструкции см. в разделе [【Обновление с V1 до V2】](v1-to-v2-migration.md).

## Изменения при миграции в V2.0.2

| Ситуация | Обработка в V2.0.2 | Примечания |
| --------- | ----------------------- | ------------------------------ |
| Первая миграция с V1 | Можно установить V2.0.2 напрямую из V1.9.13 | Больше не требуется предварительная установка V2.0.0. |
| Обычное обновление V2 | Прямое обновление с сохранением текущих данных V2 | Не нажимайте кнопку 【Повторная миграция】. |
| Повторная миграция с V1 | Выберите 【Повторная миграция】 в разделе 【Настройки】 → 【Данные】 | Текущие данные V2 будут безвозвратно удалены. Используйте только в случае неудачной миграции или пропущенных данных. |

{% hint style="danger" %}
【Повторная миграция】 не объединяет данные V1 с текущими данными V2. Сначала удаляются текущие данные V2, затем выполняется повторный импорт из сохранённых данных V1. Если миграция V1 не завершилась с ошибкой и данные не пропущены, категорически не нажимайте эту кнопку.
{% endhint %}

## Обработка данных

| Способ обработки | Охват данных | Действия после обновления |
| ---- | --------------------------------------------------------------------- | ------------- |
| Автоматическая миграция | Настройки, сервисы и модели, ассистенты и группы, сессии и сообщения, Agent и сессии, MCP, базы знаний и активные индексы, файлы, рисование, перевод, заметки, промпты, записи об использовании | Проверьте, что часто используемые элементы открываются корректно. |
| Требует проверки | Удостоверения Anthropic, сервис по умолчанию для веб-поиска, разрешения инструментов Agent и привязка к базам знаний, порядок промптов, неудачные элементы баз знаний, пользовательский CSS, закладки в боковой панели, отсутствующие файлы | Повторно подтвердите настройки согласно таблице ниже. |
| Не наследуется | История запланированных задач Agent, результаты раскрытия старых карт сайта, часть временных ссылок на изображения, текущее состояние открытых заметок, настройки удалённых функций | При необходимости создайте заново. |

{% hint style="info" %}
Миграция не удаляет исходные данные V1. Новые данные V2 не синхронизируются обратно в V1, резервные копии двух версий несовместимы.
{% endhint %}

## Основные различия

| Функция | V1 | V2 | Действия после обновления |
| --------------- | ------------------------------- | --------------------------------------------- | -------------------------------- |
| Ассистенты и промпты | Отдельная библиотека ассистентов; быстрые фразы можно связывать с ассистентами | Ассистенты управляются в чате и Agent; быстрые фразы объединены в глобальные промпты | Проверьте группы ассистентов и порядок промптов. |
| Agent | Часть настроек и рабочая область привязаны к сессии; старые разрешения могут автоматически одобрять инструменты | Идентичность, память и основные настройки принадлежат Agent; рабочая область фиксируется после создания сессии; инструменты могут запрашивать разрешение повторно | Проверьте модели, рабочую область, инструменты и разрешения. |
| База знаний Agent | Инструмент знаний может обращаться к глобальной базе знаний | Обращается только к явно привязанным базам знаний | Повторно проверьте привязку баз знаний для каждого Agent. |
| Поиск в базе знаний | Можно вручную выбирать режим поиска и источник карты сайта | При отсутствии модели встраивания используется BM25, при наличии — гибридный поиск; карта сайта обрабатывается как обычный URL | Проверьте модели встраивания и реранкинга; пересоздайте неудачные источники. |
| Веб-поиск | Выбор сервиса в ассистенте или области ввода; включает локальный поиск, сжатие RAG и черный список подписок | Настройка поиска по ключевым словам и чтения URL отдельно в разделе 【Настройки】 → 【Веб-поиск】; устаревшие опции удалены | Повторно выберите сервисы по умолчанию для двух функций и проверьте удостоверения. |
| MCP | Добавленные сервисы и сторонний рынок обнаружения сосуществуют | Добавленные сервисы продолжают мигрировать; старый сторонний рынок обнаружения больше не предоставляется | Проверьте статус сервисов; добавляйте новые сервисы из текущего рынка или через JSON. |
| Сервисы моделей | Anthropic может сохранять OAuth-удостоверения | OAuth Anthropic не мигрируется; регион AWS Bedrock сохраняется; новые сервисы отключены по умолчанию | Введите API Key для Anthropic заново, включайте сервисы по необходимости. |
| Файлы | Слабая связь между копиями файлов и бизнес-объектами | Управляемые файлы обрабатываются по ссылкам; после удаления последней ссылки управляемая копия удаляется с задержкой | Долгосрочно хранимые файлы помещайте в раздел 【Файлы】 или экспортируйте; исходные файлы пользователя не удаляются. |
| Рисование, Mini App и боковая панель | Параметры и входные точки в старых разделах | Параметры рисования перемещены в панель инструментов промптов; Mini App в верхней панели вкладок; закладки боковой панели сброшены | Освойте новые входные точки и настройте закладки заново. |
| Пользовательский CSS | Селекторы V1 действуют напрямую | Содержимое сохраняется, но по умолчанию отключено после миграции | Адаптируйте под селекторы V2, затем включите. |
| Code CLI | Можно выбрать iFlow | iFlow заменен на Qoder | При необходимости рабочих процессов используйте Qoder. |

## Совместимость для разработчиков

<details>

<summary>Какие изменения в API и внешних интеграциях?</summary>

* Идентификатор модели в API Gateway изменен с `provider::model` на `provider:model`.
* Записи, возвращаемые Knowledge API, используют поля V2.
* Точки доступа MCP-over-HTTP удалены, это не влияет на MCP внутри приложения.
* При неудачном запуске SSE может возвращаться обычная ошибка HTTP; клиент должен поддерживать как ошибки HTTP, так и SSE.
* Параметры интерфейса запланированных задач изменены, история запусков не мигрируется.

</details>
