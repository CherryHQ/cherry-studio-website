# Обновление и откат

Выберите соответствующие инструкции в зависимости от текущей и целевой версий. V1 и V2 используют различные структуры данных, поэтому перед переходом между основными версиями необходимо создать резервную копию.

{% hint style="danger" %}
Данные и форматы резервных копий V1 и V2 несовместимы. Новые сессии, Agent, настройки и файлы, созданные в V2, не будут автоматически записаны обратно в V1.
{% endhint %}

## Обновление до V2.0.2 и миграция

{% hint style="warning" %}
Если необходимо сохранить данные V1, правильный путь: **V1.9.13 → V2.0.2 (прямая миграция данных)**. Больше не требуется предварительная установка V2.0.0.
{% endhint %}

| Текущая ситуация | Рекомендуемые действия |
| --------------- | ------------------------------------ |
| Используется V1, данные необходимо сохранить | Обновите V1 до 1.9.13, затем установите V2.0.2 для завершения миграции. |
| Уже используется V2 | Выполните обычное обновление до V2.0.2 и продолжайте использовать текущие данные V2; не нажимайте [Повторная миграция]. |
| Предыдущая миграция из V1 завершилась ошибкой или данные были утеряны | Только после создания полной резервной копии текущих данных V2 можно использовать [Повторная миграция] в разделе [Настройки] → [Данные]. |
| Данные V1 не нужны | Можно выбрать [Игнорировать и использовать значения по умолчанию], но данные V1 не будут импортированы. |

{% hint style="danger" %}
[Повторная миграция] навсегда удаляет текущие данные V2 и заново импортирует исходные данные V1. Слияние или сохранение данных с обеих сторон не выполняется. Не нажимайте эту кнопку, если только предыдущая миграция из V1 не завершилась ошибкой или не привела к потере данных.
{% endhint %}

## Подготовка перед переключением

1. Завершите активные диалоги, задачи Agent, импорт в базу знаний и обработку файлов.
2. Создайте новую полную резервную копию для текущей версии и сохраните её вне каталога данных приложения.
3. Зафиксируйте текущий каталог данных приложения; при использовании пользовательского каталога или внешнего диска убедитесь, что путь доступен.

{% hint style="warning" %}
Не удаляйте данные приложения вручную ради «полного удаления». Обработка базы данных применима только при полном отказе от данных V2 или при повторной миграции, см. [Откат с V2 до V1](v2-to-v1-downgrade.md).
{% endhint %}
