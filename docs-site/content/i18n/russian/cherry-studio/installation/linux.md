# Linux

## 1. Скачивание установщика

Откройте [официальную страницу загрузки](https://cherryai.com.cn/download/v2) и выберите **Linux**. На официальном сайте доступны установщики в разных форматах в зависимости от системы и архитектуры:

| Сценарий использования | Рекомендация |
| ------------------------ | ----------------------- |
| Ubuntu, Debian, Linux Mint | Выберите пакет `.deb`, соответствующий вашей архитектуре. |
| Fedora, RHEL, openSUSE | Выберите пакет `.rpm`, соответствующий вашей архитектуре. |
| Другие дистрибутивы или портативный запуск | Выберите пакет `.AppImage`, соответствующий вашей архитектуре. |

Для устройств Intel / AMD обычно выбирается версия x64 (или x86\_64); для устройств ARM — версия ARM64 (или aarch64). Если архитектура неизвестна, выполните в терминале `uname -m`: `x86_64` соответствует x64, `aarch64` или `arm64` — ARM64.

## 2. Установка и запуск

* `.deb` и `.rpm`: предпочтительно открыть установщик через штатный установщик пакетов или менеджер пакетов дистрибутива, затем запустить Cherry Studio из меню приложений.
* `.AppImage`: предоставьте файлу права на выполнение и запустите двойным щелчком; также можно запустить в терминале с помощью `chmod +x имя-файла.AppImage`.

## Проблемы с запуском

Сначала убедитесь, что установщик соответствует архитектуре системы. Если AppImage не запускается и отображаются ошибки, связанные с `FUSE` или `libfuse`, установите необходимые компоненты совместимости согласно официальной документации вашего дистрибутива.

Если проблема сохраняется, при отправке обратной связи укажите дистрибутив, окружение рабочего стола, архитектуру устройства, имя установщика и полный текст ошибки.
