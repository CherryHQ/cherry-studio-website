# Откат с V2 на V1

Откат подходит для случаев, когда V2 временно мешает критически важной работе, а у вас сохранились доступные данные V1. Он не преобразует данные V2 в формат V1.

{% hint style="danger" %}
Новые в V2 сессии, Agent, настройки и файлы не вернутся в V1. Резервные копии V2 также нельзя восстановить в V1; перед откатом сохраните отдельно последнюю резервную копию V2 и исходную резервную копию V1 или копию каталога данных.
{% endhint %}

## Стандартный откат

{% stepper %}
{% step %}
### Остановите задачи и создайте резервную копию V2

Завершите активные диалоги, задачи Agent и обработку файлов. Создайте новую полную резервную копию V2 в разделе [Настройки] → [Данные] и сохраните её вне каталога данных приложения.
{% endstep %}

{% step %}
### Убедитесь, что данные V1 сохранились

Найдите копию каталога данных V1, сохранённую до обновления, или резервную копию V1. Если есть только резервная копия V1, её нужно восстановить в совместимой версии V1; импорт в V2 невозможен.
{% endstep %}

{% step %}
### Скачайте и установите V1

Полностью выйдите из V2, скачайте установщик, соответствующий вашей системе, с [официальной страницы загрузки V1](https://cherryai.com.cn/download/v1) и завершите установку.
{% endstep %}

{% step %}
### Запустите с исходными данными V1

Запустите V1 и используйте каталог данных V1, существовавший до обновления. Не заменяйте его базой данных V2 или резервной копией V2.
{% endstep %}

{% step %}
### Проверьте данные перед продолжением работы

Проверьте часто используемые сессии, сервисы моделей, базу знаний и файлы. Не удаляйте резервные копии V1 или V2, пока не убедитесь, что данные V1 работают корректно.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Для стандартного отката не нужно удалять базу данных. Сохранение данных V2 позволяет в будущем вернуться к V2 и избежать случайного удаления неэкспортированного контента.
{% endhint %}

{% hint style="danger" %}
Пункт [Настройки] → [Данные] → [Повторная миграция] в V2.0.2 не является инструментом отката. Он навсегда удаляет текущие данные V2 и повторно импортирует их из исходных данных V1. Не нажимайте на него, если предыдущая миграция с V1 не завершилась ошибкой или не привела к потере данных.
{% endhint %}

## Когда нужно обрабатывать базу данных V2

Обработка требуется только в следующих случаях:

* Вы окончательно отказываетесь от всех текущих данных V2 и оставляете только данные V1;
* Нужно повторно выполнить миграцию V1 → V2.

Это не стандартный шаг отката. Действия затронут все сессии, Agent, настройки и другие данные V2, а не только определённую партию тестовых записей.

### Безопасный способ обработки

1. Полностью выйдите из V1 и V2, убедитесь, что фоновые задачи не выполняются.
2. Откройте [Настройки] → [Данные] → [Данные приложения] в V1 1.9.13 и перейдите в текущий каталог данных приложения.
3. Переместите следующие элементы на рабочий стол или в другое безопасное место, не удаляя их:
   * `Data/cherrystudio.sqlite`
   * `Data/cherrystudio.sqlite-shm` и `Data/cherrystudio.sqlite-wal` (если существуют)
   * `Data/Agents/.claude`
4. Запустите V1 и проверьте исходные данные V1. Если требуется повторная миграция, запустите V2 для её выполнения.
5. Решайте об удалении ранее перемещённых файлов только после подтверждения работоспособности данных V1 и наличия резервной копии V2.

{% hint style="danger" %}
Не перемещайте базу данных при работающем приложении. Не перемещайте только `cherrystudio.sqlite`, игнорируя файлы `-shm` или `-wal` в том же каталоге, и не заменяйте базу данных V2 на базу данных V1. Если вы не уверены в назначении текущего каталога данных или файлов, прекратите действия и обратитесь в службу поддержки Cherry Studio.
{% endhint %}

## Частые вопросы

<details>

<summary>Можно ли вернуть новые диалоги из V2 в V1?</summary>

Нет. Экспортируйте нужные данные в V2, а в V1 продолжайте использовать исходные данные V1.

</details>

<details>

<summary>Скачивание V1 автоматически преобразует данные V2?</summary>

Нет. Установщик устанавливает только приложение и не преобразует данные или формат резервных копий.

</details>

<details>

<summary>Можно ли просто удалить базу данных и попробовать снова?</summary>

Не рекомендуется. Сначала переместите и сохраните файлы, а решение об удалении принимайте после проверки. При случайном удалении и отсутствии доступной резервной копии данные V2 могут быть безвозвратно потеряны.

</details>

<details>

<summary>Какую версию установить при повторном переходе на V2 после отката?</summary>

Если вы продолжаете использовать прежние данные V2, можно сразу установить V2.0.2, не нажимая [Повторная миграция]. Если предыдущая миграция с V1 завершилась ошибкой или привела к потере данных, используйте [Настройки] → [Данные] → [Повторная миграция] после создания полной резервной копии текущих данных V2; это действие навсегда удалит текущие данные V2 и повторно импортирует их из V1.

</details>
