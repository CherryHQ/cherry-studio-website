# Perplexity

Серия **Sonar** от Perplexity ориентирована на **диалоги с поисковой поддержкой** — ответы формируются с использованием актуальных данных из сети, что подходит для сценариев, требующих ссылки на свежую информацию.

## Получение API Key

* Откройте [страницу настроек API](https://www.perplexity.ai/settings/api) Perplexity (требуется регистрация/вход)
* Сгенерируйте и скопируйте API Key

## Настройка в Cherry Studio

1. Откройте [настройки модельных сервисов](../settings/providers.md) в Cherry Studio и найдите **Perplexity** в встроенном списке
2. Вставьте полученный API Key
3. Нажмите **Получить список моделей**, добавьте модели, такие как Sonar, и включите переключатель провайдера в правом верхнем углу для начала использования

{% hint style="info" %}
Модели Perplexity имеют встроенную возможность поиска в сети, поэтому дополнительная настройка режима онлайн не требуется. Для доступа из Китая обычно необходимо самостоятельно настроить сетевой прокси. Подробнее см. [официальную документацию Perplexity](https://docs.perplexity.ai/home).
{% endhint %}
