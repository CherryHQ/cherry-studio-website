# ZhiPu

Серия **GLM** от ZhiPu AI (включая мультимодальную GLM-4V) обеспечивает прямое подключение внутри страны и высокое качество работы с китайским языком. В Cherry Studio ZhiPu использует **совместимый с Anthropic эндпоинт**, поэтому, помимо обычного диалога, может использоваться в **Cherry Agent**.

## Получение API Key

* Откройте [страницу API Keys](https://open.bigmodel.cn/apikey/platform) на платформе ZhiPu (требуется предварительная регистрация/вход)
* Создайте и скопируйте API Key

## Настройка в Cherry Studio

1. Откройте [настройки модельных сервисов](../settings/providers.md) в Cherry Studio и найдите **ZhiPu** в встроенном списке
2. Введите полученный API Key
3. Нажмите **Получить список моделей**, добавьте необходимые модели GLM и включите переключатель провайдера в правом верхнем углу для начала использования

{% hint style="info" %}
Модели ZhiPu поддерживают **поиск в интернете** по умолчанию; фактическая поддержка зависит от конкретной модели. Дополнительные сведения о платформе см. в [официальной документации ZhiPu](https://docs.bigmodel.cn/).
{% endhint %}
