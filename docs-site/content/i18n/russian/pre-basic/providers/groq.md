# Groq

Groq (обратите внимание: не Grok от xAI) — это сервис инференса, отличающийся **ускорением на LPU-аппаратном обеспечении и сверхнизкой задержкой**. В основном хостит открытые модели, такие как Llama / Mixtral / Whisper, скорость вывода обычно в несколько раз выше, чем у обычного облачного инференса.

## Получение API Key

* Зарегистрируйте аккаунт на [GroqCloud](https://console.groq.com/)
* `API Keys` → `Create API Key`, скопируйте ключ `gsk_...`

## Настройка в Cherry Studio

* Откройте `Настройки → Сервисы моделей`, найдите провайдера **Groq** и перейдите на страницу деталей
* В поле **API Key** вставьте `gsk_...`
* **API Address** по умолчанию `https://api.groq.com/openai/v1`, изменения не требуются
* Нажмите **Получить список моделей**

## Рекомендуемое использование

| Модель | Подходящие сценарии |
| ------------------------- | ---------- |
| `llama-3.3-70b-versatile` | Универсальный диалог, очень высокая скорость |
| `llama-3.1-8b-instant` | Простые задачи, реакция в миллисекундах |
| `mixtral-8x7b-32768` | Длинный контекст |
| `whisper-large-v3` | Распознавание речи |

## Сценарии применения

* **Чат-боты в реальном времени**: «почти мгновенный отклик» Groq отлично подходит для интеграции с IM (в сочетании с [каналами](../../advanced-basic/automation/channels.md))
* **Высокая параллельность**: количество токенов в секунду значительно выше, чем у обычного облачного инференса
* **Не важна актуальность модели**: Groq в основном хостит открытые модели, такие как линейка Llama, закрытые модели вроде GPT-5 / Claude-4 отсутствуют

## Различия между Grok и Groq

| | [Grok](grok.md) | Groq |
| -- | --------------- | --------------- |
| Компания | xAI (Илон Маск) | Groq Inc. |
| Специализация | Собственные LLM + доступ в интернет | LPU-аппаратное обеспечение + инференс открытых моделей |
| Модели | Собственные, такие как `grok-4` | Открытые, такие как `llama-3.x` |

{% hint style="warning" %}
Grok (xAI) и Groq часто путают. В списке провайдеров Cherry Studio это два отдельных пункта, пожалуйста, не путайте их.
{% endhint %}
