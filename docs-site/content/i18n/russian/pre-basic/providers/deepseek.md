# DeepSeek

DeepSeek — один из ведущих китайских разработчиков больших языковых моделей. Серия V3 / R1 пользуется отличной репутацией в задачах программирования и рассуждений, при этом цены остаются доступными.

## Получение API-ключа

* Зарегистрируйте аккаунт на [DeepSeek Platform](https://platform.deepseek.com/)
* Перейдите в `API Keys` → `Создать API-ключ` и скопируйте ключ `sk-...`
* Пополните баланс на любую сумму (минимальная сумма для активации — 1 юань)

## Настройка в Cherry Studio

* Откройте `Настройки → Сервисы моделей`, найдите провайдера **deepseek** и перейдите на страницу деталей
* В поле **API-ключ** вставьте `sk-...`
* **Адрес API** по умолчанию `https://api.deepseek.com`, изменения не требуются
* Нажмите **Получить список моделей**

## Рекомендуемое использование

| Модель | Подходящие сценарии |
| ------------------- | ---------------------------------- |
| `deepseek-chat` | Универсальный диалог, отличное соотношение цены и качества |
| `deepseek-reasoner` | Математика, код, сложные рассуждения. Обратите внимание: в выводе будут блоки размышлений `<thinking>` |

## Нативный доступ в интернет

Модели DeepSeek с поддержкой доступа в интернет могут использовать нативный веб-поиск провайдера. При выборе модели обращайте внимание на значок 🌐 рядом с названием; конкретный список поддерживаемых моделей может меняться в зависимости от обновлений провайдера, поэтому не рекомендуется полагаться только на название модели.

Если в диалоге включен значок 🌐, а в разделе [Настройки] → [Веб-поиск] опция [Приоритетно использовать настроенный сервис поиска] включена, Cherry Studio будет в первую очередь использовать настроенный сервис поиска. Если эту опцию отключить, приоритет получит нативный доступ модели в интернет. Подробнее см. Режим доступа в интернет.

## Использование с глобальной памятью

У DeepSeek нет собственных моделей эмбеддингов. Если вы планируете использовать базу знаний:

* Для моделей эмбеддингов рекомендуется использовать провайдеров из других источников (например, `bge-m3` от [SiliconFlow](siliconcloud.md) или `text-embedding-3-small` от [OpenAI](openai.md))
* Для диалоговой модели можно продолжать использовать DeepSeek

{% hint style="info" %}
- Тарификация DeepSeek осуществляется по количеству токенов; при попадании в кэш стоимость значительно снижается (см. официальную документацию)
- Контент размышлений `deepseek-reasoner` по умолчанию отображается в диалоге; в [Настройках диалога](../../cherrystudio/preview/chat.md#dui-hua-she-zhi) можно включить «Автоматическое сворачивание контента размышлений»
{% endhint %}
