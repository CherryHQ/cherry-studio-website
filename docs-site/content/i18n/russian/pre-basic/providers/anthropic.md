# Anthropic

Claude от Anthropic — одна из наиболее подходящих моделей для использования в качестве бэкенда [Cherry Agent](../../advanced-basic/agent.md), поскольку Agent требует эндпоинт протокола Anthropic.

## Получение API Key

* Зарегистрируйте аккаунт в [Anthropic Console](https://console.anthropic.com/)
* Перейдите в `Settings → API Keys` → `Create Key` и скопируйте сгенерированный ключ `sk-ant-...`

## Настройка в Cherry Studio

* Откройте `Настройки → Сервисы моделей`, найдите провайдера **Anthropic** и перейдите на страницу деталей
* В поле **API Key** вставьте `sk-ant-...`
* **Адрес API** по умолчанию `https://api.anthropic.com`, изменения не требуются
* Нажмите **Получить список моделей** и добавьте модели `claude-opus-4`, `claude-sonnet-4`, `claude-haiku-4` и другие

## Рекомендуемое использование

| Модель | Подходящие сценарии |
|---|---|
| `claude-opus-4` | Максимальная логика / программирование / сложные задачи Agent |
| `claude-sonnet-4` | Универсальный диалог и повседневные задачи Agent, лучшее соотношение цены и качества |
| `claude-haiku-4` | Высокая пропускная способность, быстрые ответы с низкой стоимостью |

## Настройка для сценариев Agent

Выберите этого провайдера в качестве источника моделей по умолчанию при настройке [Cherry Agent](../../advanced-basic/agent.md), чтобы сразу получить возможности Agent по протоколу Anthropic.

{% hint style="info" %}
* Прямой доступ к API Anthropic из Китая невозможен, требуется собственный прокси (см. [Общие настройки → Режим прокси](../settings/general.md))
* Пользователи с подпиской Claude Code могут использовать тот же ключ и эндпоинт для подключения к Cherry Studio
* Модели Claude тарифицируются по токенам, при работе с длинным контекстом следите за расходом
{% endhint %}
