# OneAPI

* Войдите в систему и перейдите на страницу токенов

<figure><img src="../../../../assets/68288a2c3a095035189e8d25.webp" alt=""><figcaption></figcaption></figure>

* Создайте новый токен (также можно использовать токен default↑)

<figure><img src="../../../../assets/b52ed2463a5c1ea3de393a3e.webp" alt="" width="563"><figcaption></figcaption></figure>

* Скопируйте токен

<figure><img src="../../../../assets/e485ab0dd933dd974e8648e3.webp" alt="" width="563"><figcaption></figcaption></figure>

* Откройте настройки провайдеров в CherryStudio и нажмите на `Добавить` в самом низу списка провайдеров
* Введите имя для заметки, выберите OpenAI в качестве провайдера и нажмите «ОК»

* Вставьте скопированный ключ
* Вернитесь на страницу получения API Key, скопируйте корневой адрес из адресной строки браузера, например:

<figure><img src="../../../../assets/15e84703b85e9e47c3de65e4.webp" alt=""><figcaption><p><strong>Скопируйте только адрес сервера, например https://xxx.xxx.com; косая черта и последующий путь не нужны.</strong></p></figcaption></figure>

{% hint style="info" %}
* Если адрес состоит из IP-адреса и порта, укажите только `http://IP:порт`, например: `http://127.0.0.1:3000`.
* Строго различайте `http` и `https`; если SSL не включен, не используйте https
{% endhint %}

* Добавьте модель (нажмите «Управление» для автоматического получения или введите вручную). Включите переключатель в правом верхнем углу, чтобы начать использование.

{% hint style="success" %}
Интерфейс других тем OneAPI может отличаться, но процесс добавления аналогичен описанному выше.
{% endhint %}
