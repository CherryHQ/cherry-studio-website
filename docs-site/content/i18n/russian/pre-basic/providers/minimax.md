# MiniMax

MiniMax — один из ведущих отечественных разработчиков больших языковых моделей, отличающийся выдающимися **мультимодальными возможностями** (генерация текста, аудио, изображений и видео).

## Получение API Key

* Зарегистрируйте аккаунт на [платформе MiniMax](https://platform.minimaxi.com/)
* После завершения верификации личности перейдите в `Управление аккаунтом → API-ключи` и создайте API Key

## Настройка в Cherry Studio

* Откройте `Настройки → Сервисы моделей`, найдите провайдера **MiniMax** и перейдите на страницу деталей
* Введите API-ключ
* Адрес API оставьте по умолчанию
* Нажмите **Получить список моделей**

## Рекомендуемое использование

| Модель | Подходящие сценарии |
|---|---|
| `abab6.5s-chat` / `MiniMax-Text-01` | Повседневные диалоги |
| `abab6.5-chat` | Высококачественные длинные тексты |

{% hint style="info" %}
* Доступ к MiniMax из Китая удобен, новым пользователям предоставляется бесплатный лимит
* Пользователям из-за рубежа следует использовать **MiniMax Global** (в списке провайдеров Cherry Studio это отдельный пункт)
{% endhint %}
