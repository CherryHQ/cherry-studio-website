# Azure OpenAI

Azure OpenAI — это сервис моделей OpenAI, размещённый Microsoft в Azure. Он подходит для команд, которым необходимы корпоративное соответствие требованиям, обязательства по хранению данных или интеграция с экосистемой Microsoft.

## Предварительные шаги

* Активирована подписка Azure
* Получено и одобрено разрешение на доступ к Azure OpenAI Service в Azure Portal
* Созданы как минимум один **ресурс (Resource)** и одно **развёртывание (Deployment)**

## Получение API Key

* Azure Portal → ваш ресурс Azure OpenAI → `Keys and Endpoint`
* Скопируйте `KEY 1` или `KEY 2` и запишите `Endpoint` (в формате `https://<your-name>.openai.azure.com/`)

## Настройка в Cherry Studio

* Откройте `Настройки → Сервисы моделей`, найдите провайдер **Azure OpenAI** и перейдите на страницу деталей
* **API-ключ**: вставьте скопированный KEY
* **Адрес API**: вставьте Endpoint ресурса (без конечного пути)
* **API Version**: введите версию API вашего развёртывания в соответствующее поле (например, `2024-08-01-preview`)
* Нажмите **Получить список моделей** или вручную добавьте имена моделей, которые вы уже развернули в Azure (именно Deployment Name, а не исходный идентификатор модели OpenAI)

{% hint style="warning" %}
**Deployment Name и Model ID**: в Azure используется имя, которое вы присвоили развёртыванию (например, `gpt-4o-prod`), а не исходный идентификатор вида `gpt-4o`. Неправильное значение приведёт к ошибке 404.
{% endhint %}

## Рекомендуемое использование

* **gpt-4o / gpt-4o-mini**: универсальный диалог, Agent
* **gpt-4 turbo**: длинный контекст
* **text-embedding-3-**\*: модели эмбеддингов, пригодные для баз знаний

## Частые проблемы

* **401 Unauthorized**: проверьте правильность Key и отсутствие лишнего слэша в конце Endpoint
* **404 Not Found**: проверьте, совпадает ли Deployment Name с данными в Azure, и заполнено ли поле API Version
* **429 Throttled**: проверьте квоты Azure (страница Quota & Limits)
