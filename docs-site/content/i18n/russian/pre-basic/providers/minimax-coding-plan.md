# MiniMax Coding Plan

**Coding Plan** — это выгодная подписка на программирование от MiniMax (например, тарифы Starter/Plus). Настроив этот тариф в Cherry Studio, вы сможете использовать модель `MiniMax-M2.1` по фиксированной низкой цене (от ¥29/мес).

{% hint style="success" %}
**Ключевые преимущества**

* **Для кого**: для пользователей с подпиской MiniMax Coding Plan (Starter / Plus / Max).
* **Модель оплаты**: лимиты обновляются по временным интервалам (например, 40 запросов Prompt каждые 5 часов), а не по количеству токенов, поэтому не нужно беспокоиться о быстром исчерпании лимита.
{% endhint %}

### 1. Подготовка

Прежде чем начать, убедитесь, что вы приобрели тариф и получили ключ:

1. Войдите в [**открытую платформу MiniMax**](https://platform.minimaxi.com/).
2. Перейдите на [**страницу Coding Plan**](https://platform.minimaxi.com/subscribe/coding-plan?code=FYWiC6CtHy\&source=link) и убедитесь, что тариф активен.

    <figure><img src="../../../../assets/e7c5f78ce7b02d24f47e524a.png" alt=""><figcaption></figcaption></figure>
3. Скопируйте ваш уникальный `API Key` в **Coding Plan** (начинается с `sk-`).

<figure><img src="../../../../assets/b7ad13e5818755c159e9cc7d.webp" alt=""><figcaption></figcaption></figure>

### 2. Шаги настройки

#### Шаг 1: Выбор провайдера

Откройте Cherry Studio, перейдите в **Настройки** > **Сервисы моделей** в боковой панели и найдите **MiniMax** в списке.

{% hint style="info" %}
Если список длинный, введите `mini` в поле поиска вверху, чтобы быстро найти нужный пункт.
{% endhint %}

#### Шаг 2: Заполнение настроек

**Не нужно** изменять сложные адреса API, используйте настройки по умолчанию, заполните поля согласно инструкции:

#### Шаг 3: Добавление указанной модели (важно)

Тариф Coding Plan поддерживает только определенные модели, выбор неправильной модели может привести к невозможности использования или дополнительным расходам.

1. Нажмите кнопку **Управление (Manage)** внизу страницы настроек.

<figure><img src="../../../../assets/a47dc9b50635537d2cca507d.png" alt=""><figcaption></figcaption></figure>

2. Найдите и добавьте **`MiniMax M2.1`** в списке.

{% hint style="warning" %}
**Обязательно выберите правильную модель!**

* ✅ **Рекомендуется**: `MiniMax M2.1` (основная модель для Coding Plan).
{% endhint %}

#### Шаг 4: Сохранение и проверка <a href="#headingcab61b6e3e264a4b8e56bc83923488d2-di-si-bu-bao-cun-bing-yan-zheng-0" id="headingcab61b6e3e264a4b8e56bc83923488d2-di-si-bu-bao-cun-bing-yan-zheng-0"></a>

1. Нажмите кнопку **Проверка (Check)** рядом с полем ввода API-ключа.
2. Если отображается зеленый **Success**, это означает, что ваш тариф Coding Plan успешно подключен!

### 3. Информация об использовании и ограничениях

Модель оплаты Coding Plan полностью отличается от обычной API, обязательно ознакомьтесь со следующими механизмами:

{% hint style="info" %}
**Механизм обновления лимитов** Лимиты Coding Plan обновляются **периодически**. Например, тариф Starter: **каждые 5 часов** предоставляется **40** лимитов на диалоги.

* **Если ответы прекратились**: это означает, что ваш лимит на текущие 5 часов исчерпан.
* **Решение**: подождите несколько часов, лимит восстановится автоматически, дополнительные платежи не требуются.
{% endhint %}

### 4. Устранение распространенных проблем

{% hint style="danger" %}
**Встречаете ошибку `429 Too Many Requests`?**

Это не сбой программного обеспечения, а срабатывание **ограничений частоты Coding Plan**.

* Это означает, что количество отправленных сообщений в текущем интервале исчерпано.
* Пожалуйста, подождите обновления следующего 5-часового цикла.
{% endhint %}

{% hint style="warning" %}
**Встречаете ошибку `401 Unauthorized`?**

* Проверьте, нет ли лишних пробелов в API Key.
* Войдите на официальный сайт MiniMax и убедитесь, что ваша подписка Coding Plan не истекла.
{% endhint %}
