# Облако Huawei


## 1. Создайте учётную запись Huawei Cloud

Перейдите на [Huawei Cloud](https://auth.huaweicloud.com/authui/login), создайте учётную запись и войдите.

## 2. Откройте консоль MaaS

Перейдите по [этой ссылке](https://console.huaweicloud.com/modelarts/?region=cn-southwest-2#/model-studio/homepage), чтобы открыть консоль MaaS.

## 3. Выполните авторизацию

<details>

<summary>Шаги авторизации (если уже авторизованы, пропустите)</summary>

1. После перехода по ссылке из шага 2 следуйте инструкциям на странице авторизации: выберите пользователя IAM, создайте доверенность и укажите обычного пользователя.

![](<../../../../assets/aadd7fee72e30b44d96077f9.webp>)

2. После создания вернитесь по ссылке из шага 2.
3.  При появлении сообщения "Недостаточно прав доступа" нажмите "Нажмите здесь" в уведомлении
4.  Добавьте существующую авторизацию и подтвердите

![](<../../../../assets/3822fe0fbffa97d235be312a.webp>)

Примечание: Этот метод подходит для новичков — не требует глубокого изучения, просто следуйте подсказкам. Если получилось авторизоваться с первого раза, действуйте своим способом.

</details>

## 4. Создайте API-ключ

В боковой панели выберите «Управление аутентификацией», создайте API-ключ и скопируйте его.

<figure><img src="../../../../assets/3c0b273ede5384ab42e9a73f.webp" alt=""><figcaption></figcaption></figure>

Затем в CherryStudio создайте нового поставщика услуг

<figure><img src="../../../../assets/bf41900ca20696ae6431dcbe.webp" alt="" width="300"><figcaption></figcaption></figure>

После создания вставьте скопированный секретный ключ


## 5. Разверните модель

В боковой панели выберите «Развертывание моделей» и активируйте нужные ресурсы.

<figure><img src="../../../../assets/1873de6008f16a55b00da110.webp" alt=""><figcaption></figcaption></figure>

## 6. Получите адрес вызова

Нажмите «Вызов».

<figure><img src="../../../../assets/667fd368893b85c31630e57c.webp" alt=""><figcaption></figcaption></figure>

Скопируйте адрес в позиции ①, вставьте в поле адреса поставщика услуг CherryStudio и добавьте символ "#" в конец

Зачем добавлять `#`? См. раздел [Адрес API](../settings/providers.md#адрес-api).

> Конечно, можно не читать и просто следовать инструкции;
> 
> Либо использовать метод удаления v1/chat/completions при заполнении. Если понимаете процесс — делайте как удобно, если нет — строго следуйте руководству.


<figure><img src="../../../../assets/f52646aeb184a33d1ca5b707.webp" alt=""><figcaption></figcaption></figure>

Затем скопируйте название модели в позиции ② и в CherryStudio нажмите "+Добавить" для создания новой модели

<figure><img src="../../../../assets/92195d94e22636a89fa27e67.webp" alt=""><figcaption></figcaption></figure>

Введите точное название модели без добавлений, без кавычек — скопируйте как в примере.

<figure><img src="../../../../assets/88588390c9eae759a0319a2b.webp" alt=""><figcaption></figcaption></figure>

Нажмите "Добавить модель" для завершения.

{% hint style="info" %}
В Huawei Cloud каждый модель имеет уникальный адрес, поэтому для каждой модели нужно создавать отдельного поставщика услуг, повторяя указанные шаги.
{% endhint %}
