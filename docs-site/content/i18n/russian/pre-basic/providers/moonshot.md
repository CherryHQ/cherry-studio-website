# Moonshot AI (Kimi)

Moonshot AI — известная китайская команда разработчиков больших языковых моделей. Их флагманский продукт — **Kimi**, который отличается **сверхдлинным контекстом** (до 2 млн символов) и идеально подходит для обработки больших объёмов документов или кода с помощью ИИ.

## Получение API-ключа

* Зарегистрируйте аккаунт на [платформе Moonshot](https://platform.moonshot.cn/)
* Перейдите в `Управление API-ключами` и создайте `sk-...`
* Пополните баланс на любую сумму для активации (минимальная сумма небольшая)

## Настройка в Cherry Studio

* Откройте `Настройки → Сервисы моделей`, найдите провайдера **Moonshot AI** и перейдите на страницу деталей
* Введите `sk-...`
* Адрес API по умолчанию: `https://api.moonshot.cn`
* Нажмите **Получить список моделей**

## Рекомендуемое использование

| Модель | Подходящие сценарии |
|---|---|
| `moonshot-v1-8k` | Короткий контекст, дёшево и быстро |
| `moonshot-v1-32k` | Средний контекст, достаточно для повседневных задач |
| `moonshot-v1-128k` | Длинный контекст, анализ документов, ревью кода |
| `kimi-k2-* / k2.5-*` | Новейшая флагманская модель, более сильное рассуждение |

## Подходящие сценарии

* **Анализ сверхдлинных PDF / документов**: преимущество Moonshot в длинном контексте проявляется наиболее ярко
* **Ревью больших фрагментов кода**: можно загрузить целый файл целиком без разбивки
* **Резюме целых электронных книг**: модель с длинным контекстом избавляет от необходимости ручной нарезки текста

{% hint style="info" %}
* Функция «кэширования контекста» в Moonshot значительно снижает расход токенов при повторяющихся диалогах, см. официальную документацию
* У Kimi есть собственный веб-интерфейс для диалогов, но подключение через API в Cherry Studio позволяет использовать расширенные возможности Cherry Studio, такие как ассистенты, базы знаний и инструменты MCP
{% endhint %}
