# Grok

Grok — это большая языковая модель от xAI, известная неформальным стилем общения и доступом к данным X (Twitter) в реальном времени.

## Получение API-ключа

* Зарегистрируйте аккаунт в [xAI Console](https://console.x.ai/)
* `API Keys` → `Create API Key`, скопируйте ключ `xai-...`

## Настройка в Cherry Studio

* Откройте `Настройки → Сервисы моделей`, найдите провайдера **Grok** и перейдите на страницу деталей
* В поле **API-ключ** вставьте `xai-...`
* **Адрес API** по умолчанию `https://api.x.ai`, изменения не требуются
* Нажмите **Получить список моделей** и добавьте модели `grok-4`, `grok-4-fast` и другие

## Рекомендуемое использование

| Модель | Подходящие сценарии |
|---|---|
| `grok-4` | Максимальная универсальность, лучший выбор для сложных задач |
| `grok-4-fast` | Высокая пропускная способность, низкая задержка |
| `grok-3-mini` | Низкая стоимость для повседневного общения |

## Поиск в интернете

Некоторые модели Grok поддерживают доступ в интернет; после имени модели отображается значок глобуса. Можно просто включить «Интернет» в диалоговом окне. Подробнее в разделе [Режим интернета](../../../../pre-basic/websearch).

{% hint style="info" %}
* Для доступа к Grok требуется международная сеть; пользователям из Китая рекомендуется использовать прокси
* xAI предоставляет бесплатный лимит (обновляется ежемесячно), которого достаточно для повседневного использования
{% endhint %}
