# DeepSeek V3.2

Пользователи Cherry Studio теперь могут бесплатно протестировать **DeepSeek V3.2** через встроенный сервис **CherryIN** — флагманскую модель MoE со спарсенным вниманием, выпущенную DeepSeek 1 декабря 2025 года. Впервые «размышление» (thinking) нативно интегрировано в вызов инструментов, что делает её идеальным выбором для продвинутых Agent и сценариев с длинным контекстом.

***

## Что такое DeepSeek V3.2?

DeepSeek V3.2 является итерацией V3.2-Exp, использует архитектуру Mixture-of-Experts (MoE) и внедряет механизм **DeepSeek Sparse Attention (DSA)** — спарсенного внимания. Это позволяет значительно снизить стоимость инференса на длинных контекстах, сохраняя сверхбольшой общий объем параметров.

- Архитектура: MoE + DeepSeek Sparse Attention (DSA) + Multi-Head Latent Attention (MLA)
- Общее количество параметров: 685B
- Активируемые параметры на токен: ~37B
- Количество экспертов: 256 на слой
- Лицензия: MIT
- Дата выпуска: 1 декабря 2025 года (V3.2-Exp выпущена 29 сентября 2025 года)

Вместе с V3.2 выпущена версия **DeepSeek-V3.2-Speciale** для API, демонстрирующая уровень золотых медалей на IMO, CMO, ICPC World Finals и IOI 2025 в задачах сложного рассуждения.

## Совершенствование процесса обучения и выравнивания

DeepSeek V3.2 сохраняет отработанную конвейерную систему обучения серии V3 и вносит ключевые расширения для сценариев Agent:

1. **Масштабное предобучение**: базовое обучение на огромных объемах высококачественных многоязычных данных, охватывающих код, математику и научные знания.
2. **Внедрение спарсенного внимания**: обучение основной модели и lightning indexer на последовательностях длиной 128K, где каждый query-токен выбирает 2048 key-value токенов для участия в внимании.
3. **Синтез данных для Agent**: новый метод синтеза данных для обучения Agent, охватывающий более 1 800 сред и более 85 000 сложных инструкций.
4. **Слияние размышления и вызова инструментов**: V3.2 — первая модель DeepSeek, нативно интегрирующая «размышление» в вызов инструментов, поддерживающая использование инструментов как в режиме «размышления», так и в режиме «без размышления».

## Флагманские ключевые возможности

DeepSeek V3.2 позиционируется как модель с возможностями, сопоставимыми с GPT-5, с существенным усилением в сценариях Agent и сложного рассуждения:

- ✅ **Нативное размышление + вызов инструментов**: первая модель DeepSeek, интегрирующая thinking в tool-use
- ✅ **Топовые возможности рассуждения**: V3.2-Speciale достигает уровня золотых медалей на IMO / CMO / ICPC World Finals / IOI 2025
- ✅ **Код и задачи разработки**: наследует сильные возможности работы с кодом серии V3
- ✅ **Стабильность длинного контекста**: способность к анализу длинных документов и кодовых баз на уровне репозитория благодаря DSA
- ✅ **Структурированный вызов инструментов**: подходит для создания Agent с многошаговым планированием и исполнением

## DeepSeek Sparse Attention: длиннее и экономичнее

DSA — ключевое технологическое обновление V3.2, реализованное через **lightning indexer + тонкий выбор токенов**:

- Впервые реализовано тонкое спарсенное внимание в больших моделях
- Снижение сложности ядра внимания с O(L²)
- Значительное ускорение обучения и инференса на длинных контекстах при сохранении качества вывода, почти идентичного плотному вниманию

| Сценарий | Рекомендуемое использование | Примеры |
| --- | --- | --- |
| Короткие диалоги / простые вопросы | Прямой вызов | Повседневные вопросы, резюме |
| Задачи средней сложности | Включение вызова инструментов | Анализ данных, рефакторинг кода |
| Сложные задачи Agent | Размышление + вызов инструментов | Многошаговое планирование, анализ кодовой базы, рецензирование длинных документов |

## Как использовать в Cherry Studio?

1. Откройте Cherry Studio и перейдите в **Настройки → Сервисы моделей**.
2. Найдите провайдера **CherryIN** и включите его.
3. Выберите **DeepSeek V3.2** в списке моделей.
4. Вернитесь в интерфейс чата и переключите модель в верхней части на **DeepSeek V3.2**, чтобы начать диалог.

> 💡 Совет: Бесплатный лимит моделей, предоставляемый CherryIN, покрывается официально Cherry Studio и подходит для повседневного тестирования и оценки; для производственных сред рекомендуется использовать официальный API DeepSeek.
