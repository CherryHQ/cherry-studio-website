# Zhipu GLM-4.6V

Пользователи Cherry Studio теперь могут бесплатно протестировать **Zhipu GLM-4.6V** через встроенный сервис **CherryIN** — флагманскую мультимодальную модель, выпущенную Z.ai (Zhipu AI) в декабре 2025 года. Модель построена на архитектуре MoE, поддерживает нативный мультимодальный контекст 128K и нативные мультимодальные вызовы инструментов, что делает её оптимальным выбором для задач понимания изображений и текста, а также для сценариев мультимодальных Agent.

***

## Что такое GLM-4.6V?

GLM-4.6V — это новейшее поколение мультимодальных моделей серии GLM-V от Z.ai. Модель нативно поддерживает единое моделирование текста и изображений, расширяя возможности контекста и вызова инструментов по сравнению с GLM-4.5V.

- Архитектура: Mixture-of-Experts (MoE)
- Общее количество параметров: 106B
- Активные параметры: около 12B
- Длина контекста: 128K токенов
- Лицензия: MIT
- Дата выпуска: 8–9 декабря 2025 года
- Визуальный энкодер: поддержка изображений с разным разрешением (до 4K)

В серию также входит **GLM-4.6V-Flash (9B)**, предназначенная для локального использования и сценариев с низкой задержкой, доступна бесплатно для коммерческого использования.

## Продолжение мультимодальной системы обучения серии GLM-V

GLM-4.6V следует техническому пути GLM-4.1V-Thinking / GLM-4.5V, с дальнейшим усилением возможностей в области зрения и Agent:

1. **Нативное мультимодальное моделирование**: совместное обучение текста и изображений, поддержка смешанного ввода текста и изображений
2. **Расширение контекста**: контекст обучения расширен до 128K токенов, что позволяет обрабатывать за один раз документы плотностью около 150 страниц, презентации на 200 слайдов или видео длительностью 1 час
3. **Нативные мультимодальные вызовы инструментов**: инструменты могут напрямую принимать и возвращать изображения, обрабатывая мультимодальные результаты в формате URL на основе расширенного протокола MCP
4. **Усиление с помощью обучения с подкреплением**: использование масштабируемого процесса RL из серии GLM-V

## Нативная мультимодальность для реальных сценариев

Мультимодальные возможности GLM-4.6V покрывают повседневные и профессиональные задачи:

- ✅ **Понимание богатого текста**: длинные документы, многостраничный текст и смешанный макет текста и изображений
- ✅ **Визуальный веб-поиск**: поиск и понимание информации в интернете с использованием визуального ввода
- ✅ **Воспроизведение фронтенда**: генерация фронтенд-кода из макетов дизайна или скриншотов UI
- ✅ **Анализ мультимодальных документов с длинным контекстом**: обработка целых PDF, презентаций или видеоматериалов
- ✅ **Разбор графиков и таблиц**: извлечение структурированной информации

***

## Нативные мультимодальные вызовы инструментов и возможности Agent

Одно из ключевых улучшений GLM-4.6V — замкнутый цикл **«визуальное восприятие → исполняемое действие»**: вызовы инструментов нативно поддерживают изображения как вход и выход, что позволяет внедрять мультимодальных Agent в реальные бизнес-процессы.

| Сценарий | Рекомендуемый подход | Пример |
| --- | --- | --- |
| Простые вопросы по изображениям и тексту | Прямой диалог | «Что на этом изображении?» |
| Задачи средней сложности | Включение вызова инструментов | Чтение графика и поиск данных |
| Сложные мультимодальные Agent | Несколько инструментов + MCP | Скриншот → понимание → вызов API → генерация отчета |

## Фокус на практических возможностях: мультимодальный ассистент

GLM-4.6V подходит для следующих сценариев в повседневном использовании:

- **Ассистент документов**: чтение и суммаризация длинных документов, сканов и презентаций целиком
- **Анализ данных**: распознавание и интерпретация графиков и скриншотов дашбордов
- **Фронтенд и дизайн**: генерация или модификация фронтенд-кода на основе скриншотов UI
- **Визуальный поиск**: поиск в интернете и интеграция информации с использованием изображений
- **Мультимодальный Agent**: выполнение сложных задач с использованием инструментов браузера, выполнения кода и поиска

## Как использовать в Cherry Studio?

1. Откройте Cherry Studio и перейдите в **Настройки → Сервисы моделей**.
2. Найдите провайдера **CherryIN** и включите его.
3. Выберите **Zhipu GLM-4.6V** в списке моделей.
4. Вернитесь в интерфейс чата, переключите модель на **GLM-4.6V** в верхней части окна, чтобы загружать изображения прямо в диалоге для мультимодального взаимодействия.

> 💡 Примечание: Бесплатный лимит моделей, предоставляемый CherryIN, покрывается официально Cherry Studio и подходит для повседневного тестирования и оценки; для производственных сред рекомендуется использовать официальный API Z.ai (Zhipu).
