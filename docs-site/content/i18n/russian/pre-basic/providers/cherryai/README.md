# CherryAI (бесплатно)

**CherryAI** — это официальный встроенный в Cherry Studio доступ к **бесплатным моделям** — не нужно регистрироваться на сторонних платформах и запрашивать ключи: сразу после запуска доступны модели с бесплатным лимитом. Подходит для новичков, которые хотят сначала освоить базовые функции.

### Где использовать

Откройте `Настройки → Сервисы моделей` и найдите **CherryAI** в списке встроенных провайдеров. Он предустановлен в программе и обычно не требует дополнительной настройки; нажмите **Получить список моделей**, чтобы увидеть доступные бесплатные модели.

### Доступные бесплатные модели

{% hint style="warning" %}
**Состав бесплатных моделей динамический.** Конкретные модели, их лимиты и ограничения устанавливаются сервером Cherry в реальном времени и периодически меняются, **поэтому ориентируйтесь на фактический результат, отображаемый после нажатия [Получить список моделей]**. Ниже приведено описание некоторых распространённых бесплатных моделей, но это не полный текущий список.
{% endhint %}

* [DeepSeek V3.2](free-deepseek.md)
* [ZhiPu GLM-4.6V](free-glm46v.md)
* [ZhiPu GLM-4.5-Air](free-glm45air.md)
* [Qwen3-8B](free-qwen.md)

Если нужны более стабильные и мощные модели, выберите [CherryIN](../cherryin-1.md) или другого [провайдера](../README.md).
