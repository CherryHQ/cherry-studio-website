# Mistral

Mistral AI — представитель европейских открытых больших моделей, предлагающий серии Mistral / Codestral, сочетающие качество и открытость.

## Получение API Key

* Откройте страницу [API Keys](https://console.mistral.ai/api-keys/) в консоли Mistral (требуется предварительная регистрация/вход)
* Создайте и скопируйте API Key

## Настройка в Cherry Studio

1. Откройте [настройки модельных сервисов](../settings/providers.md) в Cherry Studio и найдите **Mistral** в встроенном списке
2. Введите полученный API Key
3. Нажмите **Получить список моделей**, добавьте необходимые модели и включите переключатель провайдера в правом верхнем углу для начала использования

{% hint style="info" %}
Для доступа к Mistral из Китая обычно необходимо самостоятельно настроить сетевой прокси. Дополнительные сведения см. в [официальной документации Mistral](https://docs.mistral.ai).
{% endhint %}
