# LM Studio

LM Studio — популярный **графический интерфейс для локальных больших моделей**, позволяющий загружать, квантовать и выполнять инференс различных открытых моделей на вашем устройстве. Cherry Studio может подключаться к локальному сервису LM Studio в качестве фронтенда, обеспечивая улучшенный опыт общения при сохранении локальной конфиденциальности.

## Предварительная подготовка

1. Скачайте и установите клиент с [официального сайта LM Studio](https://lmstudio.ai/)
2. Загрузите хотя бы одну модель в LM Studio (рекомендуется начать с Llama 3.x 8B или серии Qwen)
3. Откройте вкладку **Server** в верхней части LM Studio и нажмите **Start Server** (порт по умолчанию `1234`)

## Настройка в Cherry Studio

* Откройте `Настройки → Сервисы моделей`, найдите провайдера **LM Studio** и перейдите на страницу деталей
* **Адрес API** по умолчанию `http://localhost:1234`; если вы изменили порт LM Studio, обновите его здесь
* **Ключ API** можно оставить пустым (для локального инференса аутентификация не требуется) или ввести, если вы включили аутентификацию в LM Studio
* Нажмите **Получить список моделей**, Cherry Studio автоматически загрузит список моделей, загруженных в LM Studio

{% hint style="info" %}
**Список моделей пуст?** LM Studio отображает только модели, **загруженные (`Load`) в память**. Модели, которые не были загружены, не появятся в списке. Вернитесь в LM Studio, загрузите модель, а затем снова нажмите «Получить список моделей».
{% endhint %}

## Рекомендуемое использование

| Сценарий | Рекомендация |
| -------------------- | --------------------------------------------------------------------- |
| Конфиденциальные диалоги | Используйте небольшие модели (менее 8B) локально, полностью офлайн |
| Apple Silicon (чипы серии M) | Используйте бэкенд MLX в LM Studio, эффективность значительно выше, чем у llama.cpp |
| Встраиваемые модели | LM Studio также может загружать встраиваемые модели для использования в базе знаний |

## Отличия от Ollama

| | LM Studio | [Ollama](ollama.md) |
| ---- | ------------- | ------------------- |
| Формат | Графический интерфейс + сервер | Командная строка / фоновая служба |
| Управление моделями | Просмотр/загрузка через GUI | `ollama pull` |
| API | Совместимый с OpenAI | Совместимый с OpenAI |
| Подходит для | Пользователей, предпочитающих графический интерфейс | Пользователей, предпочитающих командную строку / развертывание в Docker |

Оба инструмента можно подключить к Cherry Studio, выбирайте в соответствии со своими предпочтениями.

## Частые вопросы

* **Cherry Studio не может подключиться**: убедитесь, что сервер в LM Studio запущен (статус с зеленой точкой)
* **Очень медленный отклик**: модель слишком большая / недостаточно видеопамяти, используйте более маленькую модель или более агрессивное квантование (например, Q4 → Q3)
* **Гарbled текст / обрезанный вывод**: длина контекста превышает ограничения модели, увеличьте `n_ctx` в LM Studio
