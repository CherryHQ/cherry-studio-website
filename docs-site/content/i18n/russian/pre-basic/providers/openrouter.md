# OpenRouter

OpenRouter — это **единый шлюз**, позволяющий с одним ключом API получать доступ к разговорным моделям более 200 провайдеров (GPT, Claude, Gemini, Llama, DeepSeek и др.). Тарификация происходит по количеству токенов. Подходит для сравнения нескольких моделей или пользователям, которые не хотят регистрироваться в каждом сервисе отдельно.

## Получение API-ключа

* Зарегистрируйте аккаунт на [OpenRouter](https://openrouter.ai/)
* Перейдите в `Settings → Keys` → `Create Key` и скопируйте ключ `sk-or-...`
* Пополните баланс на любую сумму (минимум $1)

## Настройка в Cherry Studio

* Откройте `Настройки → Сервисы моделей`, найдите провайдера **OpenRouter** и перейдите на страницу настроек
* В поле **API-ключ** вставьте `sk-or-...`
* **Адрес API** по умолчанию `https://openrouter.ai/api`, изменения не требуются
* Нажмите **Получить список моделей**. OpenRouter вернет сотни доступных моделей

## Рекомендуемое использование

Идентификаторы моделей в OpenRouter имеют формат `<vendor>/<model>`:

| Пример ID модели | Фактический провайдер |
| ----------------------------------- | ------------------------- |
| `openai/gpt-4o` | OpenAI GPT-4o |
| `anthropic/claude-sonnet-4` | Anthropic Claude Sonnet 4 |
| `google/gemini-2.0-flash` | Google Gemini Flash |
| `meta-llama/llama-3.3-70b-instruct` | Meta Llama 3.3 70B |
| `deepseek/deepseek-chat` | DeepSeek V3 |
| `x-ai/grok-4` | xAI Grok |

## Сценарии применения

* **Сравнение моделей (A/B тестирование)**: переключайтесь между моделями в рамках одного провайдера Cherry Studio без смены провайдера
* **Избегание множественной регистрации**: один ключ и один счет для доступа к 200+ моделям
* **Нишевые модели**: многие малые провайдеры доступны только через OpenRouter (например, Cohere, Reka и др.)

## Нативный веб-поиск и чтение URL

Разговорные модели OpenRouter поддерживают нативный веб-поиск и чтение содержимого URL. При выборе модели обращайте внимание на значок 🌐 рядом с названием и включайте 🌐 в поле ввода диалога.

Если в разделе [Настройки] → [Веб-поиск] опция [Приоритетно использовать настроенный сервис поиска] включена, Cherry Studio будет использовать внешний сервис поиска. Если эту опцию отключить, приоритет получат нативные возможности моделей OpenRouter. Провайдеры могут взимать отдельную плату за запросы в интернет; фактические расходы смотрите в счете OpenRouter.

## Отношение к протоколу Anthropic

По умолчанию OpenRouter использует формат протокола OpenAI для всех моделей верхнего уровня. Это означает:

* ✅ Обычные диалоги, база знаний и быстрые помощники работают корректно
* ⚠️ Для [Cherry Agent](../../advanced-basic/agent.md) **рекомендуется использовать** Anthropic / CherryIN напрямую, а не через OpenRouter (Agent требует нативного протокола Anthropic)

{% hint style="info" %}
- OpenRouter добавляет небольшую наценку к ценам провайдеров (обычно 5–10%), что обеспечивает «универсальность одного аккаунта»
- Для некоторых моделей доступны версии "free" (бесплатно, с ограничением скорости). При фильтрации обращайте внимание на записи с суффиксом `(free)`
- Подробная таблица цен доступна на странице [OpenRouter Models](https://openrouter.ai/models)
{% endhint %}
