# Уведомления

Настройки уведомлений управляют тем, **как Cherry Studio оповещает вас при работе в фоновом режиме**. Когда вы переключаетесь на другие окна, Cherry Studio может показывать системные уведомления по завершении ключевых событий, чтобы вы не ждали безрезультатно и не пропускали результаты.

Откройте `Настройки → Уведомления`, здесь есть три независимых переключателя:

<figure><img src="../../../../assets/8f6458a65b2bb09759c9622f.webp" alt=""><figcaption><p>Панель настроек уведомлений</p></figcaption></figure>

| Переключатель | Когда вы получаете уведомление | Рекомендация |
| --- | --- | --- |
| **Сообщения ассистента** | Уведомление появляется, если ответ ИИ **успешен** и время генерации **превышает 30 секунд** (рядом с переключателем есть ⓘ с пояснением) | **Включите**. При использовании моделей рассуждений или генерации длинных текстов не нужно следить за экраном |
| **Резервное копирование** | По завершении автоматического или ручного резервного копирования | **Включите**. Убедитесь, что данные безопасно сохранены |
| **База знаний** | Уведомление по завершении задач, связанных с базой знаний (например, построение индекса) | **Включите**. Создание базы обычно занимает много времени, уведомление о завершении избавляет от необходимости ждать |

{% hint style="info" %}
Эти уведомления передаются через центр уведомлений операционной системы. Если вы вообще не получаете оповещения, проверьте, разрешено ли Cherry Studio отправлять уведомления на уровне системы (в macOS — «Уведомления», в Windows — «Уведомления и действия»).
{% endhint %}
