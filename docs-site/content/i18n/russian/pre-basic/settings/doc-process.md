# Обработка документов

Кратко: **это центральная настройка Cherry Studio для чтения PDF и документов со сложной вёрсткой в виде структурированного текста.**

PDF-файлы с таблицами, многостолбичной вёрсткой или отсканированными страницами (научные статьи, договоры, аналитические отчёты и т. д.) при прямой передаче модели часто распознаются некорректно. Обработка документов сначала преобразует их в текст с чёткой структурой с помощью специализированного движка анализа, после чего результат передаётся в диалог или [базу знаний](../../knowledge-base/knowledge-base.md).

{% hint style="info" %}
**Обработка документов и OCR**: это две отдельные страницы настроек.

* **Обработка документов** (на этой странице): управляет структурированным анализом **PDF / документов со сложной вёрсткой**.
* **[OCR](ocr.md)**: управляет распознаванием текста в **изображениях / сканах**.

Для обычных PDF с чистым текстом, `.md`/`.txt`/`.docx` ни один из этих инструментов не требуется — текст можно читать напрямую.
{% endhint %}

### Вход в настройки

Откройте [Настройки] → [Обработка документов], выберите движок анализа в выпадающем списке в правом верхнем углу. **Выбранный движок становится значением по умолчанию.**

### Встроенные движки анализа

В обработке документов предусмотрено 5 движков, по умолчанию используется **MinerU**:

| Движок | Описание | Способ подключения |
| --- | --- | --- |
| **MinerU** (по умолчанию) | Инструмент с открытым исходным кодом от OpenDataLab для высококачественного извлечения данных из PDF | Ключ API ([mineru.net/apiManage](https://mineru.net/apiManage)) |
| **PaddleOCR** | Система распознавания текста от Baidu Paddle | Введите ключ API ([сообщество PaddlePaddle](https://aistudio.baidu.com/paddleocr/)); при самостоятельном развертывании укажите адрес API вашего сервиса |
| **Doc2x** | Продвинутый движок восстановления файлов | Ключ API ([open.noedgeai.com](https://open.noedgeai.com/apiKeys)) |
| **Mistral** | Сервис анализа и понимания файлов | Ключ API ([mistral.ai](https://mistral.ai/api-keys)) |
| **Open MinerU** | Сервис MinerU, который можно развернуть самостоятельно, подходит для команд, желающих контролировать процесс обработки | После самостоятельного развертывания укажите адрес API (при необходимости введите ключ API) |

### Взаимосвязь с базой знаний

* Обработка документов отвечает только за этап «сложный документ → структурированный текст»;
* Преобразованный текст далее проходит векторизацию через [модель эмбеддингов](../../knowledge-base/emb-models-info.md) и сохраняется в базе;
* Подробный процесс «включения в базе знаний» см. в [Предварительная обработка документов в базе знаний](../../knowledge-base/document-preprocessing.md).

### Советы и рекомендации

* MinerU значительно лучше справляется с PDF, содержащими таблицы / многостолбичную вёрстку; рекомендуется использовать его в первую очередь для научных статей и подобных документов;
* Если нужно распознать **текст на изображении** (скриншоты, сканы), а не структуру PDF, используйте [OCR](ocr.md).
