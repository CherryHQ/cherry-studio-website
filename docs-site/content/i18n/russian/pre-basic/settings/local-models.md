# Локальные модели

Локальные модели — это встроенные в Cherry Studio **малые модели, работающие автономно после загрузки**: они не используют API сторонних провайдеров и не требуют ввода API-ключа. Они имеют небольшой размер, запускаются на вашем компьютере и предназначены для обеспечения базовых функций, для которых нецелесообразно настраивать отдельную облачную модель.

Откройте `Настройки → Локальные модели` для управления:

<figure><img src="../../../../assets/3ef4a2e692da5a39fccf7406.webp" alt=""><figcaption><p>Локальные модели: ① две встроенные локальные модели — локальная модель встраивания + локальная модель OCR (на изображении обе имеют статус «Готово», их можно удалить, нажав кнопку удаления справа)</p></figcaption></figure>

В настоящее время встроены два типа локальных моделей:

| Локальная модель | База | Размер | Назначение |
| ------------- | -------------------- | -------- | --------------------------------------------------------------- |
| **Локальная модель встраивания** | Qwen3 Embedding 0.6B | Около 614 МБ | Преобразование текста в векторы для сценариев поиска и извлечения в [базе знаний](../../knowledge-base/knowledge-base.md) |
| **Локальная модель OCR** | PaddleOCR PP-OCRv6 | Около 140 МБ | Автономное распознавание текста на изображениях / сканах, используется функцией [OCR](ocr.md) |

### Загрузка и статус

* Рядом с названием модели отображается значок статуса: у карточек без загруженной модели **внизу** расположена кнопка «**Загрузить**» на всю ширину; нажмите её для начала загрузки. После завершения загрузки значок изменится на **Готово**.
* Модели со статусом «Готово» можно удалить, нажав значок **Удалить** справа, чтобы освободить место на диске; при необходимости их можно загрузить снова. (Если модель встраивания используется базой знаний, удаление будет отклонено, а веса сохранены.)
* На некоторых платформах / архитектурах локальный вывод не поддерживается: в этом случае панель отображает сообщение «**Текущая платформа не поддерживает локальные модели**», и загрузка недоступна.

Если один из зеркал недоступен во время загрузки, Cherry Studio автоматически попытается использовать другие источники загрузки. После завершения загрузки процесс вывода локальной модели встраивания выполняется на локальной машине и не требует подключения к интернету.

{% hint style="warning" %}
Если на странице появляется сообщение «Файлы модели неполные, пожалуйста, загрузите их повторно для исправления.», это означает, что в локальном кэше отсутствуют необходимые файлы. Удалите или повторно загрузите эту модель для исправления; не объединяйте файлы модели вручную.
{% endhint %}

{% hint style="info" %}
Локальные модели — это **необязательный вариант**. Если вы уже настроили облачную модель встраивания в [Сервисе моделей](providers.md) или вам достаточно встроенного OCR системы, вы можете не загружать их.
{% endhint %}

### Когда использовать локальные модели

* **Нет облачной модели встраивания / не хотите платить отдельно за базу знаний**: загрузите локальную модель встраивания, чтобы база знаний могла создавать индексы и выполнять поиск в полностью автономном режиме.
* **Нужен автономный OCR**: в сценариях без сети или когда нежелательно загружать изображения на сторонние серверы, загрузите локальную модель OCR и выберите «Локальный PaddleOCR» в [Настройках OCR](ocr.md).
* **Приоритет конфиденциальности**: все вычисления выполняются на локальной машине, содержимое не покидает ваш компьютер.

{% hint style="warning" %}
Локальные модели — это легковесное решение «достаточно для базовых задач». Если требуются высокая точность поиска или распознавания, облачные [модели встраивания](../../knowledge-base/emb-models-info.md) и более мощные OCR-сервисы обычно дают лучший результат.
{% endhint %}
