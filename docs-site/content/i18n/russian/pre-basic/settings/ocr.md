# OCR

OCR (Optical Character Recognition, оптическое распознавание символов) превращает **текст на изображениях в копируемый текст, доступный для чтения ИИ**. От этого зависят следующие сценарии:

* Перетаскивание скриншота или скана в диалоговое окно, чтобы ИИ прочитал текст
* Добавление счетов или документов в формате изображения в [Базу знаний](../../knowledge-base/knowledge-base.md) для последующего поиска
* [Агент](../../advanced-basic/agent.md) открывает локальное изображение для анализа

OCR — это отдельная страница настроек. Настройте движок распознавания один раз в разделе [Настройки] → [OCR], и все функции, использующие распознавание текста на изображениях, будут применять эту конфигурацию.

### Выбор движка распознавания

Выпадающий список в правом верхнем углу панели используется для переключения движков OCR. **Выбранный движок становится значением по умолчанию**. Встроенные движки:

| Движок | Способ подключения / запуска | Для кого подходит |
| --- | --- | --- |
| **System OCR** | Офлайн, без настройки | Использование встроенного распознавания системы (macOS Live Text / Windows OCR), готово к работе, максимальная скорость |
| **PaddleOCR** | Введите API-ключ ([Сообщество PaddlePaddle](https://aistudio.baidu.com/paddleocr/)); при самостоятельном развертывании укажите адрес API вашего сервиса. Можно выбрать модель анализа | Для тех, кто не хочет нагружать локальные ресурсы, но хочет качество распознавания Paddle |
| **Локальный PaddleOCR** | Офлайн, требуется предварительное скачивание локальной модели OCR в [Настройки] → [Локальные модели] (около 140 МБ) | Хорошее распознавание китайского языка, полностью локальный запуск, приоритет конфиденциальности |
| **Tesseract OCR** | Офлайн, встроен | Классический открытый OCR, поддержка многоязычности, вариант на случай сбоя |
| **Mistral** | API-ключ Mistral | Распознавание с помощью мультимодальной LLM, более интеллектуальная обработка сложных макетов / рукописного текста |
| **Intel OV OCR** | Локальный запуск (Intel OpenVINO, ускорение NPU) | **Появляется только на Windows + Intel Core Ultra (с NPU) при развернутой модели OV**, на других устройствах этот пункт не отображается |

{% hint style="success" %}
Не уверены, какой выбрать? Начните с **System OCR** — он справляется с большинством скриншотов и четких сканов без какой-либо настройки. Если качество распознавания неудовлетворительное, переключитесь на Локальный PaddleOCR или Mistral.
{% endhint %}

При выборе System OCR панель отображает <mark style="color:green;">Обнаружено, что движок macOS Live Text / Windows OCR доступен</mark> (если система не поддерживает, этот пункт не появится в выпадающем списке).

{% hint style="warning" %}
* Перед выбором «Локальный PaddleOCR» скачайте «Локальную модель OCR» в разделе [Настройки] → [Локальные модели], иначе вызов невозможен.
* Для **Tesseract** (и System OCR на Windows) можно отметить языки распознавания в выпадающем списке «Язык» на панели.
{% endhint %}

### Отличие от обработки документов

Многие путают OCR и [Обработку документов](doc-process.md). Краткое различие:

* **OCR**: распознавание текста в **изображениях / сканах** (изображение → текст).
* **Обработка документов**: структурированный анализ **PDF / документов со сложным макетом** (PDF с таблицами, многостолбичный → структурированный текст).

Эти функции независимы и настраиваются отдельно. Текстовые абзацы в чистых текстовых PDF, `.md`/`.txt`/`.docx` не проходят ни через один из этих процессов и читаются напрямую.
