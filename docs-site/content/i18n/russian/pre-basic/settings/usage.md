# Статистика использования

Статистика использования **агрегирует данные о вызовах моделей в Cherry Studio в наглядную панель**: сколько потрачено, сколько Token использовано, сколько запросов отправлено, какая модель используется чаще всего — всё это видно сразу. Это помогает оценивать затраты, выявлять аномальное потребление и принимать решения о выборе моделей.

Откройте `Настройки → Статистика использования`. Страница разделена на три раздела: **Обзор / Исследование / Запросы**. В правом верхнем углу можно переключать периоды: **последние 30 дней / последние 90 дней / последний год**. Все данные рассчитываются для выбранного периода.

### Обзор

Вверху расположены карточки метрик:

| Метрика | Описание |
| --- | --- |
| **Общая стоимость** | Оценочные расходы за период (рассчитаны на основе публичных цен моделей, только для справки) |
| **Количество запросов** | Общее количество отправленных запросов |
| **Общее количество Token** | Суммарное количество входных и выходных Token |
| **Частота попадания в кэш** | Доля запросов, попавших в кэш промптов (прочитанные из кэша ÷ наблюдаемые входные данные). Чем выше, тем больше экономия |
| **Активные дни / Максимальная серия** | Количество дней с записями об использовании и максимальное количество дней подряд |
| **Пиковый день** | Дата с максимальным суточным потреблением и количество Token |
| **Модель с максимальным потреблением** | Модель с наибольшим расходом за период |
| **Среднее в день** | Среднее количество Token и запросов в день |

Ниже расположена **тепловая карта ежедневной активности**, показывающая интенсивность использования по дням. Можно переключаться между метриками **Token / Стоимость**. Чем темнее цвет, тем больше использовано в этот день.

### Исследование / Анализ

В разделе **Исследование** можно детально анализировать потребление: разбивка по **группам** (провайдер / модель / API-ключ / ассистент·Agent), выбор **метрики** и просмотр распределения и трендов с помощью **столбчатой диаграммы / линейного графика / круговой диаграммы / сегментов**.

### Детализация запросов

Раздел **Запросы** содержит построчные записи запросов, что позволяет определить, какие именно запросы создали основной расход.

> Хотите посмотреть за конкретный день? Кликните на нужный день в **тепловой карте ежедневной активности** в разделе «Обзор». Раздел «Исследование» (Анализ + Запросы) **свернется** к данным за этот день, а заголовок изменится на «Детализация за [дата]». Нажмите «Очистить фильтр по дате», чтобы вернуться.

{% hint style="info" %}
Стоимость является **оценочной**: она рассчитывается на основе публичных цен моделей. Фактическое списание средств определяется счетами провайдеров моделей. Бесплатные и локальные модели не генерируют расходы.
{% endhint %}
