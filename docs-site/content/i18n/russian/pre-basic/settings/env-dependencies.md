# Зависимости среды

Раздел «Зависимости среды» предназначен для **управления бинарными утилитами и средами выполнения, необходимыми для работы некоторых расширенных функций Cherry Studio**. Для реализации ряда возможностей [MCP-сервисов](../../../../advanced-basic/extensions/mcp), [навыков](../../advanced-basic/extensions/skills.md) и [Agent](../../advanced-basic/agent.md) на уровне системы вызываются командные утилиты, такие как `uv` и `bun`. Cherry Studio централизует их управление в этом разделе, чтобы вам не приходилось вручную устанавливать и настраивать их через командную строку.

Откройте `Настройки → Зависимости среды`:

### Встроенные и устанавливаемые

Каждая утилита отображается в виде карточки с указанием статуса:

* Утилиты, отмеченные как <mark style="color:blue;">**встроенные**</mark>, поставляются вместе с Cherry Studio и готовы к использованию сразу после установки, без дополнительных действий.
* На карточках неустановленных утилит отображается кнопка **Установить**. При нажатии Cherry Studio автоматически скачивает и устанавливает утилиту в каталог приложения, не затрагивая системную среду.
* На карточках доступны ссылки на репозиторий исходного кода, официальную документацию, а также возможность открыть локальный каталог установки.

Список популярных утилит:

| Утилита | Назначение |
| --- | --- |
| **uv** | Менеджер пакетов Python для установки MCP-сервисов и зависимостей |
| **Bun** | Среда выполнения JavaScript для MCP-сервисов и связанных инструментов |
| **fd** | Быстрый поиск файлов, альтернатива `find` |
| **ripgrep (rg)** | Быстрый поиск текста, альтернатива `grep` |
| **RTK** | CLI-прокси для сжатия вывода терминала и снижения расхода токенов LLM |
| **Lark CLI** | Официальный CLI Feishu, поддерживающий более 200 команд для сообщений, документов, многомерных таблиц, календаря и т. д. |

На странице также в виде карточек перечислены утилиты `gh` (GitHub CLI), `ntn` (Notion CLI), `pi` и другие, которые можно установить в один клик по мере необходимости. (CLI-инструменты для программирования, такие как Claude Code / Codex, управляются на странице [Партнер по кодированию](../../cherrystudio/preview/code-cli.md) и не отображаются здесь.)

### Добавление утилит

Кнопка «**Добавить утилиту**» в правом верхнем углу позволяет с помощью инструмента mise добавлять утилиты, не входящие в стандартный список (например, `github:sharkdp/fd`, `uv`, `bun`).

### Расширенные настройки установки

Нажмите на значок настроек в правом верхнем углу, чтобы открыть «**Расширенные настройки установки**» и настроить способ загрузки утилит (все поля можно оставить пустыми для использования значений по умолчанию):

* **Зеркало GitHub**: добавляет префикс прокси для загрузки релизов GitHub (например, `https://ghfast.top`). Используйте, если прямое соединение нестабильно.
* **Токен GitHub**: повышает лимит запросов к API GitHub при проверке утилит (хранится в открытом виде локально).
* **Зеркало npm / адрес индекса pip**: настраивает зеркала для утилит типа `npm:` / `pipx:` (если оставить пустым, в Китае автоматически выбирается зеркало).
* **Проверка подписи утилит**: проверяет подписи Sigstore / SLSA утилит. Рекомендуется оставить включенным.

{% hint style="info" %}
Обычным пользователям, как правило, не нужно выполнять действия в этом разделе — при необходимости использования конкретной утилиты соответствующая функция (например, установка MCP-сервиса) обычно направит вас сюда для установки в один клик. Эта страница служит скорее входной точкой для проверки и дополнения среды выполнения.
{% endhint %}

{% hint style="warning" %}
Если MCP-сервис или навык выдает ошибку «uv / bun не найдены» или «команда не существует», сначала проверьте здесь, установлена ли соответствующая утилита или имеет статус «встроенная» (статус установки обновляется автоматически; кнопка в правом верхнем углу — **Проверить обновления**, используется для получения последней версии утилит).
{% endhint %}
