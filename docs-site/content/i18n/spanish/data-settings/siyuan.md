# Tutorial de Configuración de SiYuan Note


Permite exportar temas y mensajes a SiYuan Note.

## Primer paso

Abre SiYuan Note y crea un cuaderno

<figure><img src="../../../assets/dd6bc4a7ef5d1aebb8b2d312.webp" alt=""><figcaption><p>Haz clic en "Nuevo cuaderno"</p></figcaption></figure>

## Segundo paso

Abre la configuración del cuaderno y copia el `ID del cuaderno`

<figure><img src="../../../assets/722fb2171c5a8f812383d0f8.webp" alt="" width="400"><figcaption><p>Abrir configuración del cuaderno</p></figcaption></figure>

<figure><img src="../../../assets/c312b9bc99f830ab1b41ac10.webp" alt=""><figcaption><p>Haz clic en el botón "Copiar ID del cuaderno"</p></figcaption></figure>

## Tercer paso

Pega el ID del cuaderno en la configuración de Cherry Studio

<figure><img src="../../../assets/716b071bfad08d4a1da43518.webp" alt=""><figcaption><p>Ingresa el ID del cuaderno en la configuración de datos</p></figcaption></figure>

## Cuarto paso

Ingresa la dirección de SiYuan Note

* **Local**\
  Normalmente `http://127.0.0.1:6806`
* **Auto-despliegue**\
  Tu dominio `http://note.domain.com`

<figure><img src="../../../assets/81ebbe7310606969011d3c4c.webp" alt=""><figcaption><p>Ingresa tu dirección de SiYuan Note</p></figcaption></figure>

## Quinto paso

Copia el `Token de API` de SiYuan Note

<figure><img src="../../../assets/7279410a41255ae1b9eb7d42.webp" alt=""><figcaption><p>Copiar token de SiYuan Note</p></figcaption></figure>

Pégalo en la configuración de Cherry Studio y comprueba

<figure><img src="../../../assets/f2404dad4a63a2ef4c33556f.webp" alt=""><figcaption><p>Ingresa el ID de base de datos y haz clic en "Comprobar"</p></figcaption></figure>

## Sexto paso

¡Felicidades! La configuración de SiYuan Note está completa ✅ Ahora puedes exportar contenido de Cherry Studio a tu SiYuan Note

<figure><img src="../../../assets/bdf29a62e99f73745fadd772.webp" alt=""><figcaption><p>Exportar a SiYuan Note</p></figcaption></figure>
