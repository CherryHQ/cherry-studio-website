# Inicio rápido

Sigue estos pasos para configurar un modelo y enviar tu primer mensaje en pocos minutos.

## 1. Instalar Cherry Studio

Descarga el paquete correspondiente a tu sistema y procesador desde la [página oficial](https://cherryai.com/download). Consulta [Descarga e instalación](../cherry-studio/installation/README.md) si encuentras algún problema.

## 2. Elegir un proveedor de modelos

Abre **Configuración → Servicios de modelos**. Si aún no tienes una clave API, usa la [referencia rápida de proveedores](../pre-basic/providers/quick-reference.md) para elegir según tu región, las capacidades del modelo y tus necesidades de privacidad.

## 3. Añadir y activar un modelo

Abre la configuración del proveedor, introduce la clave API, obtén la lista de modelos, añade un modelo de chat y activa el proveedor. Consulta [Configuración del servicio de modelos](../pre-basic/settings/providers.md) para más detalles.

## 4. Enviar el primer mensaje

Vuelve a **Chat**, crea o abre un asistente, selecciona el modelo añadido y envía un mensaje. Recibir una respuesta confirma que la configuración básica funciona.
