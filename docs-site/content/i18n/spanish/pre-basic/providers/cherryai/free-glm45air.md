# Zhipu GLM-4.5-Air

Para que cada desarrollador y usuario pueda experimentar fácilmente las capacidades de los modelos de lenguaje de vanguardia, **Zhipu ofrece el modelo GLM-4.5-Air de forma gratuita a los usuarios de Cherry Studio**. Como un modelo base eficiente diseñado específicamente para aplicaciones de agentes (Agent), GLM-4.5-Air logra un excelente equilibrio entre rendimiento y costo, siendo la elección ideal para construir aplicaciones inteligentes.

***

**🚀 ¿Qué es GLM-4.5-Air?**

GLM-4.5-Air es el último modelo de lenguaje de alto rendimiento lanzado por Zhipu, que adopta una avanzada **arquitectura de expertos mixtos (Mixture-of-Experts, MoE)**, reduciendo significativamente el consumo de recursos de cómputo mientras mantiene una capacidad de razonamiento excepcional.

* **Parámetros totales: 106 mil millones**
* **Parámetros activos: 12 mil millones**

Gracias a su diseño optimizado, GLM-4.5-Air logra una mayor eficiencia de inferencia, lo que lo hace adecuado para su despliegue en entornos con recursos limitados, mientras sigue siendo capaz de manejar tareas complejas.

**📚 Proceso de entrenamiento unificado, base sólida para la inteligencia**

GLM-4.5-Air comparte el mismo proceso de entrenamiento que la serie insignia, lo que garantiza una base sólida de capacidades generales:

1. **Preentrenamiento a gran escala**: Entrenado con hasta **15 billones de tokens de corpus general**, construyendo una amplia capacidad de comprensión del conocimiento;
2. **Optimización de dominios específicos**: Entrenamiento reforzado en tareas clave como generación de código, razonamiento lógico e interacción de agentes;
3. **Soporte de contexto largo**: La longitud del contexto se ha extendido a **128K tokens**, permitiendo procesar documentos largos, conversaciones complejas o proyectos de código grandes;
4. **Mejora mediante aprendizaje por refuerzo**: Optimización del modelo mediante RL para mejorar su capacidad de toma de decisiones en planificación de inferencia, invocación de herramientas, entre otros.

Este sistema de entrenamiento dota a GLM-4.5-Air de una excelente capacidad de generalización y adaptabilidad a las tareas.

***

**⚙️ Capacidades centrales optimizadas específicamente para agentes**

GLM-4.5-Air se ha adaptado profundamente a los escenarios de aplicaciones de agentes, poseyendo las siguientes capacidades prácticas:

✅ **Soporte de invocación de herramientas**: Puede invocar herramientas externas a través de interfaces estandarizadas para lograr la automatización de tareas\
✅ **Navegación web y extracción de información**: Puede trabajar con extensiones de navegador para comprender e interactuar con contenido dinámico\
✅ **Asistencia en ingeniería de software**: Soporta el análisis de requisitos, generación de código, identificación y corrección de defectos\
✅ **Soporte para desarrollo frontend**: Tiene una buena comprensión y capacidad de generación para tecnologías frontend como HTML, CSS y JavaScript

Este modelo se puede integrar flexiblemente en marcos de agentes de código como **Claude Code, Roo Code**, o utilizarse como motor central para cualquier Agent personalizado.

**💡 Modo de "pensamiento" inteligente, respuesta flexible a diversos tipos de solicitudes**

GLM-4.5-Air admite el **modo de inferencia mixta**, los usuarios pueden controlar si se activa el pensamiento profundo mediante el parámetro `thinking.type`:

* `enabled`: Activa el pensamiento, adecuado para tareas complejas que requieren razonamiento paso a paso o planificación
* `disabled`: Desactiva el pensamiento, para consultas simples o respuestas inmediatas
* La configuración predeterminada es el **modo de pensamiento dinámico**, donde el modelo decide automáticamente si necesita un análisis profundo

| Tipo de tarea | Ejemplo |
| ------------------ | ----------------------------------------------- |
| **Tareas simples** (se recomienda desactivar el pensamiento) | <p>- Consultar "¿Cuándo se fundó Zhipu AI?"<br>- Traducir "I love you" al chino</p> |
| **Tareas medianas** (se recomienda activar el pensamiento) | <p>- Comparar las ventajas y desventajas del avión y el tren de alta velocidad de Pekín a Shanghái<br>- Explicar por qué Júpiter tiene muchos satélites</p> |
| **Tareas complejas** (se recomienda encarecidamente activar el pensamiento) | <p>- Explicar cómo colaboran los expertos en un modelo MoE<br>- Analizar si se debe comprar un ETF basándose en información del mercado</p> |

***

**🌟 Alto rendimiento y bajo costo, despliegue más fácil**

GLM-4.5-Air logra un excelente equilibrio entre rendimiento y costo, siendo especialmente adecuado para el despliegue en negocios reales:

* ⚡ **Velocidad de generación superior a 100 tokens/segundo**, respuesta rápida, soporta interacción de baja latencia
* 💰 **Costo de API muy bajo**: Entrada solo **0.8 yuanes/millón de tokens**, salida **2 yuanes/millón de tokens**
* 🖥️ Pocos parámetros activos, baja demanda de potencia de cómputo, fácil de ejecutar con alta concurrencia en local o en la nube

Logra verdaderamente una experiencia de servicio de IA de "alto rendimiento y bajo umbral de entrada".
