# CherryAI (gratis)

**CherryAI** es la entrada oficial integrada en Cherry Studio para **modelos gratuitos**: no es necesario registrarse en plataformas de terceros ni solicitar una clave; al abrirlo, puede utilizar directamente los modelos con cupo gratuito disponible. Es ideal para usuarios que están comenzando y desean probar las funciones básicas.

### Dónde usarlo

Abra `Configuración → Servicios de modelos` y busque **CherryAI** en la lista integrada. Está preconfigurado con el software y generalmente no requiere ajustes adicionales; haga clic en **Obtener lista de modelos** para ver los modelos gratuitos disponibles actualmente.

### Modelos gratuitos disponibles

{% hint style="warning" %}
**La oferta de modelos gratuitos es dinámica.** Los modelos específicos, sus cupos y límites de tasa los emite en tiempo real el servidor de Cherry y pueden ajustarse periódicamente; **tome como referencia los resultados reales que vea al hacer clic en [Obtener lista de modelos] dentro del software**. Los siguientes puntos solo describen algunos modelos gratuitos comunes y no representan la lista completa actual.
{% endhint %}

* [DeepSeek V3.2](free-deepseek.md)
* [Zhipu GLM-4.6V](free-glm46v.md)
* [Zhipu GLM-4.5-Air](free-glm45air.md)
* [Qwen3-8B](free-qwen.md)

Si necesita modelos más estables y potentes, puede elegir [CherryIN](../cherryin-1.md) u otros [proveedores](../README.md).
