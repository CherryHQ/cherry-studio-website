# MiniMax

MiniMax es uno de los proveedores de modelos de lenguaje de gran escala en China, destacado por sus notables **capacidades multimodales** (generación de texto, voz, imágenes y video).

## Obtener la API Key

* Registre una cuenta en la [Plataforma Abierta de MiniMax](https://platform.minimaxi.com/)
* Después de completar la verificación de identidad, ingrese a `Administración de cuenta → Claves API` para crear la API Key

## Configuración en Cherry Studio

* Abra `Configuración → Servicios de modelos`, encuentre el proveedor **MiniMax** y acceda a la página de detalles
* Introduzca la clave de API
* Mantenga la dirección de API en el valor predeterminado
* Haga clic en **Obtener lista de modelos**

## Usos recomendados

| Modelo | Escenarios adecuados |
|---|---|
| `abab6.5s-chat` / `MiniMax-Text-01` | Conversaciones diarias |
| `abab6.5-chat` | Textos largos de alta calidad |

{% hint style="info" %}
* El acceso a MiniMax es conveniente dentro de China; los nuevos usuarios cuentan con un cierto límite gratuito
* Los usuarios internacionales deben utilizar **MiniMax Global** (aparece como una entrada independiente en la lista de proveedores de Cherry Studio)
{% endhint %}
