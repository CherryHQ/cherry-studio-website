# Mistral

Mistral AI es un referente de los modelos de lenguaje de gran escala de código abierto en Europa, y ofrece series como Mistral / Codestral, equilibrando rendimiento y apertura.

## Obtener la API Key

* Abra la [página de API Keys](https://console.mistral.ai/api-keys/) de la consola de Mistral (es necesario registrarse o iniciar sesión previamente)
* Cree y copie una API Key

## Configuración en Cherry Studio

1. Abra la [configuración de servicios de modelos](../settings/providers.md) de Cherry Studio y busque **Mistral** en la lista integrada
2. Introduzca la API Key recién obtenida
3. Haga clic en **Obtener lista de modelos**, agregue los modelos que necesite y active el interruptor del proveedor en la esquina superior derecha para comenzar a usarlo

{% hint style="info" %}
El acceso a Mistral desde China generalmente requiere resolver los problemas de proxy de red por su cuenta. Para más información, consulte la [documentación oficial de Mistral](https://docs.mistral.ai).
{% endhint %}
