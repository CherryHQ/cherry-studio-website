# Perplexity

La serie **Sonar** de Perplexity se centra en el **diálogo mejorado con búsqueda**: las respuestas se combinan con búsquedas en tiempo real en la web, lo que la hace adecuada para escenarios que requieren citar información actualizada.

## Obtener la API Key

* Abra la [página de configuración de API](https://www.perplexity.ai/settings/api) de Perplexity (es necesario registrarse o iniciar sesión previamente)
* Genere y copie una API Key

## Configuración en Cherry Studio

1. Abra la [configuración de servicios de modelos](../settings/providers.md) de Cherry Studio y busque **Perplexity** en la lista integrada
2. Introduzca la API Key recién obtenida
3. Haga clic en **Obtener lista de modelos**, agregue modelos como Sonar y active el interruptor del proveedor en la esquina superior derecha para comenzar a usarlo

{% hint style="info" %}
Los modelos de Perplexity incluyen la capacidad de búsqueda en la web de forma nativa, por lo que no es necesario configurar un modo de conexión a internet adicional. Para acceder desde China, generalmente es necesario resolver los problemas de proxy de red por cuenta propia. Para más información, consulte la [documentación oficial de Perplexity](https://docs.perplexity.ai/home).
{% endhint %}
