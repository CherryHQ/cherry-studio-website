# ZhiPu

La serie **GLM** de ZhiPu AI (incluye el multimodal GLM-4V) ofrece conexión directa en China y un buen rendimiento en chino. ZhiPu utiliza un **punto de final compatible con Anthropic** en Cherry Studio, por lo que, además de la conversación normal, también puede utilizarse con **Cherry Agent**.

## Obtener la API Key

* Abra la [página de API Keys](https://open.bigmodel.cn/apikey/platform) de la plataforma abierta de ZhiPu (es necesario registrarse o iniciar sesión previamente)
* Cree y copie una API Key

## Configuración en Cherry Studio

1. Abra la [configuración de servicios de modelos](../settings/providers.md) de Cherry Studio y busque **ZhiPu** en la lista integrada
2. Introduzca la API Key recién obtenida
3. Haga clic en **Obtener lista de modelos**, agregue los modelos GLM que necesite y active el interruptor del proveedor en la esquina superior derecha para comenzar a usarlo

{% hint style="info" %}
Los modelos de ZhiPu incluyen la capacidad de **búsqueda en línea**, sujeta a la compatibilidad de cada modelo. Para más documentación de la plataforma, consulte la [documentación oficial de ZhiPu](https://docs.bigmodel.cn/).
{% endhint %}
