# Launchpad

Launchpad centraliza los puntos de entrada a las funciones más utilizadas de Cherry Studio. Haz clic en el símbolo **+** a la derecha de la barra de pestañas superior para abrir una nueva pestaña de Launchpad; al cerrar la última pestaña, se volverá automáticamente a Launchpad.

![Los nueve puntos de entrada de aplicaciones integradas en Launchpad](../../../../assets/7521831e54a609b69a5fceeb.png)

## Aplicaciones predeterminadas

Actualmente, Launchpad incluye 9 aplicaciones integradas:

| Aplicación | Uso |
| --------------------------------------- | ----------------------- |
| [Diálogo](chat.md) | Chatear con el modelo, gestionar asistentes y listas de conversaciones |
| [Trabajo](../../advanced-basic/agent.md) | Permitir que el agente invoque herramientas y complete tareas de múltiples pasos |
| [Dibujo](drawing.md) | Generar y gestionar imágenes utilizando modelos de imagen |
| [Traducción](translation.md) | Traducir texto y comparar el original con la traducción |
| [Miniaplicaciones](../../cherry-studio/preview/app) | Utilizar aplicaciones web dentro de Cherry Studio |
| [Base de conocimientos](knowledge-base.md) | Importar materiales y realizar búsquedas y preguntas |
| [Archivos](files.md) | Ver y gestionar los archivos utilizados en la aplicación |
| [Compañero de código](code-cli.md) | Instalar, configurar e iniciar herramientas CLI de programación con IA |
| [Notas](notes.md) | Crear y organizar notas en Markdown |

## Ajustar el orden de las aplicaciones

Mantén presionado el icono de la aplicación y arrástralo a la posición deseada para ajustar el orden de las aplicaciones integradas. Cherry Studio guardará automáticamente el nuevo orden.

Launchpad y la barra lateral guardan sus propios órdenes de aplicaciones de forma independiente. Reordenar en Launchpad no cambia el orden de la barra lateral.

## Fijar en la barra lateral

Las aplicaciones que se utilizan con frecuencia pueden fijarse en la barra lateral:

1. Haz clic derecho sobre la aplicación en Launchpad.
2. Selecciona **Añadir a la barra lateral**.
3. Para desanclarla, haz clic derecho nuevamente y selecciona **Quitar de la barra lateral**.

> **Sugerencia:** **Diálogo** es un punto de entrada obligatorio en la barra lateral y no puede eliminarse. Las demás aplicaciones, aunque no estén fijadas en la barra lateral, siguen pudiendo abrirse desde Launchpad.

## Gestionar miniaplicaciones

Después de añadir una aplicación web a Launchpad desde la página [Miniaplicaciones](../../cherry-studio/preview/app), esta se mostrará en la sección "Miniaplicaciones" debajo de las aplicaciones integradas.

* Arrastra el icono de la miniaplicación para ajustar el orden de visualización.
* Haz clic derecho sobre la miniaplicación para añadirla a la barra lateral o eliminarla de Launchpad.
* Eliminar de Launchpad solo quita el acceso directo y no elimina la miniaplicación en sí.
