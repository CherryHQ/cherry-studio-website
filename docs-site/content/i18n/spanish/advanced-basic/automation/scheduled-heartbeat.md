# Tareas programadas, latidos y registros de ejecución


<details>

<summary>¿Qué hacer si la tarea se ejecutó pero el canal no recibió el mensaje?</summary>

Primero, consulte el [Historial de ejecución] para confirmar si el Agent se completó con éxito. Si la tarea fue exitosa, verifique el destino de recepción del canal; si la tarea falló, haga clic en [Ver conversación] para revisar errores de modelo, permisos, espacio de trabajo y herramientas.

</details>
