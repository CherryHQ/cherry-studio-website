# Directorio de trabajo, tareas y archivos

<details>

<summary>¿Qué archivos no se pueden editar directamente?</summary>

Los archivos binarios, el texto que no es UTF-8 y los archivos de gran tamaño solo ofrecen vista previa o apertura externa. Aún pueden ser procesados por las herramientas de Agent, pero no necesariamente se pueden modificar en el editor integrado.

</details>
