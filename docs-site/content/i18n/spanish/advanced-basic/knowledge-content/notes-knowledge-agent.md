# Notas, base de conocimientos y Agent


<details>

<summary>¿Se sincronizan inmediatamente las modificaciones cuando una nota se añade a la base de conocimientos?</summary>

Primero, revise el estado de los datos en la base de conocimientos. Si el contenido ha cambiado pero los resultados de la recuperación no se han actualizado, vuelva a procesar el material correspondiente y realice nuevamente una prueba de recuperación.

</details>
