# Búsqueda global

La búsqueda global permite encontrar mensajes, conversaciones, tareas, asistentes, Agent y bases de conocimiento desde un único punto de entrada. Es útil cuando recuerdas el contenido pero no dónde lo guardaste.

## Cómo usarla

{% stepper %}
{% step %}
### 1. Haz clic en el botón de búsqueda en la parte superior de la ventana

También puedes ver o modificar el atajo de teclado correspondiente en [Configuración] → [Atajos de teclado].
{% endstep %}

{% step %}
### 2. Introduce palabras clave distintivas

Prioriza nombres de proyecto, nombres de personas, temas de archivos o frases de las conclusiones. Si solo introduces términos comunes como "configuración" o "informe", los resultados suelen ser demasiado numerosos.
{% endstep %}

{% step %}
### 3. Acota el alcance de la búsqueda

Cambia a [Mensajes] o usa los filtros [Conversaciones], [Tareas], [Asistentes], [Agentes] y [Bases de conocimiento], y luego acota por fecha de actualización.
{% endstep %}

{% step %}
### 4. Abre el resultado para continuar trabajando

La búsqueda te lleva al contenido correspondiente. Antes de abrirlo, revisa el tipo para evitar confundir un asistente con una tarea de Agent que tengan el mismo nombre.
{% endstep %}
{% endstepper %}

### Caso de uso: recuperar una conclusión de un cliente del mes pasado

Busca el nombre del proyecto del cliente, acota el tipo a [Mensajes] y limita la fecha de actualización. Una vez localizada la conclusión, abre la conversación original y verifica si hubo revisiones posteriores. Si necesitas usar la conclusión en una nueva tarea, copia el resumen ya confirmado en lugar de depender de fragmentos dispersos en la memoria de la nueva conversación.

<details>

<summary>¿Por qué no puedo encontrar el contenido de archivos en el disco? </summary>

La búsqueda global busca principalmente contenido ya guardado en Cherry Studio. Los archivos en el disco deben estar en el directorio de trabajo de Agent, en una base de conocimiento o en las notas, y luego deben seguir el flujo correspondiente para poder ser localizados a través de su entrada específica.

</details>
