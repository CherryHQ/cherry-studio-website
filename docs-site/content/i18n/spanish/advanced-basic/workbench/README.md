# Espacio de trabajo eficiente

La ventana principal de Cherry Studio está compuesta por una barra lateral, pestañas y un área de contenido. Las conversaciones de temas y las tareas de Agent pueden abrirse simultáneamente en varias pestañas o dividirse en ventanas independientes; la barra de herramientas del área de entrada se puede ajustar según los hábitos de uso.

### Escenarios adecuados para usar ventanas independientes

* Mantener una conversación de recursos mientras se ejecutan tareas de Agent;
* Fijar tareas de monitoreo a largo plazo para evitar que otras ventanas las oculten;
* Colocar conversaciones, archivos o tareas en monitores diferentes;
* Mostrar o compartir una tarea específica sin exponer otras pestañas de la ventana principal.

### Capacidades del espacio de trabajo

| Capacidad | Acceso | Función |
| ------ | -------------------- | -------------- |
| Nueva pestaña | Menú contextual de tema o tarea → [Abrir en nueva pestaña] | Mantener varios contextos en paralelo en la ventana principal |
| Ventana independiente | Menú contextual de tema, tarea o pestaña → [Abrir en nueva ventana] | Separar el contenido actual en una nueva ventana |
| Pestaña fijada | Menú contextual de pestaña → [Fijar pestaña] | Fijar páginas de uso frecuente |
| Ventana siempre visible | [Ventana siempre visible] en la parte superior de la ventana independiente | Mantener la tarea visible |
| Volver a la ventana principal | [Volver a la ventana principal] en la parte superior de la ventana independiente | Reconectar la pestaña a la ventana principal |
| Barra de herramientas personalizada | [ + ] en el área de entrada → [Personalizar barra de herramientas] | Ajustar la posición de las herramientas de entrada frecuentes |

En el menú de pestañas de la imagen anterior, seleccione [Abrir en nueva ventana] para separar el contenido actual en una ventana independiente.

### Disposición recomendada

Para la escritura de oficina, puede dejar la conversación de recursos en la ventana principal y mover el Agent de "Escritura" a la pantalla derecha; para el trabajo con código, puede fijar las tareas de Agent y mantener los archivos y documentos en la ventana principal; para tareas de monitoreo prolongado, use una ventana independiente, pero no coloque tareas que requieran confirmación de permisos frecuentes en una posición no visible.

{% hint style="info" %}
La ventana independiente sigue perteneciendo al mismo entorno de datos de Cherry Studio. No es una nueva cuenta ni un espacio de privacidad; el contenido del mismo tema o tarea se sigue guardando de forma sincronizada.
{% endhint %}
