# Mesa de trabajo de investigación con múltiples ventanas

Los investigadores necesitan conservar los materiales y las comparaciones de modelos mientras el Agent organiza archivos y genera informes. Al dividir las tareas de investigación en ventanas independientes, la ventana principal puede seguir consultando materiales sin interrumpir el estado del Agent.

## Disposición recomendada

* Ventana principal: conservar la conversación de materiales y la búsqueda global;
* Ventana independiente: abrir la tarea del Agent de investigación y mantenerla en primer plano;
* Segunda pestaña: abrir la base de conocimientos o las notas para verificar los materiales originales en cualquier momento.

## Flujo de operación

{% stepper %}
{% step %}
### 1. Comparar preguntas de investigación en [Conversación]

Utilice la comparación de múltiples modelos para identificar consensos, conflictos y elementos por verificar, sin apresurarse a generar el informe final.
{% endstep %}

{% step %}
### 2. Preparar el directorio para el Agent de investigación

Separe los materiales originales del directorio de salida, vincule las bases de conocimientos relevantes y exija que la información externa conserve los enlaces.
{% endstep %}

{% step %}
### 3. Dividir la tarea en una ventana independiente

Haga clic derecho en la pestaña del Agent y seleccione [Abrir en nueva ventana]; utilice la opción de mantener en primer plano si es necesario. La ventana principal continúa consultando materiales sin interrumpir el estado del Agent.
{% endstep %}

{% step %}
### 4. Compilar y revisar

Revise el informe en [Archivos] a la derecha del Agent y abra la conversación original en la ventana principal para verificar los conflictos. Finalmente, conserve solo las conclusiones que puedan rastrearse hasta los materiales o las fuentes.
{% endstep %}
{% endstepper %}

## Combinaciones recomendadas y criterios de finalización

| Ventana | Contenido sugerido |
| ----- | --------------------------------- |
| Ventana principal | Conversación de materiales, búsqueda global y notas |
| Ventana independiente | Una tarea del Agent en ejecución |
| Pestaña fija | La base de conocimientos o la tarea más utilizada del proyecto |
| Criterio de finalización | Las fuentes de los materiales, el estado de la tarea y las notas finales deben corresponder entre sí; al finalizar la tarea, la ventana debe haberse recogido o cerrado |

Adecuado para investigaciones que requieren observación continua de tareas largas; no se recomienda abrir muchas ventanas simultáneamente solo para "parecer más profesional".

{% hint style="info" %}
Las múltiples ventanas solo cambian la posición de visualización; no crean nuevas cuentas ni espacios aislados. Los datos y los permisos de la misma tarea siguen siendo los mismos.
{% endhint %}
