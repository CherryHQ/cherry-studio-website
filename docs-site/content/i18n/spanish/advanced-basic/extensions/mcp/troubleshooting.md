# Solución de problemas de MCP


<details>

<summary>¿Debería eliminar y volver a agregar el servidor?</summary>

Primero revise los registros y corrija cada elemento. Solo elimine y reconstruya la configuración si esta está desordenada y la fuente puede recuperarse nuevamente; antes de eliminar, guarde una copia de la configuración que no contenga claves.
