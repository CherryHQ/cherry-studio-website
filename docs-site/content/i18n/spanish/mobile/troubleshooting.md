# Solución de problemas

## ¿Por qué no puedo conversar justo después de instalar?

Cherry Studio es un cliente y no incluye crédito de modelos. Añade primero un proveedor, introduce una clave API y activa al menos un modelo de conversación.

## He añadido un proveedor, pero la lista de modelos está vacía

Revisa la clave API, el Base URL, los permisos de la cuenta y la red actual. Algunos proveedores no devuelven una lista completa de modelos y exigen introducir manualmente un identificador de modelo.

## ¿Por qué no están disponibles las funciones de imagen, herramientas o archivos?

Estas capacidades dependen de la versión de la aplicación, del modelo, de la API del proveedor y de los permisos del sistema. Confirma primero la compatibilidad del modelo y revisa después los interruptores de herramientas del agente y los accesos del sistema.

## Android bloquea la instalación

Descarga de nuevo el APK desde la página oficial y sigue el aviso de Android para permitir que tu navegador o gestor de archivos instale aplicaciones desconocidas. Puedes revocar ese permiso después de instalar.

## El enlace de TestFlight no se abre o no me admite

Asegúrate de tener TestFlight instalado y abre la invitación en Safari o en el navegador del sistema. Un grupo de prueba lleno, una compilación caducada o una incidencia temporal de Apple pueden obligarte a intentarlo más tarde.

## ¿La versión móvil sincroniza automáticamente los datos del escritorio?

No des por hecho que haya sincronización automática. Vuelve a añadir la configuración de proveedores y modelos en el móvil, y conserva las conversaciones y archivos importantes con las funciones de exportación o compartición disponibles en tu versión.

## ¿Cómo debo informar de un problema?

Anota la versión de la aplicación, el modelo del dispositivo, la versión del sistema operativo, los pasos para reproducirlo y el mensaje de error. Elimina claves API, archivos personales y contenido privado de las capturas de pantalla antes de usar el enlace de contacto del sitio oficial.
