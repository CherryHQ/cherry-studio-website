# Conversaciones y archivos

## Iniciar una conversación

Elige un asistente y un modelo en la pantalla de conversación y envía tu petición. El selector de modelos permite cambiar entre los modelos configurados sin salir de la conversación.

## Añadir imágenes o archivos

Usa el botón de añadir junto al campo de escritura para elegir material desde el selector de fotos o archivos del sistema. Que un modelo pueda interpretar un adjunto depende de los tipos de entrada que admita y de la API del proveedor.

Antes de enviar, confirma que:

* el modelo activo admite ese tipo de imagen o archivo;
* el archivo no contiene información que no deba enviarse al proveedor de modelos;
* el tamaño del archivo y el contexto resultante respetan los límites del proveedor.

## Trabajar con las respuestas

El área de respuesta admite acciones habituales como copiar y compartir con el sistema. La representación de Markdown, código y contenido estructurado depende de la versión de la aplicación y del formato de la respuesta.

## No llega ninguna respuesta

Prueba primero con un mensaje corto de texto plano. Si también falla, comprueba que el modelo esté activado y revisa la clave API, el saldo, la red y el estado del proveedor. Consulta la [solución de problemas](troubleshooting.md) para una lista más completa.
