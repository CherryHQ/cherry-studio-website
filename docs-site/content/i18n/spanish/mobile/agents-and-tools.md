# Agentes y herramientas

Un agente es una configuración de trabajo reutilizable que reúne las instrucciones de rol, un modelo y las herramientas disponibles. Resulta útil para tareas recurrentes como apoyo a la redacción, organización de información o gestión de la agenda.

## Crear un agente

1. Crea un agente y define su nombre, avatar e instrucciones de tarea.
2. Elige un modelo adecuado para esa tarea.
3. Activa la búsqueda web, la generación de imágenes o las herramientas del sistema solo cuando sea necesario.
4. Revisa el modo de aprobación de herramientas y guarda el agente.

Las instrucciones deben indicar con claridad el objetivo, el formato de salida y las restricciones. Nunca incluyas claves API, contraseñas u otras credenciales de larga duración en las instrucciones de un agente.

## Herramientas y permisos del sistema

Las herramientas del sistema, como el calendario y los recordatorios, solicitan acceso al sistema operativo la primera vez que se usan. Concede acceso solo a las capacidades que el agente necesite realmente. Después podrás revisar o revocar los permisos en los ajustes de Android o iOS.

Las herramientas pueden leer datos o ejecutar acciones externas. Mantén la confirmación manual para eventos de calendario, archivos o contenido saliente importantes, y revisa el resultado después de cada ejecución.
