# Inicio rápido

Con estos cuatro pasos podrás enviar tu primer mensaje.

## 1. Añadir un proveedor

Abre los servicios de modelos en los ajustes de la aplicación y elige un proveedor integrado. Si usas una API compatible, crea un proveedor personalizado e introduce su Base URL.

## 2. Introducir las credenciales

Introduce la clave API que te entregó el proveedor y guarda o prueba la conexión según se indique. Nunca compartas la clave ni la pegues en conversaciones públicas, capturas de pantalla o informes de errores.

## 3. Añadir un modelo

Obtén o añade los modelos del proveedor y activa al menos uno. La compatibilidad con conversación, visión, herramientas y generación de imágenes varía según el modelo.

## 4. Enviar un mensaje

Vuelve a la conversación, abre el asistente predeterminado o crea uno, selecciona un modelo y envía un mensaje breve. Recibir una respuesta confirma que la configuración básica funciona.

A continuación, lee [Proveedores y modelos](providers-and-models.md) o consulta [Conversaciones y archivos](chat-and-files.md).
