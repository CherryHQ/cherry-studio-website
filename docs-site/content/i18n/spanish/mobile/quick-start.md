# Inicio rápido

Haga que un modelo responda primero a un mensaje simple y luego agregue otras funciones según sea necesario.

## 1. Elige cómo configurar

* **¿Ya usas Cherry Studio Desktop?** [Importar configuración desde tu computadora](desktop-sync.md) y elige un modelo. Después de una importación exitosa, continúe con el paso 4 a continuación.
* **Configurar en un dispositivo móvil:** elija un proveedor durante la incorporación o abra **Configuración → Servicio modelo → Agregar proveedor** y siga los pasos 2 y 3.

Los proveedores integrados incluyen configuraciones de conexión comunes. Utilice un proveedor personalizado si su plataforma no está.

## 2. Ingrese y guarde una clave

Ingrese el **Clave API** de la plataforma, la credencial utilizada para llamar a los modelos. Los proveedores personalizados también necesitan la dirección base de la plataforma y el formato API.

Guarde o continúe con la incorporación. Una contraseña de inicio de sesión no es una clave API y la suscripción de chat para consumidores de una plataforma puede no incluir créditos API; revisa tu cuenta allí.

## 3. Agregue un modelo y habilite el proveedor.

Obtenga la lista de modelos y seleccione un modelo de texto. Si el descubrimiento falla, copie el ID del modelo exacto de la plataforma y agréguelo manualmente.

La descarga inicial de la información de los modelos puede tardar un poco. Confirme que el proveedor esté habilitado, abra la edición del agente desde la parte superior de la conversación y seleccione un modelo habilitado. Consulte [proveedores y modelos](providers-and-models.md) para obtener más detalles.

## 4. Envía un primer mensaje

Utilice el agente inicial Cherry, seleccione su modelo y pregunte "En tres oraciones, describe lo que puedes ayudarme a hacer". Una respuesta confirma que la configuración básica está funcionando.

Un agente es una configuración reutilizable que contiene un nombre, instrucciones y modelo. Puede iniciar conversaciones separadas con el mismo agente para diferentes temas.

Si no llega nada, intente enviar un mensaje corto sin archivos adjuntos y siga [solución de problemas](troubleshooting.md).
