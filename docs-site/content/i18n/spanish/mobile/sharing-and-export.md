# Compartir y exportar

Comparta una respuesta o convierta varios intercambios en imágenes, un documento web o texto editable. Seleccione el contenido, inspeccione la vista previa y luego elija el destino.

## Compartir mensajes seleccionados

1. Utilice la acción para compartir de la respuesta o el menú para compartir de un mensaje.
2. Seleccione mensajes en la página de selección; el mensaje original se selecciona inicialmente.
3. Confirme para abrir la vista previa en pantalla completa.
4. Elija un formato, diseño de imagen y si desea incluir contenido de pensamiento.
5. Toque Compartir y elija un destino en la hoja del sistema.

Solo se exportan **mensajes seleccionados**. Las preguntas no se incluyen automáticamente, así que selecciónelas cuando sea necesario por contexto. El resultado sigue la cronología de la conversación independientemente del orden de selección.

Seleccione hasta 128 mensajes a la vez. No se pueden seleccionar mensajes sin terminar. Las filas de selección muestran breves extractos; la exportación lee el contenido seleccionado completo y presenta el código/imágenes según el formato elegido.

## Elige un formato

| Formato | Bueno para | Limitaciones |
| --- | --- | --- |
| Imágenes PNG | Lectura directa en apps de mensajería | Dividido en páginas de forma predeterminada; Las vistas previas de código de bloque muestran solo su parte inicial. |
| HTML | Diseño más completo, código completo, contenido ampliable | Necesita un navegador o lector compatible |
| Markdown | Mantener el texto fuente, el código y las tablas para su posterior edición. | El renderizado depende de la aplicación receptora. |

Las exportaciones de imágenes largas producen páginas ordenadas; También está disponible una opción de una sola imagen larga. Las imágenes individuales muy largas exigen más memoria y pueden fallar al recibir aplicaciones. Prefiera las páginas, HTML o Markdown en ese caso.

Las exportaciones de imágenes o HTML simplifican la presentación de la fuente. Regrese a las fuentes originales de la conversación para una verificación detallada de las citas; una vista previa de la imagen no es un archivo fuente completo.

## ¿Por qué la pantalla de selección describe diferentes formatos?

Algunas versiones conservan un mensaje anterior que dice que la selección múltiple solo admite HTML y Markdown. La vista previa actual también admite imágenes para múltiples mensajes; Utilice los formatos realmente ofrecidos en la vista previa. Si falla la preparación de la imagen, utilice HTML o Markdown.

## Incluir pensamiento y actividad con herramientas.

Estos se omiten de forma predeterminada. **Incluir contenido de pensamiento** agrega razonamiento visible, prosa intermedia y nombres de herramientas legibles, sin exportar solicitudes de herramientas sin procesar ni datos de diagnóstico.

HTML puede ampliar este contenido; La salida de la imagen amplía el proceso incluido. Revise la vista previa antes de compartir detalles intermedios innecesarios.

## ¿Pueden las imágenes Markdown funcionar sin conexión?

Las imágenes locales/generadas PNG y JPEG están incrustadas en el archivo Markdown, lo que puede aumentar su tamaño. Algunos lectores bloquean imágenes incrustadas; utilice HTML o exporte imágenes si el destinatario no puede mostrarlas.

Los formatos locales GIF, WebP u otros que no se pueden incrustar se convierten en notas de imagen no disponibles. Otros archivos adjuntos pueden conservar sólo sus nombres/descripciones; sus archivos originales no están todos incluidos en el documento. Comparta archivos originales por separado cuando sea necesario.

Las URL de imágenes externas siguen siendo enlaces remotos y no están disponibles automáticamente sin conexión.

## Error al exportar la imagen

Si la conversión de imágenes falla, la aplicación intenta HTML. Si la vista previa de HTML también falla, conserva Markdown e indica el formato disponible. Comprueba el formato antes de compartir.

La puesta en segundo plano o la cancelación interrumpen la conversión en lugar de cambiar automáticamente el formato. Mantener las exportaciones a largo plazo en primer plano; reduzca la selección o utilice imágenes paginadas si es necesario.

Al cerrar la vista previa se vuelve a la selección de mensajes. Al cerrar la menú del sistema para compartir se vuelve al chat. **Abrir la menú para compartir no demuestra que el destino guardó o envió el contenido.**

## Quitar la marca de agua

Apague **Configuración → General → Marca de agua al compartir** antes de exportar. Está activado de forma predeterminada y afecta futuras exportaciones de conversaciones, imágenes y archivos relacionados. Los archivos guardados/compartidos existentes no cambian.

## Biblioteca de archivos y archivos originales.

Abra **Archivos** en la barra lateral para buscar archivos adjuntos importados y archivos guardados generados/exportados. Las imágenes y texto compatibles, Markdown y HTML se abren en la aplicación; Se pueden abrir otros formatos a través del sistema u otra aplicación.

* Las vistas previas de imágenes permiten hacer zoom, compartir y guardar en Fotos.
* Las vistas previas de texto grande pueden ser parciales y Copiar utiliza el contenido mostrado. **Compartir el archivo original incluye el original completo.**
* Las vistas previas fallidas de HTML pueden volver a la vista de origen o abrirse en otro lugar.
* Guarde los archivos necesarios antes de eliminarlos. Cancelar el uso compartido del sistema no elimina automáticamente los archivos de exportación que ya están guardados en la biblioteca.

## Convierta HTML en imágenes o diapositivas

Si el archivo HTML puede previsualizarse por completo, elija **Compartir como imagen** o **Compartir como PPT**, espere la conversión y luego guárdelo a través del sistema compartido.

Las diapositivas PPTX contienen imágenes de las páginas. Conservan la apariencia, **no texto, tablas y formas editables individualmente**. Conserve el original cuando sea necesario editarlo más.

Antes de desinstalar o borrar los datos de la aplicación, guarde los archivos fuera del Cherry Studio o en otro dispositivo y confirme que estén abiertos. Los archivos que solo están en la biblioteca de aplicaciones se pueden perder con los datos de la aplicación.

Las exportaciones preservan el trabajo seleccionado, no una copia de seguridad restaurable de toda la aplicación. Consulte [importación de escritorio](desktop-sync.md) para conocer los límites de transferencia de configuración.

## Compartir un archivo o presentación generada

Para compartir un archivo guardado en lugar de mensajes de chat seleccionados, abra su tarjeta de archivo y use el menú Más. Consulte [Crear y editar archivos](file-generation.md). Los archivos HTML también ofrecen [Compartir como imagen y Compartir como PPT](html-export.md); el PPT resultante contiene imágenes de página, no objetos de texto editables.
