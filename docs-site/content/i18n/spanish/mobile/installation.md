# Descarga e instalación

Usa siempre la [opción móvil de la página oficial de descargas](https://cherryai.com/download?platform=mobile). No instales paquetes de origen desconocido.

## Android

El APK actual se ofrece para dispositivos ARM64.

1. Selecciona **Descargar APK** en la página de descargas.
2. Abre el APK desde las descargas del navegador o el gestor de archivos.
3. Si Android bloquea el instalador, sigue el aviso del sistema para permitir temporalmente que tu navegador o gestor de archivos instale aplicaciones desconocidas.
4. Vuelve al instalador y completa la instalación.

Después de instalar puedes revocar el permiso de «instalar aplicaciones desconocidas». Cuando se publique una versión nueva, descarga el APK desde la página oficial e instálalo sobre la aplicación existente. Revisa las notas de la versión antes de actualizar.

## iPhone y iPad

Las versiones de iOS y iPadOS están disponibles actualmente mediante TestFlight.

1. Instala **TestFlight** de Apple desde la App Store.
2. Selecciona **Unirse a TestFlight** en la página de descarga móvil.
3. Acepta la invitación en TestFlight y selecciona **Instalar**.

El número de plazas de prueba y la caducidad de las compilaciones los gestiona el sistema beta de Apple. Si la invitación no está disponible temporalmente, inténtalo más tarde o consulta los canales oficiales de publicación.

## Después de instalar

Continúa con el [inicio rápido](quick-start.md) para añadir un servicio de modelos y enviar tu primer mensaje.
