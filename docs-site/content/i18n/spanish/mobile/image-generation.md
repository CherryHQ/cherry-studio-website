## Generar una imagen

1. Añade en los ajustes del proveedor un modelo compatible con la generación de imágenes.
2. Abre la generación de imágenes y selecciona el modelo.
3. Describe el sujeto, el entorno, el estilo y la composición.
4. Envía la tarea y espera a que el proveedor devuelva el resultado.

Los modelos de imagen suelen facturarse aparte de los modelos de conversación. La velocidad de generación, los tamaños disponibles, las restricciones de contenido y las reglas de reintento las define el proveedor.

## Consejos para las indicaciones

Describe primero el sujeto y el uso previsto. Después añade el entorno, la iluminación, el punto de vista, los materiales, la paleta y la proporción. Para obtener resultados repetibles, conserva una indicación que haya funcionado y cambia solo una variable cada vez.

## La generación falla

Confirma que el modelo seleccionado admite la generación de imágenes y revisa el saldo, el acceso a la red y la política de contenido del proveedor. Tras un tiempo de espera agotado, espera a que el estado de la tarea se estabilice antes de reenviar la misma solicitud repetidamente.
