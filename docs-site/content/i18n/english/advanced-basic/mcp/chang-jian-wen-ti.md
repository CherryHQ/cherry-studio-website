# FAQ

### 1. mcp-server-time

<figure><img src="../../../../assets/1520c1906faa98104f052666.jpg" alt=""><figcaption><p>Error screenshot</p></figcaption></figure>

**Solution**

In the "Parameters" field, enter:

```
mcp-server-time
--local-timezone
<your standard timezone, e.g.: Asia/Shanghai>
```
