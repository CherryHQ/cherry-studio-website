# Input Toolbar and Efficiency Tools

<details>

<summary>Why do pinned tools not appear in another input area?</summary>

The Chat, Agent, Quick Assistant, and Drawing pages support different tools. The pinned layouts for Chat and Agent are saved separately. Please reopen the [Custom Toolbar] in the target input area.
