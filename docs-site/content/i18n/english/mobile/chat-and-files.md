# Chat and files

## Start a conversation

Choose an assistant and model on the Chat screen, then send your request. The model picker lets you switch between configured models without leaving the conversation.

## Add images or files

Use the add button beside the composer to choose material from the system photo or file picker. Whether a model can understand an attachment depends on its supported input types and the provider API.

Before sending, confirm that:

* the active model supports the image or file type;
* the file does not contain information that should not be sent to the model provider; and
* the file size and resulting context fit the provider limits.

## Work with responses

The response area supports common actions such as copy and system sharing. Markdown, code, and structured content rendering depend on the current app version and response format.

## No response appears

Try a short plain-text message first. If that also fails, check that the model is enabled, then verify the API key, balance, network, and provider status. See [Troubleshooting](troubleshooting.md) for a fuller checklist.
