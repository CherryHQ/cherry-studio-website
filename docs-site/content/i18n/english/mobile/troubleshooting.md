# Troubleshooting

## Why can’t I chat immediately after installation?

Cherry Studio is a client and does not include model credits. Add a provider, enter an API key, and enable at least one chat model first.

## I added a provider, but the model list is empty

Check the API key, Base URL, account permissions, and current network. Some providers do not return a complete model list and require a model ID to be entered manually.

## Why are image, tool, or file features unavailable?

These capabilities depend on the app version, model, provider API, and system permissions. Confirm model support first, then inspect agent tool toggles and system access.

## Android blocks the installation

Download the APK again from the official page and follow Android’s prompt to allow your browser or file manager to install unknown apps. You can revoke that permission after installation.

## The TestFlight link will not open or accept me

Make sure TestFlight is installed and open the invitation in Safari or the system browser. A full test group, expired build, or temporary Apple service issue may require you to try again later.

## Does mobile automatically sync desktop data?

Do not assume automatic synchronization. Re-add provider and model configuration on mobile, and preserve important chats and files with the export or share features available in your current version.

## How should I report a problem?

Record the app version, device model, operating-system version, reproduction steps, and error message. Remove API keys, personal files, and private chat content from screenshots before using the feedback link on the official website.
