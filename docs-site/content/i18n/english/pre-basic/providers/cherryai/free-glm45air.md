# Zhipu GLM-4.5-Air

To enable every developer and user to easily experience the capabilities of cutting-edge large models, **Zhipu has made the GLM-4.5-Air model available for free to Cherry Studio users**. As a high-efficiency foundation model designed specifically for Agent applications, GLM-4.5-Air achieves an excellent balance between performance and cost, making it an ideal choice for building intelligent applications.

***

**🚀 What is GLM-4.5-Air?**

GLM-4.5-Air is Zhipu's latest high-performance language model, featuring an advanced **Mixture-of-Experts (MoE) architecture**. It significantly reduces computational resource consumption while maintaining exceptional reasoning capabilities.

* **Total Parameters: 106 Billion**
* **Active Parameters: 12 Billion**

Through streamlined design, GLM-4.5-Air achieves higher inference efficiency, making it suitable for deployment in resource-constrained environments while still handling complex tasks effectively.

**📚 Unified Training Pipeline, Solid Intelligent Foundation**

GLM-4.5-Air shares a consistent training pipeline with the flagship series, ensuring a solid foundation of general capabilities:

1. **Large-Scale Pre-training**: Trained on up to **15 trillion tokens of general corpus** to build broad knowledge understanding;
2. **Domain-Specific Optimization**: Reinforced training on key tasks such as code generation, logical reasoning, and Agent interaction;
3. **Long Context Support**: Context length extended to **128K tokens**, capable of handling long documents, complex conversations, or large code projects;
4. **Reinforcement Learning Enhancement**: Optimized decision-making capabilities in reasoning planning, tool calling, and other areas via RL.

This training system endows GLM-4.5-Air with outstanding generalization and task adaptability.

**⚙️ Core Capabilities Optimized for Agents**

GLM-4.5-Air is deeply adapted for Agent application scenarios, featuring the following practical capabilities:

✅ **Tool Calling Support**: Can invoke external tools via standardized interfaces to automate tasks\
✅ **Web Browsing & Information Extraction**: Can work with browser plugins to understand and interact with dynamic content\

**💡 Intelligent "Thinking Mode" for Flexible Responses**

GLM-4.5-Air supports **hybrid reasoning mode**. Users can control whether to enable deep thinking via the `thinking.type` parameter:

* `enabled`: Enable thinking, suitable for complex tasks requiring step-by-step reasoning or planning
* `disabled`: Disable thinking, for simple queries or immediate responses
* Default setting is **Dynamic Thinking Mode**, where the model automatically determines if in-depth analysis is needed

| Task Type | Example |
| ------------------ | ----------------------------------------------- |
| **Simple Tasks** (Thinking recommended off) | <p>- Query "When was Zhipu AI founded?"<br>- Translate "I love you" into Chinese</p> |
| **Medium Tasks** (Thinking recommended on) | <p>- Compare pros and cons of flying vs. high-speed rail from Beijing to Shanghai<br>- Explain why Jupiter has many moons</p> |
| **Complex Tasks** (Thinking strongly recommended on) | <p>- Explain how experts collaborate in MoE models<br>- Analyze whether to buy an ETF based on market information</p> |
