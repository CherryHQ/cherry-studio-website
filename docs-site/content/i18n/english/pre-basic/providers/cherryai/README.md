# CherryAI (Free)

**CherryAI** is the official built-in entry point for **free models** in Cherry Studio—no need to register on third-party platforms or apply for API keys. You can immediately access a batch of models with free quotas, making it ideal for beginners who want to get started and test features quickly.

### Where to Use

Open `Settings → Model Service` and find **CherryAI** in the built-in list. It is pre-configured with the software and typically requires no additional setup; click **Get Model List** to view the currently available free models.

### Available Free Models

{% hint style="warning" %}
**The lineup of free models is dynamic.** The specific models, their quotas, and rate limits are delivered in real-time by the Cherry server and may be adjusted periodically. **Always refer to the actual results you see when clicking 【Get Model List】 in the software**. The following sections provide descriptions of some common free models and do not represent the complete current list.
{% endhint %}
