# OneAPI

* Log in and go to the Tokens page

<figure><img src="../../../../../assets/68288a2c3a095035189e8d25.webp" alt=""><figcaption></figcaption></figure>

* Create a new token (or use the default token shown above)

<figure><img src="../../../../../assets/b52ed2463a5c1ea3de393a3e.webp" alt="" width="563"><figcaption></figcaption></figure>

* Copy the token

<figure><img src="../../../../../assets/e485ab0dd933dd974e8648e3.webp" alt="" width="563"><figcaption></figcaption></figure>

* Open the provider settings in Cherry Studio and click `Add Provider` at the bottom of the provider list
* Enter a display name, choose OpenAI as the provider type, and click OK

* Paste the key you just copied
* Go back to the page where you got the API key and copy the root address from the browser's address bar, for example:

<figure><img src="../../../../../assets/15e84703b85e9e47c3de65e4.webp" alt="" width="563"><figcaption><p><strong>Copy only https://xxx.xxx.com — leave out the "/" and everything after it</strong></p></figcaption></figure>

{% hint style="info" %}
* If the address is an IP and port, enter http://IP:port, for example: http://127.0.0.1:3000
* `http` and `https` are not interchangeable — if SSL isn't enabled, don't use https
{% endhint %}

* Add models (click Manage to fetch them automatically, or enter them manually), then turn on the switch in the top right to start using it.

{% hint style="success" %}
Other OneAPI themes may look different, but the steps to add it are the same.
{% endhint %}
