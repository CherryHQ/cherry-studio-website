# ZhiPu

The **GLM** series from ZhiPu AI (including the multimodal GLM-4V) offers direct domestic access and strong Chinese language performance. In Cherry Studio, ZhiPu uses an **Anthropic-compatible endpoint**, making it suitable for **Cherry Agent** in addition to standard conversations.

## Get an API Key

* Open the [API Keys page](https://open.bigmodel.cn/apikey/platform) on the ZhiPu Open Platform (registration/login required)
* Create and copy a new API Key

## Configure in Cherry Studio

1. Open [Model Service Settings](../settings/providers.md) in Cherry Studio and find **ZhiPu** in the built-in list
2. Enter the API Key you just obtained
3. Click **Get Model List**, add the required GLM models, and enable the provider switch in the top-right corner to start using it

{% hint style="info" %}
ZhiPu models include built-in **web search** capabilities, subject to model support. For more platform documentation, see the [ZhiPu Official Documentation](https://docs.bigmodel.cn/).
{% endhint %}
