## 设备上的数据

应用设置、服务商配置与对话记录主要保存在当前设备。删除应用、清除系统数据或更换设备前，请先确认重要内容已经另行保存；不要假设移动版会自动与桌面版同步。

## 发送给服务商的数据

当你发送消息、文件或生成图片时，请求会按你的配置发送给所选模型服务商。服务商如何保留和处理数据，取决于其隐私政策、账户设置与接口条款。

## API Key

* 只在官方应用内填写 API Key。
* 不要在截图、日志、聊天或反馈内容中暴露完整 Key。
* 怀疑泄露时，立即在服务商控制台撤销并重新创建。
* 建议为移动端使用可单独撤销、额度受限的 Key。

## 系统权限

图片、文件、相机、日历或提醒事项等能力可能需要系统权限。应用会在实际使用相关功能时请求授权。你可以在 Android 或 iOS 的系统设置中随时调整。

最小权限原则：不使用的能力不授权；涉及写入或外部操作的工具保留人工确认。
