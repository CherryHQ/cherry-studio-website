# 对话与文件

## 开始一段对话

在对话页选择助手与模型，输入问题后发送。顶部模型选择器可以在不离开当前对话的情况下切换已配置模型。

## 添加图片或文件

使用输入框旁的添加按钮，从系统相册或文件选择器加入材料。是否能够理解某种附件，取决于当前模型及服务商支持的输入类型。

发送前请确认：

* 当前模型支持对应的图片或文件类型。
* 文件中没有不应发送给模型服务商的敏感信息。
* 文件大小和上下文长度没有超过服务商限制。

## 处理回答

回答区域支持复制与系统分享等常用操作。Markdown、代码或结构化内容的显示效果取决于当前版本和回答格式。

## 对话没有回复

先发送一条简短纯文本消息。如果仍然失败，再依次检查模型是否启用、API Key、余额、网络和服务商状态。详细排查见[常见问题](troubleshooting.md)。
