## 开始生成

1. 先在服务商设置中添加支持图片生成的模型。
2. 打开图片生成入口并选择模型。
3. 输入主体、场景、风格和构图等要求。
4. 提交任务，等待服务商返回结果。

图片模型通常与对话模型分开计费。生成速度、尺寸、内容限制和失败重试规则由模型服务商决定。

## 提示词建议

先描述主体和用途，再补充环境、光线、视角、材质、配色与画幅。需要稳定输出时，保留有效提示词并一次只调整一个变量。

## 生成失败

确认模型确实支持图片生成，并检查余额、网络与服务商内容政策。遇到超时，先等待任务状态更新，避免短时间重复提交多次。
