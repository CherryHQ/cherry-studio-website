# 智能体与工具

智能体（Agent，即保存了角色说明、模型和可用工具的工作配置）适合重复使用的任务，例如写作辅助、信息整理或日程相关操作。

## 创建智能体

1. 新建智能体并设置名称、头像与任务说明。
2. 选择适合该任务的模型。
3. 按需启用联网搜索、图片生成或系统工具。
4. 检查工具审批方式后保存。

任务说明应写清目标、输出格式和限制条件。不要把 API Key、密码或其他长期凭据写进智能体说明。

## 工具与系统权限

日历、提醒事项等系统工具会在首次使用时请求操作系统权限。只为确实需要的能力授权；之后可以在系统设置中查看或撤销权限。

工具可能读取内容或执行外部操作。对于重要日程、文件或对外发送内容，建议保留人工确认，并在执行后检查结果。
