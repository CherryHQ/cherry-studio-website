# 常见问题

先根据现象找到对应操作。连接错误可先用一条简短、不带附件的消息缩小问题范围。

## 安装后为什么不能直接聊天？

Cherry Studio 是客户端，需要连接模型服务。先配置 API Key、添加模型并启用服务商，再为智能体选择模型。已有电脑配置可以[导入](desktop-sync.md)，首次使用步骤见[快速开始](quick-start.md)。

平台的网页聊天会员不一定包含 API（供应用调用模型的接口）额度，需要在平台单独确认。

## 服务商已添加，为什么模型选择器为空？

确认服务商已启用、模型可用，且不是仅供管理的嵌入或重排类型。图片与文字入口也可能筛选不同类型。把选择器筛选改为“全部”，并等首次模型资料下载完成。

模型还没有添加时，先[同步列表或手动添加](model-management.md)。

## 模型信息更新会改掉我的密钥或自定义设置吗？

不会。模型资料更新不修改服务商地址和密钥，也不重写手动保存的模型改动。没有覆盖的默认字段会跟随新资料。

**从电脑同步所选服务商**则会更新其地址和密钥，这两种更新不同。详见[模型更新](model-updates.md)和[电脑导入](desktop-sync.md)。

## 同步模型失败，为什么仍能聊天？

服务商的模型列表接口与对话接口分开，可能只支持后者。用平台提供的模型 ID 手动添加并检查连接即可；原有模型不会因同步失败被清空。

“远端未返回”也不代表模型下线，见[模型同步说明](model-updates.md)。

## 401、403、404、429 分别怎么处理？

| 提示 | 优先检查 |
| --- | --- |
| 401 / 未授权 | 密钥是否完整、有效、已保存并启用 |
| 403 / 无权限 | 账号、地区、目标模型或组织权限是否允许访问 |
| 404 / 不存在 | 基础地址、接口和模型 ID 是否正确，是否重复拼接了请求路径 |
| 429 / 请求过多 | 等待限流恢复，检查账户额度和请求限制，不要连续重复发送 |
| 网络失败 / 超时 | 当前网络能否访问服务商，代理与平台服务是否正常 |
| 内容过长 / 请求过大 | 减少附件或历史内容、换更合适的模型，不要只把上限数字调大 |

有些平台使用不同错误码，结合错误详情与平台说明判断。配置项的填写方法见[服务商与模型](providers-and-models.md)。

## 已经修改，为什么没有生效？

* 服务商地址和密钥、手动模型添加或模型编辑：需要点击页面保存或添加。
* 已有智能体编辑、默认模型选择、模型列表中的接口切换：自动或立即保存，注意是否出现失败提示。
* 更换服务商地址后检查连接或同步列表：先保存当前配置。
* 更改全局默认模型：不会改掉已有智能体自己的模型选择。

详见[模型管理](model-management.md)和[智能体编辑](agents-and-tools.md)。

## 为什么不能删除某个模型？

它可能正被设为全局默认模型。先到 **设置 → 默认模型** 更换或清除，再删除。删除智能体正在使用的其他模型后，需要为该智能体重新选模型。

## 图片能预览，为什么不能发给模型？

预览和模型输入是不同能力。选择支持视觉的文字模型，检查图片格式、张数和大小。给模型勾选“图片能力”不会让不支持视觉的模型看懂图片。

文档解析为空、扫描 PDF 或大文件的处理见[对话与文件](chat-and-files.md)。

## 为什么输入框没有联网开关或插件按钮？

联网搜索开关位于当前智能体的编辑页，不在输入框中；开启它并配置搜索服务后，直接在消息里要求搜索。插件按钮只在已有可用连接时出现；先去侧边栏连接插件。

插件已连接后可在对话中使用，也可通过 **＋ → 插件** 明确指定。详见[联网搜索](web-search.md)和[插件连接](plugins.md)。

## 插件授权完成后一直在等待，怎么办？

返回 Cherry Studio 检查状态，完成账号或工作区确认。可以重新打开授权页或再次检查；过期时重新发起。组织权限不足时，先在服务商侧申请权限。

钉钉的额外行为授权完成后需要重新发起原操作；企业微信链接需在有效期内在企业微信中打开。详见[插件连接](plugins.md)。

## 为什么只剩最新回答能重新回答？

重新回答会原地替换最新回答，较早内容改换方向请创建分支。重试、删除都不会撤销已经执行的外部操作，重试也可能产生新费用。详见[回答操作](chat-and-files.md)。

## “已压缩上下文”会删除聊天吗？

不会删除可见聊天记录。这表示把早期信息整理成摘要供模型继续使用，摘要可能不包含所有原文细节。需要精确引用时重新提供关键材料，详见[长对话说明](chat-and-files.md)。

## 导出的图片为什么有多张、代码不完整？

长对话默认分页，以保持阅读清晰；也可以选单张长图。图片中的代码块只展示有限区域，要保存完整代码请选择 HTML 或 Markdown。图片格式转换失败时可能回退其他格式，分享前查看预览与格式名称。

选择范围、水印、思考内容和文件保存说明见[分享与导出](sharing-and-export.md)。

## 后台没有通知，或锁屏后生成中断

确认 **设置 → 通知** 中相关开关与系统通知权限。系统仍可能限制后台运行；回到原对话或绘图查看状态，再决定是否重新提交。详见[后台回复与通知](settings-and-usage.md)。

## 手机与电脑会自动同步聊天记录吗？

当前不会。设备互联导入的是选定服务商的配置与已启用模型，不包含聊天记录，也不持续自动同步。换机前另行保存重要内容，见[电脑导入](desktop-sync.md)和[数据说明](data-privacy.md)。

## Android 禁止安装，或 TestFlight 无法加入

使用[官方下载入口](https://cherryai.com.cn/download?platform=mobile)。Android 按系统提示允许当前下载应用安装 APK；iPhone / iPad 先安装 TestFlight，再打开邀请。名额、测试版本有效期或平台服务异常也可能影响安装。

完整步骤见[下载与安装](installation.md)。

## 工具不执行、文件没有保存，去哪里查？

* 模型只回答文字、等待批准或提示权限不足：见[让 AI 使用工具](using-tools.md)，逐项检查模型、能力开关、连接与权限。
* Android 打开系统日历，或日程写入结果不确定：见[日历与提醒事项](calendar-and-reminders.md)，先核对已有记录，避免重复新增。
* 定位失败、健康记录为空或只有部分数据：见[位置与健康记录](location-and-health.md)。空结果不能直接理解为没有记录。
* 回答只有代码块，没有可以打开的文件，或修改没有覆盖原件：见[生成与修改文件](file-generation.md)。
* 想要 PPT，但只有 HTML，或转换后的文字无法单独编辑：见[HTML 转图片与 PPT](html-export.md)。

## 如何提交仍未解决的问题？

提供版本、设备与系统版本、复现步骤及错误提示，去 [App 仓库的问题反馈](https://github.com/CherryHQ/cherry-studio-app/issues)提交。发布前遮盖密钥、私人对话和文件内容。
