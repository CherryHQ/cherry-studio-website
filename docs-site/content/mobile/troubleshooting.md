# 常见问题

## 为什么安装后不能直接对话？

Cherry Studio 是客户端，不附带模型额度。请先添加模型服务商、填写 API Key，并启用至少一个对话模型。

## 已添加服务商，但模型列表为空

检查 API Key、Base URL、账户权限和当前网络。部分服务商不会返回完整模型列表，需要手动填写模型 ID。

## 为什么图片、工具或文件能力不可用？

这些能力同时取决于应用版本、模型能力、服务商接口和系统权限。先确认模型支持对应能力，再检查智能体工具开关和系统授权。

## Android 提示禁止安装

请从官方下载页重新获取 APK，并按系统提示允许当前浏览器或文件管理器安装未知应用。安装完成后可以撤销该权限。

## TestFlight 链接打不开或无法加入

确认设备已经安装 TestFlight，并使用 Safari 或系统浏览器打开邀请。测试名额已满、版本过期或 Apple 服务异常时，需要稍后重试。

## 移动版会自动同步桌面版数据吗？

不要默认自动同步。服务商与模型配置可以在移动端重新添加，重要对话和文件请根据当前版本提供的导出或分享能力单独保存。

## 如何提交问题？

记录应用版本、设备型号、系统版本、复现步骤和错误提示。提交截图前先遮盖 API Key、个人文件、对话内容等敏感信息，再通过官网的反馈入口联系项目团队。
